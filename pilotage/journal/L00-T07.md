- tests.mjs : rouge si un it/test n'a aucune assertion, si un skip/todo/skipIf/runIf (describe, suite, it, test, context.skip(), skip()) n'a pas de carte LNN-TMM, si .only (toute chaîne) ou si un alias d'import de it/test/describe/suite (vitest, node:test). Chaînes, commentaires et regex masqués.
- termine.mjs : fait exige journal titré (10 lignes au plus), dépendances faites et, si tests_requis oui, un fichier de test suivi dans fichiers_autorises.

- alias par variable ou destructuration (const { skip } = test, const d = describe.skip) ; test?.skip, globalThis.test.skip ; import * as v ;
- assertion factice (expect(true).toBe(true)), dans du code mort ou jamais appelée, expect.assertions(0), obj.expect(1), aide importée.
- Fiche de suivi garde:tests : couvrir ces limites.
