# Journal L01-T02
- outils/gardes/litteraux.mjs : analyser(fichiers, exceptions) pure, puis exécution sur les fichiers suivis par git.
- Périmètre : packages/noyau/src et apps/serveur/src (ts, tsx, mts, cts, mjs), hors tests ; packages/parametres exclu.
- Règles : date AAAA-MM-JJ en chaîne ; nombre autre que 0 et 1 sur une ligne taux/seuil/plafond/delai/duree/franchise/bareme ; nombre suivi de % en chaîne.
- Exceptions (litteraux-exceptions.json, vide) : fichier + motif d'au moins 4 caractères présent dans le fichier + raison non vide, sinon rouge ; valable pour son seul fichier.
- Nombres 500000n, 10_000, .5, 1e4, 0x10 vus ; ${…} analysé comme code ; mots accentués ; virgule non décimale.
- Commentaires /* … */ suivis d'une ligne à l'autre dans le découpeur (une chaîne contenant /* ne masque plus le code).
- 14 tests node --test (10 avant relecture, 4 ajoutés après), chaque mutation signalée est couverte.
- Limites : chaîne multiligne et regex avec apostrophe non suivies ; extension .js non examinée (hors fiche).
- Rien d'omis dans la fiche. Fusion par Will (sensible).
