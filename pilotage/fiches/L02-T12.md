## Contexte
Spec 02, fichier 02, règle 3 : « XML sans entités externes ni expansion, profondeur XML 64. » Test T02-8 : « fichier XML piégé (entité externe, bombe d'entités) : rejeté, 0 accès réseau, 0 effet ». CAMT.053 et OFX 2 n'ont besoin d'aucune DTD : le lecteur REFUSE tout `<!DOCTYPE` et tout `<!ENTITY`, ce qui ferme ces attaques par construction, sans dépendance.

## À faire
1. `packages/noyau/src/banque/import/xml.ts` :
   - `lireXml(texte, limites: { profondeurMax: number; noeudsMax: number })` → `NoeudXml { nom: string; attributs: Record<string, string>; enfants: NoeudXml[]; texte: string }` ;
   - préfixes d'espace de noms retirés du nom (`ns2:Ntry` → `Ntry`), attribut `xmlns` gardé ;
   - entités permises : les 5 prédéfinies (`&lt;` `&gt;` `&amp;` `&quot;` `&apos;`) et les références numériques (`&#233;`, `&#xE9;`) ; toute autre entité = erreur `entite_inconnue` ;
   - `<!DOCTYPE` ou `<!ENTITY` n'importe où = erreur `doctype_refuse` ; instructions `<?xml ...?>` ignorées ; commentaires et `<![CDATA[...]]>` gérés ;
   - balises mal fermées ou croisées = `xml_invalide` ; profondeur ou nombre de nœuds dépassés = `trop_profond`, `trop_de_noeuds` ;
   - `trouver(noeud, chemin: string[])` et `trouverTous(noeud, nom)` (parcours en profondeur, ordre du document) ;
   - classe locale `ErreurXml` avec `code` (aucun extrait du texte dans le message).
2. Tests nommés : `arbre-simple`, `prefixes-retires`, `entites-predefinies-et-numeriques`, `cdata-et-commentaires`, `doctype-refuse`, `entite-externe-refusee` (`<!ENTITY x SYSTEM "file:///...">`), `bombe-d-entites-refusee`, `trop-profond-refuse` (profondeur 65 avec limite 64 donnée en argument), `balises-croisees-refusees`.

## Hors périmètre
Lecture CAMT et OFX (L02-T13, T14). Encodage (L02-T10 : le texte arrive déjà décodé).

## Pièges
Aucune expression régulière à retour arrière exponentiel : lecture caractère par caractère. Cas limites exigés : texte vide, racine seule, attribut sans guillemets (refusé), `&#0;` et `&#xFFFFFFFF;` (refusés), limites `NaN`, `Infinity`, 0, non entières (refus `limites_invalides`). Sensible (fichier reçu de l'extérieur). Règles du noyau.
