## Contexte
Le plafond par tour bloque déjà l'appel (L05-T17), mais sa valeur n'est pas fixée et aucun banc ne mesure les tours.
Choix tranché (le plus prudent) : le banc mesure en jetons ; les plafonds sont des paramètres sans valeur dans le dépôt ; sans paramètre, le rapport dit « non mesuré » et ne conclut rien.

## À faire
1. Tests d'abord, conversation fictive.
2. `conversation.mjs` : rejoue une conversation fictive avec un modèle simulé, relève les jetons de chaque tour, calcule médiane et maximum (entiers) ; compare aux plafonds passés en paramètres ; un tour au plafond doit produire une réponse sans modèle.
3. Tests nommés : `mediane-et-maximum-entiers`, `plafond-absent-non-mesure`, `tour-au-dessus-signale`, `au-plafond-reponse-sans-modele`.

## Hors périmètre
Valeur des plafonds (décision à prendre après mesure).

## Pièges
Aucune valeur monétaire dans le code ni les tests. Données fictives seulement (noms inventés, e-mails en @exemple.fr) ; aucune valeur commerciale dans les textes.
