## À faire
1. Tests d'abord.
2. `exposition-mcp.ts` : constante `OUTILS_EXPOSES` vide et gelée ; type `OutilExpose` (nom, portée lecture ou écriture, référence de décision, date) ; `validerExposition(liste)` : toute entrée sans référence de décision est refusée ; toute portée écriture est refusée (lecture seule jusqu'à nouvelle décision) ; `outilAutorise(nom, societeId, consentements)` → refus si l'outil n'est pas dans la liste validée ou si la société n'a pas consenti.
3. Tests nommés : `liste-vide-par-defaut`, `outil-sans-decision-refuse`, `ecriture-refusee`, `outil-hors-liste-refuse`, `societe-sans-consentement-refusee`.
