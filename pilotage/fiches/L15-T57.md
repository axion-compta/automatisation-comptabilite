## Contexte
Liste des écrans : T05 « Mes préférences », route `/reglages/preferences`. Spec 15 : mode Simple / Comptable (PR-R3 : change les mots, jamais la place ni les données) ; raccourcis d'une lettre désactivables (PR-R4, WCAG 2.1.4 : le rapport de couverture dit que T05 n'a pas ce réglage) ; catégories de notifications ; résumé quotidien par e-mail (point P1 : quotidien seulement, l'option mensuelle est retirée ; point P5 : actif par défaut) ; mesure d'usage désactivable, décrite comme « pseudonymisée » (point P4) ; AUCUN choix de format de nombre (point P1 : le choix « point » est retiré). L'envoi réel des e-mails attend un fournisseur de l'Union européenne (L15-T63, bloquée) : l'écran ne promet pas l'envoi. PR-R9 : l'écran ne dit jamais « supprimé ».

## À faire
1. `route.tsx` (`id: 't05'`, `chemin: '/reglages/preferences'`) et `Ecran.tsx` : `<h1>` ; sections avec titres : Affichage (mode Simple / Comptable en radio), Clavier (raccourcis actifs : case), Notifications (catégories : cases ; résumé quotidien : case et heure), Mesure d'usage (case, avec la phrase « pseudonymisée, jamais votre texte ni vos montants ») ; chaque changement passe par `usePreference` (L15-T56) ; aperçu du vocabulaire du mode choisi (3 termes de `GET /vocabulaire?mode=`, L15-T44).
2. `packages/textes/src/ecrans/t05.ts` : textes au vouvoiement ; le texte du résumé dit « quand un fournisseur d'envoi de l'Union européenne sera en place » (aucune promesse d'envoi).
3. Tests nommés (jsdom, `demarrerNoeud`) : `aucun-choix-de-format-de-nombre`, `aucune-option-mensuelle`, `mode-comptable-change-les-mots`, `raccourcis-desactivables`, `resume-actif-par-defaut`, `heure-invalide-refusee` (`24:00`), `mesure-d-usage-pseudonymisee` (le mot « anonyme » n'apparaît pas), `jamais-le-mot-supprime`, `titre-h1-unique`.

## Hors périmètre
Pas de largeur du chat ni de voix (chat : L15-T67 ; voix : V2, D20), pas de confort de lecture.

## Pièges
Aucun texte en dur. Le texte de la mesure d'usage sera relu par le délégué à la protection des données avant l'ouverture (point P4) : le dire dans le journal.
