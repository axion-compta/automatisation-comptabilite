## Contexte
Spec 15, EX-R1 à EX-R3 : toute liste s'exporte avec les filtres et le tri de l'écran, donc les lignes exportées sont celles affichées ; le fichier n'est jamais envoyé par e-mail. Volume au-delà du direct : tâche (L15-T65, bloquée) : l'écran le dit en un mot. 413 : « affinez vos filtres ». E44 « Mes clients et fournisseurs » (L01-T38) sert de premier écran branché ; les autres listes suivront dans leurs lots avec le même bouton.

## À faire
1. `donnees/exporter.ts` : `exporter(liste, format, filtres)` : `POST /exports` avec `Idempotency-Key`, corps strict du contrat ; décode `octetsBase64` en `Blob` du `typeContenu` rendu ; téléchargement par `URL.createObjectURL` et un lien temporaire avec l'attribut `download` = `nom` rendu par le serveur (jamais construit au front) ; `URL.revokeObjectURL` ensuite ; erreurs par code (413, 501, 404).
2. `BoutonExporter.tsx` : bouton qui ouvre un choix CSV ou XLSX, état « en cours » (bouton désactivé, `aria-busy`), message par code d'erreur (textes en props).
3. E44 : `BoutonExporter` avec `liste = 'listerTiers'` et les filtres COURANTS de l'écran (type, recherche) ; textes dans `e44.ts`.
4. Tests nommés : `envoie-les-filtres-de-l-ecran`, `nom-du-fichier-venu-du-serveur`, `csv-commence-par-le-bom` (Blob lu), `double-clic-une-seule-requete`, `trop-gros-message-affinez`, `au-dela-du-direct-message`, `url-objet-liberee`, `e44-bouton-present`.

## Hors périmètre
Pas de suivi de tâche ni de téléchargement différé (L15-T65), pas d'autres écrans.

## Pièges
Ne pas modifier `api.ts`. Le nom de fichier ne contient jamais un texte saisi. Sensible (exports) : relecture Opus.
