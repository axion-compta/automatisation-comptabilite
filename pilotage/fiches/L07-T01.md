## Contexte
Spec 07, `01-etats-acces.md`, table « Correspondance des états » : `actif` (+ période d'essai) = ESSAI ; `actif` = ACTIF ; `actif` + impayé signalé = DELAI_DE_GRACE ; `pause` = LECTURE_SEULE ; `arrete` contrat en cours = SUSPENDU ; `arrete` + date de fin passée = RESILIE. Les champs `periodeEssaiFin`, `impayeSignale`, `dateFin` sont demandés à la console : sans eux, le module ne connaît que ACTIF, LECTURE_SEULE et SUSPENDU. Bannière (PLA-130) : `{etat, cause, consequence, prochaine_etape_le, lien}`, AUCUN montant ; `lien` = « Abonnement et factures » du portail après branchement, sinon « Contacter Axion ».

## À faire
1. `packages/noyau/src/abonnement/etats.ts` :
   - `verifierEtatVoulu(v)` : `etat` parmi les 3 valeurs, `version` entier >= 1, `arretEnvois` booléen, `droitsUsage` absent ou tableau de chaînes non vides, `periodeEssaiFin` et `dateFin` absents ou dates valides (`verifierDate` de L07-T00), `impayeSignale` absent ou booléen ; sinon `ErreurAbonnement('etat_voulu_invalide')` (`date_invalide` pour une date) ;
   - `etatDuModule(voulu, aujourdhui)` : `actif` → `DELAI_DE_GRACE` si `impayeSignale === true` (priorité sur l'essai), sinon `ESSAI` si `periodeEssaiFin` est défini et `aujourdhui <= periodeEssaiFin`, sinon `ACTIF` ; `pause` → `LECTURE_SEULE` ; `arrete` → `RESILIE` si `dateFin` est défini et `dateFin < aujourdhui` (strictement), sinon `SUSPENDU` ;
   - `contenuBanniere(etat, voulu, branche: boolean)` → `null` pour `ACTIF`, sinon `{ etat, cause, consequence, prochaineEtapeLe, lien }` où `cause` et `consequence` sont des CODES (ex. `cause: 'impaye_signale'`, `consequence: 'agents_arretes'`), jamais du texte affiché ; `prochaineEtapeLe` = `periodeEssaiFin` (ESSAI), `dateFin` (SUSPENDU avec date), sinon `null` ; `lien` = `'portail_abonnement'` si `branche`, sinon `'contacter_axion'`.
2. Tests nommés : `six-etats-table-spec` (un cas par ligne de la table), `sans-champs-demandes-trois-etats-seulement`, `impaye-prioritaire-sur-essai`, `essai-dernier-jour-encore-essai`, `date-fin-du-jour-encore-suspendu`, `etat-voulu-invalide-refuse` (version 0, -1, 1.5, NaN, Infinity, état inconnu, `droitsUsage` avec chaîne vide), `date-impossible-refusee`, `banniere-actif-nulle`, `banniere-sans-montant-et-lien-selon-branchement` (aucune clé ne contient `montant`, `prix` ni `cout`).
