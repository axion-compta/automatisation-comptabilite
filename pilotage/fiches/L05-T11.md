## Contexte
Spec 05, fichier 04 §5 : une demande à plusieurs étapes donne un plan « Appliquer les N ». Chaque étape a sa proposition ; aucune n'est appliquée avant le geste ; chaque étape s'annule seule. Cas T-CHT-8 : 3 étapes, l'étape 2 annulée seule.

## À faire
1. `packages/noyau/src/chat/plan-etapes.ts` :
   - `creerPlan(propositions)` : 1 à `maxEtapes` (argument) propositions distinctes, sinon `parametre_invalide` ;
   - `appliquerPlan(plan, contexteGeste)` : applique les étapes dans l'ordre avec `appliquer` (L05-T09), une clé par étape (`<cle>:<rang>`) ; la première erreur ARRÊTE la suite ; rend `{ appliquees: id[]; arretee?: { rang; code } }` ; rejouer le même geste ne réapplique rien ;
   - `etatDuPlan(plan)` : nombre appliquées, annulées, restantes.
2. Tests nommés : `rien-avant-le-geste`, `trois-etapes-appliquees`, `etape-deux-annulee-seule` (T-CHT-8 : 1 et 3 restent appliquées), `erreur-arrete-la-suite`, `rejeu-sans-double-effet`, `plan-vide-refuse`, `plan-trop-long-refuse` (maxEtapes + 1 ; maxEtapes 0, NaN, 1.5), `proposition-en-double-refusee`.
