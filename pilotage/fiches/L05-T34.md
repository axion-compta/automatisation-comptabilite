## Contexte
Spec 05, fichier 02 §2 et §5 : un alias absent de la liste fermée est refusé AVANT l'appel (A2-22). Chaque agent a un secours de la même zone. Panne du principal (erreur serveur ou délai dépassé) → UN appel au secours avec la même entrée. Pas de secours, ou secours en panne → arrêt franc (`ia_indisponible`), jamais de bascule hors zone. Une écriture n'est jamais rejouée par le secours (CHT-055). Cas T-CHT-16, T-CHT-17. Le MÉCANISME ne dépend pas de D43 ; la liste réelle et l'adaptateur réel, si (L05-T59).

## À faire
1. `apps/serveur/src/ia/appel.ts` :
   - port `ModeleTexte { completer(alias, entree, signal): Promise<{ texte; jetons; coutMicroCentimes; modele; version }> }` (forme de `completer` de la console, texte seul) ; `class ErreurModele` avec `sorte: 'serveur' | 'delai' | 'client'` ;
   - `appelerModele({ port, reglage: { principal, secours? }, listeFermee: readonly string[], entree, delaiMs, ecriture: boolean })` → `{ issue: 'ok' | 'secours'; reponse } | { issue: 'arret'; code: 'ia_indisponible' | 'outil_hors_liste' }` ; alias hors liste (principal ou secours) = refus sans appel ; délai par `AbortController` ; erreur `client` (4xx) = pas de secours ; `ecriture: true` = jamais de secours ;
   - `delaiMs` en argument (réglage L05-T54), jamais en dur.
2. Tests nommés (port simulé, minuteries simulées de vitest) : `principal-ok`, `panne-serveur-un-secours` (T-CHT-16 transposé), `delai-depasse-un-secours`, `secours-en-panne-arret` (T-CHT-17), `pas-de-secours-arret`, `alias-hors-liste-sans-appel` (A2-22 : compteur d'appels = 0), `secours-hors-liste-arret`, `ecriture-jamais-rejouee`, `erreur-client-pas-de-secours`, `delai-invalide` (0, -1, 1.5, NaN, Infinity).
