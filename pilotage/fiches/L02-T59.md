## Contexte
Spec 02, fichier 08 : `GET /banque/comptes/{id}/couverture` « mois couverts, trous, état par mois (pour la frise d'E12) » ; alerte « relevé non importé » (V3-UX-101) : « Il manque le relevé de septembre ». Routes : L02-T52 (faux serveur L02-T55).

## À faire
1. `Couverture.tsx` : pour le compte choisi, une frise de 12 mois (un élément par mois, état `couvert`, `manquant`, `partiel` donné par un MOT et une forme, jamais la couleur seule) ; liste équivalente en texte pour les lecteurs d'écran ; bandeau au-dessus du tableau si un trou est `ouvert` (`alerteReleveManquant` de L02-T48, mois en toutes lettres), avec l'écart si connu (`Montant`).
2. `Ecran.tsx` : place la frise sous les cartes de comptes.
3. Textes dans `e12.ts` ; mise en page dans `e12.css` (la frise passe sur deux lignes à 360 px).
4. Tests nommés : `septembre-manquant-en-mot`, `bandeau-trou-ouvert`, `pas-de-bandeau-sans-trou`, `ecart-affiche`, `liste-texte-equivalente`, `compte-sans-releve-tous-manquants`.

## Hors périmètre
« Aucune opération ce mois-ci » et demander le relevé (écritures : bloquées). Import d'un relevé (bloqué : L02-T68).

## Pièges
Chaîne du couloir D : APRÈS L02-T58, AVANT L02-T60. Cas limites exigés : écart absent (phrase sans montant), deux trous (un bandeau qui les cite tous les deux), exercice décalé (mois de début ≠ janvier).
