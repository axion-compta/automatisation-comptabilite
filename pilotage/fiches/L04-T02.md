## Contexte
Spec 04, fichier 01 §Contrôles d'entrée, point 1 : « Type réel par signature (premiers octets), jamais par l'extension ni le Content-Type. Types acceptés : PDF, JPEG, PNG, HEIC, WebP, TIFF, XML, ZIP, EML, MSG, DOCX, ODT, CSV, XLSX. Exécutable renommé en .pdf = refus type_refuse. » DOCX, XLSX et ODT sont des ZIP : leur distinction et les macros sont dans L04-T03.

## À faire
1. `packages/noyau/src/pieces/entree/signature.ts` :
   - `type TypeReel = 'pdf' | 'jpeg' | 'png' | 'heic' | 'webp' | 'tiff' | 'xml' | 'zip' | 'eml' | 'msg' | 'csv'` ;
   - `typeReel(octets: Uint8Array)` → `{ type: TypeReel }` ou `{ refus: 'type_refuse' | 'macro_refusee'; raison: string }` ;
   - signatures : PDF `%PDF-` ; JPEG `FF D8 FF` ; PNG `89 50 4E 47 0D 0A 1A 0A` ; HEIC `ftyp` à l'octet 4 puis marque `heic`, `heix`, `mif1` ou `msf1` ; WebP `RIFF` puis `WEBP` à l'octet 8 ; TIFF `49 49 2A 00` ou `4D 4D 00 2A` ; ZIP `50 4B 03 04` ; XML `<?xml` après un BOM UTF-8 éventuel et des blancs ; OLE `D0 CF 11 E0 A1 B1 1A E1` : `macro_refusee` si la chaîne UTF-16LE `_VBA_PROJECT` figure dans les octets, sinon `msg` si la chaîne UTF-16LE `__substg1.0_` y figure, sinon `type_refuse` ;
   - EML : texte ASCII dont la première ligne non vide commence par `Received:`, `Return-Path:`, `From:`, `MIME-Version:`, `Message-ID:` ou `Date:` (sans casse) ;
   - CSV : UTF-8 valide (`TextDecoder` avec `fatal: true`), aucun octet nul, au moins 2 lignes ayant le même nombre (au moins 1) de séparateurs `;`, `,` ou tabulation ;
   - tout le reste (dont `MZ`, `7F 45 4C 46`, Mach-O `CF FA ED FE`, fichier vide) : `type_refuse`.
2. Tests nommés (octets fabriqués dans le test) : `pdf-reconnu`, `executable-nomme-pdf-refuse` (en-tête `MZ`), `png-jpeg-webp-tiff-heic`, `xml-avec-bom`, `ole-msg-accepte`, `ole-macro-refusee`, `ole-inconnu-refuse`, `eml-reconnu`, `csv-reconnu-et-binaire-refuse`, `vide-et-tronque-refuses` (0 octet ; 3 premiers octets d'un PNG ; `RIFF` sans `WEBP`).

## Hors périmètre
Pas de lecture du contenu des ZIP (L04-T03), pas d'antivirus (L04-T49), pas de limite de taille (L04-T06).

## Pièges
Ne jamais lire au-delà de `octets.length` (fichier tronqué). La fonction ne reçoit pas le nom du fichier : ne rien déduire d'une extension. Règles du noyau comme L04-T00. Aucun texte affiché : `raison` est un code court.
