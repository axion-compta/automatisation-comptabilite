## Contexte
Spec 05, fichier 03 §3 : le front ignore un type d'événement inconnu ; fuzzing de 1 000 événements, 0 plantage (T-CHT-11). Stop : les propositions déjà reçues sont gardées.

## À faire
1. `apps/web/src/chat/etat.ts` (pur, sans React) :
   - `EtatConversation = { messages; tourEnCours?: { id; etapes; segments; cartes; propositions; question?; erreur?; issue? }; dernierId }` ;
   - `reduire(etat, evenementBrut: unknown)` : passe par `lireEvenement` (L05-T03) ; `null` = état inchangé ; `id` <= `dernierId` = ignoré (doublon) ; `texte` ajouté aux segments ; `tour.fin` ferme le tour ; un `tour.debut` pendant un tour ouvert ferme l'ancien en `erreur` ;
   - `arreter(etat)` : ferme le tour, garde propositions et cartes ;
   - `envoyer(etat, message)` : ajoute le message de la personne.
2. Tests nommés : `tour-complet`, `evenement-inconnu-ignore`, `doublon-ignore`, `ordre-inverse-ignore`, `arret-garde-les-propositions`, `deux-debuts-de-suite`, `mille-evenements-au-hasard` (graine fixe : objets, tableaux, nombres, chaînes, `null`, événements valides mélangés ; 0 exception, état toujours valide), `etat-initial-vide`, `etat-non-modifie-en-place` (immutabilité vérifiée par `Object.freeze`).
