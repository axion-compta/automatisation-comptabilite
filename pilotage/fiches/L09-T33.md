## Contexte
Spec 09, §04 : `GET /siren/{siren}` (Sirene, cache daté) et `GET /tva-intracom/{numero}/verification` (clé puis VIES). §01 règles 2 à 4 : SIREN refusé si la clé est fausse ; VIES indisponible = `non_verifie`, jamais `verifie` ; Sirene en panne = saisie à la main. Cas P01, P02, P03. Les vrais services sont prévus par L10-T53 et L14-T37 : ici, réponses fictives de `genererProfils().identites` (L09-T29).

## À faire
1. `packages/contrat/src/domaines/identite.ts` : schémas `ReponseSiren { body: { etat: 'trouve' | 'introuvable' | 'saisie_manuelle'; denomination?; forme?; dateReponse? } }`, `ReponseVerificationTva { body: { cle: 'juste' | 'fausse'; vies: 'verifie' | 'non_verifie' | 'invalide' } }` ; routes `lireSiren` (`GET /siren/{siren}`, paramètre `^[0-9]{9}$`) et `verifierTva` (`GET /tva-intracom/{numero}/verification`, paramètre `^FR[0-9]{11}$`) ; erreur `SIREN_INVALIDE` 422 (clé de Luhn fausse).
2. `identite-service.ts` : service pur sur `genererProfils().identites` ; contrôle de clé par `sirenValide` (`generateur.ts`, chemin relatif).
3. `apps/serveur/src/domaines/identite.ts` : implémentation ; la clé de TVA par `verifierTvaFrancaise` de `packages/noyau/src/profil/identifiants.ts` (L09-T01, chemin relatif comme L01-T23) ; `vies: 'indisponible'` du jeu = `non_verifie` ; branchement dans `app.ts`.
4. `routes.ts` : ajouter `identite: { lireSiren, verifierTva }` ; régénérer `openapi.json`.
5. Tests nommés : `siren-trouve`, `siren-cle-fausse-422-p01` (123456789), `siren-forme-400` (8 chiffres, lettres), `siren-panne-saisie-manuelle-p03`, `tva-cle-juste-p02` (FR11123456782), `tva-cle-fausse-p02` (FR12123456782 : `cle: fausse`, VIES non appelé), `vies-indisponible-non-verifie`, `serveur-repond-identite`.

## Hors périmètre
Aucun appel réseau réel ; aucun cache ; pas de faux serveur (L09-T36).

## Pièges
Comme L09-T30. SIREN fictifs 123456782 et 987654324 seulement. Si le `tsconfig` d'`apps/serveur` refuse l'import relatif du noyau, s'arrêter et le signaler dans le journal (ne pas recopier la formule de la clé).
