## Contexte
Spec 09, §02 règle 2 : biens = livraison ; services = encaissement par défaut ; option pour les débits sur demande, date d'effet par paramètre (`tva.option_debits.effet`, « à vérifier »). `exigibilite_confirmee_par` obligatoire dès que la société vend des services. Une société qui vend des services sans exigibilité confirmée : ventes en BROUILLON, TVA collectée « non calculée ». Cas P14 : option exercée le 20/10 : effet proposé au 01/11 ; une facture de service du 25/10 reste sur les encaissements.

## À faire
1. `packages/noyau/src/profil/fiscal/exigibilite.ts` :
   - `RegleEffetOption` : union FERMÉE de codes de règle lus dans la valeur du paramètre : `premier_jour_mois_suivant` | `jour_meme` ; un code inconnu = `ErreurProfil('regle_effet_inconnue')` (jamais un repli) ;
   - `dateEffetOption(dateOption, { regle, statutParametre })` → `{ effetDebut: string; aVerifier: boolean }` (`aVerifier` vrai si le statut n'est pas `valide`) ;
   - `exigibilitePour({ nature: 'bien' | 'service'; dateOperation; optionDebitsEffet: string | null; exigibiliteConfirmeePar: string | null; vendDesServices: boolean })` → `'livraison' | 'encaissement' | 'debits' | 'non_calculee'` ; service sans `exigibiliteConfirmeePar` = `non_calculee` ;
   - `ventesEnBrouillon(...)` → vrai si la société vend des services et que l'exigibilité n'est pas confirmée.
2. Tests nommés (dates inventées, sauf le cas de la spec rejoué ici avec la règle `premier_jour_mois_suivant` de test) : `option-effet-mois-suivant-p14` (option le 20/10 : effet le 01/11 ; facture du 25/10 : encaissement), `option-fin-d-annee` (option le 15/12 : effet le 01/01 suivant), `option-dernier-jour-du-mois` (31/01 et 28/02 et 29/02 d'une année bissextile), `parametre-non-valide-a-verifier`, `regle-inconnue-refusee` (chaîne vide, `PREMIER_JOUR`), `bien-a-la-livraison`, `service-sans-confirmation-non-calculee`, `date-invalide-refusee` (`2026-10-32`, ordre des dates inversé entre option et opération).

## Hors périmètre
Pas d'écriture de vente ni de compte de TVA (lot 10) ; pas de régime historisé (L03-T20).
