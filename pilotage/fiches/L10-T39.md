## Contexte
Spec 10, fichier 05 : `POST /ventes/{id}/corrections` (client, nature, date d'opération, rattachement d'avoir : `Idempotency-Key`, `If-Match`) ; `POST /ventes/{id}/valider` (geste humain, délai d'annulation du moteur d'écritures). « L'IA propose, une personne valide. » Une facture sans client ne se valide pas (spec 10, fichier 01). Identité réelle de la personne : J3a (L10-T52, bloquée) ; ici, un en-tête de test `X-Personne` fictif.

## À faire
1. `ventes-actions.ts` : routes `corrigerVente` (`POST /ventes/{id}/corrections`, corps `{ clientCode?; dateOperation?; natures?: { ligne: number; nature }[]; factureOrigineId? }`, au moins un champ) et `validerVente` (`POST /ventes/{id}/valider`) ; en-tête `Idempotency-Key` obligatoire ; `If-Match` obligatoire (version de la vente) ; erreurs `VENTE_INCONNUE` 404, `VERSION_PERIMEE` 412, `VALIDATION_REFUSEE` 409 (avec `motif`).
2. `ventes-actions-service.ts` : état EN MÉMOIRE par instance, initialisé depuis `genererVentes()` ; version incrémentée à chaque correction ; même `Idempotency-Key` + même corps = même réponse, sans 2e effet ; même clé + autre corps = 409 ; validation refusée si état `a_relire` ou `doublon` ou client absent (`peutValiderFacture`, L10-T11) ; validation acceptée = écriture `valide` + `annulableJusqua` calculé avec `demanderValidation` (L01-T07), délai lu dans la configuration du serveur (jamais écrit dans le contrat).
3. `registres/lot-10.ts` (contrat) : ajouter `ventesActions` ; régénérer `openapi/lot-10/openapi.json` ; serveur en mémoire branché dans `registres/lot-10.ts` (serveur).
4. Tests nommés : `correction-change-la-version`, `if-match-perime-412`, `idempotence-meme-reponse`, `meme-cle-autre-corps-409`, `cle-absente-400`, `validation-sans-client-409`, `validation-a-relire-409`, `validation-acceptee-annulable`, `corps-vide-400`.

## Hors périmètre
Annulation de la validation, permissions réelles (L10-T52), faux serveur (L10-T41), écran (prochaine tranche).

Aucune route de création, de numérotation ni d'envoi de facture (L10-T42). Query : bornes inversées, NaN, non entiers, chaînes trop longues → 400. Données fictives seulement (garde:fictif).
