## Contexte
Spec 03, §07, contrôles avant tout téléchargement : « Structure (en-tête, 18 colonnes, dates valides, montants au format) ». Le même module lit l'export ET un FEC importé (FEC-002, FEC-017). Un échec liste les écarts chiffrés. Les autres contrôles (équilibre, numérotation, identité) s'appuient sur la sortie de cette fiche.

## À faire
1. `packages/noyau/src/fec/controles-structure.ts` (utilise `lireLigne`, `lireMontantFec`, `lireDateFec` de `./format.js` et `ChampFec`, `ColonneFec` de `./lignes.js`) :
   - `EcartFec { regleId: string; ligne: number; champ?: ChampFec; valeur?: string; ecartCentimes?: Centimes }` (`ligne` = numéro de ligne du fichier, en-tête = 1) ; `LigneFecLue = { numero: number; valeurs: Record<ChampFec, string> }` ;
   - `REGLES_STRUCTURE` (format décrit dans L03-T06, `source: 'a_sourcer'`) : `FEC-S01` en-tête différent des colonnes attendues ; `FEC-S02` nombre de colonnes ; `FEC-S03` date invalide (`ecritureDate`, `pieceDate`, `validDate`, et `dateLet` si non vide) ; `FEC-S04` montant au mauvais format (`debit`, `credit`) ; `FEC-S05` champ obligatoire vide ; `FEC-S06` ligne vide ; `FEC-S07` marque d'ordre présente alors qu'elle n'est pas acceptée ; `FEC-S08` débit et crédit tous deux non nuls ; `FEC-S09` encodage UTF-8 invalide ;
   - `lireFichierFec(contenu: Uint8Array, { colonnes, options: OptionsFec, finDeLigne, marqueOrdreAcceptee: boolean, obligatoires: readonly ChampFec[] })` → `{ lignes: LigneFecLue[]; ecarts: EcartFec[] }` : décodage par `new TextDecoder('utf-8', { fatal: true })` ; une ligne en écart de structure n'est PAS rendue dans `lignes` ; on continue après une erreur (on liste TOUS les écarts) ; une fin de ligne finale unique est acceptée.
2. Tests nommés : `fichier-propre-zero-ecart`, `entete-different-s01`, `colonne-manquante-s02`, `date-30-fevrier-s03`, `montant-avec-point-s04` (`1234.56`), `obligatoire-vide-s05`, `ligne-vide-s06`, `marque-ordre-refusee-s07`, `debit-et-credit-s08`. Chaque titre contient l'identifiant de la règle (sert à L03-T06).

## Hors périmètre
Pas d'équilibre (L03-T11), pas de numérotation (L03-T12), pas d'identité avec la balance (L03-T13).

## Pièges
Ne pas ajouter de code à `CodeErreurFec` : attraper `ErreurFec` et le traduire en écart. Règles du noyau comme L03-T01. Cas limites exigés : fichier de 0 octet (écart `FEC-S01`), en-tête seul (zéro ligne, zéro écart), fichier avec LF au lieu de CR LF attendus (écart, pas d'exception), 1 000 lignes à graine fixe (temps raisonnable, pas de boucle quadratique).
