## Contexte
Spec 10, fichier 05 : `GET /ventes/{id}` rend la pièce, les lignes, les contrôles, l'écriture, les paiements et les avoirs liés. Les cartes d'anomalie sont des textes de L10-T44. L'écriture est « Préparée par IA, à valider ».

## À faire
1. `route.tsx` : `id: 'e24-vente'`, `chemin: '/factures/vente'`, `groupe: 'autre'` ; identifiant lu dans le paramètre de recherche `id` (même forme que L04-T41).
2. `Ecran.tsx` : `<h1>` = numéro de la facture ; sections : facture (client, dates, totaux en `Montant`), lignes (libellé, nature, taux affiché en pourcentage par une fonction locale `tauxEnTexte(pdb)` exportée par `Ecran.tsx` (calcul entier : 1 900 → « 19 % », 550 → « 5,5 % », 1 → « 0,01 % », 0 → « 0 % » ; non entier ou négatif → « taux illisible »)), cartes (titre et détail de `cartesVentes`, gabarits remplis), écriture (compte, débit, crédit) avec « Préparé par IA, à valider », paiements, avoirs liés (liens) ; identifiant absent ou inconnu : état d'erreur et lien de retour vers `/factures/ventes`.
3. `e24-vente.ts` : seulement les clés manquantes.
4. Tests nommés : `affiche-la-facture-et-les-lignes`, `cartes-en-mots`, `ecriture-preparee-par-ia`, `paiements-et-reste-du`, `avoir-lie-cliquable`, `vente-inconnue-erreur-et-retour`, `aucun-bouton-qui-ecrit` (pas de « Valider » actif dans cette fiche), `taux-en-texte` (les cinq valeurs ci-dessus et NaN).

## Hors périmètre
