## Contexte
Spec 13, fichier 01, R04 : « toute écriture naît `brouillon` ou `propose`, quel que soit le canal ; un INSERT avec le statut `valide` est refusé » (PRI-5-01 : 422). R05 : toute modification d'une écriture VALIDÉE répond `409 ecriture_validee` avec `{ proposition: 'contre_passation', route: '.../ecritures/{id}/corriger' }`, identique pour l'écran, le chat et l'API. Cas limite : écriture validée d'un exercice clôturé = `423` prioritaire ; la contre-passation est alors proposée sur la période ouverte.

## À faire
1. `packages/noyau/src/principes/brouillon.ts` (importe `StatutEcriture` de `../ecritures/modele.js`) :
   - type `Canal` : union des 7 canaux de `action_historique.canal` (clic, chat, voix, import, assistant, expert, api) ;
   - `statutCreationAutorise(statut)` → `{ ok: true }` ou `{ ok: false; statutHttp: 422; code: 'statut_initial_interdit' }` ;
   - `reponseModification(ecriture: { id; statut }, exercice: { statut: 'ouvert' | 'cloture' }, canal)` → `{ ok: true }` (brouillon, propose) ; `{ ok: false; statutHttp: 409; code: 'ecriture_validee'; proposition: 'contre_passation'; route }` où route = `/ecritures/<id encodé par encodeURIComponent>/corriger` ; `{ ok: false; statutHttp: 423; code: 'periode_cloturee'; proposition: 'contre_passation_periode_ouverte' }`. Le canal ne change JAMAIS la réponse ;
   - classe locale `ErreurBrouillon` : id vide, statut ou canal inconnus.
2. Tests nommés : `creation-validee-refusee-422`, `creation-brouillon-et-propose-acceptees`, `validee-409-meme-reponse-sur-tous-les-canaux` (boucle sur les 7 canaux, `toStrictEqual` entre réponses), `cloture-423-prioritaire`, `brouillon-modifiable`, `identifiant-encode-dans-la-route` (`a/b` donne `a%2Fb`), `entrees-invalides` (id vide, statut `archive`, canal `fax`).

## Hors périmètre
Pas de route ni de modification du contrat `ecritures` (il n'a pas encore de statut ; il sera refait par le lot du moteur d'écritures). La contre-passation : L01-T09.

## Pièges
Codes seulement, aucune phrase (la phrase de R05 est dans L13-T28). Règles du noyau comme L01-T06. Sensible (écritures).
