## Contexte
Spec 03, §07 : « équilibre de chaque écriture et du fichier ; dates dans l'exercice ». Test K2 : une écriture déséquilibrée de 0,01 → téléchargement refusé, écart « 0,01 € sur l'écriture VE 1 ».

## À faire
1. `packages/noyau/src/fec/controles-equilibre.ts` (entrée = `LigneFecLue[]` de L03-T10 ; montants relus par `lireMontantFec`) :
   - `REGLES_EQUILIBRE` : `FEC-E01` écriture déséquilibrée, `FEC-E02` fichier déséquilibré, `FEC-E03` date d'écriture hors exercice ;
   - `controlerEquilibre(lignes)` → `EcartFec[]` : une écriture = couple (`journalCode`, `ecritureNum`) ; un écart `FEC-E01` par écriture déséquilibrée, avec `ecartCentimes` = débit − crédit (signé) et `ligne` = première ligne de l'écriture ; puis `FEC-E02` si les totaux du fichier diffèrent ;
   - `controlerDatesExercice(lignes, { debut, fin })` (dates `AAAA-MM-JJ`, bornes incluses) → un écart `FEC-E03` par ligne hors bornes ; bornes inversées = exception locale `ErreurControleFec('bornes_invalides')`.
2. Tests nommés : `fichier-equilibre-zero-ecart-fec-e01`, `un-centime-sur-ve-1-fec-e01` (écart = 1, journal `VE`, numéro de l'écriture), `fichier-desequilibre-fec-e02`, `deux-ecritures-meme-numero-journaux-differents` (pas confondues), `date-hors-exercice-fec-e03`, `bornes-incluses`, `bornes-inversees-refusees`.

## Hors périmètre
Pas de numérotation (L03-T12), pas de comparaison à la balance (L03-T13).

## Pièges
Règles du noyau comme L03-T01 : sommes par `ajouter` et `soustraire` (`../argent/index.js`). Ne pas dépendre de l'ordre des lignes : une écriture dont les lignes sont dispersées dans le fichier est regroupée (test). Cas limites exigés : liste vide (zéro écart), écriture d'une seule ligne (déséquilibrée), montants maximaux sûrs (`Number.MAX_SAFE_INTEGER` en centimes refusé par `ajouter` : écart ou exception documentée, testée).
