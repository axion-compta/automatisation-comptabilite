## Contexte
Fiche MVP. E01 (L15-T50) affiche le mois, sans geste de validation en lot. Le composant `ToastAnnulation` (L05-T45) donne le compte à rebours. Les routes viennent de L25-T16, par la couche d'appels existante (aucun import du faux serveur dans l'écran). E01 absorbe l'ancien écran « À valider » : le compteur n'existe donc qu'à un seul endroit.

## À faire
1. Tests d'abord, sur le faux serveur.
2. `ToutValider.tsx` : bouton « Tout valider (N sûrs) » où N vient de l'aperçu ; masqué si N = 0 ; un clic ouvre la liste des cas sûrs (et le nombre de cas exclus) avant le geste ; le geste envoie la liste vue ; puis `ToastAnnulation` de 10 s avec « Annuler ».
3. `Ecran.tsx` : insérer le composant, sans autre changement.
4. `e01.ts` : libellés du bouton, de la liste et du message `liste_changee` (« La liste a changé, vérifiez-la à nouveau »).
