## Contexte
Spec 01, §02 : `GET …/exercices/{e}/plan?classe=&q=` : liste avec solde de la balance de l'exercice. Le contrat fait foi : serveur et faux serveur le suivent (ADR 0002 et 0003). Le préfixe de société viendra avec l'isolation (P4) : routes sans préfixe ici.

## À faire
1. `packages/contrat/src/domaines/plan.ts` : schémas zod `Exercice { id, libelle, debut, fin, statut }`, `CompteDuPlan { numero, libelle, classe, soldeCentimes }` ; routes oRPC `listerExercices` (`GET /exercices`, enveloppe `{ body, decalage, total }`) et `listerPlan` (`GET /exercices/{exercice}/plan`, query `classe` 1 à 7, `q` 50 caractères au plus, `limite` 1 à 100, `decalage`) ; erreur `EXERCICE_INCONNU` 404.
2. `packages/contrat/src/domaines/plan-service.ts` : service en mémoire pur bâti sur `genererCompta()` (L01-T22, profil `pleine`), import par chemin relatif : exercices triés par début décroissant ; plan filtré par classe et par `q` (sans casse ni accents, sur numéro et libellé) ; solde = débits − crédits des écritures validées de l'exercice.
3. `routes.ts` : `contrat = { ecritures: {...}, plan: { listerExercices, listerPlan } }`. `openapi.ts` : `definitions()` parcourt tous les domaines du contrat, pas seulement `ecritures`. Régénérer `openapi.json` (`pnpm contrat:openapi`).
4. `apps/serveur/src/domaines/plan.ts` : implémentation des deux routes par le service ; branchée dans `creerRouteur` de `app.ts`.
5. Tests nommés : `exercices-enveloppe-et-tri`, `plan-filtre-classe`, `plan-recherche-sans-accent`, `exercice-inconnu-404`, `openapi-contient-les-routes-du-plan`, `serveur-repond-au-plan` (Fastify `inject`).

## Hors périmètre
Pas de faux serveur MSW (L01-T24), pas de route d'écriture, pas d'écran.

## Pièges
`routesEcritureSansEnTete()` doit rester `[]` (routes GET seulement). `contrat.test.ts` vérifie les clés de `contrat.ecritures` : ne pas les changer. Rester sous 400 lignes, `openapi.json` compris.
