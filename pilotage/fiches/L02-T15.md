## Contexte
Spec 02, fichier 02 : `profil_import` (colonnes, séparateur, décimale, milliers, format de date, mode de signe) ; « le profil deviné est montré, confirmé d'un clic, puis mémorisé : deuxième import = 0 question » ; règle 6 : « Signe incohérent avec le chaînage des soldes = signalé, jamais corrigé en silence » ; règle 10 : nombre importé = lu − rejetées ; ligne de total « ignorée si égale à la somme, sinon signalée ». Test T02-2 : CSV `;`, montants `1.234,56-`, 140 lignes lues, 140 importées, ligne 7 = −123 456.

## À faire
1. `packages/noyau/src/banque/import/profil.ts` :
   - type `ProfilImport { colonnes: { date: number; dateValeur?: number; libelle: number[]; reference?: number; soldeCourant?: number; devise?: number }; signe: ModeSigne (L02-T08); format: { decimal; milliers }; formatDate; deviseParDefaut; ligneEntete: number }` et `verifierProfil(p, nbColonnes)` (index hors tableau, négatif, non entier, en double : `profil_invalide`) ;
   - `appliquerProfil(lignes: { rang; cellules }[], profil, total?: { cellules })` → `ReleveLu` (L02-T07) : chaque ligne lue par `lireDate` et `montantSigne` ; une ligne illisible devient un rejet `{ rang, motif }` (codes des erreurs L02-T08, L02-T09), jamais une ligne à 0 ;
   - solde courant présent : `soldeOuverture` = solde de la 1re ligne − son montant, `soldeCloture` = solde de la dernière ; chaque ligne vérifie `solde(n) = solde(n−1) + montant(n)` ; sinon signal `chainage_incoherent` avec le rang (aucune correction) ;
   - ligne de total : comparée à la somme des lignes lues ; égale → `total: 'egal'`, sinon `total: 'different'` avec l'écart ;
   - compteurs `{ lues; importees; rejetees }` avec `importees = lues − rejetees` vérifié.
2. Tests nommés : `t02-2-ligne-sept` (140 lignes générées dans le test), `rejet-numerote-jamais-zero`, `compteurs-coherents`, `solde-courant-donne-ouverture-et-cloture`, `chainage-incoherent-signale`, `total-egal`, `total-different-ecart`, `profil-invalide-refuse`, `libelle-sur-deux-colonnes-joint`.

## Hors périmètre
Choix du format de date d'un nouveau fichier (L02-T09 ; le profil reçoit le format retenu). Profil deviné par l'IA (bloqué : L02-T66). Stockage du profil (bloqué : L02-T62).

## Pièges
Cas limites exigés : 0 ligne (relevé vide, compteurs à 0), toutes les lignes rejetées, colonne de solde vide sur une ligne (chaînage `IMPOSSIBLE` à partir de là, pas une erreur), montants `NaN` ou `Infinity` en texte (rejet), lignes données dans le désordre des rangs (remises dans l'ordre des rangs). Sensible (argent). Règles du noyau.
