## Contexte
Spec 02, fichier 05 : barème unique (réglable par société, versionné) : montant 45 (exact) ou 43 (±1 centime) ; contrepartie 25 (IBAN ou alias actif) ou 15 (similarité) ; référence 20 (complète) ou 8 (fin de numéro, ≥ 4 chiffres) ; date 7 (dans la tolérance du moyen) ou 3 (jusqu'à 2 × tolérance) ; sens et moyen 3 ; règle apprise 15 ; pénalités −10 (pièce déjà partiellement liée) et −10 (écart > 60 j). « Score = min(100, Σ − pénalités) ». Ambiguïté : 2 candidats à moins de 5 points → score affiché plafonné à 79. États : `RAPPROCHEE` ≥ 95, `PROPOSEE` 80 à 94, `DOUTEUSE` 60 à 79. Tests T05-1 (100), T05-2 (80), T05-3 (95), T05-4 (115 brut → 100).

## À faire
1. `packages/noyau/src/banque/rapprochement/score.ts` :
   - type `Bareme { version; montantExact; montantCentime; contrepartieConnue; contrepartieSimilaire; referenceComplete; referenceFin; dateDansTolerance; dateDouble; sensEtMoyen; regleApprise; penalitePartielle; penaliteEcartPeriode; joursEcartPeriode; plafond; ecartAmbiguite; plafondAmbigu; seuils: { rapprochee; proposee; douteuse } }` (TOUT en argument ; les valeurs de la spec n'apparaissent que dans les tests) ;
   - `scorer(constats: { montant: 'exact' | 'centime' | 'aucun'; contrepartie: 'connue' | 'similaire' | 'aucune'; reference: 'complete' | 'fin' | 'aucune'; date: 'tolerance' | 'double' | 'hors'; sensCoherent: boolean; regleApprise: boolean; dejaPartielle: boolean; joursEcart: number }, bareme)` → `{ brut; score; facteurs: Facteur[]; penalites: Facteur[] }` (un facteur à 0 point est quand même listé) ;
   - `etatSelonScore(score, bareme)` → `'RAPPROCHEE' | 'PROPOSEE' | 'DOUTEUSE' | null` (sous le seuil douteux : `null`, la ligne garde son état) ;
   - `appliquerAmbiguite(scores: number[], bareme)` → scores plafonnés si les deux meilleurs sont à moins de `ecartAmbiguite` points ;
   - score jamais négatif (min 0).
