## Contexte
Spec 15, AL-R4. Reporter de 1, 3 ou 7 jours (autre valeur : 422 `report_invalide`) ; le report ne dépasse jamais l'échéance (422 `report_apres_echeance`) et est refusé pour une alerte urgente ou bloquante (403 `report_interdit`). Ignorer : motif de 5 caractères au moins (422 `motif_requis`), refusé pour une alerte bloquante (403 `bloquant_non_ignorable`). Version périmée : 409. Annulation possible pendant un délai court (10 s dans la spec), sinon 409 `delai_annulation_depasse`. Permission requise `compta-valider` (point T4, recommandation retenue) : 403 `role_insuffisant` ; `compta-lire` seul : 403 `role_lecture`.

## À faire
1. `alertes/actions.ts` (fonctions pures ; classe `ErreurActionAlerte { code; statut }`) :
   - `reporter(alerte, { jours; versionAttendue; permissions; jour; joursPermis: number[] })` → `{ alerte (reportee, reporteeJusquAu, version + 1); journal }` ; `jours` hors de `joursPermis` (non entier, `NaN` compris) = `report_invalide` ;
   - `ignorer(alerte, { motif; versionAttendue; permissions; motifMin: number })` : motif compté après `trim()`, en points de code (pas en unités UTF-16) ;
   - `annuler(alerte, derniereAction: { le; avant }, { maintenant; delaiMs })` : rend l'état `avant` si `maintenant - le <= delaiMs`, sinon `delai_annulation_depasse` ; horodatages en millisecondes entières ;
   - contrôle des permissions EN PREMIER, puis version, puis règles métier (ordre testé) ; alerte non active (`ignoree`, `resolue*`) = 409 `alerte_inactive`.
2. Tests nommés : `reporter-trois-jours`, `report-valeur-non-permise` (`2`, `0`, `-1`, `1.5`, `NaN`), `report-apres-echeance-refuse`, `report-urgent-ou-bloquant-interdit`, `ignorer-motif-trop-court` (`'    a   '`, emoji compté pour 1), `bloquant-non-ignorable`, `version-perimee-409`, `role-lecture-403`, `ordre-des-controles` (permission manquante ET version périmée : 403 d'abord), `annulation-dans-le-delai`, `annulation-hors-delai-409`.
