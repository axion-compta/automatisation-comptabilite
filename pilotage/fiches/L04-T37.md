   - photo : `estFloue` (L04-T07, seuil du contexte) → `a_verifier`, code `photo_floue`, `texteTransmissible` nul ;

   - `sensible` = vrai → `texteTransmissible` nul (aucun appel possible plus loin) ; sinon texte visible et masqué ;
   - texte vide après extraction (image sans OCR) → `a_verifier`, motif `ocr_trop_faible`.
