## Contexte
Spec 03, §04, règle 3 ter (« à vérifier », D31) : à partir d'une date fixée par paramètre, déclaration trimestrielle si (chiffre d'affaires HT + acquisitions taxables) de l'année N-1 ≤ seuil A ET cumul de l'année N ≤ seuil B ; sinon mensuelle ; dépassement en cours d'année : mensuelle d'office ; la première déclaration mensuelle porte sur le mois du dépassement et reprend les opérations depuis le premier jour du trimestre civil en cours. Avant cette date, autre règle : trimestrielle si la TVA annuelle est inférieure à un seuil C. Les seuils et la date d'effet sont des paramètres datés : ils arrivent en ARGUMENT.

## À faire
1. `packages/noyau/src/tva/periodicite.ts` (classe locale `ErreurPeriodicite`) :
   - `periodiciteSelonChiffreAffaires({ chiffreAffairesN1, acquisitionsN1, cumulsN: { mois: 'AAAA-MM'; cumul: Centimes }[] }, { seuilN1, seuilN })` → `{ periodicite: 'trimestrielle' | 'mensuelle'; moisBascule?: string; repriseDepuis?: string }` : comparaisons « inférieur ou égal » ; N-1 au-dessus = mensuelle dès janvier ; premier mois où le cumul dépasse `seuilN` = `moisBascule`, `repriseDepuis` = premier mois de son trimestre civil ;
   - `periodiciteSelonTvaAnnuelle(tvaAnnuelle, seuil)` → trimestrielle si strictement inférieure, sinon mensuelle.
2. Tests nommés (seuils INVENTÉS, ex. 700 000,00 et 770 000,00, puis 3 000,00 ; JAMAIS les seuils réels) : `egal-aux-seuils-trimestrielle`, `un-centime-de-plus-n1-mensuelle`, `acquisitions-comptees`, `depassement-en-mars-reprend-janvier` (moisBascule `AAAA-03`, repriseDepuis `AAAA-01`), `depassement-en-mai-reprend-avril`, `aucun-trimestre-propose-en-plus`, `tva-annuelle-strictement-inferieure`, `cumuls-non-tries-refuses`.

## Hors périmètre
Pas de choix de la règle selon la date (l'appelant lit le paramètre en vigueur, L01-T14). Pas de franchise en base (seuils distincts : spec 03 §04 règle 3 quater ; la confusion des deux est un piège testé ailleurs).

## Pièges
Règles du noyau comme L03-T01. Montants en `Centimes`, comparaisons par entiers. Cas limites exigés : `cumulsN` vide (trimestrielle si N-1 sous le seuil), cumul négatif (refus `montant_invalide`), mois mal formé (`mois_invalide`), mois en double (refus), seuil NaN ou non entier (refus). La source affichée vient du paramètre, jamais de ce module.
