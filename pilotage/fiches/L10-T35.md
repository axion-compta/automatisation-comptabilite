## Contexte
Spec 10, fichier 05 : `GET /ventes/indicateurs?mois=…` et `GET /ventes/series` (suites de numéros, trous, doublons). Chaque nombre mène à ses pièces. Régime non confirmé : TVA collectée « non calculée », aucun montant (D4).

## À faire
1. `ventes-indicateurs.ts` : schémas `Indicateur { montantCentimes; pieces: string[] }`, `Indicateurs { chiffreAffaires; aEncaisser; enRetard: Indicateur & { clients }; tvaCollectee: Indicateur | { nonCalculee: 'regime_a_confirmer' }; tvaEnAttente; provisoire }` et `Serie { serie; dernierOrdreVu; trous; tropDeTrous; doublons; datesQuiReculent }` ; routes `lireIndicateurs` (`GET /ventes/indicateurs`, query `mois` obligatoire, `avecPropositions` booléen) et `listerSeries` (`GET /ventes/series`).
2. `ventes-indicateurs-service.ts` : service pur sur `genererVentes()` ; appelle `indicateursDuMois` (L10-T23) et `analyserSeries` (L10-T16) par chemin relatif ; la société du jeu `vide` rend des zéros, jamais une erreur.
3. `registres/lot-10.ts` (contrat) : ajouter `ventesIndicateurs: { lireIndicateurs, listerSeries }` ; régénérer `openapi/lot-10/openapi.json` ; serveur en mémoire branché dans `registres/lot-10.ts` (serveur).
4. Tests nommés : `indicateurs-d-un-mois`, `chaque-nombre-a-ses-pieces`, `regime-non-confirme-aucun-montant`, `societe-vide-zeros`, `mois-absent-ou-invalide-400` (absent, `2026-00`, `2026-1`), `series-trou-et-doublon`, `serveur-repond-aux-indicateurs`.

## Hors périmètre
Faux serveur (L10-T36), affichage (L10-T47).

## Pièges
Imports du noyau par chemin relatif (comme L01-T23). Registre du lot 10 seulement : n'ajouter que le domaine de la fiche ; régénérer `openapi/lot-10/openapi.json` par `pnpm contrat:openapi`. `routesEcritureSansEnTete()` reste `[]`. Aucune route de création, de numérotation ni d'envoi de facture (L10-T42). Query : bornes inversées, NaN, non entiers, chaînes trop longues → 400. Données fictives seulement (garde:fictif). Les chemins `/ventes/indicateurs` et `/ventes/series` ne doivent pas être capturés par `/ventes/{id}` : tester l'ordre des routes.
