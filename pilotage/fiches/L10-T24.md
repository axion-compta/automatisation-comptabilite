## Contexte
Spec 10, fichier 04 (« Vers la déclaration de TVA ») : la déclaration lit les lignes de TVA COLLECTÉE validées dont la date d'exigibilité tombe dans la période, par taux (base HT et TVA) ; les lignes du compte d'attente n'y entrent jamais. Avoirs accordés : lignes dédiées, jamais de base négative sur une ligne de ventes. Acomptes : période de leur encaissement. Chaque case renvoie aux pièces (TVA-015). Contrôle annuel (TVA-038) : CA déclaré comparé au total des comptes de produits de l'exercice ; écart bloquant au-dessus d'un seuil paramétré.

## À faire
1. `packages/noyau/src/ventes/remise-declaration.ts` :
   - `ventesDeLaPeriode({ lignesTva: (LigneTvaVente & { statutEcriture })[], debut, fin, compteCollectee })` → `{ ventes: ParTaux[]; avoirs: ParTaux[]; aVerifier: ParTaux[]; ignorees: number }`, `ParTaux = { tauxPdb; base; tva; pieces: string[] }` ; seules les lignes validées, du compte collecté, `dateExigibilite` dans [début, fin] ; `sens: 'avoir'` → `avoirs` (montants positifs) ; `vente` et `acompte` → `ventes` ; les lignes négatives (imputation L10-T09, délettrage L10-T06) se retranchent de leur taux ; un taux dont la base ou la TVA nette devient négative sort de `ventes` et va dans `aVerifier` (jamais une base négative remise, jamais ramenée à 0 en silence) ; tri par taux ;

   - `debut > fin` → `ErreurVente('periode_inversee')`.
