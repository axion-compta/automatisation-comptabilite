## Contexte
Spec 13, fichier 02, R06 : toute route d'indicateur renvoie `{ etat: vide | donnee_manquante | ok, valeur, raison }` ; jamais 0 ni 0 % quand la donnée manque. R07 : ratio à dénominateur nul ou absent = `null` (« pas de point de comparaison »). R08 : société en formation (sans SIREN) : tous les écrans s'ouvrent ; déclaration et FEC officiel = « disponible après immatriculation ». Tests PRI-10-01 à PRI-10-03.

## À faire
1. `packages/noyau/src/principes/indicateurs.ts` :
   - type `Indicateur` : soit `{ etat: ok; valeur: number }`, soit `{ etat: vide ou donnee_manquante; valeur: null; raison: aucune_donnee, donnee_absente ou pas_de_point_de_comparaison }` ;
   - `indicateurDepuis({ nbElements, valeur })` : `nbElements` égal à 0 donne `vide` / `aucune_donnee` ; valeur null, undefined, NaN ou Infinity donne `donnee_manquante` / `donnee_absente` ; sinon `ok` ;
   - `croissancePointsDeBase(actuel, precedent)` : précédent nul, absent ou négatif donne `donnee_manquante` / `pas_de_point_de_comparaison` ; sinon la proportion de (actuel moins précédent) sur précédent, via `proportionPointsDeBase` (mode `inferieur`) du module argent (L13-T01) ; une baisse donne une valeur négative ;
   - `disponibilite(fonction: declaration, fec_officiel ou autre ; societe: { statut: en_formation ou immatriculee; siren? })` donne `disponible` ou `apres_immatriculation` ; une société immatriculée sans SIREN lève `ErreurIndicateur` (code `siren_absent`).
2. Tests nommés : `aucune-vente-vide-pas-zero`, `donnee-absente`, `croissance-sans-exercice-precedent` (précédent 0), `croissance-calculee` (100 000 puis 110 000 : 1 000), `baisse-negative` (100 000 puis 90 000 : −1 000), `nan-infinity-donnee-manquante`, `formation-declaration-apres-immatriculation`, `formation-autres-ecrans-disponibles`.

## Hors périmètre
Les tests d'écran vide écran par écran (R09) : dans les fiches de chaque écran. Le schéma `Indicateur` du contrat : L13-T32.
