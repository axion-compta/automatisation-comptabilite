## Contexte
Spec 14, `03`. JUR-019 : chaîne A = `document de travail, ne remplace pas le registre légal` ; chaîne B = `à recopier dans votre registre légal` (exactes). JUR-014 : phrase « pas de dépôt au greffe pour ce document », une seule fois. Cartes : « Pas de rapport de gestion demandé » (avec source et date de relevé), « Saisissez le délai prévu par vos statuts », « Convocation tardive : à vérifier avec votre expert-comptable », « complétez le bilan et l'effectif », « À vérifier » (rémunération sans décision) et l'écart chiffré, « Déposez la convention », retenue « à vérifier ». Mention « Préparé par IA, à valider ». Les modules du noyau rendent des CODES (L14-T10 à L14-T16) ; les phrases vivent ici.

## À faire
1. `packages/textes/src/documents/juridique.ts` : `export const juridique = { … } as const` avec :
   - `chaineA`, `chaineB`, `phraseGreffe`, `mentionPreparation` ;
   - `cartes` : une entrée par code rendu par le noyau (`saisir_delai_statuts`, `convocation_tardive`, `assemblee_trop_proche`, `completer_bilan_effectif`, `decision_absente`, `ecart_montant`, `deposer_convention`, `retenue_a_verifier`, `dispense`) ; les textes avec une valeur sont des fonctions (`ecart_montant: (montant: string) => …`, `dispense: (source: string, dateReleve: string) => …`) ; aucun nombre en dur ;
   - `rubriquesSci` : libellés des 6 rubriques (activité, loyers, charges, emprunts, résultat, comptes courants).
2. Tests nommés : `chaine-a-exacte`, `chaine-b-exacte`, `phrase-du-greffe-exacte`, `une-carte-par-code-du-noyau` (liste des codes écrite dans le test), `vouvoiement` (aucun « tu », « ton », « ta », « tes » en mot entier), `aucun-mot-interdit` (liste construite par morceaux comme `outils/gardes/textes.mjs`), `registre-legal-seulement-dans-a-et-b`.
