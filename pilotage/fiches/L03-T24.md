## Contexte
Spec 03, §02 : code de traitement par ligne (DEDUCTIBLE, AUTOLIQUIDATION, AUTOLIQUIDATION_FR, A_VERIFIER, NON_DEDUCTIBLE_NOM, NON_DEDUCTIBLE_NATURE, NON_DEDUCTIBLE_ETRANGERE, SANS_TVA, MARGE, SOUS_RESERVE). La facture fait foi (TVA-039). Autoliquidation : collectée = déductible, effet net nul ; en franchise, autoliquidée due mais non déductible (TVA-021). Sous réserve jamais comptée en déductible définitive (TVA-011). Spec 12, CC-T04 : solide + sous réserve + perdue = TVA lue. D4 : TVA en doute = blocage.

## À faire
1. `packages/noyau/src/tva/traitement.ts` (utilise `partDeductible` de `./deductible.js` et `pourcentage` de `../argent/index.js`) :
   - `effetTraitement({ code, sens: 'achat' | 'vente', tvaLue, base, tauxAutoliquidationPointsDeBase?, partPointsDeBase?, franchise: boolean })` → type exporté `EffetTraitement { collectee; deductible; sousReserve; perdue; aVerifier: boolean }` (montants en `Centimes`) ;
   - DEDUCTIBLE : `partDeductible` (perdue = part non déductible) ; AUTOLIQUIDATION et AUTOLIQUIDATION_FR : TVA = `pourcentage(base, taux, 'demi-superieur')`, collectée = TVA, déductible = TVA sauf en franchise (déductible 0, perdue = TVA) ; SOUS_RESERVE : sousReserve = tvaLue ; NON_DEDUCTIBLE_* : perdue = tvaLue ; SANS_TVA : tout à 0, `tvaLue > 0` = refus `tva_sur_sans_tva` ; A_VERIFIER et MARGE : `aVerifier: true`, montants à 0 ; vente DEDUCTIBLE = collectée tvaLue ;
   - classe locale `ErreurTraitementTva` (`code_inconnu`, `taux_manquant`, `tva_sur_sans_tva`, `montant_invalide`).
2. Tests nommés (taux et parts INVENTÉS) : `deductible-part-totale`, `deductible-part-partielle-perdue`, `autoliquidation-net-nul`, `autoliquidation-en-franchise-due-non-deduite`, `sous-reserve-jamais-deductible`, `non-deductible-perdue`, `a-verifier-bloque`, `sans-tva-avec-tva-refuse`, `invariant-achats-mille-cas`.

## Hors périmètre

## Pièges
Ne pas modifier `deductible.ts` ni `ErreurTva` (L01). Règles du noyau comme L03-T01. Cas limites exigés : `tvaLue` négative (refus), base 0, code inconnu passé en `as never` (refus), taux manquant pour une autoliquidation (refus).
