## Contexte
Spec 12, §02 : CC-K01 « pour chaque écriture : Σ débits = Σ crédits, au centime (écart 0) » (B) ; CC-K02 « balance de l'exercice : Σ débits = Σ crédits de toutes les écritures validées » (B) ; CC-K03 « pour chaque compte : solde d'ouverture + mouvements = solde de clôture » (B, bloque export et clôture). Tests CT-01 à CT-03 (spec 12, §06).

## À faire
1. `packages/noyau/src/controles/regles/equilibre.ts` : trois `RegleControle` (L01-T19), version 1, gravité B :
   - `CC-K01` sur une `Ecriture` : utilise `verifierEquilibre` (L01-T06) ; bloque `validation_mois`, `preparation_tva`, `export_officiel`, `cloture` ;
   - `CC-K02` sur une liste d'écritures : utilise `balance` (L01-T11) ; mêmes blocages ;
   - `CC-K03` sur `{ compte, soldeOuverture, soldeCloture }` + mouvements : bloque `export_officiel`, `cloture` ;
   - `ecartCentimes` renseigné quand l'écart n'est pas nul.
2. `docs/controles.csv` : trois lignes, `test_id` CT-01, CT-02, CT-03 ; déclencheurs `continu|avant_tva|avant_export|avant_cloture` pour K01 et K02, `avant_export|avant_cloture` pour K03.
3. Tests dont le titre contient `CT-01`, `CT-02`, `CT-03` (cas OK et cas en écart d'un centime pour chacun), plus `exigence-et-version-renseignees`.
