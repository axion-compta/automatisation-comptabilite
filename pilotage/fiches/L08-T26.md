## Contexte
Spec 08, fichier 07 §2 : « à effacer » = masquée partout et exclue de l'IA ; limitation = la donnée n'est plus lue que pour la conservation légale ; « Oublier » (préférences du chat) = la préférence n'est plus jamais lue ni envoyée à l'IA ; l'écran ne promet pas d'effacement immédiat. Cas T-EXP-8 (préférence de chat de la même personne marquée « oubliée », plus lue). Une seule fonction doit décider de la visibilité, pour que chaque lecture du produit l'appelle au lieu de réécrire la règle.

## À faire
1. `packages/noyau/src/rgpd/marques.ts` :
   - `type Usage = 'affichage' | 'ia' | 'export_client' | 'conservation_legale' | 'export_fin_contrat'` ;
   - `lisible(marques: readonly Marque[], usage: Usage)` → booléen : sans marque, tout ; `a_effacer` : seulement `conservation_legale` ; `limitee` : seulement `conservation_legale` et `export_fin_contrat` ; `oubliee` : rien (pas même l'export : la préférence est retirée) ; plusieurs marques = la plus restrictive gagne ; marque inconnue = `ErreurRgpd('marque_inconnue')` ;
   - `filtrer<T extends { id: string; marques?: readonly Marque[] }>(liste, usage)` → copie sans les objets non lisibles ;
   - `poserMarque(objet, marque, { le; par })` → `{ objet avec marques triées sans doublon; evenement }` (`personne.marque_a_effacer`, `personne.limitation` ou `personne.preference_oubliee`) ; `oubliee` n'est permise que sur un objet `source: 'preference'` (sinon `valeur_interdite`) ;
   - aucune fonction pour RETIRER une marque `a_effacer` ou `oubliee` (seule la console efface ; une limitation se lève par une décision écrite : `leverLimitation(objet, { motif })`, motif obligatoire).
2. Tests nommés : `sans-marque-tout-lisible`, `a-effacer-masque-et-exclu-de-l-ia`, `limitee-seulement-conservation-et-fin-de-contrat`, `oubliee-jamais-lue-t-exp-8`, `la-plus-restrictive-gagne`, `oubliee-hors-preference-refusee`, `lever-limitation-exige-un-motif`, `filtrer-ne-modifie-pas-l-entree`.

## Hors périmètre
Exclusion réelle dans la passerelle d'IA (L08-T52, bloquée, D43). Stockage des marques (L08-T45, bloquée). Effacement réel (L08-T49, bloquée).
