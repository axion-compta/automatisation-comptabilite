## Contexte
Spec 08, fichier 03 §3.4 : contrôles après restauration, tous chiffrés, aucun jugement : nombre de lignes par table = celui noté au dump ; pour chaque journal et chaque exercice, total débit = total crédit ; balance par compte identique à celle du dump (empreinte de la balance) ; chaîne du journal d'actions vérifiée de bout en bout (lot 06) ; FEC régénéré d'un exercice clos : empreinte identique à celle du FEC remis ; pièces : échantillon (L08-T15). Cas R1 (2 exercices × 6 journaux = 12 contrôles d'équilibre verts), R6, R7, R10 (aucune ligne d'un autre client). PRI-007 : un contrôle qui n'a pas pu tourner n'est JAMAIS compté réussi. Les calculs eux-mêmes (balance, FEC, chaîne) sont faits ailleurs ; ici on compare des résultats fournis.

## À faire
1. `packages/noyau/src/exploitation/restauration-controles.ts` :
   - `type ResultatControle = { id: string; resultat: 'OK' | 'ECHEC' | 'IMPOSSIBLE'; attendu?: string; obtenu?: string }` (valeurs en chaînes, jamais un montant en clair : les totaux sont rendus sous la forme `debit=…;credit=…` en centimes entiers seulement si `ECHEC`) ;
   - `controlerLignes(auDump: Record<string, number>, restaure: Record<string, number> | null)` : un contrôle par table du dump (`lignes:<table>`) ; table absente de la restauration = `ECHEC` ; table EN TROP dans la restauration = `ECHEC` sous l'id `lignes:en_trop:<table>` ; `restaure` nul = un seul `IMPOSSIBLE` ;
   - `controlerEquilibre(totaux: { journal; exercice; debit: number; credit: number }[] | null)` : un contrôle `equilibre:<exercice>:<journal>` par couple, montants en centimes entiers (`Number.isSafeInteger`), sinon `IMPOSSIBLE` pour ce couple ; couple en double = `ErreurExploitation('doublon')` ;
   - `controlerEmpreinte(id, attendue: string | null, obtenue: string | null)` (balance, FEC) : une des deux nulle = `IMPOSSIBLE` ; empreintes validées (64 hexa) ;
   - `controlerChaine(verification: { ok: boolean; ruptures: number } | null)` ;
   - `controlerEtancheite(lignesAutreClient: number | null)` (R10 : 0 attendu) ;
   - `bilan(controles)` → `{ reussi: boolean; ok; echecs; impossibles }` : `reussi` seulement si AUCUN échec, AUCUN impossible, et au moins un contrôle (liste vide = `ErreurExploitation('controle_absent')`).

Tests nommés : `r1-douze-equilibres-verts`, `table-manquante-ou-en-trop-echec`, `desequilibre-un-centime-echec`, `montant-non-entier-impossible` (1.5, NaN, Infinity, `'10'`), `empreinte-balance-differente-echec`, `fec-absent-impossible-jamais-ok`, `chaine-rompue-echec-r7`, `etancheite-r10` (0 : OK ; 1 : ECHEC ; nul : IMPOSSIBLE), `bilan-un-impossible-pas-reussi`.
