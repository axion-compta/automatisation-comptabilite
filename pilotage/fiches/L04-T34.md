## Contexte
Spec 04, fichier 03 §Tables : « Correction : PATCH …/pieces/{id}/champs/{nom} (permission compta-saisir), nom normalisé et proposition recalculés. » `champ_lu` garde `corrige_par`, `corrige_le`, `pourquoi`. Fichier 06 §4 : si l'écriture était déjà validée, le moteur exige une contre-passation (hors de ce lot). Les permissions réelles attendent L04-T51 (bloquée) : ici, l'auteur est un identifiant fictif de la session simulée.

## À faire
1. `packages/contrat/src/domaines/correction.ts` : route `corrigerChamp` (`PATCH /pieces/{id}/champs/{nom}`, en-tête `EnTeteEcriture`, corps `{ valeur: string (1 à 200 car.), pourquoi: string (1 à 500 car.) }`) → `PieceDetail` mise à jour ; 404 `PIECE_INCONNUE` ; 404 `CHAMP_INCONNU` (nom hors `CHAMPS_SIMPLES` et hors `ht@…`/`tva@…`) ; 400 `VALEUR_ILLISIBLE` pour un montant ou une date illisible ; 409 `PIECE_SENSIBLE` pour une pièce sensible.
2. `correction-service.ts` : montants lus par `lireMontant` (L04-T11, convention de la pièce, FR par défaut), dates par `lireDate` ; le champ corrigé passe au mot `sur`, source inchangée, `corrigePar`, `corrigeLe`, `pourquoi` gardés ; ancienne valeur conservée dans un historique en mémoire (ajout seul) ; `nomNormalise` et `cheminVirtuel` recalculés par L04-T26 (longueur max passée à la création du service).
3. `pieces-service.ts` : seulement exposer la mise à jour d'une pièce (aucune autre modification).
4. `routes.ts` : ajouter `correction: { corrigerChamp }` ; régénérer `openapi.json`. `apps/serveur/src/domaines/correction.ts` branché dans `app.ts`.
5. Tests nommés : `correction-ttc-recalcule-le-nom`, `correction-date-deplace-le-chemin`, `historique-garde-l-ancienne-valeur`, `champ-inconnu-404`, `montant-illisible-400` (`abc`, `NaN`, `Infinity`, chaîne vide), `piece-sensible-409`, `en-tete-absent-400`.

## Hors périmètre
Recalcul de la proposition d'écriture (L04-T39), permission `compta-saisir` (L04-T51), journal chaîné (L04-T51).

## Pièges
Fichiers communs (`routes.ts`, `openapi.json`, `app.ts`) : branche à jour avant fusion. Sensible (montants).
