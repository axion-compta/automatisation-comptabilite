## Contexte
Spec 07, `01-etats-acces.md` : en LECTURE_SEULE et SUSPENDU les pièces sont reçues et mises « en attente » ; en RESILIE elles sont refusées avec message ; à la reprise, la file est traitée dans l'ordre d'arrivée, sans doublon (clé = empreinte de la pièce + société), puis un résumé est montré. `02-quotas-ia.md` : plafond technique d'IA atteint = pièces en attente ; quota atteint en mode `attente` = pièces « en attente de volume ». Cas T-ABO-1 (20 pièces en pause : 20 en attente, 0 rejetée) et T-ABO-2 (reprise : 20 traitées dans l'ordre, 0 doublon, 1 résumé).

## À faire
1. `packages/noyau/src/abonnement/pieces.ts` :
   - `orienterPiece(etat: EtatAcces, options: { plafondTechniqueAtteint: boolean; enAttenteVolume: boolean })` → `{ orientation: 'traiter' | 'en_attente' | 'refusee'; cause: 'contrat_termine' | 'etat_acces' | 'plafond_technique' | 'volume' | null }` ; priorité : RESILIE → `refusee` / `contrat_termine` ; LECTURE_SEULE ou SUSPENDU → `en_attente` / `etat_acces` ; plafond → `en_attente` / `plafond_technique` ; volume → `en_attente` / `volume` ; sinon `traiter` / `null` ; état hors liste → erreur `etat_voulu_invalide` ;
   - `type PieceEnAttente = { id: string; societe: string; empreinte: string; recueLe: string }` ;
   - `reprendre(file: readonly PieceEnAttente[], dejaTraitees: ReadonlySet<string>)` → `{ aTraiter: PieceEnAttente[]; doublons: string[]; resume: { piecesTraitees: number } }` : tri par `recueLe` croissant puis `id` ; clé `societe + ':' + empreinte` ; clé déjà dans `dejaTraitees` ou déjà vue plus tôt dans la file → id dans `doublons` ; `verifierEmpreinte` et `verifierHorodatage` (L07-T00) sur chaque pièce ; `id` ou `societe` vides → `parametre_invalide` ; `resume.piecesTraitees = aTraiter.length` ; entrées jamais modifiées ;
   - `cleDePiece(societe, empreinte)` exportée (réutilisée par L07-T05).
2. Tests nommés : `pause-vingt-pieces-en-attente` (T-ABO-1), `reprise-ordre-d-arrivee-sans-doublon` (T-ABO-2, file donnée en ordre inversé), `resilie-refusee-meme-sous-plafond`, `priorite-etat-avant-plafond-avant-volume`, `meme-empreinte-deux-societes-pas-doublon`, `doublon-dans-la-file-et-deja-traite`, `file-vide-resume-zero`, `horodatage-ou-empreinte-invalide-refuse`.
