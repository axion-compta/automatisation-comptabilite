## Contexte
Spec 04, fichier 04 §1 et §4 : pièce d'identité (zone MRZ de 30, 36 ou 44 caractères avec chiffres de contrôle ; mots-clés « carte nationale d'identité », « passport », « titre de séjour ») = `sensible`, 0 appel d'IA ; santé, bulletin de paie, arrêt de travail (mots-clés, liste versionnée) = `sensible`, 0 appel d'IA ; jeton de paiement, mot de passe, code PIN = masqués. « Les motifs et mots-clés sont dans un fichier versionné du module ; tout ajout passe par une PR. » §4 : une pièce `sensible` n'est JAMAIS envoyée à un modèle. Cas T-LEC-19.

## À faire
1. `packages/noyau/src/pieces/sensibles/motifs.ts` : `MOTIFS_SENSIBLES = { version: 1, pieceIdentite: string[], santePaie: string[], secrets: string[] }` en minuscules sans accents, FR et EN (ex. `carte nationale d'identite`, `passport`, `titre de sejour`, `bulletin de paie`, `payslip`, `arret de travail`, `mot de passe`, `password`, `code pin`).
2. `packages/noyau/src/pieces/sensibles/identite.ts` :
   - `chiffreControleMrz(chaine)` : poids 7, 3, 1 répétés ; `0-9` = valeur, `A-Z` = 10 à 35, `<` = 0 ;
   - `contientMrz(texte)` : vrai si une ligne (blancs retirés) de 30, 36 ou 44 caractères `[A-Z0-9<]` porte un numéro de document dont le chiffre de contrôle est juste (TD3 : ligne 2, positions 0 à 8, contrôle en 9 ; TD2 : idem ; TD1 : ligne 1, positions 5 à 13, contrôle en 14) ;
   - `motsTrouves(texte, liste)` : comparaison sans casse ni accents (NFD puis retrait des diacritiques), mot entier ;
   - `deciderSensibilite({ texte, detectionsChiffrees })` → `{ sensible: boolean; motifs: MotifSensible[]; masquages: MotifMasquage[]; appelIaPermis: boolean; versionMotifs: number }` : `piece_identite` (MRZ ou mot-clé), `sante_paie` (mot-clé), `nir` (détection de L04-T08 passée en argument) rendent `sensible` ; `appelIaPermis = !sensible` ; `secret` ajouté aux masquages si un mot de `secrets` est trouvé.
3. Tests nommés : `mrz-td3-fictive-detectee` (MRZ construite dans le test avec un chiffre de contrôle calculé), `mrz-cle-fausse-ignoree`, `mrz-td1-detectee`, `mot-cle-identite-sans-accent`, `bulletin-de-paie-sensible`, `nir-rend-sensible`, `facture-ordinaire-non-sensible`, `mot-de-passe-masquage-sans-sensible`, `texte-vide` (non sensible, appel permis).
