## Contexte
Spec 09, §01 règle 7 : chaque pièce reçoit un statut de période : `avant_depot`, `avant_immatriculation` (société en formation), `exercice_N`. Pièce avant immatriculation : reprise par la société SEULEMENT si elle figure dans l'état des actes annexé aux statuts ou dans une décision de reprise ; sinon ni charge ni TVA déductible, carte « à vérifier ». Frais de constitution : choix proposé, jamais tranché seul. `en_formation` vrai tant que la date d'immatriculation est nulle. Cas P22.

## À faire
1. `packages/noyau/src/profil/trois-dates.ts` :
   - `DatesSociete { depotCapital: string | null; immatriculation: string | null; debutActivite: string | null; exerciceDebut: string; exerciceFin: string }` ;
   - `verifierDates(d)` : `exerciceFin < exerciceDebut` = `ordre_inverse` ; `immatriculation < depotCapital` = `immatriculation_avant_depot` (refus) ; dates mal formées = `date_invalide` ;
   - `enFormation(d)` → `immatriculation === null` ;
   - `periodeDePiece(d, datePiece)` → `'avant_depot' | 'avant_immatriculation' | 'exercice' | 'apres_exercice' | 'avant_exercice'` (bornes : le jour d'immatriculation appartient à la société immatriculée ; le jour de début d'exercice appartient à l'exercice) ;
   - `traitementPieceAvantImmatriculation({ dansEtatDesActes: boolean | null; decisionDeReprise: boolean | null })` → `{ reprise: 'oui' | 'non' | 'a_verifier'; chargePermise: boolean; tvaDeductiblePermise: boolean; carte?: 'reprise_a_verifier' }` : `null` = `a_verifier`, jamais `oui` ;
   - `choixFraisDeConstitution()` → `{ options: ['charge', 'immobilisation']; tranche: false }`.
