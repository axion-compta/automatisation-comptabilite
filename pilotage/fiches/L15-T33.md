## Contexte
Spec 15, AL-R3 et AL-R5 : `GET /compteurs` rend, par entrée du menu, `ouvertes`, `urgentes`, `pointExclamation`, plus les « alertes du jour » (au plus 3 cartes urgentes et `urgentesTotal`) ; la cloche liste les alertes ouvertes, plus récentes d'abord. Mêmes valeurs dans le menu, la cloche, E01 et le chat (TB-R1) : un seul service. Ici : lecture seulement ; reporter et ignorer viennent en L15-T41.

## À faire
1. `domaines/alertes.ts` : schémas stricts `AlerteSchema { id; regle; gravite; etat; entreeMenu; echeanceLe?; ouverteLe; version; titreCode; lien }` (aucun montant, aucun nom de tiers), `ReponseAlertes` (enveloppe `{ body, decalage, total }`), `ReponseCompteurs { body: { parEntree; alertesDuJour: { cartes; urgentesTotal } } }` ; routes `listerAlertes` (`GET /exercices/{exercice}/alertes`, query stricte : `etat?` parmi les 5, `entree?`, `limite` 1 à 100, `decalage`) et `lireCompteurs` (`GET /exercices/{exercice}/compteurs`) ; `EXERCICE_INCONNU` 404.
2. `domaines/alertes-service.ts` : état en mémoire initialisé depuis `genererInterface()` (L15-T30) ; tri : ouverte d'abord, puis gravité décroissante, puis `ouverteLe` décroissant, puis id ; compteurs et alertes du jour par `compteursParEntree` et `alertesDuJour` (L15-T13) avec 3 cartes ; `entreeMenu` porté par chaque alerte du jeu fictif (L15-T30) ; le lien au catalogue `CATALOGUE_MVP` (L15-T18) viendra avec la persistance (L15-T59). Le service garde son état (il sera modifié par L15-T41).
3. Domaine déjà branché par L15-T69 (objet vide) : remplir l'objet du domaine dans son fichier du contrat et la fonction de routes de son fichier serveur (implémentation par le service), SANS toucher `routes.ts` ni `app.ts` ; régénérer `openapi.json` (`pnpm contrat:openapi`).
4. `apps/serveur/src/domaines/alertes.ts` : implémentation par le service (fonction déjà branchée par L15-T69).
5. Tests nommés : `liste-triee`, `filtre-etat`, `filtre-etat-invalide-400`, `compteurs-par-entree`, `alertes-du-jour-trois-et-total`, `point-exclamation-urgent-ou-bloquant`, `aucun-montant-ni-tiers-dans-le-schema` (parcours du schéma JSON), `serveur-repond-aux-compteurs`.
