## Contexte
Le contrat en lecture (L02-T52, L02-T53) et l'écran E12 ont besoin de vues cohérentes avec le jeu de L02-T49 : couverture des mois (frise d'E12), trou de septembre (T08-1 : écart 1 345,67), demandes groupées (T07-1, T07-2), un doublon proposé (T10-5), flux de trésorerie au 04/11/2026 (T11-1 : départ 18 400,00 ; clients 6 000,00 ; fournisseurs 4 200,00 ; loyer 1 500,00 le 05/11 ; TVA estimée 2 300,00 le 23/11), dettes fournisseurs (T13-1 : 1 200,00 ; 830,40 avec IBAN changé ; 2 000,00).

## À faire
1. `packages/donnees-fictives/src/banque-vues.ts` (import relatif de `./banque.js`) :
   - `genererVuesBanque(jeu = genererBanque())` → `{ couverture: { compteId; mois: { mois; etat: 'couvert' | 'manquant' | 'partiel' }[] }[]; trous: { id; compteId; debut; fin; preuve; ecart?; etat }[]; demandes: { id; cle; ligneIds; impact; nombre; type; codeQuestion; reponsesPretes }[]; doublons: { id; ligneA; ligneB; motif; etat: 'propose' }[]; flux: { id; date; montant; origine; certitude; libelleCode }[]; soldesDepart: { compteId; solde; date }[]; dettes: { pieceId; fournisseurId; fournisseurNom; echeance; reste; ibanMasque; ibanChange: boolean }[] }` ;
   - les demandes reprennent EXACTEMENT les 12 lignes sans pièce du jeu (mêmes identifiants, impacts = somme des montants absolus) ;
   - valeurs écrites à la main pour coller aux tests de la spec ; aucun appel au noyau.
2. Tests nommés : `septembre-manquant-dans-la-couverture`, `trou-de-septembre-ecart`, `demandes-sur-les-lignes-du-jeu`, `impact-egal-a-la-somme`, `un-doublon-propose`, `flux-t11-1` (somme attendue 1 640 000 à J+30, calculée dans le test), `dettes-t13-1`, `graine-fixe-memes-vues`.

## Hors périmètre
Calculs du noyau (couverture L02-T04, demandes L02-T43, prévision L02-T45) : les vues sont des données d'exemple, pas des résultats calculés.

## Pièges
Les identifiants de lignes cités doivent exister dans le jeu (test). Aucun IBAN complet : seulement `ibanMasque` (`FR76 •••• 0042` forme fictive). Pas d'export par `index.ts`. Cas limites exigés : jeu vide fourni (vues vides, pas d'exception).
