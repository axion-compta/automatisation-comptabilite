## Contexte
Spec 02, fichier 05 : `GET /banque/lignes?etat=&compte_id=&periode=`, `GET /banque/lignes/{id}/explication` ; fichier 09 : `GET /banque/comptes` (soldes, devise, dernière mise à jour, état de couverture). 2. `banque-service.ts` : service pur sur `genererBanque()` (L02-T49), import relatif ; tri des lignes par date puis rang ; filtre `du`/`au` inclusifs.
3. `routes.ts` : ajouter le domaine `banque` à `contrat` sans toucher aux autres clés ; régénérer `openapi.json`.
4. `apps/serveur/src/domaines/banque.ts` branché dans `app.ts`.
5. Tests nommés : `comptes-avec-iban-masque`, `aucun-iban-complet-dans-les-reponses`, `lignes-filtre-etat`, `lignes-filtre-dates-inclusives`, `lignes-pagination`, `explication-t05-1`, `ligne-inconnue-404`, `serveur-repond-a-la-banque` (Fastify `inject`).
