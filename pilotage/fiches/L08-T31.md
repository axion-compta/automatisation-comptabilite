## Contexte
Spec 08, fichier 06 §3 : tout ajout de sous-traitant est annoncé aux sociétés AVANT activation, avec un délai d'opposition (art. 28.2, À VÉRIFIER ; délai PROPOSÉ 30 jours, réglage `sous_traitant.opposition_jours` de L08-T02) ; aucun fournisseur actif sans contrat archivé ; un fournisseur d'IA doit offrir l'option sans conservation ni partage, sinon la passerelle refuse le modèle (PLA-145). D1 : jamais hors de l'Union. La garde L08-T03 contrôle la LISTE en CI ; cette fiche est la règle d'exécution (décider si une activation est permise à une date).

## À faire
1. `packages/noyau/src/rgpd/sous-traitants.ts` :
   - `activationPossible({ ref; type: 'hebergeur' | 'ia' | 'email' | 'facture' | 'autre'; contratArchiveLe: string | null; annonceLe: string | null; traitementDansUe: boolean; conservationChezFournisseur: boolean; oppositions: { societeRef; le }[] }, { oppositionJours }, aujourdhui)` → `{ permise: boolean; raisons: ('contrat_absent' | 'non_annonce' | 'delai_en_cours' | 'hors_ue' | 'conservation_chez_fournisseur' | 'oppositions')[]; permiseLe: string | null }` :
     - `permiseLe` = `ajouterJours(annonceLe, oppositionJours)` (L03-T19) ; le jour même : permise (si rien d'autre) ;
     - une opposition reçue PENDANT le délai ajoute `oppositions` (le produit ne décide pas à la place de Will : il bloque et le dit) ; une opposition reçue après `permiseLe` est ignorée pour l'activation ;
     - IA avec conservation = `conservation_chez_fournisseur` ; hors UE = `hors_ue` (D1) ;
   - `oppositionJours` entier >= 0, sinon `ErreurRgpd('delai_invalide')` ; dates réelles.
2. Tests nommés : `tout-est-en-regle-permise`, `contrat-absent-refuse`, `non-annonce-refuse`, `delai-en-cours-et-jour-meme` (veille : refusée avec `permiseLe` ; jour : permise), `opposition-pendant-le-delai-bloque`, `opposition-apres-le-delai-ignoree`, `ia-qui-conserve-refusee`, `hors-ue-refuse`.
