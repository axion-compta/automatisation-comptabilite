## Contexte
V3-VEN-011 : litiges, créances douteuses et irrécouvrables ; reclassement du client en 416 AVANT toute dépréciation ; provision proposée, jamais passée sans validation. Écritures de vente : `ventes/ecriture-facture.ts` (L10-T02) ; balance âgée : `ventes/balance-agee.ts` (L10-T21) ; plan : `plan/comptes.ts` (L01-T12) ; forme `Ecriture` : `ecritures/modele.ts`.

## À faire
1. Tests d'abord, client et créance fictifs.
2. `creances-douteuses.ts` : `proposerReclassement(creance)` → écriture `brouillon` D 416 / C 411 du montant TTC restant ; `proposerDepreciation(creance, montantHt)` → refusée tant que le reclassement n'est pas validé (erreur codée), sinon écriture `brouillon` séparée ; `proposerIrrecouvrable(creance)` → brouillon, jamais validé.
3. Critère du registre : créance douteuse fictive de 1 200,00 € : D 416 1 200,00 / C 411 1 200,00 en brouillon, puis dépréciation proposée séparément ; rien de validé sans geste.
4. Tests nommés : `reclassement-416-en-brouillon`, `depreciation-avant-reclassement-refusee`, `depreciation-proposee-separement`, `rien-valide-sans-geste`, `irrecouvrable-en-brouillon`, `montant-negatif-refuse`.

## Hors périmètre
Taux de dépréciation (choix de l'utilisateur), TVA sur créance irrécouvrable, écran.

## Pièges
Statut `brouillon` seulement, jamais `valide`. Comptes lus dans le plan, centimes entiers.
