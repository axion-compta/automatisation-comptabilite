## Contexte
Spec 03, §10 : « Questionnaire bloquant avant tout dossier sans expert : un "oui" sur un sujet non couvert bloque ; aucun "néant" sans nom (DEC-051). » « Contrôles avant clôture chiffrés (CTL-031) : 0 brouillon, compte d'attente à 0,00, banque = relevé, balance équilibrée, immobilisations revues. » P3 : « oui » à « stocks » → dossier bloqué avec le sujet cité.

## À faire
1. `packages/noyau/src/cloture/avant-cloture.ts` :
   - `evaluerQuestionnaire(reponses: { sujet; reponse: 'oui' | 'non' | 'neant'; nomRepondant?; date? }[], { sujetsAttendus: readonly string[]; sujetsCouverts: readonly string[] })` → `{ ok: boolean; bloquants: { sujet; code: 'sujet_non_couvert' | 'neant_sans_nom' | 'sans_reponse' }[] }` ;
   - `controlesAvantCloture({ ecritures; prefixeAttente; prefixeBanque; soldeReleve: Centimes; immobilisationsRevues: boolean })` → `{ id: 'CLO-01' | 'CLO-02' | 'CLO-03' | 'CLO-04' | 'CLO-05'; ok: boolean; valeur: string; ecartCentimes?: Centimes }[]` : CLO-01 nombre de brouillons (valeur = le nombre), CLO-02 solde des comptes d'attente, CLO-03 solde banque (balance L01-T11) − relevé, CLO-04 balance équilibrée, CLO-05 immobilisations revues ; chaque contrôle a une valeur chiffrée, même réussi.
2. Tests nommés (préfixes de comptes passés en argument, jamais en dur) : `oui-sur-sujet-non-couvert-bloque` (P3), `neant-sans-nom-bloque`, `sujet-sans-reponse-bloque`, `questionnaire-complet-ok`, `brouillons-comptes-clo-01`, `attente-non-soldee-clo-02`, `banque-differente-du-releve-clo-03`, `tout-vert-valeurs-chiffrees`.

## Hors périmètre
Pas de dossier de fin d'année ni d'archive (spec 10, lots suivants), pas de route.

## Pièges
Règles du noyau comme L03-T01. Cas limites exigés : `nomRepondant` fait d'espaces (refusé), sujet répondu deux fois (la dernière réponse compte : test), préfixe vide (refus, classe locale `ErreurCloture`), aucune écriture (contrôles OK sauf CLO-05 si non revues).
