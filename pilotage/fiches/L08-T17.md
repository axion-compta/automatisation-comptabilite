## Contexte
Spec 08, fichier 03 §4 : essai automatique chaque mois (1er lundi, 03 h) ; un client tiré au sort parmi les clients actifs + le client témoin ; une fois par trimestre, restauration depuis la copie hors site. Cas R11 : dernier dump de X en erreur, l'avant-dernier sain : l'essai prend l'avant-dernier et le dit ; alerte « dump en erreur ». Le jour de la semaine vient de `jourDeSemaine` (L03-T19) ; le tirage est déterministe (empreinte de L03-T01), sans `Math.random`.

## À faire
1. `packages/noyau/src/exploitation/planification-essai.ts` :
   - `choisirSauvegarde(dumps: { nom; empreinte; le: string; statut: 'reussi' | 'erreur' }[])` → `{ dump; ignores: string[]; alerte: 'dump_en_erreur' | null }` : le plus récent `reussi` ; les dumps en erreur PLUS RÉCENTS que lui sont listés dans `ignores` (noms, triés) et donnent l'alerte ; aucun dump réussi = `ErreurExploitation('liste_vide')` ; deux dumps de même nom = `doublon` ;
   - `premierLundi(mois: 'AAAA-MM')` → date `AAAA-MM-JJ` ;
   - `essaiDuMois(mois, { moisHorsSite: number[] })` → `{ date; source: 'locale' | 'hors_site' }` : `hors_site` si le numéro du mois est dans `moisHorsSite` (réglage passé en argument : la spec dit « une fois par trimestre », sans dire quels mois) ; numéros hors 1..12 ou en double = `reglage_invalide` ;
   - `tirerClients(actifs: string[], temoin: string, graine)` → `[tire, temoin]` : `tire` = premier de `actifs` (hors témoin) par tri sur `empreinteSha256(graine + ':' + id)` ; aucun client actif hors témoin = `[temoin]` seul ; doublons refusés.
