## Contexte
Spec 09, §01 règle 6 : SA, société cotée, commissaire aux comptes, coopérative, GIE, paie, siège hors de France métropolitaine (DOM, Corse), multi-pays → démarrage BLOQUÉ avec une phrase claire ; jamais de traitement partiel silencieux. `je_ne_sais_pas` sur le commissaire aux comptes = question reposée avant la première clôture. Cas limite : siège transféré en Corse en cours d'année = blocage à partir de la date d'effet. Cas P15, P16, P17.

## À faire
1. `packages/noyau/src/profil/perimetre.ts` :
   - `ReponsesPerimetre { formeLue: string; cotee: boolean | null; commissaireAuxComptes: 'oui' | 'non' | 'je_ne_sais_pas'; paie: boolean | null; plusieursPays: boolean | null; codePostalSiege: string | null }` ;
   - `verifierPerimetre(reponses, { formesHorsPerimetre: string[]; prefixesPostauxExclus: string[] })` → `{ bloque: boolean; motifs: string[]; questionsAvantCloture: string[] }` ; motifs : `forme_hors_perimetre`, `societe_cotee`, `commissaire_aux_comptes`, `paie`, `plusieurs_pays`, `siege_exclu` ; `je_ne_sais_pas` = pas de blocage mais `questionsAvantCloture` contient `commissaire_aux_comptes` ; `null` = question `a_poser`, jamais un « non » supposé ;
   - code postal : 5 chiffres `[0-9]`, sinon motif `code_postal_invalide` (bloque) ; exclusion par préfixe, listes passées en argument (données de L09-T28, jamais en dur) ;
   - `bloqueALaDate(historiqueSiege, date, regles)` : lit le code postal en vigueur à la date (lignes `{ effetDebut, codePostal }`) et rend le blocage à partir de la date d'effet du transfert.
2. Tests nommés (listes inventées : formes `FORME_X`, préfixes `99`, `998`) : `commissaire-oui-bloque-p15`, `commissaire-je-ne-sais-pas-question-p15`, `siege-exclu-p16` (code postal fictif sous un préfixe exclu), `forme-hors-perimetre-p17`, `plusieurs-motifs-tous-rendus` (ordre stable), `null-jamais-non` (`paie: null` donne `a_poser`), `code-postal-invalide` (4 chiffres, lettres, chaîne vide, espaces), `transfert-en-cours-d-annee` (veille : non bloqué ; jour d'effet et lendemain : bloqué ; historique donné dans le désordre), `listes-vides-rien-d-exclu`.
