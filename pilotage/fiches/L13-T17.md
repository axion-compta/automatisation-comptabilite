## Contexte
Spec 13, fichier 04, R04 : restitution de capital décidée : D 101300 / C 512000 ; ce n'est ni un apport ni un produit (aucune ligne en classe 7). Un virement vers l'associé sans décision n'est pas une restitution : il est qualifié compte courant (455100) ; s'il rend le compte courant débiteur : carte et geste G07. Tests MOT71-5 (500,00 décidée) et MOT71-6 (455100 à 0,00, virement de 500,00 sans décision : débiteur, G07).

## À faire
1. `packages/noyau/src/capital/restitution.ts` (type `Ecriture` de `../ecritures/modele.js`) :
   - `qualifierVersementAssocie({ id; date; journal; montant; decisionId?; soldeCourantAvant }, comptes { capitalAppeleVerse; banque; courantAssocie })` ; solde courant en convention débit moins crédit (négatif = créditeur) ;
   - avec décision (chaîne non vide après coupe des blancs) : écriture `brouillon` D capitalAppeleVerse / C banque, `nature: restitution` ;
   - sans décision : écriture `brouillon` D courantAssocie / C banque, `nature: compte_courant`, `soldeCourantApres`, et `gesteRequis: G07` si le solde après est strictement positif (débiteur) ;
   - montant nul, négatif ou non entier : `ErreurCapital('montant_invalide')`.
2. Tests nommés (comptes passés en argument : 101300, 512000, 455100) : `restitution-decidee` (50 000), `aucune-ligne-en-classe-7` (aucun compte de l'écriture ne commence par 7), `sans-decision-compte-courant`, `courant-debiteur-demande-g07` (MOT71-6), `courant-reste-crediteur-sans-g07` (avant −100 000, virement 50 000), `decision-vide-traitee-comme-absente` (chaîne vide, blancs), `montant-invalide-refuse` (0, −1, NaN, 1,5, Infinity).
