## Contexte
Spec 07 (abonnement via la console) : la console décide de l'état d'accès, des paliers et de la fin de contrat ; le module obéit (PLA-071) et journalise chaque transition (PLA-132). Toutes les fiches L07-T01 à L07-T12 s'appuient sur ce fichier. Il est le SEUL fichier partagé du dossier `packages/noyau/src/abonnement/` : il doit donc déclarer dès maintenant TOUS les codes d'erreur et TOUS les types d'événements du lot, pour qu'aucune autre fiche n'ait à le modifier.

## Pièges
Règles du noyau (eslint) : ni littéral décimal, ni `/`, ni `Math.round`, ni `parseFloat`, ni `toFixed`. `ecartJours` : la différence de `Date.UTC` est en millisecondes ; ne pas diviser : compter les jours par une boucle bornée ou comparer `d * msParJour` sans `/` (le nombre de millisecondes par jour est un produit `24 * 60 * 60 * 1000` écrit sur une ligne qui ne contient ni `delai` ni `duree`). Aucune date littérale `AAAA-MM-JJ` dans `src` (garde L01-T02). Ne pas toucher `packages/noyau/src/index.ts` : les autres fichiers importent par chemin relatif. Toute fiche du lot qui croit avoir besoin d'un nouveau code d'erreur doit d'abord vérifier cette liste : elle n'a pas le droit de modifier ce fichier.
