## Contexte
Spec 02, fichier 02 : états `recu | analyse | apercu | a_confirmer | importe | refuse | annule` ; `GET /banque/imports/{id}` → état, aperçu 10 lignes, questions. Ce module assemble les briques pures ; il ne crée aucune ligne (la confirmation et l'écriture en base sont bloquées : L02-T63).

## À faire
1. `packages/noyau/src/banque/import/analyse.ts` :
   - `analyserReleve(entree, contexte)` avec `entree` : `{ format: 'csv'; texte } | { format: 'tableur'; lignes: string[][] } | { format: 'camt053' | 'ofx1' | 'ofx2'; texte } | { format: 'pdf'; pages }` ; `contexte` : `{ profil?; reglesPdf?; comptes; compteChoisi?; ibanHache?; taillesApercu: number; limitesXml }` ;
   - résultat `RapportImport { etat: 'apercu' | 'a_confirmer' | 'refuse' | 'vide'; releves: { releve: ReleveLu; rattachement; controle }[]; apercu: LigneLue[]; questions: { code: 'format_date' | 'quel_compte' | 'profil_a_choisir'; choix: string[] }[]; compteurs: { lues; importees; rejetees }; motifRefus?: 'solde_pdf_faux' | 'format_inconnu' | 'xml_refuse' }` ;
   - règles : PDF avec `ECART` → `refuse` (`solde_pdf_faux`) ; `mauvais_compte` → `a_confirmer` ; une question ouverte → `a_confirmer` ; 0 ligne → `vide` ; sinon `apercu` ;
   - CSV ou tableur sans profil → question `profil_a_choisir` (jamais deviné ici : L02-T66 bloquée) ;
   - plusieurs relevés dans un fichier : un rattachement par relevé.
