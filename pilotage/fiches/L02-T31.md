## Contexte
Spec 02, fichier 05, passes 1 et 2 : « Préparation : seules les lignes `completee` ; pièces comptées de la société ; une pièce ne sert qu'à hauteur de son reste. » « Neutralisation : débit puis crédit identiques le même jour, même contrepartie → `NEUTRALISEE` (V3-BAN-036). » Test T05-8 : « pièce d'une autre société au même montant : jamais candidate ».

## À faire
1. `packages/noyau/src/banque/rapprochement/preparation.ts` :
   - `preparer(societeId, lignes: LigneBancaire[], pieces: PieceCandidate[], liens: Lien[])` → `{ lignes: LigneBancaire[]; pieces: (PieceCandidate & { reste: Centimes })[]; ecartees: { id; motif: 'autre_societe' | 'non_comptable' | 'deja_validee' | 'piece_soldee' }[] }` ;
   - ligne écartée si `societeId` différent, si non `completee`, si elle a déjà un lien `valide` couvrant tout son montant ; pièce écartée si `societeId` différent ou si son reste est nul ;
   - reste calculé par la même règle que L02-T30 (copie locale de 10 lignes OU import de `./sommes.js` si L02-T30 est fusionnée ; le choix est noté dans le journal) ;
   - `neutraliser(lignes)` → paires `{ debitId; creditId }` : montant opposé exact, même `dateOperation`, même `contrepartieId` (non vide), même compte ; appariement par rang croissant ; chaque ligne dans une seule paire.
2. Tests nommés : `t05-8-autre-societe-ecartee`, `en-attente-ecartee`, `deja-validee-ecartee`, `piece-soldee-ecartee`, `aller-retour-neutralise`, `contrepartie-differente-non-neutralise`, `trois-debits-deux-credits-deux-paires`, `ordre-d-entree-sans-effet`.
