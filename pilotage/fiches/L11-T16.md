## Contexte
Spec 11, fichier 03 : `km_retenus = km_saisis × (2 si aller-retour sinon 1)`, au dixième ; jamais de distance inventée sans départ et arrivée ; carte grise absente → `a_completer`. Fichier 02, règle 6 : véhicule de la société → refusé (`vehicule_societe`, cas NF-13) ; `location` ou `conjoint` → « à vérifier », aucun montant (point P5, recommandation suivie). Deux-roues → refusé au MVP (P4). Statut social et plafonds éventuels : ignorés au MVP (P3).

## À faire
1. `packages/noyau/src/frais/trajet.ts` :
   - `lireKmDixiemes(texte: string)` : `'120'` → 1 200 ; `'12,5'` ou `'12.5'` → 125 ; au plus 1 décimale ; refus `''`, `'0'`, `'-3'`, `'1e2'`, `'NaN'`, `'12,55'` ;
   - `kmRetenus(trajet)` → dixièmes, × 2 si aller-retour ; `kmSaisisDixiemes` non entier, ≤ 0 ou non sûr → `entree_invalide` ;
   - `admissibilite(trajet, vehicule)` → `{ etat: 'calculable' } | { etat: 'a_verifier'; raison: 'location' | 'conjoint' } | { etat: 'a_completer'; manque: ('carte_grise' | 'motif' | 'depart_arrivee')[] } | { etat: 'refuse'; code: 'vehicule_societe' | 'deux_roues_non_pris_en_charge' }` ; ordre : refus d'abord, puis « à vérifier », puis « à compléter » ;
   - véhicule d'une autre personne que le trajet → `entree_invalide`.
