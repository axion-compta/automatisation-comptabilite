## Contexte
Spec 02, fichier 02 : `profil_import.pdf_regles` ; test T02-5 : PDF texte fictif « Banque Exemple », solde d'ouverture 3 200,00, 42 lignes, somme 1 180,25, solde de clôture imprimé 4 380,25 → OK ; falsifié à 4 390,25 → refusé, écart 10,00. Cas limite : « PDF de 2 relevés collés (découpé par en-tête de période) ». Le texte arrive déjà extrait (L02-T02, côté serveur) : cette fiche est pure.

## À faire
1. `packages/noyau/src/banque/import/pdf-texte.ts` :
   - type `ReglesPdf { ligne: string; soldeOuverture: string; soldeCloture: string; entetePeriode: string; formatDate; format: { decimal; milliers }; devise }` : chaque règle est la SOURCE d'une expression régulière à groupes nommés (`date`, `libelle`, `debit`, `credit` ou `montant`, `solde`, `du`, `au`) ;
   - `verifierRegles(r)` : source de plus de 300 caractères, groupe obligatoire absent, expression invalide → `regles_invalides` ;
   - `lirePdfTexte(pages: { numero; lignes: string[] }[], regles)` → `ReleveLu[]` : une ligne qui correspond à `ligne` crée une opération ; une ligne suivante qui ne correspond à rien prolonge le libellé de l'opération précédente (libellés sur deux lignes) ; un nouvel `entetePeriode` ouvre un nouveau relevé ;
   - montants par `lireMontant` (L02-T08), dates par `lireDate` (L02-T09) ; une ligne d'opération illisible devient un rejet avec son numéro (page, ligne).
2. Tests nommés (texte fictif écrit dans le test) : `t02-5-quarante-deux-lignes`, `soldes-imprimes-lus`, `libelle-sur-deux-lignes`, `deux-releves-colles`, `debit-et-credit-en-colonnes`, `ligne-illisible-rejet-numerote`, `regles-invalides-refusees`, `pages-dans-le-desordre-remises-en-ordre`.

## Hors périmètre
Contrôle des soldes et refus de l'import (L02-T17, L02-T20). Extraction du texte (L02-T02). Profils réels de banques (données fictives seulement, L02-T50).

## Pièges
Les expressions viennent d'un profil : longueur bornée et AUCUN drapeau autre que `u` et `i` ; test d'une expression à retour arrière catastrophique (`(a+)+$`) refusée par `verifierRegles` (liste de motifs dangereux refusés). Cas limites exigés : pages vides, aucune ligne reconnue (0 opération, pas d'exception), montant `NaN` en texte, solde d'ouverture absent (`soldeOuverture` absent, pas 0). Sensible (argent). Règles du noyau.
