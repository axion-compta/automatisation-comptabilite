## Contexte
Issue du découpage de L04-T49 (D88, décision de Will du 11/11/2026). Point P2 : OCR local derrière un port `Ocr.lire(image) → texte + boîtes`, moteur choisi sur le banc. Aucun moteur n'est choisi : l'OCR s'écrit contre une INTERFACE et un faux (condition 4 de D55) ; aucune nouvelle dépendance. `ImageGris` : `packages/noyau/src/pieces/entree/nettete.ts` ; `ElementTexte` : `packages/noyau/src/pieces/sensibles/texte-cache.ts`.

## À faire
1. Tests d'abord ; images fabriquées dans le test (pixels fictifs).
2. `ocr-local.ts` : interface `Ocr { lire(image: ImageGris): Promise<{ boites: { texte: string; x: number; y: number; largeur: number; hauteur: number }[] }> }` ; faux `OcrMemoire` (réponses fixées par le test, panne simulable) ; fonction `elementsDepuisOcr(resultat, page, image)` qui rend des `ElementTexte` (calque visible, aucune annotation) ; boîte hors de l'image ou valeur non finie : rejetée et comptée ; OCR en panne : `{ code: 'ocr_indisponible' }`, jamais un texte vide présenté comme lu.
3. Tests nommés : `ocr-ticket-fictif`, `boite-hors-image-rejetee`, `ocr-indisponible-signale`, `entree-non-modifiee`.
