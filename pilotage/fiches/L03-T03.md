## Contexte
Spec 03, principes 3 et 5 : tout document préparé porte « Préparé par IA, à valider », puis le nom du validateur et la date une fois validé ; filigrane tant que non validé. Le mode de travail commande ce qui est produit : en « Saisie seule », pas d'état officiel, seulement l'indicatif filigrané (spec 09, B3 : réponse 409). Un état officiel exige un exercice clôturé (spec 09 : 422 sinon). Les vues de travail (brouillons inclus) sont marquées « Non officiel » (spec 08, règle 4).

## À faire
1. `packages/noyau/src/documents/mention.ts` (codes seulement, AUCUN texte affiché : les phrases sont dans `packages/textes`, L03-T39) :
   - types `ModeTravail = 'autonome' | 'assiste' | 'saisie_seule'`, `NatureDocument = 'officiel' | 'indicatif' | 'travail'` ;
   - `natureAutorisee({ mode, exerciceStatut: 'ouvert' | 'en_cloture' | 'cloture' | 'rouvert', demande: NatureDocument, type: 'fec' | 'etat' | 'declaration' | 'paquet' })` → `{ ok: true; nature } | { ok: false; code: 'mode_saisie_seule' | 'exercice_non_cloture' }` : `officiel` refusé en `saisie_seule` pour le type `etat` (l'appelant proposera l'indicatif) ; `officiel` refusé si l'exercice n'est pas `cloture` pour les types `etat` et `fec` ; `indicatif` et `travail` toujours permis ;
   - `etatMention({ statut: 'brouillon' | 'a_valider' | 'valide', nature, validePar?, valideLe? })` → `{ mention: 'prepare_par_ia'; validation?: { par; le }; filigrane: 'aucun' | 'a_valider' | 'indicatif' | 'non_officiel' }` : `indicatif` et `travail` gardent toujours leur filigrane, même validés ; `valide` sans `validePar` ou `valideLe` = `validation_incomplete` (classe locale `ErreurMention`).
2. Tests nommés : `officiel-refuse-en-saisie-seule`, `officiel-refuse-exercice-ouvert`, `indicatif-toujours-permis`, `filigrane-tant-que-non-valide`, `valide-sans-filigrane-avec-validateur`, `indicatif-garde-son-filigrane`, `validation-incomplete-refusee`.
