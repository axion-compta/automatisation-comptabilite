## Contexte
Spec 02, fichier 09 : virements internes « sortie du compte A et entrée du compte B de la société, même montant, ±2 j ouvrés → paire proposée, passée par 580, qui doit revenir à 0,00 ; une moitié manquante = `A_QUALIFIER` » ; carte à débit différé : « le prélèvement global mensuel du compte courant solde ce compte ; jamais de double comptage (l'achat ne se rapproche pas aussi du prélèvement global) » ; « la trésorerie totale est la somme au centime ». Cas limite : virement entre deux sociétés du même dirigeant : jamais interne. Tests T09-3, T09-4, T09-5. L'ÉCRITURE du virement interne est faite par L13-T14 : ici, seulement la détection.

## À faire
1. `packages/noyau/src/banque/comptes-multiples.ts` :
   - `apparierVirementsInternes(lignes, comptesDeLaSociete: string[], reglage: { joursOuvres: number; joursFermes: readonly string[] })` → `{ paires: { sortieId; entreeId; montant }[]; orphelines: { ligneId; code: 'moitie_manquante' }[] }` : même `societeId`, comptes différents, montants opposés exacts, écart en jours ouvrés ≤ réglage ; appariement par affectation la plus proche en date, départage par id ; une ligne d'une autre société n'est jamais appariée ;
   - `soldeCarteDiffere(achats: { id; montant; date }[], prelevement: { id; montant; date })` → `{ soldeApres: Centimes; nbCharges: number; prelevementInterne: true }` (le prélèvement global est marqué « interne carte », jamais candidat d'une pièce) ; écart ≠ 0 → `soldeApres` non nul, rendu tel quel (jamais forcé à 0) ;
   - `soldeTotalParDevise(comptes: { solde: Centimes; devise }[])` → `Record<devise, Centimes>` (jamais d'addition entre devises).
