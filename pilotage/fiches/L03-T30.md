## Contexte
Spec 03, §03 : TVA-C09 « CA déclaré de l'année vs total des comptes de produits » (M au-delà du seuil, détail par période ; C3 : écart 100,00 pour un seuil de test 50,00) ; TVA-C10 « ligne de report = ligne de crédit précédente » (B) ; TVA-C11 « solde collectée − déductible = TVA nette de la déclaration préparée » (B) ; TVA-C13 « base négative » (B, jamais produite). Chaque contrôle affiche une valeur chiffrée ; IMPOSSIBLE n'est jamais OK (PRI-007). Moteur : `RegleControle` (L01-T19) ; catalogue `docs/controles.csv` (L01-T21, garde L01-T03).

## À faire
1. `packages/noyau/src/controles/regles/tva-declaration.ts` : quatre `RegleControle`, version 1 :
   - `TVA-C09` (M, bloque rien, déclencheur `avant_tva`) sur `{ caDeclareCumule; totalComptesProduits; seuilEcart }` : ALERTE si |écart| > seuil, `ecartCentimes` signé ; seuil absent = IMPOSSIBLE ;
   - `TVA-C10` (B, bloque `tva`) sur `{ precedente; actuelle; codes }` : utilise `reporterCredit` (L03-T28) ;
   - `TVA-C11` (B, bloque `tva`) sur `{ soldeCollectee; soldeDeductible; tvaNetteDeclaree }` (soldes fournis par l'appelant depuis la balance ; comptes jamais en dur) ;
   - `TVA-C13` (B, bloque `tva`) sur les cases calculées : ALERTE si une case `base` est négative.
2. `docs/controles.csv` : 4 lignes ajoutées (ne pas toucher les lignes existantes), `test_id` `CT-D01` à `CT-D04`, colonne `bloque` dans le vocabulaire déjà utilisé par le fichier (`preparation_tva`), colonne `parametres` = `tva.controle.seuil_ecart_ca` pour TVA-C09 (nom de clé, sans valeur).
3. Tests dont le titre contient `CT-D01` … `CT-D04` (cas OK et cas en écart d'un centime pour chacun, cas IMPOSSIBLE pour C09), plus `exigence-et-version-renseignees`.

## Hors périmètre
CC-T01 à CC-T19 (catalogue de la spec 12, autre lot) : ne pas les recréer ; TVA-C10 et TVA-C11 sont aussi des parties de CC-T01 : le lot du catalogue réutilisera ces règles au lieu de les dupliquer (noté dans LOT-03-PLAN).

## Pièges
Fichier partagé `docs/controles.csv` : ajouter en fin de fichier, fusionner sur une base à jour (le lot du catalogue y écrit aussi). Le vocabulaire du code (`Blocage = 'tva'`) et celui du CSV (`preparation_tva`) diffèrent déjà dans L01 : ne pas les « corriger » ici. Règles du noyau comme L03-T01. Cas limites exigés : seuil NaN ou négatif (IMPOSSIBLE), soldes à 0 (OK), écart exactement égal au seuil (OK).
