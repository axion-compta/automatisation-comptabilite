## Contexte
Cas T-ABO-6 : dans les états non actifs, bannière présente sur 100 % des écrans, 0 montant. La coque (L01-T33) entoure tous les écrans : y monter le bandeau une seule fois suffit. Le lien « Abonnement et factures » du portail (E53 = lien, PLAN V5.3 §6) et le lien « Demander la fin de mon contrat » (D3) dépendent de l'adresse du portail, inconnue tant que la console n'a pas répondu (D29) : ils sont donc lus dans une variable de construction, et absents tant qu'elle n'est pas fournie.

## À faire
1. `socle/liens.ts` : `lienPortail(cible: 'abonnement' | 'fin_contrat')` → URL `https:` construite depuis `import.meta.env.VITE_URL_PORTAIL` (chemins `/abonnement` et `/demandes/fin-de-contrat`, à confirmer par la console : écrire « à confirmer (D29) » en commentaire), ou `null` si la variable est absente, vide ou pas en `https:`. `vite-env.d.ts` : déclarer `VITE_URL_PORTAIL?: string`.
2. `socle/BandeauAcces.tsx` : `useLecture('/acces', ReponseAcces)` (schéma du contrat, L07-T14) ; état `pret` avec `banniere` non nulle → `BanniereAcces` (L07-T24) avec les textes de L07-T23 (date formatée par `affichage.ts` de L01-T31), `lien.href` = `lienPortail('abonnement')` si le code est `portail_abonnement`, sinon `null` ; `resume` = `reprise(pieces_traitees)` ; `gravite` `attention` pour SUSPENDU et RESILIE, sinon `info` ; chargement ou erreur → rien (le bandeau ne doit jamais bloquer l'écran).
3. `Coque.tsx` : monter `<BandeauAcces />` au-dessus de `<main>`, une seule ligne de plus.
4. Tests nommés (`// @vitest-environment jsdom`, faux serveur côté Node de L01-T24 avec `scenarioAbonnement`) : `actif-pas-de-bandeau`, `cinq-etats-un-bandeau-sur-chaque-ecran` (T-ABO-6 : 3 écrans fictifs injectés × 5 états), `aucun-montant-affiche`, `resume-de-reprise-affiche`, `erreur-reseau-pas-de-bandeau-ecran-intact`, `lien-portail-absent-sans-variable`, `lien-portail-https-seulement` (`http:`, `javascript:` → `null`), `coque-existante-inchangee` (les tests de L01-T33 passent ; adapter `coque.test.tsx` seulement pour fournir le faux serveur si la coque lit désormais `/acces`).

## Hors périmètre
Pas de lien « Retour au portail » (attend la console), pas de porte d'acceptation (L07-T30), pas d'écran.

## Pièges
`Coque.tsx` est un fichier commun du couloir D : changement d'une ligne seulement ; L07-T30 le touchera après celle-ci. Aucune adresse réelle de portail dans le dépôt (pas même dans les tests : utiliser `https://portail.exemple.invalid`). Le bandeau se lit avec le contrat : aucun texte d'état en dur dans le `.tsx`.
