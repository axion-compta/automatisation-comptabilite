## Contexte
Spec 04, fichier 03 §1 : « Contrôle de netteté avant lecture : en dessous du seuil (variance du laplacien, valeur à mesurer sur le banc), demande de reprise de la photo, 0 appel d'IA. » Cas T-LEC-11. Le seuil est un argument (mesuré plus tard sur le banc).

## À faire
1. `packages/noyau/src/pieces/entree/nettete.ts` :
   - `ImageGris { largeur: number; hauteur: number; pixels: Uint8Array }` (longueur = largeur × hauteur, largeur et hauteur >= 3, sinon `ErreurPiece('image_invalide')`) ;
   - `mesureNettete(img)` → `{ n: bigint; somme: bigint; sommeCarres: bigint }` : laplacien à 4 voisins (`4·p − haut − bas − gauche − droite`) sur les pixels intérieurs ;
   - `estFloue(img, seuil: number)` : vrai si `n·sommeCarres − somme² < seuil·n²` (variance comparée SANS division, en `bigint`) ; seuil entier >= 0 sinon `ErreurPiece('reglage_invalide')`.
2. Tests nommés : `image-uniforme-floue` (variance 0), `damier-net`, `flou-moyen-sous-seuil`, `egalite-au-seuil-non-floue`, `dimensions-trop-petites-refusees` (2×2), `longueur-incoherente-refusee`, `seuil-invalide-refuse` (NaN, Infinity, -1, 0.5).

## Hors périmètre
Décodage de la photo en niveaux de gris (conteneur, L04-T49) ; écran M02.

## Pièges
Division interdite dans le noyau : garder la forme multipliée. Le nom `seuil` ne porte aucun littéral sur la même ligne (garde L01-T02). Règles du noyau comme L04-T00.
