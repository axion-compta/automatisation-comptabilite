## Contexte
Spec 05, fichier 03 §6 : IA coupée, budget épuisé ou fournisseur en panne : les commandes « / » déterministes et la palette Ctrl+K appellent les MÊMES outils du registre, sans modèle. Au MVP : `/importer`, `/valider-lot`, `/rapprocher`, `/vue`, `/annuler`, `/exporter`, `/aide`. `/aller` existe déjà (`apps/web/src/commandes/aller.ts`, L00-T16).

## À faire
1. `apps/web/src/commandes/barre-oblique.ts` :
   - `COMMANDES` : les 7, chacune `{ nom; outil?: string; destination?: string }` ; `outil` doit être un nom de `NOMS_OUTILS` (L05-T05) ou absent ; une commande dont l'outil n'est pas encore déclaré mène à sa destination d'écran (liste de `aller.ts`) ;
   - `analyser(saisie)` → `{ commande; arguments: string[] } | { inconnue: string } | null` (pas de « / » en tête = `null`) ; insensible à la casse ; espaces multiples ; `/aller` laissé à `aller.ts` ;
   - `suggestions(debut)` → commandes qui commencent par `debut`, triées.
2. Tests nommés : `sept-commandes`, `outils-declares-ou-destination` (chaque `outil` existe dans `NOMS_OUTILS`), `analyse-avec-arguments`, `casse-et-espaces`, `commande-inconnue`, `sans-barre-null`, `aller-non-capture`, `suggestions-triees`, `saisie-vide-ou-barre-seule`.

## Hors périmètre
Pas d'exécution d'outil, pas de modification de `Palette.tsx` ni de `aller.ts` (l'écran L05-T52 branche les commandes).
