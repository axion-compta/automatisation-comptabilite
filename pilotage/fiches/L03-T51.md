## Contexte
Spec 03, §11 : le comptable du client n'a aucun accès au logiciel (D44, A6) : il reçoit un paquet. Contenu (DEC-031) : FEC (officiel ou _TRAVAIL) + notice + rapport ; livres ; états (indicatifs filigranés en Saisie seule) ; pièces ORIGINALES classées + `index_pieces.csv` (PieceRef, écriture, empreinte) ; journal des actions ; `MANIFESTE.sha256`. « Jamais une version retravaillée d'une photo à la place de l'original. » Brouillons exclus sauf « export de travail » marqué. X1 : 3 pièces fictives → `index_pieces.csv` de 3 lignes, manifeste vérifié.

## À faire
1. `packages/noyau/src/exports/paquet.ts` (utilise `empreinteSha256`, `manifeste` de L03-T01 et `natureAutorisee` de L03-T03) :
   - `composerPaquet({ mode; exerciceStatut; travail: boolean; documents: { nom; nature: 'officiel' | 'indicatif' | 'travail'; type; octets }[]; pieces: { pieceRef; ecritureIds: string[]; nom; octets; empreinteOriginale: string }[] }, { separateurCsv: string; finDeLigne: string })` → `{ fichiers: { nom; octets }[]; indexPieces: string; manifeste: string }` ;
   - un document `travail` n'entre que si `travail` est vrai ; un document `officiel` refusé par `natureAutorisee` est exclu et listé dans `exclus` ; une pièce dont l'empreinte des octets ≠ `empreinteOriginale` = refus `piece_non_originale` (classe locale `ErreurPaquet`) ;
   - `index_pieces.csv` : en-tête puis une ligne par couple (pièce, écriture), triées ; `MANIFESTE.sha256` couvre tous les fichiers, index compris, sauf lui-même.
2. Tests nommés : `trois-pieces-trois-lignes` (X1), `manifeste-verifie`, `travail-exclu-par-defaut`, `travail-inclus-si-demande`, `officiel-exclu-en-saisie-seule` (état officiel remplacé par l'indicatif s'il est fourni), `piece-retouchee-refusee`, `noms-en-double-refuses`.

## Hors périmètre
Aucun envoi, aucun lien, aucun e-mail (L03-T55, bloquée). Pas d'archive zip (dépendance à choisir plus tard). Pas d'import du retour de l'expert.

## Pièges
Règles du noyau comme L03-T01. Le séparateur et la fin de ligne du CSV sont des arguments. Cas limites exigés : aucune pièce (index réduit à l'en-tête), pièce rattachée à 0 écriture (refus), séparateur présent dans un nom de pièce (refus), ordre des pièces inversé (même paquet, mêmes octets).
