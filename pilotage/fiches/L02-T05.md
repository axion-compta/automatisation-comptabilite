## Contexte
Spec 02, fichier 08, règles 3 et 5 : un compte actif sans relevé couvrant le mois écoulé, au jour J du mois suivant, déclenche l'alerte « Il manque le relevé d'octobre » ; « Aucune opération ce mois-ci » est accepté SEULEMENT si les soldes avant et après sont égaux, sinon refusé avec l'écart. Tests T08-2, T08-3, T08-4 (J = 5 donné en argument dans le test). Compte fermé : plus attendu après sa fermeture.

   - `relevesAttendus(comptes: { id; ouvertLe; fermeLe? }[], releves, aujourdhui: string, jourAlerte: number)` → `{ compteId; mois: 'AAAA-MM' }[]` (mois écoulés non couverts, depuis l'ouverture du compte, triés) ;
   - `accepterAucuneOperation(trou: { soldeAvant?: Centimes; soldeApres?: Centimes })` → `{ accepte: true } | { accepte: false; motif: 'ecart'; ecart: Centimes } | { accepte: false; motif: 'soldes_inconnus' }` ;
