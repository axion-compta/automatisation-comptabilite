## Contexte
Spec 04, fichier 08 §3 : `GET …/pieces?…` (recherche par fournisseur, période, montant, état) et détail d'une pièce. La route d'état (`GET …/pieces/{id}/etat`) est dans L04-T32. Le préfixe `/societes/{s}` viendra avec l'isolation (L04-T51, bloquée) : routes SANS préfixe ici, comme L01-T23. Aucun pourcentage de confiance ne sort : seulement le mot (CTL-010).

## À faire
1. `packages/contrat/src/domaines/pieces.ts` : schémas zod `PieceResume { id, nomNormalise, typePiece, etat, comptee, sensible, datePiece?, fournisseur?, ttcCentimes?, motConfiance }`, `PieceDetail` (résumé + `canal`, `recuLe`, `motifNonComptee?`, `motifsAVerifier[]`, `champs: { nom, valeur, valeurCentimes?, mot, source }[]`, `cheminVirtuel`) ; routes oRPC `listerPieces` (`GET /pieces`, query `fournisseur` (50 car. au plus), `du`, `au` (dates), `montantMin`, `montantMax` (centimes entiers), `etat`, `type`, `limite` 1 à 100, `decalage`, enveloppe `{ body, decalage, total }`) et `lirePiece` (`GET /pieces/{id}`) ; erreur `PIECE_INCONNUE` 404 ; `du > au` ou `montantMin > montantMax` = 400.
2. `packages/contrat/src/domaines/pieces-service.ts` : service pur sur `genererPieces()` (L04-T29, import par chemin relatif) : tri par `recuLe` décroissant puis `id` ; filtres combinés ; recherche fournisseur sans casse ni accents ; pièce `sensible` : `champs` vide et `fournisseur` absent dans le détail (masquage par défaut tant que les permissions n'existent pas).
3. `routes.ts` : ajouter `pieces: { listerPieces, lirePiece }` sans toucher les autres domaines ; `openapi.ts` : seulement si la génération échoue sur un schéma nouveau ; régénérer `openapi.json`.
4. `apps/serveur/src/domaines/pieces.ts` branché dans `app.ts`.
5. Tests nommés : `liste-enveloppe-et-tri`, `filtres-combines`, `recherche-fournisseur-sans-accent`, `bornes-inversees-400` (du > au ; montantMin > montantMax ; limite 0, 101, 1.5), `piece-inconnue-404`, `sensible-masquee-dans-le-detail`, `serveur-repond-aux-pieces` (Fastify `inject`).
