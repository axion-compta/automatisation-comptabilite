## Contexte
Spec 05, fichier 03 §3 : `POST .../chat/messages` rend un flux d'événements (chaque événement a un `id` croissant) ; même `message_id` rejoué = même réponse, 0 nouvel appel d'IA (T-CHT-10) ; Stop : `POST .../chat/tours/{id}/arreter`, flux coupé, propositions déjà reçues gardées, 0 écriture appliquée (T-CHT-9). Routes SANS préfixe de société tant que l'identité n'est pas réglée (comme le lot 01) ; la société vient d'une configuration du serveur en mémoire, JAMAIS de la requête.
