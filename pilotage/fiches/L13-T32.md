## Contexte
Spec 13, fichier 01 : route `GET /v1/societes/{id}/gestes-humains` (liste des 12). Fichier 02, R06 : forme commune des indicateurs `{ etat, valeur, raison }`. Le préfixe de société viendra avec l'identité (bloquée : J3a, D29) ; comme les domaines `plan` et `tiers`, la route est posée sans préfixe. `apps/serveur/src/app.ts` implémente TOUT le contrat : la route et son traitement vont dans la même fiche.

## À faire
1. `packages/contrat/src/domaines/principes.ts` (modèle : `domaines/plan.ts`) : schémas `GesteHumain { code (G01 à G12); action; permission; reauth (toujours, jamais, fusion_seulement) }`, `ReponseGestesHumains` (enveloppe `body`, `decalage`, `total`), `Indicateur` (union discriminée par `etat` : ok avec `valeur` nombre ; vide ou donnee_manquante avec `valeur` null et `raison`) exporté pour les domaines futurs ; route `listerGestesHumains` : `GET /gestes-humains`.
2. `packages/contrat/src/routes.ts` : ajouter `principes` à `contrat` (une ligne d'import, une clé). `pnpm contrat:openapi` pour régénérer `openapi.json`.
3. `apps/serveur/src/domaines/principes.ts` : `routesPrincipes()` rend `CATALOGUE_GESTES` (L13-T02, import par chemin relatif comme `domaines/plan.ts`) ; `app.ts` : brancher `principes`.
4. Tests nommés : contrat : `route-gestes-dans-openapi`, `indicateur-accepte-les-trois-etats`, `indicateur-refuse-zero-sans-donnee` (`{ etat: vide, valeur: 0 }` refusé) ; serveur : `douze-gestes-servis`, `codes-identiques-au-noyau`, `ordre-g01-a-g12`.

## Hors périmètre
Faux serveur : L13-T33. Garde de route (403) et réauthentification : fiche bloquée L13-T49. Aucune route d'écriture.

## Pièges
Fichiers communs à plusieurs lots (`routes.ts`, `openapi.json`, `app.ts`) : branche remise à jour juste avant la fusion, `openapi.json` régénéré, jamais édité à la main. Une seule PR du couloir C ouverte à la fois, tous lots confondus.
