## Contexte
Spec 03, §06 : « Module unique `fec_format` partagé par l'export ET la lecture d'un FEC importé. » « Nettoyage des libellés : retrait du séparateur, CR, LF, caractères de contrôle et invisibles (U+200B, U+00A0 → espace) ; accents gardés ; longueur maximale paramétrée ; jamais vide (repli : libellé du compte). » Montant : « virgule décimale, sans séparateur de milliers ». Date : AAAAMMJJ. Le séparateur et la présence d'une marque d'ordre des octets sont encore à vérifier : ils sont des OPTIONS obligatoires, sans valeur par défaut.

## À faire
1. `packages/noyau/src/fec/format.ts` :
   - type `OptionsFec { separateur: string; finDeLigne: string; longueurMaxLibelle: number }` (tous obligatoires) ;
   - `nettoyerLibelle(texte, repli, options)` : retire séparateur, CR, LF, caractères de contrôle, U+200B, U+FEFF ; U+00A0 et U+202F → espace ; espaces de tête et de fin retirés ; coupé à `longueurMaxLibelle` ; vide → `repli` nettoyé ; repli vide aussi = `ErreurFec('libelle_vide')` ;
   - `formaterMontantFec(centimes)` → `1234,56`, `0,00` ; négatif refusé ;
   - `lireMontantFec(texte)` → `Centimes` sans `parseFloat` (découpe de chaîne, entiers) ; forme invalide = `ErreurFec('montant_invalide')` ;
   - `formaterDateFec('2026-03-31')` → `20260331` et `lireDateFec` inverse ;
   - `assemblerLigne(valeurs, options)` (refus si une valeur contient le séparateur ou une fin de ligne) et `lireLigne(ligne, options)`.
2. Tests nommés : `libelle-pieges-nettoyes` (30 libellés piégés : tabulation, `|`, sauts de ligne, U+200B, U+00A0), `repli-si-vide`, `libelle-coupe-a-la-longueur`, `montant-virgule-sans-milliers`, `montant-lu-identique` (aller-retour sur 1 000 montants à graine fixe), `date-aller-retour`, `ligne-aller-retour-tabulation`, `ligne-aller-retour-barre`.
