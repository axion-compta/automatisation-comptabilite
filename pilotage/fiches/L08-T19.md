## Contexte
Spec 08, fichier 09 §2 : un `LISEZMOI.txt` en français simple : ce que contient l'archive, comment vérifier le manifeste, durée de conservation à la charge du client selon son pays, avec source. D3 et décision a : le client conserve lui-même ; le produit ne conserve pas pour lui après J+30. D31 : la durée vient d'un paramètre daté ; tant qu'il n'est pas vérifié, le texte dit « à confirmer » et ne donne aucun nombre d'années. Les textes du produit vivent dans `packages/textes` (garde des textes, vouvoiement, mots interdits).

## À faire
1. `packages/textes/src/ecrans/export-complet.ts` : `export const exportComplet = { titre, contenu, dossierFec, dossierComptable, dossierPieces, dossierConversations, dossierParametrages, verifierTitre, verifierEtapes, conservationTitre, conservationDate, conservationAConfirmer, conservationSource, contact }` : chaînes simples, vouvoiement, placeholders `{date}` et `{source}` seulement dans `conservationDate` et `conservationSource` ; aucun nombre d'années, aucun nom de produit tiers.
2. `packages/noyau/src/export-complet/lisezmoi.ts` :
   - `lisezmoi({ chemins: string[]; conservation: { etat: 'date'; date: string; source: string } | { etat: 'a_confirmer' } ; modele: Record<string, string> })` → texte : titre, une ligne par dossier PRÉSENT dans `chemins` (dossier absent = ligne absente), étapes de vérification du manifeste, conservation (date formatée `JJ/MM/AAAA` et source, ou la phrase « à confirmer »), contact ; lignes séparées par CRLF (lecture sous Windows), texte terminé par CRLF ;
   - placeholder non remplacé restant dans le texte = `ErreurExploitation('champ_inconnu')` ; clé de modèle manquante = `champ_inconnu`.
3. Tests nommés (`__tests__/lisezmoi.test.ts`, modèle de test = le vrai `exportComplet` importé par chemin relatif) : `dossiers-presents-seulement`, `conservation-avec-date-et-source`, `conservation-a-confirmer-sans-annee` (aucun chiffre suivi de « an »), `fin-de-ligne-crlf`, `placeholder-oublie-refuse`, `cle-de-modele-manquante-refusee`, `aucun-mot-interdit` (appelle `analyserMotsInterdits` de `outils/gardes/textes.mjs` sur le texte produit).

## Hors périmètre
Calcul de la date de conservation (L03-T04, `conserverJusquAu`). Arborescence (L08-T18). Écriture du fichier dans l'archive (L08-T50, bloquée).
