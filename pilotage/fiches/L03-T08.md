## Contexte
Aujourd'hui `lignesFec` (L01-T18, L01-T42) écrit `pieceRef` = identifiant de l'écriture, `pieceDate` = date de l'écriture, `ecritureLet` et `dateLet` toujours vides, et cherche le nom du tiers (`compAuxLib`) dans `libellesComptes`. Spec 03, §06 : PieceRef = « identifiant stable de la pièce ; sans pièce : OD-AAAA-nnn » (jamais vide, FEC-005) ; PieceDate = date de la pièce ; EcritureLet et DateLet = lettrage « au moment de la production » (un lettrage fait après ne change pas un FEC figé, FEC-024) ; CompAuxLib = nom du tiers. Sans ces champs, les jeux « lettrage partiel » et « à-nouveaux par tiers » du banc (L03-T16, L03-T18) sont impossibles.

## À faire
1. `packages/noyau/src/fec/lignes.ts`, ajouts OPTIONNELS à `ContexteFec` (absents = comportement actuel inchangé) :
   - `pieces?: Readonly<Record<string, { ref: string; date: string }>>` (clé = id de l'écriture) ;
   - `lettrages?: Readonly<Record<string, { code: string; date: string }>>` (clé = `<idEcriture>#<indexDeLigne>`, index à partir de 0) ;
   - `libellesTiers?: Readonly<Record<string, string>>` (clé = code du tiers) : utilisé pour `compAuxLib` avant le repli actuel ;
   - date de pièce et de lettrage formatées par `formaterDateFec` (une date mal formée lève `ErreurFec('date_invalide')`, code déjà existant) ; `ref` vide ou fait d'espaces lève `ErreurFec('valeur_invalide')` (code déjà existant : NE PAS ajouter de code à `CodeErreurFec`).
2. Tests nommés ajoutés dans `lignes.test.ts` : `piece-ref-et-date-de-la-piece`, `sans-piece-repli-inchange`, `lettrage-au-moment-de-la-production`, `ligne-non-lettree-vide`, `nom-du-tiers-prioritaire`, `piece-ref-vide-refusee`.

## Hors périmètre
Pas de génération de la convention `OD-AAAA-nnn` (l'appelant fournit `ref`). Pas de devise (`montantDevise`, `idevise` restent vides : le modèle d'écriture n'a pas de devise). Pas de fichier en octets (L03-T09).

## Pièges
Fichier d'une fiche L01 déjà fusionnée : NE changer aucune attente des tests existants ; seulement ajouter. `exactOptionalPropertyTypes` est actif : déclarer les champs avec `?:` et tester leur absence. Règles du noyau comme L03-T01. Cas limites exigés : index de ligne hors bornes dans `lettrages` (ignoré, test), clé de lettrage pour une écriture brouillon (ignorée car le brouillon est exclu), code de lettrage contenant le séparateur (refusé par `assemblerLigne`, test).
