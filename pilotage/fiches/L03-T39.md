## Contexte
Spec 03, §01 : erreurs métier = phrase simple pour l'écran (`message_client`) + code technique ; S1 : « Ajoutez votre numéro SIREN pour préparer ce fichier ». Mention « Préparé par IA, à valider » puis « Validé par … le … » (S2). B3 : « Votre expert-comptable réalise la clôture : je vous montre une vue indicative ». K5 : « Ce fichier appartient à une autre entreprise ». C5 : « Votre déclaration demande un calcul de prorata : à faire avec votre expert-comptable ». X3 : « Ce lien a expiré : demandez-en un nouveau ». DEC-062 : « Dates indicatives, calculées sur votre année comptable du JJ/MM au JJ/MM. À vérifier sur impots.gouv.fr et urssaf.fr. » TVA-C12 : « Il reste N pièces à regarder ». IMP-032 : « Conservez vos justificatifs originaux ».

## À faire
1. `packages/textes/src/documents/declarations.ts` :
   - `messagesDeclarations` : objet `as const` code → phrase, pour au moins `siren_absent`, `mode_saisie_seule`, `exercice_non_cloture`, `autre_entreprise`, `doublon`, `fichier_de_travail`, `prorata`, `lien_expire`, `tva_en_doute`, `regime_non_traite`, `ligne_absente`, `base_negative`, `controle_bloquant_ouvert`, `conserver_originaux` ;
   - `mentionDocument({ validePar?, valideLe? })` → « Préparé par IA, à valider » ou « Préparé par IA, à valider. Validé par {nom} le {JJ/MM/AAAA} » (date reçue en `AAAA-MM-JJ`, reformatée sans objet `Date`) ;
   - `piecesARegarder(n)` (singulier et pluriel) ; `datesIndicatives(debut, fin)` (JJ/MM) ; `filigranes` : `a_valider`, `indicatif` (« Indicatif »), `non_officiel` (« Non officiel »), `provisoire`.
2. Tests nommés : `phrases-exactes-de-la-spec` (S1, B3, K5, C5, X3, DEC-062), `mention-avant-et-apres-validation` (S2 avec « Camille Fictif » et le 12/05/2026), `pluriel-pieces`, `chaque-code-a-une-phrase-non-vide`, `vouvoiement-sauf-citation` (la phrase B3 est à la première personne de l'assistant : permise ; aucun « tu »), `aucun-mot-interdit` (liste construite par morceaux dans le test, comme `MOTS_INTERDITS` de `outils/gardes/textes.mjs` ; ne pas importer ce `.mjs`).
