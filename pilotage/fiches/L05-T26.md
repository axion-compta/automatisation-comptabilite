## Contexte
Spec 05, fichier 07 §2 : le contrôleur se déclenche sur risque (montant, nouveau tiers, doute) et sur échantillon ; il relit avec un fournisseur DIFFÉRENT du classificateur. Agent TVA : divergence entre le moteur en code et l'IA = escalade, jamais de choix par l'IA. Fichier 08 §3 : désaccord entre agents = état `desaccord` et escalade humaine, jamais de vote.

## À faire
1. `packages/noyau/src/agents/controleur.ts` :
   - `doitControler({ id, montant: Centimes, nouveauTiers, confiance }, { seuilMontant: Centimes, echantillonPointsDeBase })` → `{ controler: boolean; motif: 'montant' | 'nouveau_tiers' | 'doute' | 'echantillon' | 'aucun' }` ; échantillon déterministe : empreinte entière de l'`id` (FNV-1a 32 bits, `Math.imul`), `empreinte % 10000 < echantillonPointsDeBase` (l'opérateur `%` est permis par l'eslint du noyau, `/` et `Math.random` ne le sont pas) ;
   - `choisirFournisseurControleur(fournisseurs: string[], fournisseurClassificateur)` → un fournisseur différent, ou `null` (alors la décision passe `a_verifier`) ;
   - `arbitrer(resultats: { agent; valeur }[])` → `{ sorte: 'accord'; valeur } | { sorte: 'desaccord' }` : toutes égales = accord ; sinon désaccord, même à 2 contre 1 (jamais de vote).
2. Tests nommés : `montant-au-dessus-du-seuil`, `nouveau-tiers`, `doute`, `echantillon-deterministe` (même id = même décision), `echantillon-proche-du-taux` (10 000 ids fictifs : proportion dans une marge écrite dans le test), `taux-zero-et-maximum`, `reglages-invalides` (taux > 10000, -1, NaN, 1.5), `fournisseur-different`, `aucun-autre-fournisseur-null`, `deux-contre-un-desaccord`.

## Hors périmètre
Pas d'appel au modèle, pas d'escalade réelle (L05-T28 pour la consolidation).

## Pièges
Règles du noyau (eslint) : ni `/`, ni `Math.random`, ni littéral décimal ; empreinte calculée en entiers non signés (`>>> 0`). Aucun nom de fournisseur réel dans les tests (« fournisseur-a », « fournisseur-b »).
