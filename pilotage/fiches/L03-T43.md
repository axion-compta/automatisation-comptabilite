## Contexte
Spec 03, §14 : le logiciel REÇOIT les factures électroniques par des plateformes agréées, il n'en émet pas (A1). Règle 3 : dédoublonnage entre plateformes, dépôt manuel et e-mail, clé = SIREN de l'émetteur + numéro + date + TTC ; doublon rattaché, jamais compté deux fois (PA2 : TVA comptée une fois). Cas limites : webhook rejoué (idempotence sur l'identifiant externe, PA4) ; facture d'un autre SIREN que la société (refus et carte). Règle 4 : un statut (« refusée », « litige ») n'est envoyé qu'après validation explicite du client, tracée (PA6). Cette fiche est la partie PURE ; la réception réelle est la fiche L03-T57 (bloquée).

## À faire
1. `packages/noyau/src/factures-recues/cycle.ts` (classe locale `ErreurFactureRecue`) :
   - `cleDedoublonnage({ sirenEmetteur; numero; date; ttc: Centimes })` : numéro sans espaces et en majuscules ; SIREN de 9 chiffres sinon `siren_invalide` ;
   - `recevoir(etat: { factures: FactureRecue[] }, arrivee: { source; idExterne; sirenEmetteur; sirenDestinataire; numero; date; ttc; tva }, sirenSociete)` → `{ etat; resultat: 'nouvelle' | 'rejouee' | 'doublon_rattache' | 'autre_destinataire' }` : même `source` + `idExterne` = `rejouee` (état inchangé) ; même clé depuis une autre source = `doublon_rattache` (rattachée à la première, sa TVA n'est pas recomptée) ; destinataire différent de la société = `autre_destinataire` (non rangée) ; l'état reçu n'est jamais modifié ;
   - `tvaComptee(etat)` → somme des TVA des factures non rattachées ;
   - `statutAEnvoyer(facture, statut, statutsPermis: readonly string[], validation?: { par; le })` → `{ ok: true; envoi: { statut; validePar; valideLe } } | { ok: false; code: 'validation_client_requise' | 'statut_inconnu' }`.
2. Tests nommés (SIREN fictifs 123456782 et 987654324, montants inventés) : `nouvelle-facture`, `rejeu-trois-fois-une-facture` (PA4), `deux-sources-un-doublon-rattache` (PA2), `tva-comptee-une-fois`, `autre-destinataire-refuse`, `statut-sans-validation-refuse` (PA6), `statut-apres-validation-trace`, `statut-hors-liste-refuse`.

Aucun adaptateur de plateforme, aucun appel réseau, aucun webhook, aucun nom de plateforme réelle (L03-T57, bloquée). Pas de lecture de Factur-X ni d'UBL (demande une dépendance XML : fiche ultérieure).
