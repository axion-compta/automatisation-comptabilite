## Contexte
Spec 08, fichier 07 §2, droit d'accès : recherche par nom, e-mail ou IBAN dans les tiers, pièces, écritures, conversations ; le résultat sert à produire le fichier d'accès (L08-T24). Cas T-EXP-7 : personne fictive citée sur 12 pièces. La recherche porte sur des collections passées en argument (aucune base ici) ; elle doit être sûre : pas de recherche vide qui rend tout, pas d'expression régulière construite depuis la saisie.

## À faire
1. `packages/noyau/src/rgpd/recherche-personne.ts` :
   - `type Collections = { tiers: { id; nom; email?: string; iban?: string }[]; pieces: { id; texteLu: string }[]; ecritures: { id; libelle: string }[]; conversations: { id; texte: string }[] }` ;
   - `normaliserNom(s)` : minuscules, accents retirés (NFD puis retrait des marques), espaces multiples réduits, tirets et apostrophes changés en espace ; `normaliserIban(s)` : majuscules, espaces retirés ; `normaliserEmail(s)` : `trim` et minuscules ;
   - `rechercherPersonne(critere: { nom?: string; email?: string; iban?: string }, c: Collections)` → `{ source: 'tiers' | 'pieces' | 'ecritures' | 'conversations'; id: string; par: 'nom' | 'email' | 'iban' }[]` triés par source puis id, sans doublon (un même objet trouvé par nom ET e-mail apparaît une fois, `par` = le premier critère dans l'ordre nom, e-mail, IBAN) ;
   - nom : MOT ENTIER (frontières de mot sur le texte normalisé, par recherche de sous-chaîne entourée d'espaces ou de bords, sans `RegExp` construite depuis la saisie) ; e-mail et IBAN : égalité sur le champ du tiers, et sous-chaîne normalisée dans les textes ;
   - critère vide (aucun champ, ou champs vides après `trim`) = `ErreurRgpd('recherche_vide')` ; nom normalisé de moins de 3 caractères = `recherche_trop_courte`.
2. Tests nommés : `t-exp-7-douze-pieces` (personne fictive citée sur 12 pièces parmi 30), `nom-sans-casse-ni-accent`, `mot-entier-seulement` (`Martin` ne trouve pas `Martineau`), `email-exact-sur-le-tiers`, `iban-avec-ou-sans-espaces` (IBAN fictif construit à l'exécution), `un-objet-une-fois`, `recherche-vide-refusee`, `nom-trop-court-refuse`, `caracteres-speciaux-sans-danger` (`.*`, `(`, `[a-z]+` cherchés comme du texte, aucune exception).

## Hors périmètre
Paquet de réponse (L08-T24). Recherche dans les vraies tables (L08-T45, bloquée). Masquage des données marquées (L08-T26).

Noms des tests fictifs (« Camille Exemple », « Société Exemple »). Ne jamais journaliser le critère. Sensible (données personnelles).
