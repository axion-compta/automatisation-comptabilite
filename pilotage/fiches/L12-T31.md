## Contexte
Spec 12, `05-traitement-des-doutes`, C1 (V3-CTL-011) : « Une pièce n'est jamais VERTE si : TTC ≥ 500,00 € (paramètre réglable) ; immobilisation possible (CC-K12) ; manuscrite ; ou fournisseur nouveau, pour ses 3 premières pièces (compteur par fournisseur). Au mieux JAUNE : jamais validée dans un lot VERT. » Cas CT-35 (pièce 520,00 TTC très lisible : JAUNE ; 3e pièce d'un fournisseur nouveau : JAUNE ; 4e : peut être VERTE). Le seuil et le nombre de pièces sont des réglages (`controle.couleur.seuil_ttc`, `controle.couleur.pieces_fournisseur_nouveau`).

## À faire
1. `packages/noyau/src/controles/doutes/couleur.ts` :
   - `Couleur = 'VERT' | 'JAUNE' | 'ROUGE'` ;
   - `plafonnerCouleur({ couleurLue: Couleur; ttc: Centimes; immobilisationPossible: boolean; manuscrite: boolean; rangChezFournisseur: number /* 1 = première pièce */; seuilTtc: Centimes; piecesFournisseurNouveau: number })` → `{ couleur; raisons: string[] }` : ROUGE reste ROUGE ; VERT devient JAUNE si une raison existe ; raisons triées ; rang < 1 ou non entier = exception ; seuil ou nombre invalides = exception.
2. `packages/noyau/src/controles/doutes/__tests__/couleur.test.ts`, tests nommés : `CT-35`, `seuil-exact-jaune` (TTC = seuil), `seuil-moins-un-vert`, `rouge-reste-rouge`, `manuscrite-jaune`, `immobilisation-jaune`, `plusieurs-raisons-triees`, `entrees-invalides` (rang 0, 1,5, NaN ; seuil négatif).

## Hors périmètre
Calcul de la confiance par champ (lot 04, seuil 85 %). Validation par lot (L12-T32).

## Pièges
Règles du noyau comme L01-T06 : montants en `Centimes` via `packages/noyau/src/argent`, ni `/`, ni littéral décimal, ni `Math.round`, ni `parseFloat`, ni `toFixed`. Stryker (seuil 80 %) porte sur tout le noyau : chaque branche doit être tuée par un test. Ne pas toucher `packages/noyau/src/index.ts` ni `controles/moteur.ts` (imports par chemin relatif). Aucun taux, seuil, délai ni date légale dans `src` (garde:litteraux, D31) : tout seuil ou tolérance arrive en argument ou dans un `ParametreLu` (L12-T00) ; paramètre absent = `IMPOSSIBLE`, jamais OK (PRI-007). Le noyau ne contient aucun texte affiché : seulement des codes. Montants et seuils des tests INVENTÉS ou repris des cas fictifs de la spec ; noms et SIREN fictifs seulement. Cas limites exigés dans les tests : montant NaN, Infinity, non entier (1,5) et négatif là où il est interdit = exception codée (le moteur la change en `IMPOSSIBLE`) ; liste vide ; objets reçus dans l'ordre inverse (même résultat) ; écart d'exactement un centime de chaque côté de la tolérance. Chaque test doit rougir si l'on casse la branche qu'il couvre (inverser une comparaison, retirer un cas). Les 500,00 € et 3 pièces sont des valeurs de TEST passées en argument.
