## Contexte
Spec 11, fichier 02, V3-MOT-062 : pièce payée par la personne avec une part personnelle → seule la part société est remboursable, la part personnelle n'est pas comptabilisée ; pièce payée par la société avec une part personnelle → la part personnelle TTC va au débit du compte de la personne, jamais en charge. Cas NF-15 : 110,00 TTC (100,00 HT + 10,00 TVA), moitié personnelle → part société 50,00 HT + 5,00 TVA, part personnelle 55,00 TTC.

## À faire
1. `packages/noyau/src/frais/part-perso.ts` (utilise `repartir`, `soustraire`, `ajouter` de `../argent/index.js`) :
   - `repartirPiece({ ttc; tva; partPersoTtc })` → `{ societe: { ttc; ht; tva }; perso: { ttc } }` ; la TVA est répartie entre société et personne au prorata des TTC par `repartir(tva, [societeTtc, partPersoTtc])` (plus grand reste, aucune division) ; `societe.ht = societe.ttc − societe.tva` ;
   - égalités toujours vraies : `societe.ttc + perso.ttc = ttc` ; `societe.ht + societe.tva + perso.ttc = ttc` ;
   - refus `ErreurFrais('entree_invalide')` : part perso négative ou supérieure au TTC ; TVA négative ou supérieure au TTC ; valeurs non entières, `NaN`, `Infinity` ;
   - `partRemboursable(repartition, payeur)` → `societe.ttc` si `payeur = personne`, 0 sinon (jamais la part personnelle).
2. Tests nommés (montants inventés + cas NF-15 transposé) : `nf15-moitie-personnelle`, `part-perso-nulle`, `tout-personnel` (société 0 HT, 0 TVA), `tva-impaire-somme-exacte` (TVA 1 centime, moitié perso : la somme reste exacte), `somme-exacte-boucle` (1 000 cas à graine fixe : les deux égalités), `part-superieure-refusee`, `entrees-invalides` (NaN, Infinity, 1,5, −1), `paye-societe-rien-a-rembourser`.
