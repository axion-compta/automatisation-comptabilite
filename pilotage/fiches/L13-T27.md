## Contexte
Spec 13, fichier 05, R07 : `change.expliquer_ecart(ecart_id)` est en lecture seule et appelle la même route que l'écran ; réponse : le sens (gain ou perte), le montant, les deux taux avec leur source et leur date. R08 : l'écran dit seulement « gain de change » ou « perte de change » ; le numéro de compte n'apparaît qu'au second niveau ; aucun pourcentage de confiance. Tests MOT97-1 à MOT97-3 (0 écriture créée, 0 geste requis).

## À faire
1. `packages/noyau/src/change/explication.ts` :
   - `expliquerEcart(ecart { montant (centimes, signé : positif = perte); devise }, tauxPiece { tauxE8; source; date }, tauxPaiement { tauxE8; source; date })` donne `{ sens (gain, perte, aucun); montant (valeur absolue); devise; taux: [piece, paiement] }`, sans aucun numéro de compte ;
   - `detailSecondNiveau(explication, comptes { perte; gain })` donne `{ compte }` (aucun compte si sens `aucun`) ;
   - source ou date absente ou vide : `ErreurExplication('source_absente')` (pas d'explication sans source) ; taux nul, négatif ou non entier, montant non entier : `entree_invalide`.
2. Tests nommés : `perte-de-18-euros` (1 800 ; taux 92 000 000 et 95 000 000, sources fictives, dates 2026-10-07 et 2026-11-20), `gain`, `ecart-nul-aucun`, `source-absente-refusee`, `compte-absent-du-premier-niveau` (aucune valeur de la sortie ne vaut 656000 ni 756000 quand on les passe en second niveau), `second-niveau-donne-le-compte`, `entrees-invalides` (NaN, 1,5, Infinity, taux 0).
