## Contexte
Spec 15, EX-R4 et EX-R6 : en XLSX, toute cellule texte est écrite comme CHAÎNE, jamais comme formule ni avec une balise de formule ; montants en cellules numériques au format monétaire, dates en cellules date. Choix : un écrivain minimal (quelques parties XML et une archive) plutôt qu'une grosse bibliothèque de tableur : l'absence de formule vient de la construction même (aucun chemin du code n'écrit `<f>`). Placé dans le noyau pour être utilisé à la fois par le serveur en mémoire et par le faux serveur (navigateur). Seule dépendance : `fflate` (archive zip, licence MIT, sans dépendance, fonctionne dans Node et le navigateur).

## À faire
1. `packages/noyau/package.json` : ajouter `fflate` (version exacte) ; `pnpm install` met à jour `pnpm-lock.yaml`.
2. `packages/noyau/src/exports/xlsx.ts` :
   - `partiesXlsx({ nomFeuille; colonnes; lignes; total?; filtresRappeles? })` → `Record<string, string>` : `[Content_Types].xml`, `_rels/.rels`, `xl/workbook.xml`, `xl/_rels/workbook.xml.rels`, `xl/styles.xml` (un format monétaire, un format date), `xl/worksheets/sheet1.xml` ;
   - chaque cellule passe par `cellule()` de L15-T21 ; texte = `t="inlineStr"` avec `<is><t xml:space="preserve">` et échappement XML (`& < > " '`) ; caractère de contrôle interdit en XML (autre que tabulation, retour chariot, saut de ligne) = erreur `caractere_interdit` ; `centimes` = nombre en euros écrit à partir de `formater()` (virgule remplacée par un point, jamais de division flottante) avec le style monétaire ; date = numéro de série du tableur (`joursEntre` de L15-T01 depuis la date d'origine du format) avec le style date ;
   - `ecrireXlsx(...)` → `Uint8Array` = `zipSync` de `fflate` sur `partiesXlsx(...)`.
3. Tests nommés : `archive-lisible-six-parties` (`unzipSync`), `aucune-balise-formule` (aucun `<f` dans aucune partie, même avec `=SOMME(A1)`), `texte-en-chaine-inline`, `formule-prefixee-apostrophe`, `echappement-xml` (`<script>&"'`), `centimes-en-nombre-exact` (123456789 donne `1234567.89`, -5 donne `-0.05`), `date-en-numero-de-serie` (valeur attendue calculée à la main dans le test), `caractere-de-controle-refuse` (U+0001), `liste-vide-entetes-seulement`.

## Hors périmètre
Pas de route (L15-T39), une seule feuille, pas de largeur de colonne.

## Pièges
Fichiers communs : `pnpm-lock.yaml` et `packages/noyau/package.json` (le portier refuse toute PR qui les touche : fiche sensible, fusion manuelle, une seule PR de dépendance ouverte à la fois tous lots confondus). Garde des littéraux : la date d'origine du numéro de série (30/12/1899, convention du format, pas une valeur légale) se construit à partir de trois nombres, jamais comme chaîne AAAA-MM-JJ littérale, sur une ligne sans « délai » ni « durée ». Règles du noyau : pas de division, pas de `toFixed`. Sensible (dépendance, sécurité) : relecture Opus.
