## Contexte
Le contrat fait foi (ADR 0002). Même méthode que L07-T14 : contrat déclaré et figé d'abord, serveur branché sur un fichier par domaine qui répond « non implémenté » (501), puis domaines implémentés en parallèle (L08-T36, L08-T37) sans toucher les fichiers communs. Fichier 07 : demandes des personnes traitées par l'administrateur de la société. Routes sans préfixe de société, comme le lot 01. Étiquettes `acces:*` comme le lot 07 (lues par la garde L07-T22) : les droits des personnes restent possibles dans TOUS les états d'accès (`acces:compte`). La recherche d'une personne vient dans L08-T33, qui ajoute sa route à ce domaine.

## À faire
1. `packages/contrat/src/domaines/personnes.ts` (enums = constantes de L08-T01, recopiées en `z.enum` et comparées par test) :
   - `listerDemandes` (`GET /personnes/demandes`, `tags: ['acces:compte']`) → `{ body: DemandeVue[] }` avec `DemandeVue = { id; type; recue_le; echeance; etat; en_retard: booléen; a_rappeler: booléen; issue: Issue | null; conserve_jusqu_au: date | null; source_motif: chaîne | null }` (le motif libre n'est PAS renvoyé dans la liste) ;
   - `enregistrerDemande` (`POST /personnes/demandes`, `successStatus: 201`, en-tête Idempotency-Key, corps `{ type; recue_le }`) → `DemandeVue` ;
   - `traiterDemande` (`POST /personnes/demandes/{id}/traitement`, en-tête Idempotency-Key, corps `{ issue; motif?: chaîne 1 à 500 après trim; source?: chaîne; inclure_autres_personnes?: booléen }`) → `DemandeVue` ; erreurs `REGLAGE_ABSENT` 503 (déclarée sur les trois routes), `DEMANDE_INTROUVABLE` 404, `DEJA_TRAITEE` 409, `TRANSITION_INTERDITE` 409, `ISSUE_NON_PERMISE` 422, `MOTIF_MANQUANT` 422, `SOURCE_MANQUANTE` 422.
2. `personnes.ts` exporte `export const personnes = { listerDemandes, enregistrerDemande, traiterDemande }` ; `routes.ts` ajoute la clé `personnes` (même forme que `sante`) sans toucher les autres clés ; `openapi.ts` seulement si la génération ne parcourt pas déjà toutes les clés ; régénérer `openapi.json`.
3. `apps/serveur/src/domaines/personnes.ts` : `implementerPersonnes(os, options: OptionsExploitation)`, signature figée, bouchons `new ORPCError('NOT_IMPLEMENTED')` pour les trois routes ; branché dans `app.ts` avec `options.exploitation ?? {}`.
4.
