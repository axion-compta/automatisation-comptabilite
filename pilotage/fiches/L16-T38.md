2. `etat-acces-console.ts` :
   - Port `PortConsole { lireEtat(clientId): Promise<EtatVoulu>; envoyerMesures(m): Promise<void> }`.
   - `synchroniserEtat(port, transitions)` : l'état lu est appliqué par les transitions existantes ; un réglage local contraire est ignoré et journalisé (`source: 'console'`).
   - Console injoignable : dernier état connu conservé, aucun passage automatique à un état plus permissif.
   - `remonterMesures(port, compteurs)` : codes et compteurs entiers seulement.
3. Tests nommés : `etat-console-applique-sans-reglage-local`, `reglage-local-ignore-et-journalise`, `console-injoignable-dernier-etat`, `version-ancienne-ignoree`, `mesures-sans-contenu`.
