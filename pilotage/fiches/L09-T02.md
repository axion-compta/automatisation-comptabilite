## Contexte
Spec 09, §01 règles 3 et 4 : « VIES indisponible → `non_verifie`, jamais supposé valide » ; Sirene : « API en panne → saisie à la main, rien de bloqué ». Cas P02 et P03 (saisie à la main ouverte en moins de 5 s, origine `saisie_personne`). Les vrais clients Sirene et VIES sont prévus par L10-T53 et L14-T37 : ici, seulement la logique de repli, avec des sources passées en argument.

## À faire
1. `packages/noyau/src/profil/identite-externe.ts` :
   - interfaces `SourceSirene { chercher(siren: string, signal: AbortSignal): Promise<{ trouve: true; denomination: string; forme: string; dateReponse: string } | { trouve: false }> }` et `SourceVies { verifier(numero: string, signal: AbortSignal): Promise<'valide' | 'invalide'> }` ;
   - `rechercherSirene(source, siren, { delaiMaxMs, horloge })` : SIREN invalide (L09-T01) = `{ etat: 'refuse', motif: 'siren_invalide' }` sans appel ; réponse = `{ etat: 'trouve', origine: 'sirene', ... }` ; absence = `{ etat: 'introuvable' }` ; exception, rejet ou dépassement de `delaiMaxMs` = `{ etat: 'saisie_manuelle', origine: 'saisie_personne' }` ; le signal est annulé au dépassement ;
   - `statutVies(source, numero, { delaiMaxMs, horloge })` → `'verifie' | 'invalide' | 'non_verifie'` ; clé fausse (L09-T01) = `invalide` sans appel ; toute panne = `non_verifie` ;
   - `delaiMaxMs` est un réglage passé en argument (entier > 0, sinon `ErreurProfil('delai_invalide')`) ; `horloge` injectable (`setTimeout` et `clearTimeout`).
2. Tests nommés (fausses sources, minuterie simulée de vitest) : `sirene-trouve`, `sirene-introuvable`, `sirene-panne-saisie-manuelle` (rejet), `sirene-delai-depasse-p03` (délai de test inventé, la source ne répond jamais : `saisie_manuelle` à l'échéance, signal annulé), `siren-invalide-sans-appel` (compteur d'appels = 0), `vies-valide-verifie`, `vies-panne-jamais-verifie` (rejet, délai dépassé, réponse inattendue `'peut-etre'`), `delai-invalide-refuse` (0, -1, NaN, Infinity, 1.5).

## Hors périmètre
Aucun appel réseau réel, aucun cache (lot 14), aucune route (L09-T33).

## Pièges
Règles du noyau comme L01-T06. Une réponse inattendue de VIES n'est JAMAIS `verifie`. Nettoyer la minuterie après réponse (pas de minuterie pendante : vérifier `vi.getTimerCount()` à 0). Le délai de 5 s de la spec est un réglage, jamais écrit dans le module.
