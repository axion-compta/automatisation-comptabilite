## Contexte
Spec 03, §01 (conventions d'API) : « Pas de route `deposer`, `transmettre`, `envoyer_administration`. Test CI : liste des routes sans ces mots. » Principe 1 du bloc : préparer, jamais déposer ; le client dépose lui-même et enregistre son accusé. Ce test doit exister AVANT les routes TVA et FEC du lot (L03-T32 à L03-T34), pour que chacune passe dessous.

## À faire
1. `packages/contrat/src/__tests__/routes-interdites.test.ts` (seul fichier touché) :
   - fonction locale au test `routesInterdites(document: { paths?: Record<string, Record<string, { operationId?: string }>> })` → liste `{ methode, chemin, operationId, fragment }` ;
   - fragments interdits, comparés sans casse et sans accents (normalisation NFD puis retrait des diacritiques) : `deposer`, `depot`, `transmettre`, `transmission`, `envoyer_administration`, `envoyer-administration`, `teledeclarer` ;
   - on cherche dans le chemin ET dans l'`operationId` ;
   - le document est celui que produit `genererOpenapi()` (déjà exporté par `packages/contrat/src/index.ts`), donc TOUS les domaines du contrat.
2. Tests nommés : `contrat-actuel-sans-route-interdite`, `fragment-dans-le-chemin-detecte` (document forgé `/tva/declarations/{d}/deposer`), `fragment-dans-operation-id-detecte` (`operationId: 'transmettreDeclaration'`), `accents-et-casse-ignores` (`/Déposer`), `accuse-autorise` (`/tva/declarations/{d}/accuse` n'est PAS refusé : le client enregistre son accusé, ce n'est pas une transmission).

## Hors périmètre
Aucune route ajoutée. Pas de modification de `openapi.ts`, `routes.ts` ni `openapi.json`.

## Pièges
Le fragment « depot » couvre aussi « dépôt » après retrait des accents : vérifier qu'aucune route existante (écritures, plan, tiers) ne le contient. La spec 10 prévoit `POST /pv/{id}/deposer-signe` : cette route devra être nommée autrement (ex. `piece-signee`) quand elle sera écrite (noté dans LOT-03-PLAN). Cas limites exigés : document sans `paths` (liste vide, pas d'exception), chemin vide, `operationId` absent.
