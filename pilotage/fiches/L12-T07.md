## Contexte
Spec 12, `02-controles-coherence`, CC-K13 (V3-CTL-060) : « Paiement sans pièce = débit bancaire de type achat, non neutralisé (virement interne, emprunt, impôt), non qualifié personnel, sans motif pas de pièce nécessaire. Distinct de à qualifier (type inconnu). Le nombre est calculé par une seule fonction. » M ; bloque la validation du mois si le montant ≥ seuil réglable. Cas CT-14 : 47 débits (38 rapprochés, 2 virements internes, 1 URSSAF, 1 personnel qualifié, 1 frais « pas de pièce nécessaire », 3 sans pièce 500,00 + 72,40 + 186,00, 1 de type inconnu) : 3 paiements sans pièce pour 758,40 ; 1 « à qualifier » compté à part.

## À faire
1. `packages/noyau/src/controles/regles/paiement-sans-piece.ts` :
   - `DebitBancaire { id; montant: Centimes; type: 'achat' | 'virement_interne' | 'emprunt' | 'impot' | 'inconnu'; rapproche: boolean; qualification?: 'personnel' | 'pas_de_piece_necessaire' }` ;
   - `compterPaiementsSansPiece(debits)` → `{ sansPiece: { nombre; total: Centimes; ids: string[] }; aQualifier: { nombre; total; ids } }` (ids triés) : LA seule fonction de comptage, réutilisée par la santé (L12-T37) ;
   - `regleCCK13` : id `CC-K13`, version 1, gravité `M`, bloque `[]`, déclencheurs `continu`, `nocturne`, `avant_cloture`, `a_la_demande` : ALERTE si nombre > 0, `valeur` = nombre, `ecartCentimes` = total ;
   - `regleCCK13S` : id `CC-K13S`, gravité `B`, bloque `validation` : objet `{ debits; seuil?: Centimes }` ; ALERTE si total ≥ seuil ; seuil absent = exception.
2. `packages/noyau/src/controles/regles/__tests__/paiement-sans-piece.test.ts`, tests nommés : `CT-14` (les 47 débits construits dans le test), `type-inconnu-compte-a-part`, `neutralises-exclus`, `personnel-qualifie-exclu`, `seuil-exact-bloque` (total = seuil : ALERTE ; seuil + 1 : OK), `liste-vide-ok`, `ordre-inverse-meme-resultat`, `montants-invalides`.
