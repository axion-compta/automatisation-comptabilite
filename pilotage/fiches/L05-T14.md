## Contexte
Spec 05, fichier 03 §4 : « celle-ci », « les trois dernières » sont résolues dans un ordre fixe : sélection, puis pièce ouverte, puis liste affichée triée. Doute = question, jamais une écriture sur un objet supposé. Jeu du fichier 10 : 0 écriture sur objet supposé.

## À faire
1. `packages/noyau/src/chat/designations.ts` :
   - `analyserDesignation(phrase)` → `{ sorte: 'celle_ci' | 'ces' | 'n_dernieres' | 'n_premieres'; n? } | null` ; nombres en chiffres (« 3 ») ou en lettres de un à dix (« trois », « deux ») ; insensible à la casse, aux accents et aux espaces multiples ;
   - `resoudre(designation, { selection, pieceOuverte, listeAffichee })` → `{ sorte: 'cibles'; ids } | { sorte: 'question'; choix: string[] }` : sélection non vide d'abord ; sinon pièce ouverte (seulement pour `celle_ci`) ; sinon liste affichée (déjà triée par l'appelant) ; `n` > taille de la liste ou plusieurs sources possibles et contradictoires = question avec 2 à 5 choix ; rien = question.
2. Tests nommés : `celle-ci-prend-la-selection`, `celle-ci-prend-la-piece-ouverte`, `trois-dernieres-en-lettres`, `trois-dernieres-en-chiffres`, `n-plus-grand-que-la-liste-question`, `rien-a-designer-question`, `n-invalide` (« zéro », « -1 », « 2,5 », « onze »), `ordre-de-la-liste-respecte` (liste inversée = autres ids), `phrase-sans-designation-null`.

## Hors périmètre
Pas de compréhension générale de la langue : seulement ces formes. Pas de tri (l'appelant trie).

## Pièges
Règles du noyau (eslint). La question rend des identifiants, jamais du texte affiché.
