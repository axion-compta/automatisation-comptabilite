## Contexte
Liste des écrans : T08 « Ce qui demande mon attention » = la cloche (tiroir, pas de route). Spec 15, AL-R4, AL-R5, PR-R5 : la cloche liste les alertes ouvertes, plus récentes d'abord ; reporter, ignorer, annuler pendant 10 s ; notifications lues, « tout lire ». Le tiroir est monté dans la coque par L15-T53.

## À faire
1. `donnees/actions-alerte.ts` : `agirSurAlerte(exercice, id, action: 'reporter' | 'ignorer' | 'annuler', corps)` et `marquerNotification(id | 'tout')` : `POST` avec `Idempotency-Key` = `crypto.randomUUID()` (même clé si on rejoue la même intention), corps validé par le schéma du contrat ; erreurs rendues par code (`ErreurLecture` de `api.ts` réutilisée sans modifier `api.ts`) ; après succès : `relireApresAction` (L15-T49) sur alertes, compteurs, tableau de bord.
2. `Cloche.tsx` : tiroir (`role="dialog"`, `aria-modal`, piège du focus, Échap ferme, focus rendu) ; deux sections : alertes (`CarteAlerte` avec actions, `joursReport = [1, 3, 7]`, `motifMin = 5`) et notifications (lue / non lue, « Tout lire ») ; après une action, message « Annuler » visible 10 s (minuterie), qui appelle `annuler` ; 409 version = relit la liste et le dit en un mot.
3. `packages/textes/src/ecrans/t08.ts` : textes au vouvoiement.
4. Tests nommés (jsdom, `demarrerNoeud`, minuteries simulées) : `liste-des-alertes-ouvertes`, `reporter-met-a-jour-la-liste`, `ignorer-avec-motif`, `annuler-dans-les-dix-secondes`, `annuler-disparait-apres-dix-secondes`, `conflit-409-relit`, `tout-lire`, `echap-ferme-et-rend-le-focus`, `meme-intention-meme-cle` (double clic : une seule action côté serveur).
