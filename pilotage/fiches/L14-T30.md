## Contexte
Une seule route de lecture : `GET /exercices/{exercice}/juridique`, qui rend l'état des obligations de l'exercice (rapport de gestion, convocation, confidentialité, cartes). Comme les domaines `plan` et `tiers` (L01-T23, L01-T25) : schémas zod exportés, réponse exportée (convention L01-T52), service pur sur les données fictives (L14-T29), serveur en mémoire qui implémente TOUT le contrat (`implement(contrat)` dans `apps/serveur/src/app.ts`). La mention est un CODE (`prepare_par_ia`), la phrase vit dans `packages/textes`. Aucune route d'écriture : valider, choisir, déposer passent par L14-T39 (bloquée).

## À faire
1. `packages/contrat/src/domaines/juridique.ts` : schémas `ObligationsJuridiques` (champs de `genererJuridique()`, L14-T29 ; `mention: z.literal('prepare_par_ia')`) et `ReponseObligationsJuridiques` ; route oRPC `lireObligationsJuridiques` (`GET /exercices/{exercice}/juridique`, `operationId: 'lireObligationsJuridiques'`) ; erreur `EXERCICE_INCONNU` (404).
2. `juridique-service.ts` : service pur sur `genererJuridique()` (import relatif, comme `tiers-service.ts`).
3. `routes.ts` : ajouter la clé `juridique` à `contrat` SANS toucher aux autres clés ; régénérer `openapi.json` (`pnpm contrat:openapi`).
4. `apps/serveur/src/domaines/juridique.ts`, branché dans `app.ts`.
5. Tests nommés : `obligations-de-la-sarl`, `obligations-de-la-sci-sans-convocation`, `mention-prepare-par-ia`, `exercice-inconnu-404`, `identifiant-vide-refuse`, `openapi-contient-la-route`, `serveur-repond-aux-obligations` (Fastify `inject`).
