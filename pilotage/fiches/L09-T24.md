## Contexte
Spec 09, §03 règle 7 : quand une valeur `valide` s'avère fausse après diffusion, la ligne fautive n'est JAMAIS modifiée : elle passe à `retire` et une ligne corrigée est créée, avec sa source, sa date de relevé et ses deux lectures. Le paquet (lignes retirées, lignes nouvelles, motif, validateur nommé) est daté et versionné. Le rapport d'impact liste par société : brouillons recalculés, déclarations non déposées recalculées, écritures validées et périodes déposées touchées ; pour ces dernières rien n'est modifié, une régularisation est PROPOSÉE ; chaque société reçoit une carte.

## À faire
1. `packages/parametres/src/correctif.ts` :
   - `PaquetCorrectif { version: string; date; motif (non vide); validateur: { id; type: 'personne' }; retraits: { cle; effet_debut }[]; ajouts: ParametreSource[] }` ;
   - `appliquerPaquet(catalogue, paquet)` → NOUVEAU catalogue : chaque ligne visée passe à `statut = retire` (toutes les autres propriétés identiques), les ajouts sont ajoutés ; refus `ligne_introuvable`, `retrait_sans_remplacement` (une clé retirée sans ajout pour la même clé et la même période), `validateur_absent`, `version_deja_appliquee` (registre des versions passé en argument) ;
   - `rapportImpact(ancien, nouveau, societes: { id; objets }[])` → par société `{ brouillons: number; declarationsNonDeposees: periodes[]; ecrituresValideesTouchees: number; periodesDeposeesTouchees: periodes[]; regularisationProposee: boolean; carte: boolean }` : seules les dates à partir de l'effet comptent ; aucune donnée d'une société dans le rapport d'une autre ;
   - après application, `parametreAuJour` (L01-T14) ne rend plus la ligne retirée.
2. Tests nommés (clés et valeurs inventées) : `ligne-retiree-jamais-modifiee` (comparaison champ par champ), `ligne-corrigee-ajoutee`, `lecture-apres-paquet` (veille, jour, lendemain de l'effet, L01-T14), `retrait-sans-remplacement-refuse`, `validateur-absent-refuse`, `version-deja-appliquee`, `rapport-par-societe`, `deposees-regularisation-proposee`, `catalogue-d-entree-non-modifie`.

## Hors périmètre
Aucune vraie valeur ; pas de diffusion réelle ; pas de carte affichée (codes seulement).

## Pièges
Sensible (valeurs légales, déclarations). Ne pas modifier `au-jour.ts`. Rejouer les dates frontières (règle 5) dans `lecture-apres-paquet`.
