## Contexte
Spec 15, TB-R4. Le calcul des 5 sous-indicateurs appartient au catalogue des contrôles (spec 12, `GET /sante`) : ce module le CONSOMME. Trois arcs (Pièces, Banque, TVA) regroupent les 5 sous-indicateurs ; la répartition est une proposition (point T2) : elle est donc un ARGUMENT. Couleur en entiers : vert si `nombre × 100 ≥ seuilVert × sur`. Seuils = paramètres (point T3 : HYPOTHÈSE), jamais en dur. Couleur d'un arc et couleur globale = la pire des sous-indicateurs connus. Donnée absente : pointillés, ni vert ni rouge. Aucun pourcentage rendu sans son nombre.

## À faire
1. `anneau.ts` :
   - `SousIndicateur { code; nombre: number; sur: number } | { code; absent: true }` ; `Seuils { vertPourCent: number; orangePourCent: number }` (entiers de 0 à 100, orange ≤ vert, sinon erreur `seuils_invalides`) ;
   - `couleurDe(si, seuils)` → `Couleur | 'pointille'` ; `sur = 0` = pointillé ; `nombre` ou `sur` négatif, non entier, `NaN`, infini, ou `nombre > sur` = erreur `valeur_invalide` ;
   - `calculerAnneau(sous, regroupement: Record<'pieces' | 'banque' | 'tva', string[]>, seuils)` → `{ arcs: { code; couleur | 'pointille'; sous: [...] }[]; global; centre: { mot: string; nombre: number; sur: number } | { mot: 'donnees_absentes' } }` ; un code de regroupement inconnu des sous-indicateurs = erreur `regroupement_invalide` ; le résultat n'a AUCUN champ `pourcentage`.
2. Tests nommés (seuils inventés, ex. 70 et 40) : `vert-a-la-limite-exacte` (nombre × 100 = seuil × sur), `orange-juste-sous-le-vert`, `rouge-sous-l-orange`, `sur-zero-pointille`, `valeurs-invalides-refusees` (`-1`, `1.5`, `NaN`, `Infinity`, nombre > sur), `arc-prend-la-pire-couleur`, `absent-ignore-dans-la-pire-couleur`, `tout-absent-anneau-pointille`, `aucun-champ-pourcentage` (parcours récursif du résultat), `seuils-invalides-refuses` (orange > vert, 101, -1).

## Hors périmètre
Pas de calcul des sous-indicateurs (spec 12), pas de dessin (L15-T47).

## Pièges
Aucune division : comparer des produits d'entiers. Aucun seuil réel dans `src` ni sur une ligne de `src` qui contient le mot « seuil » avec un nombre autre que 0 ou 1 (garde L01-T02) : la borne 100 s'écrit via une constante nommée `CENT` déclarée sur une ligne sans ce mot.
