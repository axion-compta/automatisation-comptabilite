## Contexte
Spec 05, fichier 04 §6 : toast juste après l'application, puis annulation depuis l'historique tant que l'objet n'est ni validé ni envoyé ; ensuite le chat propose la contre-passation (niveau M), jamais une modification. Annuler = appliquer l'« avant » gardé ; test : empreinte des lignes avant = après annulation. Cas T-CHT-3 (annulation à 9 s) et T-CHT-4 (à 16 min).

## À faire
1. `packages/noyau/src/chat/annulation.ts` :
   - `modeAnnulation({ appliqueLe, maintenant, objetValideOuEnvoye, toastMs, historiqueMs })` → `'toast' | 'historique' | 'contre_passation'` ; maintenant < appliqueLe = `ErreurChat('parametre_invalide')` ; `toastMs` > `historiqueMs`, valeurs non entières ou négatives = `parametre_invalide` ;
   - `empreinteCanonique(valeur)` : chaîne stable (clés triées à tous les niveaux, tableaux dans l'ordre) ; refuse `undefined`, fonctions, NaN, Infinity (`parametre_invalide`) ;
   - `annuler(etatActuel, apres, avant)` : si `empreinteCanonique(etatActuel) !== empreinteCanonique(apres)` (objet changé depuis) = `ErreurChat('annulation_expiree')` ; sinon rend une copie profonde d'`avant`.
2. Tests nommés (durées inventées, pas celles de la spec) : `dans-le-toast`, `borne-du-toast` (exactement toastMs = historique), `dans-l-historique`, `borne-de-l-historique` (exactement historiqueMs = contre-passation), `objet-valide-contre-passation`, `horloge-reculee-refusee`, `reglages-invalides` (NaN, Infinity, -1, 1.5, toast > historique), `empreinte-independante-de-l-ordre-des-cles`, `retour-exact` (empreinte avant = après annulation), `objet-change-depuis-refuse`.

## Hors périmètre
Pas de contre-passation elle-même (L01-T09), pas de route (L05-T38).

## Pièges
Règles du noyau (eslint). Les bornes doivent être testées des deux côtés : Stryker tue un `<` changé en `<=`. Fiche sensible (argent : retour d'état).
