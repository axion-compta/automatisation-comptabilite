## Contexte
Spec 05, fichier 04 §4 : 7 types de cartes au MVP ; JSON invalide = carte « affichage indisponible » ; aucun HTML, aucun lien ni image venus de l'extérieur. Carte de téléchargement : lien interne seulement.

## À faire
1. `RenduCarte.tsx` : `{ brut: unknown; libelles; onOuvrir(source) }` ; passe `brut` par `validerCarte` (L05-T02) DANS le composant (jamais confiance au parent) ; un sous-rendu par type (écriture, pièce, liste, proposition résumée, rapprochement, TVA, téléchargement) ; montants par `Montant` ; lien de téléchargement rendu comme bouton qui appelle `onOuvrir`, jamais `<a href>` vers l'extérieur ; type `indisponible` = état d'erreur de L01-T29 avec le libellé reçu.
2. Tests nommés : `sept-types-rendus` (un test par type, 7 cas regroupés en tableau), `json-invalide-indisponible`, `html-dans-un-champ-indisponible` (A2-29), `lien-externe-indisponible`, `aucun-lien-href-externe` (aucun `a[href^=http]` dans le DOM), `liste-vide`, `liste-longue-pagination` (plus de 50 éléments : Tableau de L01-T30 ou « voir tout »), `montant-zero-affiche`, `brut-null-ou-undefined`, `champ-manquant-indisponible`.
