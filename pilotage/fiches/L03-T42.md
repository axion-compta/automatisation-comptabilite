## Contexte
Spec 03, §05 : table `echeance_type` du paquet signé (code, formulaire, règle de date, ancrage : création, clôture, année civile, période ; condition de profil ; statut de la source ; niveau : préparée, alerte, rappel seul ; rappels ; interdiction de « ne plus rappeler »). Règle 2 : source `non_verifie` = « date à vérifier ». Règle 5 : « Ne plus me le rappeler » interdit pour une échéance légale ; « Plus tard » et « Me prévenir moins tôt » permis. E1 et E2 : approbation après clôture et alerte avant ; E5 : société sans salarié → aucune échéance sociale. Tous les délais sont des paramètres (D31).

## À faire
1. `packages/noyau/src/echeances/catalogue.ts` (utilise `ajouterMois`, `ajouterJours` de L03-T19 et `reporter` de L03-T41) :
   - `TypeEcheance { code; ancrage: 'creation' | 'cloture' | 'annee_civile' | 'periode'; decalage: { mois: number; jours: number }; report: 'suivant' | 'precedent' | 'aucun'; condition: { formes?: string[]; avecSalaries?: boolean; avecVehicule?: boolean; regimesTva?: string[] }; statutSource: 'verifie' | 'non_verifie'; niveau; rappelsJours: number[]; alerteJours?: number; legale: boolean }` ;
   - `echeancesDe(types, profil, ancres: { creation?; clotures: string[]; anneesCiviles: number[]; finsDePeriode: string[] }, calendrier)` → `{ code; dateLimite; dateAVerifier: boolean; rappels: string[]; alerte?: string; niveau }[]` triées par date puis code ; type dont la condition n'est pas remplie = aucune échéance ; ancre absente = aucune échéance (pas de date inventée) ;
   - `actionRappel(echeance, action: 'plus_tard' | 'moins_tot' | 'ne_plus_rappeler', type)` → refus `interdit_echeance_legale` pour `ne_plus_rappeler` si `legale`.
2. Tests nommés (délais INVENTÉS, ex. 5 mois et 40 jours ; jamais les délais réels) : `approbation-depuis-la-cloture` (forme de E1), `exercice-decale` (forme de E2), `report-au-jour-ouvre`, `source-non-verifiee-a-verifier`, `sans-salarie-aucune-echeance-sociale` (E5), `avec-vehicule-alerte`, `ne-plus-rappeler-interdit-si-legale`, `plus-tard-permis`.

## Hors périmètre
Pas de formulaire préparé (IS, liasse, CFE : lots ultérieurs). Pas de route (L03-T34 sert des données fictives). Le premier exercice de 16 mois (E3) : test à écrire quand les règles d'IS existeront.

## Pièges
Règles du noyau comme L03-T01. Aucun délai réel : le test échoue si une valeur comme le délai légal d'approbation apparaît en dur dans src (garde L01-T02). Cas limites exigés : `decalage` NaN ou non entier (refus), `rappelsJours` négatifs (refus), liste de types vide, deux types de même code (refus).
