## Contexte
Suite de L09-T49, créée par L00-T84 : l'ancienne L09-T49 exigeait le préfixe de société sur toutes les routes du lot (L09-T30 à T35). Les régimes (L09-T31, `/profil/regimes/*`), les paramètres (L09-T32, `/parametres`) et l'identité (L09-T33, `/siren/*`, `/tva-intracom/*`) n'étaient pas dans ses fichiers d'origine : cette fiche reprend l'exigence, sans la retirer. Mêmes décisions de Will que L09-T49 (D42, D29 du 09/11/2026 ; J3a du 07/11/2026 avec ses quatre conditions).

Spec 09, §04 : API sous le préfixe `PREFIXE_ROUTES_SOCIETE` (L00-T50). Étanchéité (lot 13) : société prise dans la session ; même 404 pour une société d'autrui.

## À faire
1. Contrat : chemins de `regimes.ts`, `parametres.ts`, `identite.ts` sous le préfixe, par `cheminSociete` comme L09-T49 ; régénérer `openapi.json`.
2. Vrai serveur : routes exigeant la session posée au contexte par L09-T49 (`sessionDeRequete`) ; sans session, 401 ; société du chemin comparée à `societeId` ; société d'autrui : 404 au même statut et au même corps qu'une route inconnue (`{ code: 'INTROUVABLE', status: 404 }`). `app.ts` : seulement le passage de cette session à ces trois groupes de routes.
3. Faux serveur : mêmes handlers aussi servis sous le chemin préfixé ; chemins sans préfixe servis tant que les écrans E45 et E39 les lisent. Suite commune `suite-profil.ts` adaptée, sans retirer d'assertion.
4. Tests existants adaptés au chemin préfixé et à une session fictive (`soc-lemoine`, `creerFauxSessions`, en-tête `authorization: Bearer` d'un jeton fictif), sans retirer ni affaiblir une assertion.
5. Tests nommés : `societe-d-autrui-404-meme-corps-regimes-parametres-identite`, `sans-session-401-regimes-parametres-identite` (serveur, `profil-isolation.test.ts`, sur chaque route) ; `chemin-sans-prefixe-404` (serveur : `/profil/regimes/tva`, `/parametres`, `/siren/{siren}`, `/tva-intracom/{numero}/verification` sans préfixe) ; `chemins-prefixes-dans-l-openapi` (contrat : plus aucun de ces chemins sans préfixe).
6. Règle de séparation de L09-T49 (aucune adresse, aucun secret, valeurs d'exemple fictives) reprise telle quelle.

## Hors périmètre
Réauthentification et `confirmePar` (L09-T52) ; routes du profil, champs et changements (L09-T49) ; services du contrat ; base ; écrans ; noyau ; dans `app.ts`, tout le reste.

## Pièges
Sensible (sécurité, droits) : double relecture. Exécuter après la fusion de L09-T49 et L09-T52 (statut fait ; fichiers partagés dont `app.ts`). Ne pas défaire la session de L09-T49. Recoupement de `apps/serveur/src/app.ts` avec L09-T52, L04-T51 et L06-T38 (avertissements de `garde:fiches` attendus). Une suite commune qui passe sans session sur le vrai serveur est un défaut.
