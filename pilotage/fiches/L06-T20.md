## Contexte
Spec 06, `06-securite-applicative.md` §4 (PLA-178) : marqueur lisible par machine (`genere_par_ia: true`, modèle, version) dans les métadonnées des exports et brouillons d'e-mails produits par un modèle ; absent d'un texte saisi par une personne. PLA-143 : mention « Préparé par IA, à valider » sur chaque proposition (le texte affiché est dans `packages/textes`, pas ici).

## À faire
1. `packages/noyau/src/securite/marqueur-ia.ts` :
   - `marquerGenereParIA(meta, { modele, version })` → copie de `meta` avec `genere_par_ia: true`, `modele`, `version` ; modèle ou version vides → `ErreurSecurite('argument_invalide')` ;
   - `marquerModifieParPersonne(meta, personneId)` → garde le marqueur et ajoute `modifie_par_personne: true` (un brouillon d'IA retouché reste d'origine IA) ;
   - `metaSaisieHumaine(meta)` → copie SANS `genere_par_ia`, `modele`, `version`, `modifie_par_personne` (texte écrit de zéro par une personne) ;
   - `estGenereParIA(meta)` → booléen strict (`genere_par_ia === true`, pas une chaîne `'true'`).
2. Tests nommés : `marqueur-pose`, `modele-vide-refuse`, `retouche-garde-le-marqueur`, `saisie-humaine-sans-marqueur`, `chaine-true-n-est-pas-un-marqueur`, `meta-d-entree-non-modifiee`, `autres-champs-conserves`.

## Hors périmètre
Pose du marqueur dans les exports et les e-mails (lots concernés, quand ils produisent du texte d'IA).
