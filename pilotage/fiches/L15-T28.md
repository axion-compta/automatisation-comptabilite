## Contexte
Spec 15, PR-R1 et PR-R2. Exception écrite à la règle de version : pour les préférences, la DERNIÈRE ÉCRITURE GAGNE, aucun 409. Conflit entre deux appareils : clé par clé, selon `modifie_le_client` borné par l'horloge du serveur (tolérance de quelques minutes). Premier lancement : sans `chat_etat` d'origine `personne` et avec `premier_lancement.termine = false`, la lecture rend `chat_etat = elargi` (origine `defaut`). Fin de l'installation guidée : `premier_lancement.termine = true` et, SEULEMENT si `chat_etat` n'a pas été choisi par la personne, `chat_etat = normal`. Un choix de la personne n'est jamais écrasé.

## À faire
1. `preferences/fusion.ts` :
   - `Ligne { cle; appareil; valeur; origine: 'defaut' | 'personne' | 'systeme'; modifieLe: number (ms) }` ;
   - `appliquerEcriture(lignes, ecriture: { cle; appareil; valeur; modifieLeClient?: number }, { maintenant: number; toleranceMs: number })` : horodatage retenu = `modifieLeClient` borné à `[maintenant - toleranceMs, maintenant + toleranceMs]`, ou `maintenant` s'il est absent ; écrase seulement si l'horodatage retenu est ≥ celui en place ; origine `personne` ; entrée non modifiée ; nombres non entiers ou non finis = erreur ;
   - `lirePreferences(lignes, appareil, defauts)` : valeur de l'appareil, sinon `tous`, sinon défaut ; règle du premier lancement appliquée ici ;
   - `terminerInstallation(lignes, maintenant)` → nouvelles lignes (règle ci-dessus, origine `systeme`).
2. Tests nommés : `derniere-ecriture-gagne`, `ecriture-plus-ancienne-ignoree`, `horloge-client-en-avance-bornee`, `horloge-client-en-retard-bornee`, `cle-par-cle-independantes`, `premier-lancement-elargi`, `fin-installation-normal-si-pas-choisi`, `choix-personne-jamais-ecrase`, `horodatages-invalides-refuses` (`NaN`, `Infinity`, `1.5`).
