## Contexte
Spec 15, TB-R1 : « Un seul service `chiffres` calcule chaque indicateur ; tableau de bord, compteurs, chat et rapport l'appellent tous. Aucun autre calcul du même indicateur n'est permis (test de recherche dans le code). » Le calcul est dans `packages/noyau/src/tableau-de-bord/chiffres.ts` (L15-T07).

## À faire
1. `source-unique.test.ts` : liste les fichiers suivis par git (`git ls-files`) sous `apps/*/src` et `packages/*/src`, hors tests ; fonction pure `violations(fichiers: { chemin; texte }[])` testée sur des fichiers forgés PUIS appliquée au dépôt réel :
   - une seule définition exportée de `calculerChiffres`, `chiffreAffaires`, `resultatProvisoire`, `tresorerie`, et elle est dans `chiffres.ts` ;
   - aucun fichier de `apps/web/src` n'importe `livres/balance` ni `tableau-de-bord/chiffres` (le front lit les chiffres par l'API, il ne les recalcule pas).
2. Tests nommés : `une-seule-definition`, `definition-en-double-detectee` (fichier forgé), `front-n-importe-pas-la-balance` (fichier forgé rouge), `depot-reel-sans-violation`.

## Hors périmètre
Aucun changement de code de production.

## Pièges
Le test doit tourner sous Windows et Linux (chemins normalisés en `/`). Ne pas lire `node_modules` ni `dist`. Un faux positif bloquerait tous les lots : s'en tenir aux deux règles ci-dessus.
