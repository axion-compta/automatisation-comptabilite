## Contexte
Spec 05, fichier 07 §3 : tout vit dans la base de la société ; aucune mémoire partagée entre sociétés. Chaque correction humaine devient un exemple. Plusieurs corrections concordantes (même fournisseur, même compte) font PROPOSER une règle ; la société la valide (niveau M) ; rien n'est appliqué seul. Fichier 03 §5 : « Non, c'est faux » validé devient un exemple.

## À faire
1. `packages/noyau/src/agents/curateur.ts` :
   - `ajouterCorrection(exemples, { societe; fournisseur; compte; par: 'personne' | 'piece'; le })` : `par: 'piece'` refusé (`ErreurChat('parametre_invalide')`) ; même correction (mêmes champs et même date) non dupliquée ;
   - `reglesAProposer(exemples, societe, { concordantes })` → `{ fournisseur; compte; niveau: 'M'; etat: 'proposee' }[]` : seulement la société demandée ; `concordantes` corrections au moins vers le même compte ET aucune correction plus récente vers un autre compte ; jamais d'état `appliquee` ;
   - `exemplesDe(exemples, societe)`.
2. Tests nommés : `correction-devient-exemple`, `correction-par-une-piece-refusee`, `seuil-de-concordance-exact` (n - 1 : rien ; n : une règle), `correction-contraire-plus-recente-annule`, `aucune-fuite-entre-societes`, `regle-jamais-appliquee`, `doublon-ignore`, `reglage-invalide` (0, -1, 1.5, NaN, Infinity), `liste-vide`.

Pas de stockage (L05-T56), pas de validation de la règle (outil M, plus tard).
