## Contexte
Spec 03, §09 : « Contrôles : total actif = total passif ; résultat du bilan = résultat du compte de résultat ; comparaison N-1 si disponible. » B1 : produits 6 000,00, charges 1 500,00, résultat 4 500,00. B2 : actif 17 500,00 = passif 17 500,00 (résultat inclus). Cas limites : capitaux propres sous une fraction du capital (indicateur bloquant, JUR-006 ; la fraction est un paramètre daté) ; résultat négatif ; premier exercice sans N-1.

## À faire
1. `packages/noyau/src/etats/bilan.ts` (entrée = sortie de `affecterPostes`, L03-T47) :
   - `etatsFinanciers(affectation, { posteResultat: string; precedent?: EtatsFinanciers })` → `EtatsFinanciers { compteResultat: { produits; charges; resultat }; bilan: { actif; passifHorsResultat; resultat; passif }; controles: { id: 'ETAT-01' | 'ETAT-02'; ok: boolean; ecartCentimes }[]; variations?: { poste; n; n1 }[] }` : `resultat` = produits − charges (négatif possible) ; le résultat est ajouté au passif dans le poste `posteResultat` ; ETAT-01 actif = passif ; ETAT-02 résultat du bilan = résultat du compte de résultat ;
   - `capitauxPropresSousSeuil({ capitauxPropres, capital }, fractionPointsDeBase)` → booléen (comparaison par `pourcentage`, jamais de division ; la fraction arrive en argument).
