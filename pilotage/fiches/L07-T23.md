## Contexte
Spec 07 : bannière (PLA-130) avec cause, conséquence, prochaine étape et lien, AUCUN montant ; résumé de reprise (« 20 pièces reçues pendant la pause ont été traitées », PLA-135) ; jauge de volume avec le mot « estimation » (PLA-155) ; contrôle transverse : 0 mot interdit du lexique (QUA-028) dans la bannière, les alertes et la fin de contrat. D5 : vouvoiement partout. Les codes `cause` et `consequence` viennent de `contenuBanniere` (L07-T01). Les textes propres à un écran vont dans le fichier de l'écran (E53 : L07-T28, E50 : L07-T29, acceptation : L07-T30).

## À faire
1. `packages/textes/src/ecrans/abonnement.ts` (même forme que `ecrans/socle.ts` de L01-T28) :
   - `banniere` : pour `ESSAI`, `DELAI_DE_GRACE`, `LECTURE_SEULE`, `SUSPENDU`, `RESILIE` : `titre`, `consequence` (ce que l'utilisateur peut encore faire : consulter et exporter toujours ; l'assistant arrêté sauf en essai et en délai de grâce), `prochaineEtape(dateFormatee: string)` ; textes des codes de cause (`periode_essai`, `impaye_signale`, `pause`, `arrete`, `contrat_termine`) ;
   - `liens` : `portail_abonnement` = « Abonnement et factures », `contacter_axion` = « Contacter Axion » ;
   - `reprise(n: number)` : 0 → chaîne vide ; 1 → « 1 pièce reçue pendant la pause a été traitée. » ; n → « n pièces reçues pendant la pause ont été traitées. » ; `n` non entier, négatif, NaN ou Infinity → chaîne vide ;
   - `jauge` : `libelle` (« Pièces traitées ce mois-ci »), `valeur(utilise: string, compris: string)` (« 72 sur 100 »), `estimation(n: string)` (« Estimation de fin de mois : … »), `seuilAtteint(pourcent: string)`, `depasse` (« Vous avez dépassé le volume de votre palier. Vos pièces continuent d'être traitées. ») ;
   - `erreurs` : un message par code `ETAT_ACCES`, `ACCORD_MANQUANT`, `PALIER_INCONNU`, `PALIER_IDENTIQUE`, `PALIER_NON_SUPERIEUR`, `PAS_DE_REMISE`, `DEJA_ACCUSE`, `EMPREINTE_DIFFERENTE`, `GEL_DEJA_ACTIF`, `GEL_INACTIF`, `VERSION_PERIMEE`, `DOCUMENT_ABSENT`.
2. Tests nommés : `cinq-etats-non-actifs-ont-un-texte`, `aucun-mot-interdit` (liste `MOTS_INTERDITS` importée de `outils/gardes/textes.mjs`, sans casse, sur toutes les chaînes et sur le résultat des fonctions), `aucun-montant` (ni `€`, ni « euro », ni « prix », ni « tarif »), `vouvoiement` (aucun « tu », « ton », « ta », « tes » en mot entier), `reprise-singulier-pluriel-et-cas-limites` (0, 1, 20, -1, 1.5, NaN, Infinity), `tous-les-codes-d-erreur-ont-un-message` (liste des 12 codes écrite dans le test), `aucun-pourcentage-en-dur` (aucun nombre suivi de `%` dans les chaînes : le seuil est fourni en argument).
