## Contexte
Spec 07, `02-quotas-ia.md` §2 : seuils lus dans la console, une seule source (70 % et 100 % aujourd'hui, `SEUIL_ALERTE_BPS = 7000` dans le code de la console) ; une alerte par seuil et par mois. D13 : la même règle sert au budget d'IA (70 % et 100 %), jamais présentée comme un quota. Cas T-ABO-7 : palier fictif de 100 pièces ; 69 puis 70 pièces → 0 alerte à 69, 1 alerte à 70, aucune seconde alerte à 71.

## À faire
1. `packages/noyau/src/abonnement/seuils.ts` :
   - `seuilAtteint(utilise, compris, seuilBps)` → `utilise * 10000 >= compris * seuilBps` (sans division) ; `utilise` entier >= 0, `compris` entier >= 1 (0 → `palier_invalide`), `seuilBps` entier >= 1 ; produits vérifiés entiers sûrs (`depassement_entier`) ;
   - `nouvellesAlertes({ utilise, compris, seuilsBps, mois, dejaEmises: ReadonlySet<string>, horodatage, objet: 'volume' | 'budget_ia' })` → `{ alertes: { seuilBps: number; mois: string }[]; dejaEmises: ReadonlySet<string>; evenements: EvenementJournal[] }` : un seuil atteint dont la clé `objet + ':' + mois + ':' + seuilBps` n'est pas dans `dejaEmises` donne 1 alerte et 1 événement `abonnement.seuil_atteint` ; la liste `seuilsBps` peut arriver dans le désordre ou avec des doublons (dédoublonnée, alertes rendues dans l'ordre croissant) ; liste vide → aucune alerte ; ensemble reçu jamais modifié (nouvel ensemble rendu).
2. Tests nommés (seuils passés en argument, valeurs de T-ABO-7 dans les tests seulement) : `soixante-neuf-zero-alerte`, `soixante-dix-une-alerte`, `soixante-et-onze-pas-de-seconde` (T-ABO-7), `deux-seuils-franchis-d-un-coup` (de 50 à 120 : deux alertes, ordre croissant), `nouveau-mois-nouvelle-alerte`, `volume-et-budget-separes`, `seuils-desordre-et-doublons`, `entrees-invalides-refusees` (compris 0, NaN, Infinity, -1, 1.5, seuil 0).

## Hors périmètre
Pas d'envoi d'alerte ni de réservation atomique en base (fiches bloquées L07-T33 et L07-T39), aucun texte (L07-T23).

## Pièges
Règles du noyau. AUCUN seuil en dur dans `src` : pas de `7000`, pas de `10000` sur une ligne qui contient `seuil` (garde L01-T02) ; écrire la base des points de base comme constante nommée `BASE_POINTS = 10000` sur sa propre ligne (nom sans `seuil`, `taux`, `plafond`) ou passer par `pourcentage` de `argent` si c'est plus simple. Les valeurs 70 % et 100 % ne vivent que dans les tests et, plus tard, dans la console.
