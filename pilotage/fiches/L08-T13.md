## Contexte
Spec 08, fichier 04 §4 : « Paquet de paramètres légaux faux : remise du paquet précédent (versionné, signé) ; déclarations calculées avec le paquet faux marquées "à revoir" » ; §6 : une déclaration dont un paramètre est périmé est bloquée avec la raison. Cas T-EXP-5 : toutes les déclarations calculées avec le faux sont marquées, aucune autre. La signature et le refus d'un paquet non signé sont au lot 06 (non redits) ; l'utilisation d'un paramètre par une écriture est tracée par L14-T34 (`utilisation_parametre`, `version_paquet`).

## À faire
1. `packages/noyau/src/exploitation/paquet-retour.ts` :
   - `remettrePaquetPrecedent(historique: { version: number; installeLe: string; retireLe: string | null }[], versionFausse, maintenant)` → nouvel historique (append seulement) : la version fausse reçoit `retireLe = maintenant`, la version précédente la plus haute NON fausse est réinstallée en NOUVELLE ligne ; version fausse inconnue ou déjà retirée = `ErreurExploitation('ordre_invalide')` ; aucune version précédente = `liste_vide` ;
   - `marquerARevoir(declarations: { id: string; versionPaquet: number; statut: string }[], versionsFausses: number[])` → `{ aRevoir: string[]; inchangees: number }` (identifiants triés, sans doublon ; une déclaration déjà `a_revoir` reste listée une seule fois) ;
   - `declarationBloquee({ versionPaquet }, paquetEnVigueur)` → `{ bloquee: boolean; raison: 'paquet_perime' | null }` : bloquée si la déclaration a été calculée avec une version différente du paquet en vigueur.
2. Tests nommés : `remise-du-precedent-ajoutee`, `historique-jamais-reecrit` (les lignes d'origine sont intactes, l'ancienne liste n'est pas modifiée), `version-fausse-inconnue-refusee`, `aucune-precedente-refusee`, `toutes-les-declarations-du-faux-marquees-t-exp-5` (10 déclarations, 4 avec la version fausse : exactement ces 4), `liste-vide-rien-a-revoir`, `declaration-bloquee-si-paquet-different`.

Signature, vérification et application d'un paquet (lot 06 et L14-T17). Recalcul des déclarations (lots 03 et 14).
