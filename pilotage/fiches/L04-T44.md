## Contexte
Spec 04, fichier 01 : dépôt par glisser, sélecteur, lot ou dossier (IMP-001), même service pour toutes les voies (IMP-040). Le glisser-déposer seul n'est pas accessible : un bouton de choix de fichiers doit toujours exister.

## À faire
1. `ZoneDepot.tsx` : props `surFichiers(fichiers: File[], canal: 'glisser' | 'selecteur')`, `libelles: { zone: string; bouton: string; survol: string }`, `desactive?: boolean` ; `<input type="file" multiple>` visuellement masqué mais présent, déclenché par un `Bouton` (L01-T29) ; zone avec `onDragOver` (empêche le défaut, montre l'état de survol), `onDragLeave`, `onDrop` (rend `dataTransfer.files`) ; liste vide ignorée (aucun appel) ; `desactive` bloque les deux voies.
2. `zone-depot.css` : seulement des `var(--…)` ; état de survol par bordure (pas seulement la couleur) ; cible de 44 px au moins.
3. Tests nommés (`// @vitest-environment jsdom`) : `bouton-ouvre-le-selecteur`, `selection-rend-les-fichiers-canal-selecteur`, `depot-rend-les-fichiers-canal-glisser`, `liste-vide-ignoree`, `survol-visible`, `desactive-bloque-les-deux-voies`, `bouton-nomme-par-son-libelle`.

## Hors périmètre
Envoi au serveur (L04-T42), dossier complet (`webkitdirectory`) : prochaine tranche.
