## Contexte
Second mode de déploiement (installation chez le client), spec 08 `02-hebergement-environnements.md` §4 : rien n'est construit au MVP. La machine du client doit avoir un processeur x86-64, au moins 4 cœurs virtuels, 8 Go de mémoire, un disque dimensionné selon le volume de pièces et un système Debian 12 ou Ubuntu 24.04. Ces seuils sont des réglages (modèle : `packages/parametres/src/reglages-exploitation.ts`), jamais des littéraux du code.

## À faire
1. Tests d'abord.
2. `packages/noyau/src/installation/prerequis.ts` : type `FaitsMachine` (`architecture`, `coeurs`, `memoireOctets`, `disqueLibreOctets`, `systeme`, `versionSysteme`) ; type `SeuilsPrerequis` (reçu en paramètre, avec la liste des systèmes admis et un disque minimal calculé par `disqueRequis(volumePiecesOctets, marge)`) ; `controlerPrerequis(faits, seuils)` → `{ ok: true } | { ok: false; manques: Manque[] }`, chaque manque portant un code (`architecture`, `coeurs`, `memoire`, `disque`, `systeme`), la valeur trouvée et la valeur attendue.
3. `messagePrerequis(resultat)` : texte clair, une ligne par manque, sans jargon.
4. Tests nommés : `machine-2-coeurs-refusee`, `machine-4-go-refusee`, `plusieurs-manques-tous-listes`, `machine-aux-prerequis-acceptee`, `systeme-non-admis-refuse`.
