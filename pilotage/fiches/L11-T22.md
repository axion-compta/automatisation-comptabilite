## Contexte
Spec 11, fichier 06 (API) : `GET /frais?personne=&du=&au=&statut=` rend la liste ET les trois totaux ; détail d'un frais. Routes sans préfixe de société tant que D29 et J3a ne sont pas réglés (préfixe : L11-T38, bloquée). Les totaux viennent du noyau (`calculerTotaux`, L11-T14), jamais recalculés dans le contrat.

## À faire
1. `packages/contrat/src/domaines/frais.ts` : schémas zod `FraisResume { id; personneId; nature; date; libelle; montantTtcCentimes; payeur; statut; manque?: string[]; kmDixiemes?: number; montantTrajetCentimes?: number | null }`, `Totaux { aRembourserCentimes; enAttenteCentimes; exclusCentimes; kmSansMontantDixiemes }`, `FraisDetail` (résumé + `trajet?`, `vehiculeId?`, `pieceId?`, `motifSansJustificatif?`, `partPersoTtcCentimes`, `version`) ; routes oRPC `listerFrais` (`GET /frais`, query `personne` (50 car. au plus), `du`, `au` (`AAAA-MM-JJ`), `statut` (union), `limite` 1 à 100, `decalage` ; réponse `{ body, decalage, total, totaux }`) et `lireFrais` (`GET /frais/{id}`) ; erreur `FRAIS_INCONNU` 404 ; exporter `ReponseFrais` et `ReponseFraisDetail` (comme L01-T52) ;
2. `frais-service.ts` : service pur sur `genererFrais()` (L11-T21) ; totaux par `calculerTotaux` (import du noyau par chemin relatif) sur la sélection FILTRÉE (pas seulement la page) ; tri par date décroissante puis id ; `du` > `au` → 400.
3. `routes.ts` : ajouter `frais: { listerFrais, lireFrais }` sans toucher les autres domaines ; `openapi.ts` seulement si la génération échoue ; régénérer `openapi.json` ; `contrat.test.ts` : seulement si un test existant compte les domaines ; `apps/serveur/src/domaines/frais.ts` branché dans `app.ts`.
4. Tests nommés : `liste-enveloppe-tri-et-totaux`, `totaux-sur-la-selection-pas-sur-la-page` (limite 1 : totaux inchangés), `exemple-de-la-demo-12-60-45-64`, `filtre-par-statut`, `filtre-par-periode`, `bornes-invalides-400` (`du` après `au`, `2025-02-30`, `limite` 0, 101, 1.5, NaN, `personne` de 51 caractères), `frais-inconnu-404`, `openapi-contient-les-routes-des-frais`, `serveur-repond-aux-frais` (Fastify `inject`).
