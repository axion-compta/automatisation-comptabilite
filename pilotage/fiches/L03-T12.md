## Contexte
Spec 03, §07 : « numérotation continue par journal ; […] libellé unique par compte ». §06 : JournalCode dans une liste fermée (FEC-023) ; CompAuxLib vide si CompAuxNum vide. La suite des rangs se vérifie déjà avec `verifierSuite` (L01-T08) ; le format des numéros vient de `formaterNumero` (L01-T08, L01-T40).

## À faire
1. `packages/noyau/src/fec/controles-coherence.ts` (entrée = `LigneFecLue[]` de L03-T10) :
   - `REGLES_COHERENCE` : `FEC-C01` trou ou doublon de numérotation dans un journal, `FEC-C02` deux libellés pour un même compte, `FEC-C03` tiers incohérent (`compAuxNum` rempli et `compAuxLib` vide, ou l'inverse), `FEC-C04` code journal hors de la liste fermée ;
   - `controlerCoherence(lignes, { rangDe: (numero: string) => number | undefined; journauxPermis: readonly string[] })` → `EcartFec[]` : les numéros distincts d'un journal sont convertis par `rangDe` puis passés à `verifierSuite` ; un numéro que `rangDe` ne sait pas lire = écart `FEC-C01` avec la valeur ; chaque trou et chaque doublon = un écart ; la liste des journaux est un ARGUMENT (jamais en dur).
2. Tests nommés (`rangDe` du test : chiffres de fin du numéro `AC-2026-000007`) : `suite-continue-zero-ecart-fec-c01`, `trou-detecte-fec-c01`, `doublon-detecte-fec-c01`, `numero-illisible-fec-c01`, `deux-libelles-meme-compte-fec-c02`, `tiers-sans-nom-fec-c03`, `nom-sans-tiers-fec-c03`, `journal-hors-liste-fec-c04`.

## Hors périmètre
Pas d'équilibre (L03-T11). Pas de choix du mode de numérotation (par journal, proposé par la spec et expliqué dans la notice, L03-T38).

## Pièges
Plusieurs lignes d'une même écriture partagent un numéro : dédoublonner AVANT `verifierSuite`, sinon chaque écriture de 3 lignes devient un doublon (test). Règles du noyau comme L03-T01. Cas limites exigés : liste vide, journal avec un seul numéro, numéros donnés dans l'ordre inverse (même résultat), `journauxPermis` vide (tout journal en écart).
