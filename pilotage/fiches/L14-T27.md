## Contexte
Spec 14, `03`, JUR-019, règle 1 : les listes d'aide (associés, décisions, mouvements de titres) passent par le composant unique `liste_travail`, qui ajoute la formule A ; la mention est imposée par le composant, non modifiable. `packages/ui` ne dépend pas de `packages/textes` (et ajouter une dépendance rendrait la fiche sensible) : la mention arrive en prop, mais son TYPE est la chaîne littérale exacte, donc aucun autre texte ne compile.

## À faire
1. `packages/ui/src/composants/ListeTravail.tsx` :
   - `type MentionListeTravail = 'document de travail, ne remplace pas le registre légal'` ;
   - props `{ mention: MentionListeTravail; titre: string; colonnes; lignes; type: 'associes' | 'decisions' | 'mouvements_titres' }` ; rend la mention AVANT le tableau, dans un élément relié au tableau par `aria-describedby` ; réutilise `Tableau` (L01-T30) ;
   - aucune prop ne masque ou ne remplace la mention ; liste vide : la mention reste affichée avec l'état vide de `Etats` (L01-T29).
2. `liste-travail.css` : uniquement des variables de `jetons.css` (garde:couleurs).
3. Tests nommés (`@testing-library/react` comme les tests voisins) : `mention-toujours-rendue`, `mention-avant-le-tableau`, `mention-decrit-le-tableau` (aria-describedby), `liste-vide-mention-gardee`, `autre-mention-ne-compile-pas` (`// @ts-expect-error` sur une autre chaîne : rougit à `tsc` si le type est élargi), `trois-types-de-liste`.

## Hors périmètre
Pas de route ni d'écran (les listes réelles viennent plus tard). Ne pas toucher `packages/ui/src/index.ts` (import par chemin).

## Pièges
Le texte de la mention dans les tests et dans le type est la chaîne A exacte (garde:registre-legal, L14-T01). garde:textes : aucun texte visible en dur dans le `.tsx` hors de la prop. Cas limites exigés : `titre` vide, une seule colonne, 1 000 lignes (pas d'erreur, pagination de `Tableau`).
