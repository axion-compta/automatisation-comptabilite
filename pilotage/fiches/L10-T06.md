## Contexte
Spec 10, fichier 04, point 5 : délettrage = nouvelle ligne `annule_lettrage_id` (le lettrage d'origine n'est jamais effacé) ; en cas B, la TVA encaissée est contre-passée sur la période OUVERTE (jamais dans une période déposée). L'écriture bancaire (512 / 411) reste : seule la TVA est inversée.

## À faire
1. `packages/noyau/src/ventes/delettrage.ts` :
   - `delettrer({ lettrageId, idAnnulation, idEcriture, journal, dateCorrection, motif, lignesTvaEncaissement: LigneTvaVente[], comptes })` → `{ annulation: { id; annuleLettrageId; motif; date }; ecriture: Ecriture | null; lignesTva }` ;
   - pour chaque ligne de TVA encaissée : D `tvaCollectee` / C `tvaEnAttente` du même montant ; `lignesTva` de signe opposé, `dateExigibilite = dateCorrection` ; aucune ligne de TVA (cas A ou C) → `ecriture: null` ;
   - écriture `brouillon`, `type: 'correction'` ; refus `motif_obligatoire` (vide ou blanc), `date_invalide`.
2. Tests nommés : `delettrage-cas-b-inverse-la-tva`, `delettrage-cas-a-sans-ecriture`, `lettrage-d-origine-intact` (entrée gelée par `Object.freeze`), `motif-obligatoire` (chaîne vide, espaces), `date-de-correction-pas-la-date-d-origine`, `deux-taux-deux-lignes`, `ecriture-equilibree`.

## Hors périmètre
Choix de la période ouverte (L10-T19), écriture bancaire, contre-passation générale (L01-T09 : non utilisée ici car elle inverserait aussi la banque).
