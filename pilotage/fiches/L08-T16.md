## Contexte
Spec 08, fichier 03 §3.3 et §4 : manifeste de restauration (date, sauvegarde utilisée : nom et empreinte du dump, durées mesurées par étape, résultat de chaque contrôle, opérateur `systeme` ou personne), AUCUNE donnée comptable. Chronomètre : télécharger, déchiffrer, restaurer, contrôler, chaque étape en secondes. Résultat « réussi » seulement si tous les contrôles passent ET si la durée totale est sous le RTO retenu. Échec : le résultat reste « échec » jusqu'à un nouvel essai réussi ; un échec n'est jamais effacé du manifeste. Sans la clé (PLA-161) : échec « clé de restauration absente », sans rien détruire ni écrire. Cas R2, R3, R4, R5, R9. RTO = réglage (L08-T02).

## À faire
1. `packages/noyau/src/exploitation/essai-restauration.ts` :
   - `ETAPES = ['telecharger', 'dechiffrer', 'restaurer', 'controler'] as const` ;
   - `ECHECS = ['cle_restauration_absente', 'dechiffrement_impossible', 'bloc_altere', 'fin_du_flux_absente', 'controles_en_echec', 'trop_long'] as const` ;
   - `construireEssai({ id; le; dump: { nom; empreinte }; operateur; etapes: { etape; debutLe; finLe }[]; arret?: { etape; cause: Echec; bloc?: number }; controles: ResultatControle[] }, rtoSecondes)` → `{ id; le; dump; operateur; dureesMs: Record<Etape, number | null>; totalMs; controles; resultat: 'reussi' | 'echec'; cause: Echec | null; lignesEcrites: number }` :
     - étapes dans l'ordre de `ETAPES`, sans doublon ni trou avant l'arrêt (sinon `ordre_invalide`) ; étape inconnue = `etape_inconnue` ; `finLe` >= `debutLe` ;
     - `arret` présent = `echec` avec sa cause ; `cle_restauration_absente` ou `dechiffrement_impossible` impose `lignesEcrites: 0` et aucune étape après `dechiffrer` (R2, R3) ;
     - pas d'arrêt : `controles_en_echec` si le bilan de L08-T14 n'est pas réussi ; `trop_long` si `totalMs` DÉPASSE `rtoSecondes * MS_PAR_SECONDE` ;

   - `ajouterEssai(historique, essai)` → nouvel historique (ajout seul ; même `id` déjà présent = `essai_deja_enregistre`) ;
   - `etatCourant(historique)` → `'jamais' | 'reussi' | 'echec'` : celui du DERNIER essai par date ; un échec reste l'état tant qu'aucun essai plus récent n'est réussi.

## Pièges
Règles du noyau comme L08-T00 : les durées restent en MILLISECONDES (`dureesMs`, `totalMs`, par `ecartMillisecondes`) et le RTO est comparé par `totalMs > rtoSecondes * MS_PAR_SECONDE` ; aucune division, aucune conversion en secondes. Cas limites : `rtoSecondes` NaN, Infinity, 0, négatif ou 1.5 = `entier_invalide` ; liste d'étapes vide sans arrêt = `ordre_invalide`. Sensible (restauration, sécurité).
