## Contexte
Spec 14, `03`, JUR-017. Règle 1 : seul un compte courant rattaché à une `convention` de type `compte_courant_remunere` au statut `archivee` produit une proposition ; sans convention archivée : contrôle BLOQUANT, 0 écriture, carte « Déposez la convention ». Règle 3 : écriture en BROUILLON : débit compte d'intérêts / crédit compte de retenue / crédit compte courant (net). Comptes À VÉRIFIER (paramètres `jur.cca.compte_interets`, `jur.cca.compte_retenue`, compte courant) : arguments. Retenue = intérêts × taux de retenue de l'associé, arrondie au centime ; taux lu PAR associé selon son statut ; personne morale ou statut inconnu = 0 retenue proposée et carte « à vérifier ». Tests I1 (retenue 31 400, net 68 600 ; 184 jours : retenue 15 829, net 34 582) et I2.

## À faire
1. `packages/noyau/src/juridique/ecriture-cca.ts` (`pourcentage`, `soustraire` de `../argent/index.js` ; `Ecriture`, `verifierEcriture` de `../ecritures/modele.js` ; classe locale `ErreurEcritureCca`) :
   - `Convention { id; type: 'compte_courant_remunere' | 'autre'; statut: 'declaree' | 'traitee' | 'archivee' }` ;
   - `proposerEcritureCca({ convention: Convention | null; interets: Centimes; statutAssocie: 'personne_physique' | 'personne_physique_dispensee' | 'personne_morale' | 'inconnu'; date; journal; id }, { retenueParStatut: Partial<Record<statut, number>>; comptes: { interets: string; retenue: string; compteCourant: string }; arrondi })` → `{ etat: 'bloque'; carte: 'deposer_convention' } | { etat: 'brouillon'; ecriture: Ecriture; retenue: Centimes; net: Centimes; cartes: readonly 'retenue_a_verifier'[] }` ;
   - l'écriture a le statut `brouillon`, passe `verifierEcriture` (équilibrée), n'a pas de ligne de retenue quand la retenue vaut 0 ; statut absent de `retenueParStatut` = 0 et carte `retenue_a_verifier`.
