## Contexte
Spec 10, fichier 02, règles 5 et 8 : clé = SIREN du vendeur + numéro + date + TTC. Même clé par deux canaux (dépôt et plateforme agréée) = UNE seule pièce, l'autre `doublon` rattachée ; jamais comptée deux fois (cas V20, A10). Réimport du même fichier = rien créé (cas V22).

## À faire
1. `packages/noyau/src/ventes/dedoublonnage.ts` :
   - `cleDedoublonnage({ sirenVendeur, numero, dateFacture, ttc })` → `string | null` : SIREN sans espaces, numéro en majuscules sans espaces, date validée, TTC entier ; un champ manquant ou vide → `null` (jamais doublon) ;
   - `dedoublonner(pieces: { id; recuLe; cle }[])` → `{ gardees: string[]; doublons: { id; doublonDe }[] }` : la première reçue est gardée (`recuLe`, puis `id`) ;
   - `aCreer(clesExistantes: ReadonlySet<string>, entrantes: { cle }[])` → entrantes dont la clé est nulle ou inconnue, sans doublon interne.
2. Tests nommés : `v20-deux-canaux-une-piece`, `v22-reimport-zero-cree`, `numero-different-pas-doublon`, `ttc-different-pas-doublon`, `casse-et-espaces-ignores` (`f-2026-0047 ` = `F-2026-0047`), `premiere-recue-gardee` (ordre d'entrée inversé), `champ-manquant-jamais-doublon`, `entrees-invalides` (TTC 1.5, NaN, Infinity ; date `2026-02-30`).
