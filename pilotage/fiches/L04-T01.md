## Contexte
Spec 04, fichier 05 §2 : le XML Factur-X (CII) ou UBL est analysé « sans entités externes ni expansion ». Node n'a pas d'analyseur XML : une dépendance est nécessaire. Le noyau reste sans dépendance ; la lecture XML vit dans `apps/serveur/src/pieces/xml/` (L04-T21, L04-T46).

## À faire
1. `pnpm view fast-xml-parser version` : prendre la dernière version stable publiée ; l'ajouter à `dependencies` de `apps/serveur/package.json` en version EXACTE.
2. `pnpm install` pour mettre à jour `pnpm-lock.yaml`.
3. Noter dans le journal : version retenue, licence lue dans le `package.json` du paquet, date de publication.

## Hors périmètre
Aucun code. Aucune autre dépendance. Ne pas toucher `packages/noyau/package.json`.

## Pièges
Le portier refuse toute PR qui touche un `package.json` : PR sensible. Une version avec avis de sécurité ouvert (`pnpm audit`) est refusée : prendre la précédente sans avis et le noter.
