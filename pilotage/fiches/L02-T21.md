## Contexte
Spec 02, fichier 10 : `empreinte_ligne` = SHA-256 de (compte, date d'opération, montant, devise, libellé normalisé) et `occurrence` = rang de cette empreinte dans le relevé source ; règle 1 : « la n-ième ligne identique d'un fichier correspond à la n-ième ligne identique déjà importée. Réimporter ne crée rien ; deux opérations réellement identiques le même jour restent deux lignes. » Règle 2 : fichier identique (même SHA-256) refusé tôt. Tests T10-1 (30 lignes dont 2 cafés à −2,50 → 30 créées ; réimport → 0), T10-2 (25 + 14 = 39), T10-3 (3e café → 1 créée).

## À faire
1. `packages/noyau/src/banque/doublons.ts` :
   - `empreinteLigne({ compteId, dateOperation, montant, devise, libelleNormalise })` → hexadécimal SHA-256 (`node:crypto`) d'une forme canonique séparée par `\u001f` ;
   - `numeroterOccurrences(lignes)` → mêmes lignes avec `empreinte` et `occurrence` (1, 2, 3… dans l'ordre des rangs) ;
   - `lignesNouvelles(existantes: { empreinte; occurrence }[], lues)` → lignes dont le couple (empreinte, occurrence) est absent, dans l'ordre des rangs ;
   - `fichierDejaImporte(empreinteFichier, connus: { empreinte; recuLe }[])` → `{ deja: true; recuLe } | { deja: false }`.
2. Tests nommés : `t10-1-deux-cafes-deux-lignes`, `t10-1-reimport-zero`, `t10-2-chevauchement-trente-neuf`, `t10-3-troisieme-occurrence`, `empreinte-stable` (même entrée, même empreinte ; libellé brut différent mais normalisé égal : même empreinte), `compte-different-empreinte-differente`, `fichier-deja-importe-date-rendue`, `ordre-des-rangs-fait-foi` (entrée mélangée, même résultat).

## Hors périmètre
Sources différentes et doublons suspects (L02-T22). Doublon d'écriture qui bloque l'export (règle de contrôle d'un autre lot, V3-CTL-022).

## Pièges
Cas limites exigés : liste vide, montant 0, montant `NaN` ou non entier (erreur `montant_invalide` : jamais d'empreinte sur un montant faux), libellé normalisé vide (accepté : frais), séparateur `\u001f` présent dans un libellé (refusé ou échappé, test). JAMAIS de suppression d'une ligne existante. Sensible (doublon = argent compté deux fois). Règles du noyau.
