## Contexte
`PageEnPreparation` n'est testée que pour les routes inconnues ; le filigrane de `packages/noyau/src/documents/mention.ts` n'a pas de valeur « EXEMPLE ». Aucune fonction non codée ne doit paraître disponible.
Choix tranché (le plus petit) : pas de nouvelle garde ; un test unitaire parcourt le menu.

## À faire
1. Tests d'abord.
2. `mention.ts` : ajoute la valeur de filigrane `EXEMPLE`, imposée pour tout document produit en mode `demo` ; les autres valeurs restent inchangées.
3. `PageEnPreparation.tsx` : étiquette visible « Maquette · fonction à venir » et aucun bouton d'action actif.
4. `maquette-etiquette.test.tsx` : lit le menu (`apps/web/src/socle/menu.ts`, en lecture seule) et les écrans découverts ; chaque entrée sans écran codé rend l'étiquette.
5. Tests nommés : `filigrane-exemple-en-demo`, `filigranes-existants-inchanges`, `entree-sans-ecran-etiquetee`, `page-en-preparation-sans-action`.

## Hors périmètre
