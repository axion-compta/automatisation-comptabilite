## Contexte
Spec 15, TB-R6 : `GET /tableau-de-bord?vue=` (8 blocs) et `GET /tableau-de-bord/{bloc}` ; enveloppe `{ etat, mot, gravite, periode, donnees, lien }` ; montants `{ centimes, devise: "EUR" }` ; un champ inconnu rend 400 ; l'exercice est obligatoire. Comme pour le plan (L01-T23), les routes n'ont pas encore le préfixe de société (il viendra avec l'isolation, L15-T60, bloquée). L'anneau est servi ici à partir des sous-indicateurs FICTIFS (L15-T30) en attendant `GET /sante` du lot 12. Cas limite : société sans écriture = tous les blocs `vide`, anneau en pointillés.

## À faire
1. `domaines/tableau-de-bord.ts` : schémas zod stricts (`z.strictObject`) `Montant`, `PeriodeSchema`, `EnveloppeBlocSchema`, `AnneauSchema` (sans champ `pourcentage`), `ReponseTableauDeBord { body: { vue; periode; comparaison; chiffres; blocs (8); anneau } }`, `ReponseBloc` ; routes oRPC `lireTableauDeBord` (`GET /exercices/{exercice}/tableau-de-bord`, query stricte `vue` parmi les 3, `profil?` pour les essais) et `lireBloc` (`GET /exercices/{exercice}/tableau-de-bord/{bloc}`) ; erreurs `EXERCICE_INCONNU` 404, `BLOC_INCONNU` 404 ; réponses exportées (`ReponseTableauDeBord`, `ReponseBloc`, comme L01-T52).
2. `domaines/tableau-de-bord-service.ts` : service pur sur `genererCompta()` (L01-T22) et `genererInterface()` (L15-T30) ; appelle `periodeDeVue` et `periodeComparaison` (L15-T06), `calculerChiffres` (L15-T07) avec les définitions de démonstration, `assemblerTableau` et `blocTva` (L15-T09), `calculerAnneau` (L15-T08) ; aucun calcul refait ici (TB-R1) ; « jour » = `jourDeReference` du jeu fictif (pas d'horloge réelle).
3. Domaine déjà branché par L15-T69 (objet vide) : remplir l'objet du domaine dans son fichier du contrat et la fonction de routes de son fichier serveur (implémentation par le service), SANS toucher `routes.ts` ni `app.ts` ; régénérer `openapi.json` (`pnpm contrat:openapi`).
4. `apps/serveur/src/domaines/tableau-de-bord.ts` : implémentation par le service (fonction déjà branchée par L15-T69).
5. Tests nommés : `huit-blocs-dans-l-ordre`, `vue-invalide-400`, `champ-inconnu-400`, `exercice-inconnu-404`, `bloc-inconnu-404`, `profil-vide-tout-vide-anneau-pointille`, `aucun-pourcentage-dans-la-reponse`, `openapi-contient-les-routes`, `serveur-repond-au-tableau-de-bord` (Fastify `inject`).
