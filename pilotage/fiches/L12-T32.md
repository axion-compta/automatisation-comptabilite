## Contexte
Spec 12, `05-traitement-des-doutes` : C2 (V3-CTL-041) « Au niveau A0 (MVP) : un lot VERT est validé par un geste humain unique "Valider N" qui affiche N et le total ; chaque écriture du lot reçoit `valide_par` = la personne. Auto-validation seulement aux niveaux A1 à A3 (V1). » C3 (V3-CTL-042) « regroupement des cas semblables (même motif, même fournisseur) ; appliquer à tout le fournisseur ; annuler pendant le délai de `04-journaux-ecritures` règle 3 ». Cas CT-36 (lot de 20 pièces VERTES, « Valider 20 » : 20 écritures avec `valide_par` = la personne ; un agent appelle la validation : 403). Gestes humains : L13-T02 ; états et délai d'annulation : L01-T07.

## À faire
1. `packages/noyau/src/controles/doutes/lot.ts` :
   - `Acteur = { type: 'personne'; id: string } | { type: 'agent'; id: string }` ;
   - `recapitulatifLot(pieces)` → `{ nombre; total: Centimes }` (seulement les pièces VERTES ; une pièce non VERTE = exception `piece_non_verte`) ;
   - `validerLot({ pieces; acteur; niveau: 'A0'; recapitulatifVu: { nombre; total } })` → `{ ok: true; ecritures: { id; valide_par }[] } | { ok: false; code: 'geste_humain_requis' | 'recapitulatif_perime' }` : agent = `geste_humain_requis` (403 côté route) ; récapitulatif vu différent du recalcul = `recapitulatif_perime` ; niveau autre que A0 = exception (V1) ;
   - `regrouper(cas: { id; motif; fournisseurId }[])` → groupes par (motif, fournisseur), triés, sans perte ni doublon.
2. `packages/noyau/src/controles/doutes/__tests__/lot.test.ts`, tests nommés : `CT-36`, `agent-refuse`, `recapitulatif-perime`, `piece-jaune-refusee`, `lot-vide-refuse`, `regroupement-20-cas-1-groupe`, `regroupement-sans-perte` (1 000 cas à graine fixe), `niveau-v1-exception`.

## Hors périmètre
Écriture effective et annulation dans le délai (moteur, L01-T07). Niveaux A1 à A3 (V1). Route HTTP (bloquée avec l'identité).
