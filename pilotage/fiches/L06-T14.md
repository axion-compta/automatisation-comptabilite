## Contexte
Spec 06, `05-journal-chaine.md` §1 : une entrée par transaction métier ; `sequence` par société sans trou ; contenu = avant et après (diff minimal), motif, canal (`clic`, `chat`, `voix`, `import`, `api`, `systeme`), acteur ; AUCUN secret, jeton, IBAN en clair ni contenu de pièce. Cas T-JRN-3 (séquences 1 à 50 sans trou ni doublon). La concurrence réelle (verrou en base) est dans la fiche bloquée L06-T40 ; ici, la logique pure.

## À faire
1. `packages/noyau/src/journal/chaine.ts` :
   - `EntreeJournal = { societeId; sequence; horodatage; acteur; canal: Canal; evenement: string; motif?; avant?; apres?; formatCanonique; empreintePrecedente; empreinte }` ; `Tete = { societeId; sequence; empreinte }` ;
   - `teteInitiale(societeId, creeLe)` → `{ sequence: 0, empreinte: empreinteInitiale(…) }` ;
   - `ajouterEntree(tete, brouillon)` → `{ entree; tete }` : `sequence = tete.sequence + 1` ; société du brouillon différente de la tête → `ErreurJournal('societe_differente')` ; canal hors `CANAUX` → `canal_invalide` ; `evenement` hors forme `domaine.action` → `evenement_invalide` ; acteur vide → `acteur_absent` ; contenu avec secret (appel à `verifierSansSecret` de L06-T17) → `secret_dans_le_journal` avec les chemins fautifs ;
   - `ajouterLot(tete, brouillons)` : ajout dans l'ordre ; une erreur au milieu → aucune entrée rendue.
2. Tests nommés : `cinquante-ajouts-sequences-1-a-50` (T-JRN-3, pur), `premiere-entree-part-de-l-initiale`, `empreinte-chainee-a-la-precedente`, `autre-societe-refusee`, `canal-inconnu-refuse`, `evenement-mal-forme-refuse`, `secret-refuse-avec-chemin`, `lot-tout-ou-rien`, `tete-d-entree-non-modifiee`.
