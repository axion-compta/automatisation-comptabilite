## Contexte
Spec 02, fichier 02, règle 10 : « Nombre importé = nombre lu − rejetées ; chaque rejet est réparable. CSV d'en-tête seul = « Fichier vide, 0 ligne ». » Cas limites : ligne de total en fin de fichier ; séparateur « ; » ; cellule vide. Cette fiche découpe le texte en cellules ; l'interprétation (dates, montants) est faite par le profil (L02-T15).

## À faire
1. `packages/noyau/src/banque/import/csv.ts` :
   - `lireCsv(texte, separateur)` → `{ entete: string[]; lignes: { rang: number; cellules: string[] }[]; rejets: { rang: number; brut: string; motif: 'guillemet_non_ferme' | 'nombre_de_colonnes' }[] }` ;
   - guillemets doublés (`""`), séparateur dans des guillemets, retour à la ligne dans des guillemets ; fins de ligne `\r\n`, `\n`, `\r` ;
   - lignes vides ignorées (pas comptées comme rejet) ; `rang` = numéro de ligne dans le fichier (1 = première ligne après l'en-tête), il fait foi pour l'ordre ;
   - lignes avant l'en-tête (titre de la banque) : `ligneEntete` en argument (index 0 par défaut) ;
   - `ligneDeTotal(lignes)` : repère une dernière ligne sans date dont une cellule commence par « total » (sans casse) → retirée des lignes et rendue à part (la comparaison à la somme est faite par L02-T15).
2. Tests nommés : `trois-lignes-point-virgule`, `guillemets-et-separateur-interne`, `retour-ligne-dans-guillemets`, `en-tete-seul-zero-ligne`, `colonnes-en-trop-rejet-numerote`, `guillemet-non-ferme-rejet`, `ligne-de-total-mise-a-part`, `titre-avant-en-tete`.

## Hors périmètre
Encodage (L02-T10). Montants et dates (L02-T08, T09).

## Pièges
Cas limites exigés : texte vide, une seule cellule, séparateur absent du texte, `ligneEntete` négatif, `NaN` ou au-delà du texte (erreur `entete_invalide`), 2 lignes identiques (gardées toutes les deux : les doublons se traitent ailleurs). Règles du noyau. Aucun contenu de ligne dans un message d'exception (V3-BAN-090) : le contenu brut va seulement dans `rejets`.
