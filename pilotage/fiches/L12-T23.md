## Contexte
Spec 12, `01-socle-catalogue` §Déclencheurs (V3-CTL-002) : arrivée = contrôles de l'objet arrivé ; continu = objets touchés par une écriture, un lien, une correction ; nocturne = tout le catalogue sur l'exercice ouvert, fini en moins de 24 h sinon alerte d'exploitation ; avant TVA = toute règle dont `bloque` contient la TVA, sur la période ; avant export = TOUJOURS tout le catalogue de l'exercice, pas de cache ; avant clôture = tout le catalogue ; à la demande = même périmètre que le nocturne pour la période affichée. Cas CT-43 (passage nocturne OK, une pièce modifiée depuis, puis demande d'export : tout le catalogue rejoué, aucun résultat réutilisé). Le moteur (L01-T19) sait déjà filtrer les règles ; il manque le choix des OBJETS et la règle « pas de cache ».

## À faire
1. `packages/noyau/src/controles/declencheurs.ts` :
   - `Contexte { declencheur: Declencheur; objetArrive?: ObjetRef; objetsTouches?: readonly ObjetRef[]; tousLesObjets: readonly ObjetRef[]; periode?: { debut; fin } }` avec `ObjetRef { type; id; date?: string }` ;
   - `objetsAControler(ctx)` → liste sans doublon, triée (type puis id) : arrivée = l'objet seul (absent = exception) ; continu = objets touchés ; nocturne, avant clôture, avant export = tous ; à la demande et avant TVA = ceux dont la date est dans la période (bornes incluses ; période inversée = exception) ;
   - `reglesAJouer(regles, declencheur)` : avant TVA = règles actives dont `bloque` contient `tva`, quel que soit leur déclencheur ; sinon même filtre que le moteur ;
   - `peutReutiliser(declencheur)` → toujours `false` pour `avant_export` et `avant_cloture` ;
   - `nocturneEnRetard(debut, fin, dureeMaxMinutes)` : durée maximale en ARGUMENT (réglage d'exploitation), horodatages ISO UTC ; fin absente et maintenant passé en argument.
2. `packages/noyau/src/controles/__tests__/declencheurs.test.ts`, tests nommés : `CT-43`, `arrivee-un-seul-objet`, `continu-sans-doublon`, `avant-tva-selon-bloque`, `periode-bornes-incluses`, `periode-inversee-exception`, `export-jamais-de-cache`, `nocturne-en-retard` (durée = max : non ; max + 1 : oui), `horodatage-invalide-exception`.
