## Contexte
Spec 11, fichier 02, règle 1 : « La banque de la société fait foi. Si une ligne de débit d'un compte ou d'une carte de la société correspond au ticket (même montant au centime, date à ± N jours, paramètre `frais.fenetre_jours`, commerçant compatible), alors payeur = société. » La fenêtre est un réglage : elle arrive TOUJOURS en argument.

## À faire
1. `packages/noyau/src/frais/correspondance-banque.ts` :
   - `LigneBanqueSociete { id; date: string; montant: Centimes; sens: 'debit' | 'credit'; libelle: string; compte: string }` ;
   - `commercantCompatible(fournisseur: string | undefined, libelleBanque: string)` : comparaison sans casse ni accents ; vrai si le fournisseur est absent ou vide, ou si un mot d'au moins 4 lettres du fournisseur figure dans le libellé ;
   - `lignesCorrespondantes(ticket: { montantTtc; date; fournisseur? }, lignes, fenetreJours: number)` → lignes de DÉBIT de montant égal au centime (valeur absolue), date dans `[date − n ; date + n]` bornes INCLUSES, commerçant compatible ; triées par écart de jours puis id ;
   - bornes de dates calculées par `Date.UTC(a, m − 1, j ± n)` puis comparées en chaînes ISO (aucune division) ;
   - refus `ErreurFrais('entree_invalide')` : fenêtre négative, `NaN`, `Infinity` ou non entière ; date invalide (`2025-02-30`, `''`) ; montant non entier.
2. Tests nommés (montants et libellés inventés) : `meme-montant-meme-jour`, `un-centime-d-ecart-refuse`, `borne-de-fenetre-incluse` (± n jours exactement), `hors-fenetre-refuse` (n + 1), `fenetre-a-cheval-sur-le-mois` (31/10 et 02/11), `credit-ignore`, `commercant-incompatible-ignore`, `fournisseur-absent-compatible`, `tri-par-ecart-de-jours`, `entrees-invalides-refusees` (fenêtre −1, 1,5, NaN, Infinity ; date `2025-02-30`).

## Hors périmètre
Décision du payeur (L11-T04) ; import réel des relevés (lot 02) ; plusieurs lignes qui se partagent un ticket.

## Pièges
Règles du noyau (eslint) : ni littéral décimal, ni `/`, ni `Math.round`, ni `parseFloat`, ni `toFixed` ; montants en `Centimes`. Stryker sur tout le noyau : le test de borne doit tuer le mutant `<=` → `<`. Aucune valeur de fenêtre écrite dans `src` (garde:litteraux). Ne pas toucher `packages/noyau/src/index.ts`. Sensible (argent, rapprochement).
