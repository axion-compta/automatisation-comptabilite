## Contexte
Spec 05, fichier 04 §1 : « une action de la matrice sans outil ni exclusion déclarée = build rouge ». `scripts/verifier.mjs` lance tout `outils/gardes/*.mjs` trouvé : pas besoin de toucher `package.json`.

## À faire
1. `outils/gardes/outils-chat.mjs` (même forme que `actions.mjs` : fonction `analyserOutilsChat(outils, registre)` exportée et testée, lancement qui sort en code 1 si problème) ; lit `packages/contrat/src/chat/outils.json` et `packages/contrat/src/actions/registre.json`. Rouge si :
   - nom en double, vide, ou nom `appliquer` (toute casse, avec ou sans préfixe) ;
   - `outil_registre` absent du registre ;
   - niveau différent de celui du registre ;
   - niveau I, ou outil `chat: "ferme"` dans le registre ;
   - permission qui ne commence pas par `compta-` ;
   - `codes_erreur` vide ou contenant un code inconnu (liste lue dans `packages/noyau/src/chat/types.ts` par expression régulière sur `CODES_ERREUR`).
2. Tests nommés : `main-vert`, `doublon-rouge`, `appliquer-rouge` (`appliquer`, `Appliquer`, `chat.appliquer`), `outil-registre-inconnu-rouge`, `niveau-different-rouge`, `niveau-i-rouge`, `permission-sans-prefixe-rouge`, `code-erreur-inconnu-rouge`, `fichier-vide-ou-illisible-rouge`.

## Hors périmètre
Pas de modification de `outils.json` ni du registre.

## Pièges
Fiche sensible (`outils/gardes/`). Chaque règle doit avoir un test qui rougit si on la retire. Ne pas lancer de sous-processus réseau.
