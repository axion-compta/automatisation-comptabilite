## Contexte
Spec 07, `04-plans-cgv-mise-en-service.md` §2 : le texte des CGV est hors back-end ; le back-end garde `document_contractuel` (type, version, date d'approbation par l'éditeur, empreinte du texte, sources citées) et `acceptation` (personne, organisation, type, version, date) ; aucune action de la compta avant l'acceptation de la version en vigueur ; nouvelle version = nouvelle acceptation au prochain accès. D11 et D31 : sources officielles citées, aucune signature extérieure. Q7 : si la console tient déjà l'acceptation de ses CGV, le module ne garde que les clauses propres à la compta (la liste des types requis est donc un ARGUMENT).

## À faire
1. `packages/noyau/src/abonnement/documents.ts` :
   - `type DocumentContractuel = { type: string; version: number; approuveLe: string; empreinte: string; sources: readonly string[] }` ; `verifierDocument(d)` : type non vide, version entier >= 1, `approuveLe` date valide, empreinte valide (L07-T00), `sources` non vide et sans chaîne vide, sinon `parametre_invalide` (ou le code du contrôle appelé) ;
   - `documentEnVigueur(documents, type, date)` → document de PLUS GRANDE version dont `approuveLe <= date`, ou `null` ; deux documents de même type et même version → `parametre_invalide` ;
   - `type Acceptation = { personne: string; organisation: string; type: string; version: number; accepteLe: string }` ;
   - `acceptationsManquantes({ documents, acceptations, personne, organisation, typesRequis, date })` → liste `{ type, version }` des documents en vigueur non acceptés par CETTE personne de CETTE organisation ; type requis sans document en vigueur → `document_absent` (fermé par défaut : aucune action) ; `typesRequis` vide → `[]` ;
   - `accepter({ documents, personne, organisation, type, version, horodatage })` → `{ acceptation; evenement: acceptation.enregistree }` ; version différente de la version en vigueur à la date de l'horodatage → `version_perimee` ; personne ou organisation vides → `auteur_manquant`.
2. Tests nommés : `version-en-vigueur-la-plus-haute-approuvee`, `version-future-pas-encore-en-vigueur`, `nouvelle-version-demande-nouvelle-acceptation`, `acceptation-d-une-autre-organisation-ignoree`, `type-requis-sans-document-refuse`, `accepter-version-perimee-refuse`, `document-sans-source-refuse`, `doublon-type-version-refuse`.
