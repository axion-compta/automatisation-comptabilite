## Contexte
Spec 06, `05-journal-chaine.md` §2 : toutes les heures, chaque nuit, avant chaque clôture et avant chaque export officiel, la tête (dernière séquence, dernière empreinte) de chaque société est signée par le coffre de la console et déposée hors base. T-JRN-5 : la signature de la veille se vérifie avec la clé publique du coffre. Le coffre et son algorithme sont à la console (D29) : on code contre un PORT de vérification, et les tests utilisent une paire de clés Ed25519 générée dans le test (`node:crypto`).

## À faire
1. `packages/noyau/src/journal/tete-signee.ts` :
   - `documentTete({ societeId, sequence, empreinte }, horodatage)` → chaîne canonique (format de L06-T13 s'il est fusionné, sinon JSON aux clés triées écrit ici et noté au journal) ;
   - `type VerificateurSignature = (document: string, signatureBase64: string) => boolean` ; `verificateurEd25519(clePubliquePem)` → `VerificateurSignature` (`crypto.verify(null, …)`) ;
   - `verifierTeteSignee(document, signatureBase64, verificateur)` → booléen ; signature non base64 ou vide → faux, jamais d'exception ;
   - `doitSignerTete(derniereSignatureMs | null, maintenantMs, intervalleMs, evenement?: 'cloture' | 'export' | 'nuit')` → booléen : `null` → vrai ; un événement → vrai ; sinon vrai si l'intervalle est atteint ; arguments NaN, négatifs, non entiers → `ErreurJournal('argument_invalide')`.
2. Tests nommés : `signature-valide-verifiee`, `document-modifie-d-un-caractere-refuse`, `autre-cle-refusee`, `signature-vide-ou-illisible-refusee`, `jamais-signee-signer`, `intervalle-exact-signer`, `avant-intervalle-ne-pas-signer-sauf-evenement`, `arguments-invalides-refuses`.
