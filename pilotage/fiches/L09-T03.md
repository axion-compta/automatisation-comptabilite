## Contexte
Spec 09, §01 : `champ_profil`, « Ajout seul : une nouvelle valeur = une nouvelle ligne » ; `effet_debut` (défaut = date de saisie) ; `confirme_par` : « personne en session ; jamais un agent ». §04 règle 1 : la consultation « au 31/12/N-1 » lit ces lignes.

## À faire
1. `packages/noyau/src/profil/champs.ts` :
   - `ajouterValeur(historique, nouvelle)` → NOUVELLE liste (l'ancienne n'est jamais modifiée, vérifiée par `Object.freeze` dans le test) ; `rang` = rang maximal + 1 ; `effetDebut` absent = `dateSaisie` passée en argument ; refus `cle_vide`, `date_invalide`, `origine_inconnue`, `confiance_inconnue`, `statut_inconnu` ;
   - `valeurEnVigueur(historique, societeId, cle, date)` → le champ dont `effetDebut <= date`, le plus récent par `effetDebut` puis par `rang` ; `null` si aucun ;
   - `confirmer(historique, { societeId, cle, effetDebut }, confirmant: { type: 'personne' | 'agent'; id: string }, horodatage)` → nouvelle ligne `statut = confirme`, `confirmePar`, `confirmeLe` ; refus `confirmation_par_agent` si `type = agent`, `confirmant_vide` si `id` vide, `rien_a_confirmer` si aucune valeur ;
   - `marquerJeNeSaisPas(historique, ...)` → nouvelle ligne `statut = je_ne_sais_pas`, valeur `null`.
2. Tests nommés : `ajout-sans-modifier`, `rang-croissant`, `effet-par-defaut-date-de-saisie`, `valeur-en-vigueur-a-une-date` (veille, jour, lendemain d'un effet), `meme-effet-departage-par-rang`, `aucune-valeur-avant-effet` (`null`), `confirmation-par-agent-refusee`, `confirmation-trace-personne-et-heure`, `refus-entrees-invalides` (clé vide, date `2026-02-30`, origine `ia`, historique vide pour `confirmer`, dates en ordre inverse dans l'historique : le résultat ne dépend pas de l'ordre du tableau).

## Hors périmètre
Pas d'état du profil (L09-T04), pas de règle « aucun doute » (L09-T05), pas de stockage (L09-T48, bloquée).

## Pièges
Règles du noyau comme L01-T06. Comparer des dates APRÈS `exigerDate` (une chaîne mal formée comparée en texte donne un faux résultat). L'identité réelle du confirmant viendra de la session (L09-T49, bloquée) : ici, elle est passée en argument.
