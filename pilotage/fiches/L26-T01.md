## Contexte
Aujourd'hui `apps/web/src/main.tsx` lève une erreur hors développement : aucune démo ne peut être publiée. Le faux serveur MSW (`packages/faux-serveur/src/navigateur.ts`) démarre en `onUnhandledRequest: 'bypass'` : un appel de même origine vers un vrai moteur passerait inaperçu. La démo doit être le front complet sur faux serveur (même code d'écrans), avec un bandeau permanent et une remise à zéro.
Choix tranché (le plus prudent) : le verrou n'est levé que pour le mode Vite `demo` ; tout autre build hors développement reste refusé.

## À faire
1. Tests d'abord.
2. `navigateur.ts` : `demarrerNavigateur(options, mode)` démarre en `onUnhandledRequest: 'error'` quand `mode === 'demo'` ; `enProduction()` reste vrai en production SAUF pour le mode `demo`. Tests nommés (`navigateur-demo.test.ts`) : `demo-autorisee-en-build`, `production-toujours-refusee`.
3. `main.tsx` : en mode `demo`, démarre le faux serveur puis rend `BandeauDemo` au-dessus du routeur ; tout autre mode hors développement lève toujours l'erreur actuelle.
4. `BandeauDemo.tsx` : bandeau fixe, rôle `status`, texte tiré de `packages/textes/src/ecrans/demo.ts` (« DÉMONSTRATION · données fictives ») et bouton « Réinitialiser la démo » qui vide le stockage local de la démo puis recharge la page (l'état du faux serveur est en mémoire). Test nommé : `bandeau-present-et-reinitialise`.
5. `ecrans-sans-faux-serveur.test.ts` : parcourt `apps/web/src/ecrans/**` et échoue si un fichier importe `faux-serveur` ou `donnees-fictives`. Test nommé : `aucun-ecran-n-importe-le-faux-serveur`.
6. `apps/web/package.json` : scripts `build:demo` (`vite build --mode demo`) et `apercu:demo` (`vite preview --mode demo`), aucune dépendance. `playwright.demo.config.ts` : `testDir: './e2e-demo'`, serveur `apercu:demo` après `build:demo`.
7. `e2e-demo/demo.e2e.ts` : (a) chaque entrée du menu au premier clic : aucun écran vide, aucune erreur de console, bandeau visible ; (b) une route non déclarée appelée depuis la page fait échouer la requête (aucune réponse réseau réelle) ; (c) après une modification, « Réinitialiser » rend l'état initial.
