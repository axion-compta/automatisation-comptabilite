## Contexte
Spec 06, `10-signalements-et-renvois.md` §1 (SUP-008) : chaque réponse d'erreur et chaque signalement portent le même `correlation_id` ; l'outil d'erreurs ne reçoit que ce code, le nom de la route et le code d'erreur, jamais de contenu client. Le code est placé dans l'en-tête `x-correlation-id` (le corps des erreurs garde le format commun au vrai et au faux serveur).

## À faire
1. `apps/serveur/src/securite/correlation.ts` (remplit le fichier vide de L06-T23 ; crochet `onRequest` et `onError`) : code = `randomUUID()` de `node:crypto` ; un `x-correlation-id` reçu n'est repris que s'il a la forme d'un UUID, sinon il est remplacé ; en-tête `x-correlation-id` sur TOUTE réponse ; sur erreur, appelle `options.outilErreurs?.(rapportOutilErreurs({ correlation_id, route, code }))` (fonction de L06-T21) avec la route MODÈLE (`/ecritures/{id}`), jamais l'adresse réelle ni le corps.
2. Tests nommés : `en-tete-sur-200-404-409`, `uuid-recu-repris`, `valeur-recue-mal-formee-remplacee` (`'<script>'`, 500 caractères, vide), `deux-requetes-deux-codes`, `erreur-500-rapport-trois-champs` (service fictif qui lève une erreur contenant un montant et un nom de tiers fictifs : absents du rapport), `meme-code-en-tete-et-rapport`, `outil-absent-sans-erreur`.

## Hors périmètre
Outil d'erreurs réel (lot 08), signalement N01 et N02 (fiche bloquée L06-T48).

## Pièges
Serveur : ne jamais lire un rôle ni une société dans un en-tête de la requête (seule l'option `securite` de `creerApp`, utilisée par les tests, injecte une session). Format d'erreur identique à celui de `packages/faux-serveur/src/handlers.ts` (`{ defined, code, status, message, data? }`). Les tests existants de `apps/serveur` et du faux serveur restent verts. Cas limites obligatoires : en-têtes absents, vides, en double, trop longs ; options absentes (rien ne change) ; réglages NaN, Infinity, négatifs ou non entiers refusés. Chaque test doit rougir si l'on retire la protection qu'il couvre (vérifié à la main, noté au journal). Données fictives seulement. Ne toucher ni `app.ts` ni `securite/index.ts`. Fiche sensible (journaux, données du client).
