## Contexte
Spec 05, fichier 06 §2 : les valeurs reprises d'une pièce portent `origine: piece` jusqu'à validation ; elles ne deviennent jamais une consigne, une préférence ni un argument d'outil M ou I sans geste humain. Fichier 03 §2 : préférences : un nombre maximal par personne, jamais créées par le contenu d'une pièce, source `dit_par_la_personne` ; « Oublier » marque la préférence comme oubliée (pas d'effacement par l'application). Cas A2-24 ; jeu de 50 pièces piégées : 0 préférence créée.

## À faire
1. `packages/noyau/src/chat/quarantaine.ts` :
   - `Valeur<T> = { valeur: T; origine: Origine }` ; `marquer(valeur, origine)` ;
   - `verifierArguments(niveau, args: Record<string, Valeur<unknown>>, gesteHumain: boolean)` → permis ou `{ permis: false; code: 'parametre_invalide'; champs }` si niveau M ou I, sans geste, et au moins un champ `origine: piece` ;
   - `creerPreference(existantes, { cle, valeur, origine, personne }, max)` → nouvelle liste ou refus (`origine` autre que `personne`, clé vide, `max` atteint, `max` non entier ou <= 0) ; même clé = remplacement ;
   - `oublier(preferences, cle)` → copie avec `oubliee: true` ; `preferencesActives(preferences)` sans les oubliées.
2. Tests nommés : `piece-vers-m-sans-geste-refuse`, `piece-vers-m-avec-geste-permis`, `piece-vers-l-permis`, `preference-depuis-une-piece-refusee` (A2-24), `cinquante-pieces-piegees-zero-preference` (jeu inventé), `plafond-de-preferences` (max et max + 1), `max-invalide` (0, -1, 1.5, NaN, Infinity), `meme-cle-remplace`, `oublier-ne-supprime-pas`, `entrees-vides`.
