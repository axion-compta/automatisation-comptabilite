## Contexte
Débloquée par D43 (décision de Will du 07/11/2026, liste fermée de fournisseurs d'IA dans l'UE) ; L05-T59 est faite.
Spec 05, fichier 07 §5 : rejoue le jeu de cas de chaque agent sans donnée de client ; champs chiffrés notés par code (égalité exacte en centimes, compte, date) ; texte libre noté par un modèle, une part revue par une personne. ## À faire
1. `evaluateur.mjs` : rejoue un jeu fictif sur un port de modèle ; notation par code des champs chiffrés ; rapport par modèle et version ; coût médian et 90e centile en micro-centimes (calcul en entiers).
2. Tests nommés (port simulé) : `notation-exacte-au-centime`, `rapport-par-modele`, `mediane-et-centile`, `jeu-vide`, `aucune-donnee-reelle`.

## Hors périmètre
