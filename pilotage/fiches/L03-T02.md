## Contexte
Spec 03, §01 : `document_produit` est l'historique unique des FEC, déclarations, états, PV et paquets (statuts brouillon, a_valider, valide, remplace, indicatif). §07 : neuf champs tracés (qui, quand, exercice, version du logiciel, version du paquet, SHA-256, résultat des contrôles, motif, destinataire) ; réouverture encadrée : nouvelle version, l'ancienne marquée « Remplacé » ; un document figé ne bouge pas après coup (FEC-024). MOD-006 : un changement de mode laisse intacts les documents déjà validés.

## À faire
1. `packages/noyau/src/documents/historique.ts` :
   - types `TypeDocument = 'fec' | 'declaration_tva' | 'declaration' | 'etat' | 'pv' | 'paquet'`, `StatutDocument = 'brouillon' | 'a_valider' | 'valide' | 'remplace' | 'indicatif'` ;
   - `DocumentProduit { id; type; exerciceId; version: number; statut; sha256; versionLogiciel; versionPaquet; preparePar; prepareLe; resultatControles: 'ok' | 'ecarts'; validePar?; valideLe?; motif?; destinataire? }` ;
   - classe locale `ErreurHistorique` (`code` : `motif_obligatoire`, `version_invalide`, `deja_valide`, `validation_incomplete`, `document_inconnu`, `indicatif_non_validable`) ;
   - `ajouterVersion(historique, nouveau)` → nouvel historique : `version` = plus grande version du même couple (type, exercice) + 1 (1 si aucune) ; si une version `valide` existe pour ce couple, `nouveau.motif` est obligatoire et l'ancienne passe `remplace` ; la liste reçue n'est jamais modifiée (copie) ;
   - `valider(historique, id, { par, le })` : `par` et `le` non vides sinon `validation_incomplete` ; `indicatif` jamais validable ; déjà `valide` = `deja_valide` ; id absent = `document_inconnu` ;
   - `dernierEnVigueur(historique, type, exerciceId)` → la plus haute version non `remplace`, ou `undefined`.
2. Tests nommés : `premiere-version-1`, `version-suivante-par-couple` (deux exercices ne se mélangent pas), `remplacement-avec-motif`, `remplacement-sans-motif-refuse`, `liste-recue-intacte` (`Object.freeze` sur l'entrée), `indicatif-non-validable`, `dernier-en-vigueur-ignore-remplace`.
