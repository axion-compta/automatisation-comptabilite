## Contexte
Spec 08, cas T-EXP-9 : « journaux et suivi d'erreurs d'un parcours complet (import, chat, export) : 0 montant, 0 nom de tiers, 0 IBAN, 0 e-mail ; identifiants sous forme d'empreinte ». La console a un équivalent pour ses journaux de CI (`scripts/scanner-journaux.ts`) ; le module a besoin du sien, pur, pour ses tests et pour la CI de ses parcours fictifs.

## À faire
1. `packages/noyau/src/exploitation/scanner-journaux.ts` :
   - `chercherFuites(lignes: string[], { nomsInterdits: string[] })` → `{ ligne: number; type: 'email' | 'iban' | 'montant' | 'nom' }[]` (numéro de ligne à partir de 1 ; JAMAIS la valeur trouvée dans le résultat) ;
   - e-mail : `une adresse de la forme nom, arobase, domaine` ; IBAN : 2 lettres, 2 chiffres, puis 11 à 30 caractères alphanumériques avec espaces permis, CLÉ MODULO 97 VALIDE (un identifiant technique qui ressemble à un IBAN mais dont la clé est fausse n'est pas compté) ; montant : nombre avec virgule ou point décimal suivi ou précédé de `€` ou `EUR`, ou clé JSON `montant`, `amount`, `debit`, `credit` avec une valeur numérique ; nom : un des `nomsInterdits` (comparaison sans casse ni accents, mot entier) ;
   - une empreinte hexadécimale de 64 caractères n'est JAMAIS comptée comme IBAN ou montant ;
   - `resume(fuites)` → `{ email; iban; montant; nom }` (comptes).
2. Tests nommés : `journal-propre-zero`, `email-trouve`, `iban-valide-trouve` (IBAN fictif CONSTRUIT dans le test par calcul de la clé, jamais écrit en clair dans le fichier), `faux-iban-ignore` (clé fausse), `montant-euro-trouve` (`12,50 €`, `EUR 3.20`, `"montant":1250`), `nom-sans-casse-ni-accent` (`Société Exemple` trouvé dans `societe exemple`), `empreinte-hexa-ignoree`, `valeur-jamais-recopiee` (le résultat sérialisé ne contient pas la chaîne trouvée), `lignes-vides-et-liste-vide`.

## Hors périmètre
Parcours fictif complet passé au scanner (test d'intégration de la fiche bloquée L08-T44). Garde de CI sur des fichiers du dépôt (déjà couverte pour e-mails et IBAN par `garde:fictif`).

## Pièges
`garde:fictif` refuse tout IBAN valide écrit dans un fichier suivi : dans le test, construire l'IBAN à l'exécution (pays, clé calculée par modulo 97 sur `BigInt`, compte inventé). Les e-mails des tests sont `@exemple.fr`. Règles du noyau : le modulo 97 passe par `%`, permis ; pas de `/`. Sensible (sécurité, données personnelles).
