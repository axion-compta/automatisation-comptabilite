## Contexte
Les routes de lecture du lot (L03-T32 à L03-T34) et le faux serveur (L03-T35 à L03-T37) servent les écrans E19 et E57 sans base réelle. Comme `genererCompta()` (L01-T22), le jeu est déterministe (graine fixe) et 100 % fictif. Les montants de la déclaration doivent être cohérents avec les écritures du jeu, pour que « D'où vient ce montant ? » renvoie à de vraies écritures du jeu.

## À faire
1. `packages/donnees-fictives/src/declarations.ts` (réutilise `genererCompta`, `creerAlea`, `GRAINE` par import relatif sans modifier ces fichiers) :
   - `genererDeclarations(graine = GRAINE)` → `{ version: 1; periodesTva: { id; exerciceId; debut; fin; statut; formulaire }[]; declarations: { id; periodeId; formulaire; millesime; statut; cases: { code; montantCentimes; baseCentimes: number | null; sources: { ecritureId; ligneIndex }[] }[]; validePar: string | null; valideLe: string | null; versionPaquet }[]; estimations: { exerciceId; etat: 'calculee' | 'non_calculee'; motif?: 'tva_en_doute' | 'regime_non_traite'; piecesARegarder?: number; collecteeCentimes?: number; deductibleCentimes?: number }[]; fec: { id; exerciceId; version; statut; sha256; nomFichier; preparePar; prepareLe; resultatControles: 'ok' | 'ecarts'; controles: { regleId; nombreEcarts }[]; motif: string | null; destinataire: string | null }[]; traces: { regleId; gravite; objetType; objetId; resultat; valeur: string | null; ecartCentimes: number | null; horodatage }[]; echeances: { code; dateLimite; statut; dateAVerifier: boolean; niveau }[] }` pour le profil `pleine` (le profil `vide` rend des listes vides) ;
   - codes de formulaire et de lignes FICTIFS (`FORM_A`, `X01`…), noms de validateurs fictifs (« Camille Fictif »), SIREN fictif 123456782 dans les noms de FEC ;
   - une période `ouverte` avec estimation `non_calculee` (motif `tva_en_doute`, 2 pièces à regarder), une `validee`, une `deposee_par_client` ; un FEC `_TRAVAIL` et un FEC définitif remplacé puis sa nouvelle version.
2. Tests nommés : `meme-graine-meme-empreinte` (SHA-256 de la sérialisation figé), `sources-existent-dans-le-jeu-compta` (chaque `ecritureId` existe dans `genererCompta()`), `montant-case-egal-somme-sources`, `une-estimation-non-calculee-sans-montant`, `profil-vide-listes-vides`, `aucun-mot-interdit` (liste construite par morceaux comme `outils/gardes/textes.mjs`), `noms-fec-fictifs`.

## Hors périmètre
Pas de route, pas de handler. Aucune valeur légale réelle (taux, seuils, dates limites légales) : les dates d'échéance sont inventées.

## Pièges
`garde:fictif` contrôle e-mails et IBAN : aucun IBAN. Ne pas toucher `compta.ts` ni `generateur.ts`. Cas limites exigés : graine 0 et graine négative (déterministes), sérialisation stable (clés triées).
