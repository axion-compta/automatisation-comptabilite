## Contexte
Fiche du MVP issue de l'audit de couverture n° 3 (manque PARTIEL ou NON COUVERT). `LigneEcriture` (`ecritures/modele.ts`) ne garde que les centimes en euros ; L24-T02 modifie aussi ce fichier (d'où la dépendance).

## À faire
1. Tests d'abord.
2. `LigneEcriture` : bloc facultatif `devise: { code, montantOrigine, taux, dateTaux, source }` ; `verifierLigne` refuse un bloc incomplet ou un code hors ISO 4217 à 3 lettres.
3. `change/ecriture-ecart.ts` : les lignes de règlement portent ce bloc.
4. Tests nommés (5) : `devise-origine.test.ts` : `devise-et-montant-origine-conserves`, `taux-et-date-conserves`, `devise-sans-montant-refusee`, `euro-sans-champ-devise` ; `ecriture-ecart.test.ts` : `reglement-porte-la-devise`.

## Hors périmètre
Connecteur de taux et historique (domaine DEC) ; colonnes devise du FEC ; écarts latents (L24-T21).

## Pièges
Champ facultatif : aucune écriture en euros ne change. Données fictives seulement. Moins de 300 lignes ; au-delà, découper et le noter au journal.
