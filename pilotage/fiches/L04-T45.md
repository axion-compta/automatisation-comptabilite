## Contexte
Spec 04, fichier 07 §4 et fichier 09 : « Texte à l'écran (IMP-044, sans le mot "jeter") » ; « recherche des mots interdits du lexique (QUA-028, avec "jeter" pour IMP-044) dans tous les messages de ce lot : 0 occurrence. » `MOTS_INTERDITS` de `outils/gardes/textes.mjs` cherche des sous-chaînes : « jeter » y serait faux positif dans « rejeter » ou « projeter ».

## À faire
1. `outils/gardes/textes.mjs` : nouvelle liste `MOTS_INTERDITS_ENTIERS`, écrite en morceaux comme `MOTS_INTERDITS` (`['je', 'ter']`, `['je', 'tez']`, `['je', 'té']`, `['je', 'tée']`, `['je', 'tés']`, `['je', 'tées']`) ; dans `analyserMotsInterdits`, recherche par expression `(?<!\p{L})mot(?!\p{L})` avec drapeaux `iu` ; même message que pour les autres mots.
2. Tests nommés (dans `textes.test.mjs`) : `jeter-refuse`, `rejeter-et-projeter-acceptes`, `jetez-majuscule-refuse` (« Jetez »).

## Hors périmètre
Aucun autre mot ; aucune autre garde.

## Pièges
Ne pas écrire le mot interdit en un seul morceau dans `textes.mjs` (la garde se lirait elle-même) ; les tests construisent le mot par concaténation. Chemin `outils/gardes/` : PR sensible.
