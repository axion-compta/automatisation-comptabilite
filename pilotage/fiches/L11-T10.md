## Contexte
Spec 11, fichier 05, E5 : pièce payée par la carte de l'entreprise avec une part personnelle : D charge (part société HT) ; D TVA déductible (TVA de la part société) ; D compte de la personne (part personnelle TTC) / C banque ou compte de carte (TTC). Jamais de crédit du compte de la personne (E6 : une dépense payée par la société ne crée aucune dette envers la personne). Règle 5 : si le compte de la personne devient débiteur, alerte bloquante V3-MOT-064 (déjà spécifiée ailleurs) : la fonction rend seulement le signal. Cas NF-15 : D charge 50,00 ; D TVA 5,00 ; D personne 55,00 / C banque 110,00 ; 0 remboursement.

## À faire
1. `packages/noyau/src/frais/ecriture-part-perso.ts` (utilise `repartirPiece` de L11-T06) :
   - `proposerEcriturePartPerso(piece { ttc; tva; partPersoTtc }, comptes: ComptesFrais & { compteCharge: string }, { id; journal; date; soldePersonneAvant: Centimes })` → `{ ecriture: Ecriture (statut propose); compteDebiteur: boolean }` ; `compteDebiteur` vrai si `soldePersonneAvant − partPersoTtc` < 0 (solde créditeur compté positif) ;
   - ligne de TVA omise si la TVA de la part société vaut 0 ; ligne personne omise si la part perso vaut 0 ;
   - AUCUNE ligne au crédit du compte de la personne (test dédié) ;
   - refus `entree_invalide` sur les mêmes entrées que L11-T06 et si `soldePersonneAvant` n'est pas un entier.
2. Tests nommés : `nf15-moitie-personnelle`, `sans-part-perso-pas-de-ligne-personne`, `tout-personnel-sans-charge` (pas de ligne de charge à 0), `jamais-de-credit-personne` (boucle de 500 cas à graine fixe), `compte-debiteur-signale`, `compte-crediteur-non-signale` (borne : solde exactement égal à la part → non débiteur), `entrees-invalides`.

## Hors périmètre
Reclassement automatique d'un compte débiteur (interdit par la spec) ; dépense entièrement personnelle payée par la carte sans ticket (circuit banque, lot 02).

## Pièges
Règles du noyau (eslint) comme L01-T06 ; Stryker sur tout le noyau ; ne pas toucher `packages/noyau/src/index.ts`, `part-perso.ts` ni `ecritures/modele.ts`. Numéros de compte uniquement dans les tests. Une écriture avec une ligne à 0 est refusée par L01-T06 (`ligne_nulle`) : omettre la ligne, ne jamais l'écrire à 0. Sensible (argent).
