## Contexte
Spec 05, fichier 06 §4 : toute citation légale d'un agent est un identifiant du registre des sources (DEC-001) avec sa version ; référence inconnue = sortie rejetée (A2-19). Une valeur légale est montrée « sourcée » seulement si sa source officielle est citée avec la date de relevé ET qu'un contrôle croisé l'a confirmée (deux lectures indépendantes) ; sinon « à vérifier » (D44, D31).

## À faire
1. `packages/noyau/src/agents/sources.ts` :
   - `lireCitation(texte)` → `{ registre: 'DEC-001'; id; version } | null` pour la forme `DEC-001:<id>@<version>` (`id` `[A-Z0-9-]+`, `version` non vide sans espace) ;
   - `verifierCitations(citations: string[], registre: { id; version; source?; dateReleve?; lectures: number }[])` → `{ valide: true } | { valide: false; inconnues: string[]; malFormees: string[] }` ; une citation dont la version n'existe pas = inconnue ;
   - `statutAffiche(entree)` → `'sourcee' | 'a_verifier'` : sourcée seulement si `source` non vide, `dateReleve` au format AAAA-MM-JJ et `lectures >= 2`.
2. Tests nommés : `citation-lue`, `citation-mal-formee` (`DEC-001:`, `DEC-001:X`, `X:Y@1`, vide, espaces), `citation-inconnue-rejetee` (A2-19 : `DEC-001:FAUX-9@1`), `version-inconnue-rejetee`, `toutes-valides`, `sourcee-avec-deux-lectures`, `une-seule-lecture-a-verifier`, `date-de-releve-invalide-a-verifier` (`2026-13-01`, `01/01/2026`, vide), `lectures-invalides` (NaN, -1, 1.5, Infinity → à vérifier).

## Hors périmètre
Pas de contenu du registre DEC-001 (dépôt privé et lot 5 de specs). Aucune valeur légale.
