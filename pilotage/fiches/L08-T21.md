## Contexte
Spec 08, fichier 09 §4 : avant de proposer le lien : (1) chaque FEC passe les contrôles du lot 03 ; (2) nombre de pièces de l'index = nombre de pièces en base ; (3) chaque empreinte du manifeste recalculée sur l'archive ; (4) total débit = total crédit par exercice dans le grand livre exporté. Un contrôle en échec bloque la remise et alerte Will (code `export_bloque` de L08-T00). Un contrôle qui n'a pas pu tourner bloque aussi (PRI-007). Résultats au format `ResultatControle` de L08-T14.

## À faire
1. `packages/noyau/src/export-complet/controles.ts` :
   - `controleFec(resultats: { exercice; ok: boolean }[] | null, exercices: string[])` : un contrôle `fec:<exercice>` par exercice attendu ; exercice sans résultat = `IMPOSSIBLE` ; résultat d'un exercice non attendu = `ErreurExploitation('ordre_invalide')` ;
   - `controleNombrePieces(lignesIndex: { pieceId }[], piecesEnBase: number)` : compte les `pieceId` DISTINCTS ;
   - `controleManifeste(texte: string | null, fichiers: { nom; octets }[])` : via `verifierManifeste` (L03-T01) ; texte illisible = `ECHEC` (pas une exception) ;
   - `controleGrandLivre(lignes: { exercice; debit: number; credit: number }[])` : addition en centimes entiers par exercice (`Number.isSafeInteger` sur chaque montant et chaque somme, sinon `IMPOSSIBLE` pour l'exercice) ; un contrôle `grand_livre:<exercice>` ;
   - `deciderRemise(controles)` → `{ remise: 'permise' | 'bloquee'; alerte: Alerte | null }` (alerte `export_bloque` avec `clientRef` et horodatage en argument) ; liste vide = `controle_absent`.
2. Tests nommés : `tout-vert-remise-permise`, `fec-manquant-impossible-bloque`, `pieces-index-dedoublonnees`, `nombre-de-pieces-different-bloque`, `fichier-modifie-bloque`, `manifeste-illisible-echec`, `grand-livre-desequilibre-bloque` (écart de 1 centime), `montant-invalide-impossible` (1.5, NaN, Infinity, au-delà de `MAX_SAFE_INTEGER` en somme).

## Hors périmètre
Contrôles du FEC eux-mêmes (lot 03). Accusé lié au manifeste (L07-T10). Envoi de l'alerte (L08-T43, bloquée).

## Pièges
