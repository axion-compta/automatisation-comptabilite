## Contexte
Spec 09, §04 règles 2 et 3 : `POST /profil/changements/apercu` rend la liste chiffrée des objets touchés (brouillons, déclarations non déposées, échéances, écritures validées = TOUJOURS 0) ; « Rien n'est enregistré sans "Confirmer" » ; date d'effet antérieure à une période dont la TVA est déposée = `409 periode_deposee`. `POST /profil/changements` exige la réauthentification pour forme, régime de TVA, impôt et dates : elle viendra avec l'identité de la console (L09-T49, bloquée).

## À faire
1. `packages/contrat/src/domaines/profil-changements.ts` : schémas `DemandeChangement { cle; valeur: json; effetDebut; motif }`, `Apercu { apercuId; brouillonsRecalcules: number; declarationsRecalculees: { debut; fin }[]; echeancesDeplacees: string[]; ecrituresValideesTouchees: 0 (littéral) }` ; routes `apercuChangement` (`POST /profil/changements/apercu`, en-tête) et `confirmerChangement` (`POST /profil/changements`, en-tête, corps `{ apercuId }`) ; erreurs `PERIODE_DEPOSEE` 409, `APERCU_INCONNU` 404, `APERCU_PERIME` 409 (le profil a changé depuis l'aperçu).
2. `profil-changements-service.ts` : objets fictifs (brouillons, déclarations dont une déposée) de `genererProfils()` ou définis dans le service ; aperçu sans aucun effet sur l'état ; confirmation = nouvelle ligne datée (ajout seul).
3. `routes.ts` : ajouter `profilChangements: { apercuChangement, confirmerChangement }` ; régénérer `openapi.json`.
4. `apps/serveur/src/domaines/profil-changements.ts` + `app.ts`.
5. Tests nommés : `apercu-sans-effet` (`GET /profil` identique avant et après), `apercu-zero-ecriture-validee`, `effet-avant-periode-deposee-409`, `confirmation-cree-une-ligne`, `confirmation-sans-apercu-404`, `apercu-perime-409` (un champ modifié entre aperçu et confirmation), `sans-en-tete-refuse`.

## Hors périmètre
Pas de réauthentification (L09-T49) ; pas de recalcul réel des déclarations (lot 03) ; pas de faux serveur (L09-T37).

## Pièges
Comme L09-T30. Le littéral de type `0` doit apparaître dans le JSON Schema (`const: 0`) : le vérifier dans `openapi.json`.
