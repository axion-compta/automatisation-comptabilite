## Contexte
Spec 09, §01 règle 6 : hors périmètre (SA, société cotée, commissaire aux comptes, coopérative, GIE, paie, siège en Corse ou outre-mer, plusieurs pays) = démarrage bloqué avec une phrase claire, jamais de traitement partiel. `je_ne_sais_pas` sur le commissaire aux comptes = question reposée avant la première clôture. Règle 8 : « je ne sais pas » permis pour les champs du calendrier. Cas P15, P16, P17. **Prérequis hors lot** : `ecrire()` d'`api.ts` (L07-T26) sur main. Les clés `societe_cotee`, `paie`, `plusieurs_pays` et leurs blocages sont posés par L09-T54 (ajoutée par L00-T85, BLOQUE-L09-T44) : valeurs envoyées `oui` / `non`.

## À faire
1. `route.tsx` (`id: 'e38'`, `chemin: '/demarrage/questions'`) ; `Ecran.tsx` : questions une par une (forme, société cotée, commissaire aux comptes oui / non / je ne sais pas, paie, plusieurs pays, code postal du siège) ; chaque réponse envoyée par `POST /profil/champs/{cle}` (`origine: saisie_personne`) ; après envoi, `GET /profil` : si `blocages` non vide, page de blocage (phrases de L09-T38), aucune autre question, aucun bouton « continuer » ; sinon suite du parcours (lien vers E39) ;
2. code postal : 5 chiffres vérifiés avant envoi (message clair) ; « je ne sais pas » proposé seulement là où la spec le permet ;
3. `e38.ts` : textes (vouvoiement).
4. Tests nommés (MSW) : `commissaire-oui-bloque-p15`, `commissaire-je-ne-sais-pas-continue-p15`, `siege-exclu-bloque-p16`, `forme-hors-perimetre-bloque-p17`, `blocage-sans-continuer`, `code-postal-invalide-avant-envoi` (4 chiffres, lettres, vide), `navigation-clavier` (chaque question atteignable au clavier, focus sur la question suivante), `erreur-serveur-reessayer`.

## Hors périmètre
Pas de correction de E37 (point P9 : équipe démo). Pas de règle de périmètre dans l'écran : le serveur décide (`blocages`).

## Pièges
