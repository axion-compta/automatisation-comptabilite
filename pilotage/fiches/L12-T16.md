## Contexte
Spec 12, `03-controles-tva` : CC-T09 (V3-TVA-026) « Décision de Will (06/11/2026) : achats hors UE et importations non traités au MVP. Vendeur hors UE ou non établi sans TVA française, importation avec déclaration en douane, numéro IOSS : ligne toujours `A_VERIFIER`, donc blocage de la préparation de la TVA (CC-T02). Aucun montant d'autoliquidation calculé au MVP. » CC-T14 (V3-CTL-024) « TVA d'un autre État de l'UE facturée → `NON_DEDUCTIBLE_ETRANGERE`, 0,00 déduit », M. Cas CT-26 (logiciel hors UE 1 000,00 HT sans TVA : `A_VERIFIER`, B via CC-T02, 0,00 collecté et déduit ; facture espagnole 100,00 + 21,00 : 0,00 déduit, charge 121,00).

## À faire
1. `packages/noyau/src/controles/regles/tva-etrangere.ts` :
   - `OrigineAchat { paysVendeur: string /* code ISO à 2 lettres */; tvaFrancaise: boolean; declarationDouane: boolean; numeroIoss: boolean; tvaFacturee: Centimes; ttc: Centimes }` ;
   - `qualifierOrigine(o, etatsUe: readonly string[], paysSociete: string)` → `{ code: 'A_VERIFIER' | 'NON_DEDUCTIBLE_ETRANGERE' | 'NATIONAL'; deduit: Centimes; charge: Centimes }` : la liste des États de l'UE est un ARGUMENT (paramètre daté, jamais en dur) ; douane ou IOSS = `A_VERIFIER` même si le pays est dans l'UE ; pays hors liste = `A_VERIFIER`, 0 calculé ; pays de l'UE autre que celui de la société avec TVA = `NON_DEDUCTIBLE_ETRANGERE`, charge = TTC ; code pays invalide = exception ;
   - `regleCCT09` : id `CC-T09`, version 1, gravité `B`, bloque `tva`, déclencheurs `arrivee`, `continu`, `avant_tva`, `a_la_demande` : ALERTE pour `A_VERIFIER` ;
   - `regleCCT14` : id `CC-T14`, gravité `M`, bloque `[]` : ALERTE pour `NON_DEDUCTIBLE_ETRANGERE`.
2. `packages/noyau/src/controles/regles/__tests__/tva-etrangere.test.ts`, tests nommés : `CT-26` (les deux pièces), `ioss-a-verifier`, `douane-a-verifier-meme-dans-l-ue`, `liste-ue-vide-tout-a-verifier`, `pays-de-la-societe-national`, `code-pays-invalide-exception` (`'E'`, `'esp'`, `''`), `aucune-autoliquidation-calculee` (aucun champ collecté dans la sortie), `montants-invalides`.

## Pièges
Règles du noyau comme L01-T06 : montants en `Centimes` via `packages/noyau/src/argent`, ni `/`, ni littéral décimal, ni `Math.round`, ni `parseFloat`, ni `toFixed`. Stryker (seuil 80 %) porte sur tout le noyau : chaque branche doit être tuée par un test. Ne pas toucher `packages/noyau/src/index.ts` ni `controles/moteur.ts` (imports par chemin relatif). Aucun taux, seuil, délai ni date légale dans `src` (garde:litteraux, D31) : tout seuil ou tolérance arrive en argument ou dans un `ParametreLu` (L12-T00) ; paramètre absent = `IMPOSSIBLE`, jamais OK (PRI-007). Le noyau ne contient aucun texte affiché : seulement des codes. Montants et seuils des tests INVENTÉS ou repris des cas fictifs de la spec ; noms et SIREN fictifs seulement. TVA : chemin sensible (fusion après relecture Opus et double relecture argent). Aucun taux de TVA ni pourcentage légal dans src : taux en points de base et parts déductibles viennent d'un `ParametreLu` ; un paramètre au statut autre que `valide` rend la ligne `A_VERIFIER` (donc CC-T02, L12-T09), jamais une estimation. Comptes (445660, 445800, 275000…) en argument, jamais en dur. Le moteur (L01-T19) a une gravité FIXE par règle : quand la spec donne deux gravités à un même contrôle, la fiche crée deux règles (identifiant suffixé, voir LOT-12-PLAN §7). Le vocabulaire du code (`Blocage` = validation, tva, export, cloture ; `Declencheur` = `a_la_demande`) et celui du CSV (`validation_mois`, `preparation_tva`, `export_officiel`, `cloture`, `aucun` ; `demande`) diffèrent déjà : ne pas les « corriger ». La ligne du catalogue `docs/controles.csv` n'est PAS écrite ici (L12-T26 ou L12-T27) ; le titre du test `CT-nn` doit être exact, `garde:controles` le cherche. Cas limites exigés dans les tests : montant NaN, Infinity, non entier (1,5) et négatif là où il est interdit = exception codée (le moteur la change en `IMPOSSIBLE`) ; liste vide ; objets reçus dans l'ordre inverse (même résultat) ; écart d'exactement un centime de chaque côté de la tolérance. Chaque test doit rougir si l'on casse la branche qu'il couvre (inverser une comparaison, retirer un cas).
