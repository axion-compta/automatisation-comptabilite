## Contexte
Spec 04, fichier 01, points 2 et 4 : « Macros refusées : XLSM, XLSB, DOCM, et tout OOXML contenant vbaProject.bin = refus macro_refusee. » ; « ZIP : […] archive imbriquée ou chiffrée refusée […] noms en CP437 convertis ». On lit SEULEMENT le répertoire central (aucune décompression ici) : noms, tailles, drapeaux.

## À faire
1. `packages/noyau/src/pieces/entree/zip.ts` :
   - `EntreeZip { nom: string; nomBrut: Uint8Array; utf8: boolean; chiffre: boolean; methode: number; tailleCompressee: number; tailleDecompressee: number }` ;
   - `lireRepertoireZip(octets: Uint8Array): EntreeZip[]` : cherche la fin du répertoire central (signature `50 4B 05 06`) en partant de la fin, sur au plus 22 + 65 535 octets ; parcourt les entrées (signature `50 4B 01 02`) ; bit 0 du drapeau général = chiffré, bit 11 = nom en UTF-8, sinon nom décodé en CP437 (table de 128 caractères écrite dans le fichier) ; ZIP64 (valeurs `0xFFFFFFFF` ou `0xFFFF`) = `ErreurPiece('archive_refusee')` ; répertoire tronqué, signature absente ou décalage hors du fichier = `ErreurPiece('archive_refusee')` ;
   - `classerConteneur(entrees)` → `'docx' | 'xlsx' | 'odt' | 'zip'` ou `{ refus: 'macro_refusee' }` : `vbaProject.bin` à n'importe quel niveau = macro ; `[Content_Types].xml` + `word/document.xml` = docx ; `+ xl/workbook.xml` = xlsx ; entrée `mimetype` + `content.xml` = odt ; sinon zip.
2. Tests nommés (ZIP fabriqués octet par octet dans le test, avec une petite fonction d'aide) : `liste-les-noms`, `drapeau-chiffre-lu`, `nom-cp437-converti` (octet `0x82` = « é »), `nom-utf8-lu`, `docx-reconnu`, `xlsx-avec-vbaproject-refuse`, `odt-reconnu`, `zip64-refuse`, `repertoire-tronque-refuse` (fichier coupé au milieu ; décalage plus grand que le fichier ; zéro octet).

## Hors périmètre
Pas de décompression, pas de zip-slip ni de ratio (L04-T04).

## Pièges
Lire les entiers en petit-boutiste avec `DataView` et TOUJOURS vérifier `decalage + longueur <= octets.length` avant de lire (archive piégée). Aucune boucle sans borne : nombre d'entrées lu dans la fin du répertoire et comparé à ce qui tient dans le fichier. Règles du noyau comme L04-T00.
