## Contexte
Spec 12, `05-traitement-des-doutes`, C4 (V3-CTL-044) : « Mode amorçage (premier import) : cas regroupés par cause, décisions par fournisseur, rapport de reprise (nombre de cas, décisions, restants). Premier lot du banc traité en moins de 50 décisions. » Cas CT-37 (premier import : 400 pièces, 60 cas : traité en ≤ 50 décisions, rapport de reprise produit).

## À faire
1. `packages/noyau/src/controles/doutes/amorcage.ts` :
   - `CasAmorcage { id; cause: string; fournisseurId: string }` ;
   - `planDecisions(cas)` → `{ decisions: { cause; fournisseurId; casIds: string[] }[] }` : une décision par couple (cause, fournisseur), triée par nombre de cas décroissant puis cause ;
   - `appliquerDecision(etat, decision)` → nouvel état (aucune mutation) ;
   - `rapportReprise(etat)` → `{ cas: number; decisions: number; restants: number }`.
2. `packages/noyau/src/controles/doutes/__tests__/amorcage.test.ts`, tests nommés : `CT-37` (400 pièces et 60 cas fictifs construits pour tenir en ≤ 50 décisions), `une-decision-par-couple`, `tri-stable`, `etat-non-modifie`, `rapport-apres-chaque-decision`, `aucun-cas`, `decision-inconnue-exception`.

## Hors périmètre
Import réel des pièces (lot 04). Écrans de reprise (lot 15 ou 04).
