## Contexte
Spec 08, fichier 09 §2 : en plus des tables brutes de la console, l'archive de fin de contrat contient des fichiers lisibles par un comptable : un FEC par exercice avec son empreinte ; balance, grand livre et journaux en CSV ; pièces rangées `pieces/AAAA/MM/<empreinte>.<ext>` avec un index CSV (pièce vers écritures) ; conversations du chat et transcriptions validées (texte) ; paramétrages rejouables (PLA-174) ; un `LISEZMOI.txt`. Ce fichier décrit seulement QUELS chemins l'archive contient, pas leur contenu.

## À faire
1. `packages/noyau/src/export-complet/arborescence.ts` :
   - `cheminPiece({ empreinte; recueLe: 'AAAA-MM-JJ'; extension })` → `pieces/AAAA/MM/<empreinte>.<ext>` : extension en minuscules, `^[a-z0-9]{1,8}$` (sinon `ErreurExploitation('chemin_invalide')`), empreinte validée (L08-T00) ;
   - `indexPieces(pieces: { id; empreinte; recueLe; extension; ecritures: string[] }[])` → lignes `{ chemin; pieceId; ecritures: string }` (écritures triées, séparées par `|`), triées par chemin ; deux pièces de même empreinte = UN seul chemin, une ligne par pièce (le fichier n'est pas dupliqué) ;
   - `arborescence({ exercices: { code; fecNom: string }[]; pieces; avecConversations: boolean; avecParametrages: boolean })` → liste triée de chemins : `LISEZMOI.txt`, `fec/<fecNom>` par exercice, `comptable/balance.csv`, `comptable/grand-livre.csv`, `comptable/journaux.csv`, `pieces/index.csv`, chemins des pièces, `conversations/conversations.txt` si demandé, `parametrages/regles.jsonl`, `parametrages/modeles.jsonl`, `parametrages/fournisseurs.jsonl`, `parametrages/memoire.jsonl` si demandé ;
   - `fecNom` fourni par l'appelant (nom calculé par L01-T18) : refusé s'il contient `/`, `\`, `..`, un caractère de contrôle, ou s'il est vide ; deux chemins identiques = `chemin_en_double`.
2. Tests nommés : `chemin-piece-par-empreinte-et-mois`, `extension-normalisee-ou-refusee` (`PDF` → `pdf` ; `p d f`, `../x`, 9 caractères refusés), `meme-empreinte-un-seul-fichier-deux-lignes`, `index-trie-et-ecritures-triees`, `arborescence-complete-triee`, `options-retirent-conversations-et-parametrages`, `fec-nom-dangereux-refuse` (`../a.txt`, `a/b`, vide, caractère nul), `aucune-piece-index-vide`.
