## Contexte
Spec 11 (notes de frais et indemnités kilométriques), fichier 01 : un frais est une `depense` ou un `trajet` ; payeur `societe`, `personne` ou `a_confirmer` ; source du payeur `banque`, `declaration` ou `ia` ; statuts `brouillon` → `a_completer` → `propose` → `valide` → `rembourse` ou `en_compte_courant`, sorties `exclu_paye_societe`, `refuse`, `perso` ; destination `remboursement` ou `compte_courant`. Véhicule : énergie `thermique`, `hybride`, `hydrogene`, `electrique` ; propriétaire `personne`, `conjoint`, `societe`, `location`. Toutes les fiches du dossier `packages/noyau/src/frais/` importent ce fichier : il est posé seul, en premier.

## À faire
1. `packages/noyau/src/frais/types.ts` (aucune logique métier, seulement des types et deux petites fonctions de garde) :
   - unions `NatureFrais`, `Payeur`, `SourcePayeur`, `StatutFrais`, `Destination`, `Energie`, `Proprietaire`, `CategorieVehicule = 'voiture' | 'deux_roues'` ;
   - `Frais { id; personneId; nature; categorieDepense?: string (ex. `repas_affaires`, `parking` : code libre, sert à choisir le compte de charge et la clé de TVA) ; dateDepense: string; libelle; montantTtc: Centimes; tva: Centimes; pieceId?: string; payeur; sourcePayeur?; ligneBanqueId?; statut; justificatifPerdu: boolean; motifSansJustificatif?: string; partPersoTtc: Centimes; destination?: Destination; ecritureId?; remboursementId?; version: number }` ;
   - `Trajet { fraisId; vehiculeId; depart; arrivee; motif; kmSaisisDixiemes: number; allerRetour: boolean }` ; `Vehicule { id; personneId; puissanceCv: number; energie; proprietaire; categorie; carteGrisePieceId?: string }` ;
   - `ComptesFrais { chargeParNature: Readonly<Record<string, string>>; chargeIk: string; tvaDeductible: string; comptePersonne: string; banque: string }` : AUCUN numéro de compte écrit dans `src` (ils arrivent en argument) ;
   - classe `ErreurFrais extends Error` avec un champ `code` typé par l'union `CodeErreurFrais` : `frais_paye_societe`, `justificatif_manquant`, `bareme_a_verifier`, `vehicule_societe`, `deux_roues_non_pris_en_charge`, `remboursement_superieur`, `transition_interdite`, `doublon_piece`, `entree_invalide`, `motif_obligatoire`, `compte_courant_reserve_associes` ;
   - `estStatutSortie(s)` (vrai pour `exclu_paye_societe`, `refuse`, `perso`) et `estStatutFinal(s)` (sorties + `rembourse`, `en_compte_courant`).
2.
