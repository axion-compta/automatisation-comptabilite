## Contexte
Toutes les briques existent mais ne sont pas assemblées : `lignesFec` et `nomFichierFec` (`fec/lignes.ts`), `fichierFec` (`fec/fichier.ts`), `rapportFec` (`fec/rapport.ts`), `fecEtDeclarationsPermis` (`profil/etat.ts`, motif `siren_absent`), `controlerAvantExport` côté serveur (`apps/serveur/src/securite/tete-journal.ts`, L06-T41). Aucun point d'entrée ne produit le FEC d'un exercice.

## À faire
1. Tests d'abord, sur les jeux du banc FEC (`fec/__tests__/banc/`).
2. `production.ts` (pur) : `preparerFecExercice({ exercice, ecritures, profil, chaine })` où `chaine` est le RÉSULTAT déjà calculé du contrôle de la chaîne (`{ ok: true } | { ok: false }`), passé en argument. Ordre : SIREN absent → `{ ok: false, code: 'siren_absent' }` ; chaîne rompue → `{ ok: false, code: 'chaine_rompue' }` ; sinon `{ ok: true, nomFichier, octets, sha256, rapport }` (nom à la date de clôture, exercices de 6 à 24 mois du banc 2).
3. `textes/documents/declarations.ts` : texte du code `chaine_rompue` (export bloqué, qui prévenir), à côté du texte `siren_absent` existant.
4. Tests nommés : `sans-siren-refus-code`, `chaine-rompue-refus-code`, `exercice-18-mois-nom-a-la-cloture`, `meme-jeu-meme-empreinte`, `empreinte-egale-au-banc-1`, `rapport-joint`, `texte-chaine-rompue-present`.
