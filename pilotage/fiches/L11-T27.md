## Contexte
Spec 11, fichier 06 : `POST /frais/{id}/proposer` (calcule et propose l'écriture), `POST /frais/valider` (valide un lot ; récapitulatif chiffré au-delà des seuils de V3-CTL-045), `POST /remboursements` (prépare, AUCUN virement émis). Erreurs : `justificatif_manquant`, `bareme_a_verifier`, `frais_paye_societe`, `remboursement_superieur`. « L'IA propose, une personne valide » : jamais de validation automatique. Les seuils du récapitulatif et le délai d'annulation viennent de la configuration du serveur, jamais du contrat.

## À faire
1. `frais-validation.ts` : routes `proposerFrais` (`POST /frais/{id}/proposer`), `validerFrais` (`POST /frais/valider`, corps `{ ids: string[] (1 à 100, sans doublon); confirmeRecapitulatif?: boolean }`), `preparerRemboursement` (`POST /remboursements`, corps `{ personneId; fraisIds; montantCentimes? }`) ; `Idempotency-Key` obligatoire ; erreurs `JUSTIFICATIF_MANQUANT` 409, `BAREME_A_VERIFIER` 409, `FRAIS_PAYE_SOCIETE` 409, `REMBOURSEMENT_SUPERIEUR` 409, `RECAPITULATIF_A_CONFIRMER` 409 (avec le total), `FRAIS_INCONNU` 404.
2. `frais-validation-service.ts` : sur l'état de L11-T26 ; écriture par `proposerEcritureDepense` (L11-T09) ou `proposerEcritureTrajet` (L11-T11) à la date de `dateEcriture` (L11-T08) ; trajet sur barème `a_verifier` → `BAREME_A_VERIFIER`, aucune écriture ; validation : en-tête `X-Personne` obligatoire, `demanderValidation` (L01-T07) ; lot au-delà du seuil de configuration sans `confirmeRecapitulatif` → `RECAPITULATIF_A_CONFIRMER` ; remboursement par `preparerRemboursement` (L11-T12), statut `propose`.
3. `routes.ts` : ajouter `fraisValidation` ; régénérer `openapi.json` ; serveur branché dans `app.ts`.
4. Tests nommés : `proposer-depense-ecriture-equilibree`, `proposer-trajet-bareme-a-verifier-409`, `proposer-sans-justificatif-409`, `valider-sans-personne-400`, `valider-lot-au-dela-du-seuil-recapitulatif`, `valider-lot-ids-en-double-400`, `remboursement-superieur-409`, `remboursement-prepare-sans-virement` (réponse sans aucun champ de paiement émis), `idempotence-meme-reponse`, `corps-invalides-400` (liste vide, 101 ids, montant NaN ou 1.5).
