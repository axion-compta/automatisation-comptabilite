## Contexte
Spec 03, §06 : « Fin de ligne CRLF ; aucune ligne vide ; ligne d'en-tête avec les 18 noms. » Encodage proposé UTF-8 sans BOM, « acceptation du BOM par l'outil officiel à vérifier » : la marque d'ordre et la fin de ligne sont donc des OPTIONS obligatoires, sans valeur par défaut. FEC-013 : régénérer un exercice clôturé donne le même fichier, octet pour octet.

## À faire
1. `packages/noyau/src/fec/fichier.ts` :
   - `OptionsFichierFec { finDeLigne: string; marqueOrdreOctets: boolean; finDeLigneFinale: boolean }` (tous obligatoires) ;
   - classe locale `ErreurFichierFec` (`code` : `option_invalide`, `ligne_vide`, `ligne_avec_fin_de_ligne`) ;
   - `texteFec(resultat: ResultatLignesFec, options)` → chaîne : en-tête, puis chaque ligne, joints par `finDeLigne`, suivis d'une `finDeLigne` si `finDeLigneFinale` ; une ligne vide ou contenant CR ou LF est refusée ;
   - `fichierFec(resultat, options)` → `Uint8Array` : `TextEncoder` (UTF-8), précédé des octets EF BB BF si `marqueOrdreOctets` ;
   - `finDeLigne` doit valoir exactement CR LF ou LF (construits par `String.fromCharCode(13, 10)` et `String.fromCharCode(10)`), sinon `option_invalide`.
2. Tests nommés : `octets-exacts-petit-fichier` (en-tête de 3 colonnes fictives et 2 lignes, octets attendus écrits à la main), `marque-ordre-en-tete`, `sans-marque-premier-octet-en-tete`, `aucune-ligne-vide`, `fin-de-ligne-finale-optionnelle`, `meme-entree-memes-octets` (deux appels, même empreinte via L03-T01 NON importé : comparer les octets), `fin-de-ligne-invalide-refusee`.

## Hors périmètre
Pas d'écriture sur disque, pas de contrôle (L03-T10 et suivantes), pas de nom de fichier (déjà dans `lignes.ts`).

## Pièges
Règles du noyau comme L03-T01 (aucune barre oblique inverse n'est nécessaire : utiliser `String.fromCharCode`). Le jeu sans mouvement donne un fichier réduit à l'en-tête : tester `lignes: []`. Cas limites exigés : accents (é, ç) encodés sur 2 octets, caractère hors plan de base (emoji fictif dans un libellé) encodé sur 4 octets, options partielles passées en `as never` → `option_invalide`.
