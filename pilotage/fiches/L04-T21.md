## Contexte
Spec 04, fichier 05 §2 : détection, « analyse sûre du XML (sans entités externes : IMP-033), validation […]. XML invalide = pièce lue comme un PDF ordinaire, marque xml_invalide. Le XML fait foi (TVA-039) : champs remplis depuis le XML, confiance 99, aucun OCR, aucun appel d'IA pour les montants. Profil MINIMUM ou BASIC WL (sans lignes) : lignes absentes, montants par taux lus dans le XML. » Ici : le XML CII seul (fichier `factur-x.xml` déjà extrait). L'extraction du fichier incorporé au PDF est dans L04-T49.

## À faire
1. `apps/serveur/src/pieces/xml/xml-sur.ts` : `analyserXmlSur(texte: string)` : refuse (`{ erreur: 'xml_invalide' }`) si le texte contient `<!DOCTYPE` ou `<!ENTITY` (sans casse) ou dépasse une longueur passée en argument ; sinon `XMLParser` de `fast-xml-parser` avec `processEntities: false`, `htmlEntities: false`, `ignoreAttributes: false`, `removeNSPrefix: true`, `parseTagValue: false` (toutes les valeurs restent des chaînes) ; exception de l'analyseur = `xml_invalide`.
2. `apps/serveur/src/pieces/xml/lire-cii.ts` : `lireCii(texte, longueurMax)` → `{ profil: 'minimum' | 'basicwl' | 'basic' | 'en16931' | 'extended' | 'inconnu'; champs: ChampLu[] (source `xml`, lecteur `xml`); emetteurSiren?: string; destinataireSiren?: string }` ou `{ erreur: 'xml_invalide' }` :
   - racine `CrossIndustryInvoice` obligatoire ; profil d'après `ExchangedDocumentContext/GuidelineSpecifiedDocumentContextParameter/ID` ;
   - `numero` = `ExchangedDocument/ID` ; `date_piece` = `IssueDateTime/DateTimeString` au format 102 (`AAAAMMJJ` → `AAAA-MM-JJ`) ;
   - dans `ApplicableHeaderTradeSettlement` : `ttc` = `GrandTotalAmount`, `montant_du` = `DuePayableAmount`, par `ApplicableTradeTax` (un ou plusieurs) : `ht@<pdb>` = `BasisAmount`, `tva@<pdb>` = `CalculatedAmount`, pdb tiré de `RateApplicablePercent` par chaîne ; `devise` = `InvoiceCurrencyCode` ;
   - SIREN : `SellerTradeParty/SpecifiedLegalOrganization/ID` dont l'attribut `schemeID` vaut `0002` ; idem `BuyerTradeParty` ;
   - montants lus par `lireMontant` de L04-T11 avec la convention `{ decimal: '.', ordreDate: 'JMA' }` ; import par chemin relatif vers `packages/noyau/src/pieces/…` (comme L01-T23).
3. Tests nommés (XML CII fictifs écrits dans le test, SIREN fictifs) : `cii-un-taux`, `cii-trois-taux`, `profil-minimum-sans-lignes`, `doctype-refuse`, `entite-refusee`, `xml-mal-forme-invalide`, `racine-inconnue-invalide`, `date-format-102`, `siren-emetteur-et-destinataire`.
