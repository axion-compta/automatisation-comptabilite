## Contexte
Spec 08, fichier 09 §2 point 2 : si l'export dépasse la taille maximale de la console (`TAILLE_MAX_ZIP`, valeur inconnue : passée en argument), le module découpe en parties (`partie-01.zip`, …) d'au plus cette taille, chacune avec son manifeste, et un manifeste global qui liste les parties. Reprise : chaque partie est une tâche idempotente ; une interruption reprend à la première partie absente. Cas T-EXP-12 : 4 Go avec un maximum de 1 Go → 4 parties + manifeste global ; interruption après la partie 2 → reprise à la partie 3 ; 100 % des empreintes vérifiées. Le manifeste vient de `manifeste` et `verifierManifeste` (L03-T01).

## À faire
1. `packages/noyau/src/export-complet/parties.ts` :
   - `decouper(fichiers: { chemin; taille: number }[], tailleMax)` → `{ nom: 'partie-NN.zip'; chemins: string[]; taille }[]` : remplissage dans l'ordre des chemins triés, nouvelle partie quand l'ajout DÉPASSERAIT `tailleMax` ; un fichier seul plus grand que `tailleMax` = `ErreurExploitation('fichier_trop_grand')` (le message donne le chemin, pas le contenu) ; tailles entières >= 0, `tailleMax` >= 1 (`taille_invalide`) ; liste vide = une seule partie vide ; numéros sur 2 chiffres, 3 au-delà de 99 parties ;
   - `manifesteGlobal(parties: { nom; empreinte }[])` → texte au format de L03-T01 (une ligne par partie, triée) ;
   - `premierePartieAbsente(plan, faites: { nom; empreinte }[])` → nom de la première partie du plan absente de `faites`, ou `null` si tout est fait ; une partie « faite » dont l'empreinte est mal formée compte comme absente ;
   - `verifierParties(plan, faites, manifesteGlobalTexte)` → `{ ok; manquantes; modifiees }` (s'appuie sur `verifierManifeste`).
2. Tests nommés : `t-exp-12-quatre-parties` (tailles simulées, 4 × 1 Go exactement avec `tailleMax` = 1 Go : 4 parties ; un octet de plus : 5), `borne-egale-meme-partie`, `fichier-trop-grand-refuse`, `liste-vide-une-partie-vide`, `reprise-apres-partie-2-donne-3`, `tout-fait-null`, `empreinte-mal-formee-refaite`, `manifeste-global-trie-et-verifie`, `tailles-invalides-refusees` (NaN, Infinity, -1, 1.5, `tailleMax` 0).
