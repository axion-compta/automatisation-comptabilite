## Contexte
Spec 02, fichier 05 : `POST /banque/liens/valider { ids | filtre: "surs" }` → « réponse préalable `{ nb_objets_touches: 12 }` puis confirmation (V3-BAN-038) » ; « Une ligne `RAPPROCHEE` n'est pas « validée » : la validation est un geste humain distinct ». README du bloc : « le mode Autonome ne peut valider que dans les limites écrites par le dirigeant, toujours tracé ». Test T05-7 : 12 lignes sûres → « 12 lignes seront touchées », puis 12 liens `valide` et 12 lignes de journal `acteur_type=personne`.

## À faire
1. `packages/noyau/src/banque/rapprochement/validation.ts` :
   - `preparerValidation(liens, etats, filtre: { ids: string[] } | { surs: true })` → `{ nbObjetsTouches; ids }` ; `surs` = liens `propose` dont la ligne est `RAPPROCHEE` ; id inconnu ou lien non `propose` → refus `lien_non_validable` (avec l'id) ;
   - `validerLot(liens, ids, acteur: { type: 'personne' | 'ia' | 'systeme'; id }, contexte: { mode: 'assiste' | 'autonome'; limites?: { montantMaxParLien: Centimes }; horodatage; confirmationNb: number })` → `{ liens: Lien[]; journal: EntreeJournal[] }` ;
   - refus : `ia_interdite` (type `ia` en mode `assiste`), `systeme_interdit`, `hors_limites` (IA en mode `autonome` sans limites, ou un lien au-dessus de `montantMaxParLien`), `confirmation_differente` (`confirmationNb` ≠ nombre préparé : la liste a changé entre-temps) ;
   - lien validé : objet neuf, `etat: 'valide'`, `version + 1`, `validePar`, `valideLe` ; entrée de journal `{ objetType: 'lien'; objetId; action: 'valider'; avant; apres; acteurType; acteurId; horodatage }` par lien.
2. Tests nommés : `t05-7-douze-surs`, `preparation-annonce-le-nombre`, `ia-refusee-en-assiste`, `autonome-dans-les-limites`, `autonome-hors-limites-refuse`, `confirmation-differente-refusee`, `lien-deja-valide-refuse`, `entree-non-modifiee`.

## Hors périmètre
Route HTTP, persistance et journal chaîné en base (bloqués : L02-T64). Défaire un lien (même fiche bloquée).

## Pièges
Cas limites exigés : liste d'ids vide (0 touché, refus `rien_a_valider`), ids en double (comptés une fois), `confirmationNb` `NaN` ou non entier, `montantMaxParLien` négatif. Tout est refusé ou tout est validé (jamais à moitié). Sensible (validation, argent). Règles du noyau.
