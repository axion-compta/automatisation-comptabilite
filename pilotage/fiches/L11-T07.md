## Contexte
Spec 11, fichier 04 : la TVA lue fait foi ; la part déductible vient d'un paramètre daté par nature (`tva.repas_affaires`, `tva.repas_deplacement`, `tva.hebergement_dirigeant`, `tva.transport_personnes`, `tva.vehicule_personnel`). Un paramètre au statut autre que `valide` ne produit jamais de TVA déductible définitive : la ligne est codée `A_VERIFIER`, 0 déduit, et la période de TVA ne peut pas être préparée (décision D4 : TVA avec pièce en doute = blocage). IK : aucune TVA. Justificatif perdu : 0. Ticket au nom de la personne : `NON_DEDUCTIBLE_NOM` (interrupteur V3-TVA-012 à NON). Cas NF-20. Les VALEURS (part déductible) ne sont jamais dans le code : la fonction reçoit la ligne de paramètre.

## À faire
1. `packages/noyau/src/frais/tva-frais.ts` (utilise `partDeductible` de `../tva/deductible.js`, L01-T15, sans le modifier) :
   - `ParametreTva { statut: 'valide' | 'a_verifier' | 'non_verifie' | 'retire'; partPointsDeBase: number }` (forme minimale : le noyau ne dépend pas de `packages/parametres`) ;
   - `traiterTvaFrais({ nature: string; tvaLue: Centimes; ticketAuNomDeLaPersonne: boolean; justificatifPerdu: boolean; estIk: boolean }, parametre: ParametreTva | undefined)` → `{ code: 'AUCUNE' | 'DEDUCTIBLE' | 'PARTIELLE' | 'NON_DEDUCTIBLE' | 'NON_DEDUCTIBLE_NOM' | 'A_VERIFIER' | 'SANS_PIECE'; deductible: Centimes; nonDeductible: Centimes; bloquePreparationTva: boolean }` ;
   - ordre : IK → `AUCUNE` ; perdu → `SANS_PIECE` (0) ; nom de la personne → `NON_DEDUCTIBLE_NOM` ; paramètre absent ou non `valide` → `A_VERIFIER`, 0 déduit, `bloquePreparationTva: true` ; sinon `partDeductible` ;
   - `deductible + nonDeductible = tvaLue` toujours ; TVA négative, non entière, `NaN` → `entree_invalide` ; part hors 0 à 10 000 → `entree_invalide`.
2. Tests nommés (parts INVENTÉES, ex. 7 000 points de base ; jamais une part réelle) : `ik-sans-tva`, `perdu-sans-piece-zero`, `nom-de-la-personne`, `nf20-parametre-a-verifier-bloque`, `parametre-absent-bloque`, `parametre-retire-bloque`, `part-totale-deductible`, `part-nulle-non-deductible`, `part-partielle-somme-exacte`, `entrees-invalides`.
