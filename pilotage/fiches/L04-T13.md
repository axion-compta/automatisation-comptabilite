## Contexte
Spec 04, fichier 03 §3 : « Lecteur B : […] Au MVP : règles en code (expressions pour SIREN avec clé de Luhn, n° de TVA intracommunautaire avec clé, dates, montants près des mots "Total", "TTC", "TVA", taux connus du paramètre daté). » Le lecteur B est indépendant du modèle : il ne voit que le texte visible et masqué (L04-T08, L04-T10).

## À faire
1. `packages/noyau/src/pieces/lecture/mots-cles-lecture.ts` : `MOTS_CLES_LECTURE = { version: 1, ttc: [...], ht: [...], tva: [...], numero: [...], date: [...] }` FR et EN, minuscules sans accents (ex. ttc : `total ttc`, `net a payer`, `total a payer`, `amount due`, `total due`, `grand total` ; numero : `facture n`, `facture no`, `invoice no`, `invoice number` ; date : `date de facture`, `date`, `invoice date`).
2. `packages/noyau/src/pieces/lecture/lecteur-b.ts` :
   - `lireAvecRegles({ texte, source: 'texte_pdf' | 'ocr', convention, tauxConnusPdb: number[] })` → `{ champs: ChampLu[]; ambigus: string[] }` (lecteur `B`) ;
   - par ligne du texte : mot-clé TTC puis DERNIER montant de la ligne (`lireMontant` de L04-T11) → champ `ttc` ; ligne TVA ou HT portant un taux (« 20 % », « 5,5 % », « 5.5% ») converti en points de base PAR CHAÎNE (jamais `parseFloat`), gardé seulement s'il est dans `tauxConnusPdb` → champs `tva@<pdb>` et `ht@<pdb>` ; numéro après un mot-clé numéro (`[A-Z0-9][A-Z0-9/-]{2,}`) ; date après un mot-clé date (`lireDate`) ; SIREN, SIRET, TVA (L04-T12) → `fournisseur_siren`, `fournisseur_tva` (première occurrence valide) ;
   - `citation` = sous-chaîne EXACTE du texte d'où vient la valeur ; deux valeurs différentes pour le même champ = champ omis et nom ajouté à `ambigus`.
3. Tests nommés : `facture-fr-un-taux` (HT 1 000,00, TVA « 19 % » 190,00, TTC 1 190,00 : 4 champs ; taux inventé de 1 900 pdb passé en argument), `facture-trois-taux`, `taux-inconnu-ignore`, `facture-en-convention-point`, `ttc-ambigu-omis`, `citation-exacte`, `siren-et-tva-lus`, `texte-vide-aucun-champ`, `tauxconnus-vide-aucune-tva`.

Comparaison avec le lecteur A (L04-T14), confiance (L04-T15), contrôles arithmétiques (L04-T16).
