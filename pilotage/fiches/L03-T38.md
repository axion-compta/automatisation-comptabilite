## Contexte
Spec 03, §07 : notice en 7 rubriques (journaux, mode de numérotation, repérage des à-nouveaux, convention des opérations sans pièce, sens de ValidDate, encodage, séparateur) ; encadré avant téléchargement, texte exact (FEC-012) : « Préparé par IA à partir de vos opérations validées. Contrôle de structure : N règles vérifiées. À faire vérifier par votre expert-comptable avant toute remise à l'administration. Conservez vos justificatifs originaux. » Les choix techniques (séparateur, encodage, marque d'ordre) sont encore « à confirmer » : la notice les reçoit en paramètre, elle ne les affirme pas.

## À faire
1. `packages/textes/src/documents/fec.ts` (aucun import d'un autre paquet) :
   - `encadreFec(nombreRegles: number)` → le texte exact ci-dessus, `N` remplacé (« 1 règle vérifiée » au singulier) ;
   - `noticeFec({ journaux: { code; libelle }[]; numerotation: 'par_journal' | 'continue'; journalANouveaux; conventionSansPiece; separateurNom; encodageNom; marqueOrdre: boolean })` → `{ titre; rubriques: { titre; texte }[] }` avec 7 rubriques dans l'ordre de la spec ;
   - libellés du rapport (`rapportFec` : titre, « Préparé par IA », totaux, nombre de lignes, empreinte, versions) en objet `as const` ;
   - en-tête de fichier : convention des textes (un objet de chaînes, vouvoiement), comme `packages/textes/src/ecrans/socle.ts`.
2. `__tests__/fec.test.ts`, tests nommés : `encadre-texte-exact`, `encadre-singulier`, `notice-sept-rubriques-dans-l-ordre`, `notice-reprend-les-parametres` (séparateur et encodage passés en argument apparaissent tels quels), `vouvoiement` (aucun mot isolé `tu`, `ton`, `ta`, `tes`, `toi`, `te`), `aucun-mot-interdit` (liste construite par morceaux dans le test, comme `MOTS_INTERDITS` de `outils/gardes/textes.mjs` ; ne pas importer ce `.mjs` dans un paquet TypeScript).

## Hors périmètre
Pas de PDF, pas de mise en page. Pas de texte des écrans (fichiers `ecrans/`).

## Pièges
Sensible (FEC) : relecture du texte exact mot pour mot contre la spec. Ne jamais écrire que le fichier est accepté par l'administration. `nombreRegles` NaN, négatif ou non entier = exception (test). Ne pas toucher `fr.ts`, `index.ts`, ni `ecrans.test.ts`.
