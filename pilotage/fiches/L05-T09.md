## Contexte
Spec 05, fichier 04 §3 : le modèle appelle `proposer_validation` ; le serveur range une proposition (outil, arguments, avant, après, cibles, nombre d'objets, montant total, expiration) ; seul le geste d'une PERSONNE l'applique. Fichier 03 §3 : un compte de service, un outil du modèle ou une tâche de fond reçoit un refus (403). Niveau I fermé au chat (CHT-067). Reprise sur erreur : même clé d'idempotence (AGT-048).

## À faire
1. `packages/noyau/src/chat/proposition.ts` (fonctions pures, horloge en argument, ISO) :
   - `creerProposition({ id, outil, niveau, cibles, avant, apres, montantTotal?, creeLe, dureeMs })` : `nombreObjets` = nombre de cibles distinctes ; `expireLe` = creeLe + dureeMs ; refus `parametre_invalide` si aucune cible, cible en double, `dureeMs` non entier ou <= 0 ;
   - `appliquer(p, { acteur, cle, maintenant, niveauIOuvert })` → `{ proposition; effet: 'applique' | 'deja_applique' }` ou `ErreurChat` : `acteur_non_humain` si l'acteur n'est pas `personne` ; `niveau_ferme` si niveau I et `niveauIOuvert` faux ; `proposition_expiree` si maintenant >= expireLe ; même `cle` sur une proposition déjà appliquée = `deja_applique` ; autre clé = `parametre_invalide` ; état `annulee`, `expiree` ou `refusee` = `proposition_inconnue` ;
   - `refuser(p)`, `expirer(p, maintenant)`.
2. Tests nommés : `creation-compte-les-objets`, `cible-en-double-refusee`, `duree-invalide` (0, -1, 1.5, NaN, Infinity), `personne-applique`, `compte-service-refuse` (A2-07), `modele-et-agent-refuses`, `niveau-i-ferme`, `expire-a-la-milliseconde-pres` (expireLe - 1 ms passe, expireLe refusé), `meme-cle-meme-resultat`, `autre-cle-refusee`, `aucune-ecriture-avant-le-geste` (la proposition créée n'a pas d'état appliqué).
