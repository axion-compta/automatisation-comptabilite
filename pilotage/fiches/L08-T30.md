## Contexte
Spec 08, fichier 08 §2 : étapes à partir de l'heure de détection : qualifier (sous 12 h, PROPOSÉ) ; informer chaque société touchée sous 24 h (PLA-129) ; la société notifie l'autorité dans les 72 h après en avoir pris connaissance (art. 33.1, À VÉRIFIER) ; Axion notifie pour ses propres traitements (72 h, À VÉRIFIER) ; retour d'expérience sous 15 jours. §4 : registre des violations (date de détection, date des faits, nature, données et personnes concernées, conséquences, mesures, sociétés informées, notification oui/non avec date ou motif si non, clôture). §5 : faille activement exploitée : qualification sous 4 h (PROPOSÉ), première alerte sous 24 h (règlement (UE) 2024/2847, À VÉRIFIER). §6 : exercice à blanc réussi si le message n° 1 et le dossier n° 2 sont prêts en moins de 24 h. Cas T-EXP-14. Toutes les durées viennent de L08-T02 (en heures), passées en argument.

## À faire
1. `packages/noyau/src/rgpd/violations.ts` :
   - `echeancesViolation(detecteeLe, { qualificationHeures; informationSocieteHeures; autoriteHeures; retourExperienceJours })` → horodatages `{ qualifierAvant; informerSocietesAvant; autoriteAvant; retourExperienceAvant }` (via `ajouterSecondes` de L08-T00, `heures * 3600` par multiplication) ;
   - `echeancesFaille(recueLe, { qualificationHeures; premiereAlerteHeures })` ;
   - `etatEcheances(echeances, faits: Partial<Record<keyof echeances, string>>, maintenant)` → pour chaque étape `'faite_a_temps' | 'faite_en_retard' | 'a_faire' | 'depassee'` ;
   - `validerLigneRegistre(ligne)` → codes : dates réelles ; `faitsLe` <= `detecteeLe` (`ordre_invalide`) ; `clotureLe` >= `detecteeLe` ; `notificationAutorite` = `{ faite: true; le } | { faite: false; motif }` (motif obligatoire si non : `motif_manquant`) ; `societesInformees` : liste de `{ societeRef; le }` ; aucune colonne de nom de personne (une clé `nom*` = `valeur_interdite`) ;
   - `resultatExercice({ debutLe; messageSocietePretLe: string | null; dossierAutoritePretLe: string | null; arretUrgenceActions: number | null }, { limiteHeures })` → `{ reussi; raisons: ('message_en_retard' | 'dossier_en_retard' | 'arret_non_essaye' | 'arret_plus_d_une_action')[] }` (T-EXP-14 : arrêt d'urgence en 1 action).

## Hors périmètre
Procédure écrite, modèles de messages, contacts, exercice réel (dépôt privé et fiche bloquée L08-T54). Arrêt d'urgence lui-même (lot 06).

## Pièges
Règles du noyau ; aucune heure légale écrite en dur : la multiplication `heures * 3600` porte sur un ARGUMENT, et la constante `3600` s'écrit `SECONDES_PAR_HEURE` sur une ligne qui ne nomme ni `delai` ni `duree`. Cas limites : heures NaN, Infinity, 0, négatives, 1.5 = `delai_invalide` ; horodatage mal formé = `horodatage_invalide`. Sensible (sécurité, RGPD).
