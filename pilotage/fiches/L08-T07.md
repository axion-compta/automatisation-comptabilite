## Contexte
Spec 08, fichier 05 §2 (scripts sans IA, règle de Will : on n'alerte qu'en cas de problème) : dump de nuit de plus de 26 h ; copie hors site en retard de plus de 2 h (PLA-164) ; aucun battement de la sonde externe depuis 15 min (« homme mort ») ; essai de restauration en échec ou absent depuis 35 jours ; plus de 100 tâches en attente depuis plus de 1 h ; plus de 2 % de réponses 5xx sur 15 min ; paquet de paramètres périmé (date d'effet dépassée par un paquet plus récent). Cas R13 (essai absent depuis 36 jours : 1 alerte) et R14 (copie en retard de 3 h : 1 alerte ; sonde coupée : 1 alerte « sonde muette »). Tous les seuils sont des réglages (L08-T02) passés en argument.

## À faire
1. `packages/noyau/src/exploitation/sondes.ts`, une fonction pure par sonde, chacune rend `Alerte | null` (type de L08-T00, `clientRef` passé en argument ou `null` pour la plateforme, `horodatage` = maintenant) :
   - `sondeDump({ dernierDumpReussiLe: string | null }, maintenant, ageMaxSecondes, clientRef)` : aucun dump réussi = alerte `dump_trop_ancien` ;
   - `sondeCopieHorsSite({ derniereSauvegardeLe; derniereCopieLe: string | null }, maintenant, retardMaxSecondes)` : retard = âge de la copie par rapport à la sauvegarde attendue ; copie absente alors qu'une sauvegarde existe = alerte ;
   - `sondeBattement({ dernierBattementLe: string | null }, maintenant, maxSecondes)` → `sonde_muette` ;
   - `sondeEssai({ dernierEssai: { le: string; resultat: 'reussi' | 'echec' } | null }, maintenant, absenceMaxJours)` → `essai_restauration_echec` si le dernier est un échec, `essai_restauration_manquant` s'il est absent ou trop ancien ;
   - `sondeFile({ taches: { enAttenteDepuis: string }[] }, maintenant, { attenteMinSecondes; tachesMax })` → `file_saturee` si le nombre de tâches en attente depuis plus de `attenteMinSecondes` DÉPASSE `tachesMax` ;
   - `sondeErreurs({ requetes: number; erreurs5xx: number }, maxPointsDeBase)` → `erreurs_5xx` si `erreurs5xx * 10000 > requetes * maxPointsDeBase` ; 0 requête = aucune alerte ; `erreurs5xx > requetes` = `ErreurExploitation('ordre_invalide')` ;
   - `sondePaquet({ installe: { version: number; effetLe: string }; disponibles: { version: number; effetLe: string }[] }, aujourdhui)` → `paquet_parametres_perime` si un paquet disponible de version supérieure a une date d'effet passée ;
   - `executerSondes(liste)` → `Alerte[]` (les `null` retirés ; liste vide si tout va bien : AUCUN message « tout va bien »).
