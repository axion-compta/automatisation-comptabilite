## Contexte
Garde-fou (spec 12, `01-socle-catalogue`) : un refus montre la liste des B et une phrase par B. Le même composant sert avant l'action (`GET /controles/bloquants`, L12-T42) et après un refus 409. Composants de base : L01-T29 (Carte, Pastille, États).

## À faire
1. `ListeBloquants.tsx` : props `{ titre: string; points: { cle: string; phrase: string; lien?: { libelle: string; href: string } }[]; vide: string }` ; liste `<ul>` dans une région `role="alert"` quand au moins un point ; état vide = phrase `vide` sans rôle d'alerte ; ordre des points conservé.
2. `liste-bloquants.css` : jetons seulement.
3. `__tests__/liste-bloquants.test.tsx`, tests nommés : `une-ligne-par-point`, `alerte-annoncee`, `vide-sans-alerte`, `lien-accessible` (nom accessible = libellé), `ordre-conserve`, `aucun-texte-en-dur` (rendu avec des props factices : seules ces chaînes apparaissent).

## Hors périmètre
Branchement dans un écran (lots 03 et 15). Textes (L12-T39).

## Pièges
Composants dans `packages/ui` (V3-UX-074) : aucun texte en dur (les textes arrivent en props depuis `packages/textes`, garde:textes) ; jetons de design seulement (garde:couleurs : aucun bleu, graisse 600 au plus, 14 px) ; cibles tactiles d'au moins 24 px ; accessibilité vérifiée par test (rôles, noms accessibles). Ne pas toucher `packages/ui/src/index.ts` : les écrans importent le composant par son chemin (les trois fiches de ce couloir tournent en parallèle ; un fichier commun les forcerait à se suivre).
