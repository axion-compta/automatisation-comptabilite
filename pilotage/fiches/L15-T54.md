## Contexte
Liste des écrans : N08 « Chercher ou demander », route `/recherche`. Spec 15, RE-R1 et RE-R4 : `POST /recherche` (texte dans le corps) ; résultats groupés par type ; `extrait` échappé avec `<mark>` ; vide = un mot « rien trouvé ». La partie « demander » (chat) et les conversations attendent D43 (L15-T67) : la page ne propose que la recherche.

## À faire
1. `extrait.tsx` : `Extrait({ html })` découpe la chaîne sur `<mark>` et `</mark>` SEULEMENT, décode les 5 entités (`&amp; &lt; &gt; &quot; &#39;`) et rend des nœuds texte React et des `<mark>` ; toute autre balise reste du texte visible ; jamais `dangerouslySetInnerHTML`.
2. `route.tsx` (`id: 'n08'`, `chemin: '/recherche'`) et `Ecran.tsx` : `<h1>` ; champ de recherche avec étiquette, envoi à la touche Entrée ou au bouton ; requête par `fetch` `POST` (corps JSON, schéma du contrat) dans une fonction locale `chercher()` ; moins de 2 caractères : message, aucun appel ; résultats groupés (pièces, écritures, tiers, commentaires) avec lien ; « Voir plus » par curseur ; région `aria-live="polite"` qui annonce le nombre de résultats ; le texte cherché n'apparaît jamais dans l'URL.
3. `packages/textes/src/ecrans/n08.ts`.
4. Tests nommés (jsdom, `demarrerNoeud`) : `script-reste-du-texte` (aucun élément `script` dans le DOM), `seul-mark-est-une-balise`, `entites-decodees-une-fois` (`&amp;lt;` reste `&lt;` à l'écran), `moins-de-deux-caracteres-aucun-appel`, `groupes-par-type`, `rien-trouve`, `voir-plus-par-curseur`, `texte-absent-de-l-url`, `annonce-du-nombre-de-resultats`.
