## Contexte
Contrat figé par L07-T15 (`GET /fin-contrat`, `POST /fin-contrat/accuse`, `POST /fin-contrat/gel`, `POST /fin-contrat/gel/levee`). Spec 07, `03-fin-contrat-gel.md` et D3 : accusé de réception du manifeste remis, effacement planifié à J+30 de l'accusé (paramètre fictif, L07-T13), jamais pendant un gel. Ici, AUCUN effacement n'est exécuté ni demandé : le service calcule seulement `efface_prevu_le` ; la demande réelle à la console est la fiche bloquée L07-T36.

## À faire
1. `packages/contrat/src/domaines/fin-contrat-service.ts` : `creerServiceFinContrat({ horloge, scenario })` → `{ lire(); accuser(cle, corps); poserGel(cle, corps); leverGel(cle, corps); journal() }` : état initial par `donneesDuScenario` ; `statut` déduit (`aucune` sans date de fin, `preavis` avec date de fin sans remise, `remis`, `accuse`) ; `efface_prevu_le` par `effacementPrevuLe` (L07-T10) ; accusé par `enregistrerAccuse` (L07-T10) avec l'auteur fictif `personne-fictive-1` ; gel par `poserGel` / `leverGel` (L07-T11) avec `par: 'client'` et `longueurMaxMotif` des paramètres fictifs ; traduction des codes : `pas_de_remise` → `PAS_DE_REMISE`, `deja_accuse` → `DEJA_ACCUSE`, `empreinte_differente` → `EMPREINTE_DIFFERENTE`, `gel_deja_actif` → `GEL_DEJA_ACTIF`, `gel_inactif` → `GEL_INACTIF`, `motif_manquant` → 400 ; toute autre erreur → 500 ; idempotence par clé (même clé = même réponse, un seul événement).
2. `apps/serveur/src/domaines/fin-contrat.ts` et `packages/faux-serveur/src/domaines/fin-contrat.ts` : remplacent les bouchons, même service. Le faux serveur garde l'état PAR instance de `creerHandlers` (un accusé reste visible au `GET` suivant).
3. `suite-fin-contrat.ts` + `commun-fin-contrat.test.ts`.
4. Tests nommés : `aucune-fin-par-defaut`, `preavis-avec-date-de-fin`, `accuse-puis-effacement-prevu-trente-jours-plus-tard` (date calculée, jamais d'effacement exécuté), `accuse-avant-remise-409`, `accuse-double-409`, `empreinte-differente-422`, `gel-pose-puis-leve`, `gel-double-409-et-levee-sans-gel-409`, `meme-cle-un-seul-evenement`.

## Hors périmètre
Aucun effacement, aucune tâche de fond, aucune relance envoyée (fiche bloquée L07-T36) ; pas de permission `compta-parametrer` ni de réauthentification (fiche bloquée L07-T37) ; pas d'export complet (lot 05).

## Pièges
Le motif du gel ne va dans AUCUN `console.log` ni message d'erreur technique. Le gel de la console (`gel_console`) est lu dans le scénario et jamais modifié par une route. Ne toucher ni `handlers.ts`, ni `app.ts`, ni le contrat. Sensible (effacement de données) : relecture Opus obligatoire.
