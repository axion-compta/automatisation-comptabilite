## Contexte
Spec 12, `00-LISEZMOI` et `01-socle-catalogue` : un catalogue, un contrôle par ligne, exécuté par le moteur (L01-T19, `controles/moteur.ts`). Les contrôles CC-K (cohérence) et CC-T (TVA) du lot 12 lisent tous une pièce (achat ou vente, lignes par taux, totaux, destinataire) et des paramètres réglables ou datés. Ce fichier commun évite que chaque fiche invente son propre type : il est posé une fois, puis seulement LU par les autres fiches du lot. PRI-007 : un contrôle qui n'a pas pu tourner n'est jamais compté OK.

## À faire
1. `packages/noyau/src/controles/regles/commun.ts` (types de `../moteur.js`, montants de `../../argent/index.js`) :
   - `LignePiece { taux: number /* points de base */; nature: string; ht: Centimes; tva: Centimes; ttc: Centimes; compte?: string }` ;
   - `PieceControlee { id; sens: 'achat' | 'vente'; date: string /* AAAA-MM-JJ */; lignes: readonly LignePiece[]; totaux: { ht; tva; ttc }; montantDu?: Centimes; destinataire?: { nom: string; siren?: string }; emetteur?: { nom: string; siren?: string; pays?: string }; fournisseurId?: string; mentions: readonly string[] }` ;
   - `ParametreLu { cle: string; valeur: string | null; statut: 'valide' | 'a_verifier' | 'non_verifie' | 'absent' }` (copie simple de ce que rend `packages/parametres`, L01-T14 ; le noyau n'importe pas ce paquet) ;
   - `parametreUtilisable(p)` : vrai seulement si `statut === 'valide'` et `valeur !== null` ;
   - `entierParametre(p)` : lit la valeur comme entier sûr (refus de `'1.5'`, `'NaN'`, `''`, `'Infinity'`) ou lève `ErreurControle('parametre_invalide')` ;
   - `classe ErreurControle extends Error` avec `code` parmi `entree_invalide`, `parametre_invalide`, `parametre_absent` ;
   - `exigerCentimes(n)` : lève `entree_invalide` si `n` n'est pas un entier sûr ;
   - `ok()` et `alerte(ecart?: Centimes, valeur?)` : fabriques de `SortieRegle`.
2. `packages/noyau/src/controles/regles/__tests__/commun.test.ts`, tests nommés : `parametre-valide-utilisable`, `parametre-a-verifier-inutilisable`, `parametre-sans-valeur-inutilisable`, `entier-parametre-refuse-non-entiers` (`'1.5'`, `'NaN'`, `''`, `'Infinity'`, `'1e3'`), `exiger-centimes-refuse` (NaN, Infinity, 1,5, `Number.MAX_SAFE_INTEGER + 2`), `alerte-porte-l-ecart`, `ok-sans-ecart`.
