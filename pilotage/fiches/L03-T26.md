## Contexte
Spec 03, §04 : `formulaire_ligne` (formulaire, millésime, code de ligne, libellé, formule, règle d'alimentation par comptes et codes TVA, TVA-032) ; « Préparation depuis les écritures validées de la période et la table du millésime ; chaque case garde ses sources (TVA-015) : "D'où vient ce montant ?" ouvre les écritures puis les pièces. » Principe 6 du bloc : chaque montant renvoie à ses écritures.

## À faire
1. `packages/noyau/src/declarations/cases.ts` (classe locale `ErreurDeclaration`) :
   - `TableFormulaire { formulaire; millesime; lignes: LigneFormulaire[] }`, `LigneFormulaire { code: string; alimentation?: { comptes: readonly string[] /* préfixes */; sens: 'debit' | 'credit' | 'solde_debiteur' | 'solde_crediteur' }; formule?: string; base?: boolean }` ;
   - `alimenterCases(table, ecritures: readonly Ecriture[], periode: { debut; fin })` → `CaseDeclaration { code; montant: Centimes; sources: { ecritureId; ligneIndex }[] }[]` : seulement les écritures `valide` dont la date est dans la période ; un compte est retenu s'il COMMENCE par un préfixe de la ligne ; les lignes à `formule` sont laissées à L03-T27 (montant 0, sources vides, champ `aCalculer: true`) ;
   - une ligne sans `alimentation` ni `formule` = `ligne_sans_regle` (avec le code).
2. Tests nommés (table fictive : codes `X01`, `X02`, `X03`, préfixes de comptes inventés ou du plan fictif L01-T22) : `case-alimentee-par-prefixe`, `brouillon-ignore`, `hors-periode-ignore`, `sources-completes` (chaque ligne d'écriture retenue apparaît une fois), `solde-crediteur`, `ligne-sans-regle-refusee`, `formule-laissee-a-calculer`.

## Hors périmètre
Pas de formule (L03-T27), pas de report de crédit (L03-T28), pas de table réelle d'un millésime (paramètre signé, dépôt privé, D31).

## Pièges
Règles du noyau comme L03-T01. Aucun code de ligne ni numéro de compte réel dans src. Cas limites exigés : table vide (liste vide), préfixe vide (refusé : il prendrait tous les comptes), deux lignes de même code (refus `ligne_en_double`), écritures dans l'ordre inverse (mêmes cases, sources triées par id puis index).
