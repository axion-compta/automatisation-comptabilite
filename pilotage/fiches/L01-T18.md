## Contexte
Spec 03, §06, règles de contenu : « Ordre : à-nouveaux en premier, puis ordre de validation. » Le brouillon est absent du fichier. Nom : `{SIREN}FEC{AAAAMMJJ de clôture}.txt` ; fichier de travail : suffixe `_TRAVAIL` avant l'extension tant que l'exercice est ouvert (FEC-009). L'ordre définitif des colonnes est encore à reconfirmer sur le texte en vigueur : il est donc passé en argument.

## À faire
1. `packages/noyau/src/fec/lignes.ts` :
   - type `ChampFec` = union des clés `journalCode`, `journalLib`, `ecritureNum`, `ecritureDate`, `compteNum`, `compteLib`, `compAuxNum`, `compAuxLib`, `pieceRef`, `pieceDate`, `ecritureLib`, `debit`, `credit`, `ecritureLet`, `dateLet`, `validDate`, `montantDevise`, `idevise` ;
   - `lignesFec(ecritures, contexte, colonnes: { champ: ChampFec; entete: string }[], options)` → `{ entete: string; lignes: string[]; totalDebit; totalCredit }` : seulement les écritures `valide` ; celles du journal `contexte.journalANouveaux` d'abord, puis tri par date de validation puis numéro ; une ligne de texte par ligne d'écriture, valeurs formatées et assemblées par L01-T17 ; libellé vide → libellé du compte (`contexte.libellesComptes`) ;
   - `nomFichierFec({ siren, dateCloture, travail })` → `123456782FEC20260331.txt` ou `…_TRAVAIL.txt` ; SIREN de 9 chiffres sinon `ErreurFec('siren_invalide')`.
   - `packages/noyau/src/fec/format.ts` (créé par L01-T17) : le type `CodeErreurFec` ne contient pas `'siren_invalide'`. Étendre le type en ajout seul (une nouvelle valeur dans l'union), sans changer le comportement existant ; ajouter dans `packages/noyau/src/fec/__tests__/format.test.ts` un test qui vérifie que `new ErreurFec('siren_invalide').code` vaut `'siren_invalide'`, sans modifier les tests existants.
2. Tests nommés (jeu fictif inventé : 3 écritures validées + 1 brouillon, SIREN fictif) : `brouillon-absent`, `a-nouveaux-en-premier`, `ordre-de-validation`, `totaux-egaux`, `colonnes-dans-l-ordre-donne` (deux ordres de colonnes donnent deux en-têtes), `libelle-de-repli`, `nom-travail-puis-final`.
