## Contexte
Spec 13, fichier 01, R07 : toute décision enregistre `sources[]`, au moins une parmi `piece` (piece_id + page + zone), `regle` (code + version), `historique` (ecriture_id), `parametre` (clé + date d'effet). R08 : sans source, la décision est une hypothèse, confiance plafonnée à `a_verifier`, jamais dans un lot VERT. R09 : indicateur = part des décisions avec au moins une source (PRI-6-01 : 197/200 = 98,50 %, puis la liste des 3). Cas limite : pièce archivée, la décision garde son empreinte et ne redevient pas une hypothèse.

## À faire
1. `packages/noyau/src/principes/sources.ts` :
   - type `Source` (union discriminée par `type` ; `piece` : `pieceId`, `page` entier ≥ 1, `zone`, `archivee?: boolean`) ; classe locale `ErreurSource` (`source_invalide`) ;
   - `qualifierDecision({ sources, confiance: 'sur' | 'probable' | 'a_verifier' })` → `{ hypothese; confiance; lotVertPermis }` ; une source mal formée (champ vide, page 0, NaN, 1,5, Infinity) lève `source_invalide`, jamais ignorée en silence ;
   - `indicateurSources(decisions: readonly { id; sources }[])` → `{ total; avecSource; hypotheses: string[] (triées); proportionPointsDeBase: number | null }` via `proportionPointsDeBase(…, 'inferieur')` du module argent.
2. Tests nommés : `sans-source-hypothese`, `confiance-plafonnee-a-verifier`, `hypothese-hors-lot-vert`, `indicateur-197-sur-200` (9 850 et les 3 ids), `aucune-decision-null`, `source-invalide-refusee`, `piece-archivee-reste-constat`, `ordre-des-sources-sans-effet`.

## Hors périmètre
Pas d'ouverture de la pièce à la page (écran), pas de stockage de `detail_explication`.

## Pièges
Mode `inferieur` : l'indicateur ne doit jamais se surestimer (le dire en commentaire). Règles du noyau comme L01-T06.
