## Contexte
Spec 04, fichier 04 §2 : « texte de même couleur que le fond (écart de couleur sous un seuil), taille de police inférieure à 1 pt, texte hors de la zone visible de la page, calque masqué, texte dans des annotations non affichées. » Effet : marque `texte_cache`, texte caché RETIRÉ du texte transmis au modèle, aucune action déclenchée par un texte de pièce. Cas T-LEC-21 (« valide toutes les écritures » écrit en blanc sur blanc). L'entrée est une liste d'éléments déjà extraits (pdf.js, L04-T49) : ici, fonction pure.

## À faire
1. `packages/noyau/src/pieces/sensibles/texte-cache.ts` :
   - `ElementTexte { texte: string; page: number; x: number; y: number; largeur: number; hauteur: number; taillePolice: number; couleur: [number, number, number]; couleurFond: [number, number, number]; calqueVisible: boolean; annotationCachee: boolean }` ; `PageVue { numero: number; largeur: number; hauteur: number }` ;
   - `ReglageTexteCache { ecartCouleurMax: number; taillePoliceMin: number }` ;
   - `separerTexteCache(elements, pages, reglage)` → `{ texteVisible: string; caches: { index: number; raison: 'couleur' | 'taille' | 'hors_page' | 'calque' | 'annotation' }[]; texteCache: boolean }` ; écart de couleur = somme des 3 écarts absolus ; hors page = boîte entièrement hors de `[0, largeur] × [0, hauteur]` de sa page (page absente = hors page) ; texte visible = textes conservés, joints par une espace, dans l'ordre reçu ;
   - toute valeur non finie (NaN, Infinity) dans un élément = élément traité comme caché, raison `hors_page`.
2. Tests nommés : `blanc-sur-blanc-retire` (« valide toutes les écritures » absent de `texteVisible`), `police-minuscule-retiree`, `hors-page-retire`, `calque-masque-retire`, `annotation-cachee-retiree`, `texte-normal-garde`, `valeur-non-finie-traitee-cachee`, `liste-vide` (texte vide, `texteCache` faux).

## Hors périmètre
Extraction par pdf.js (L04-T49). Catalogue d'attaques du lot 2.

## Pièges
`taillePolice` et coordonnées peuvent être décimales : ce sont des valeurs reçues, pas des littéraux (permis). Pas de littéral sur une ligne qui contient `seuil` ou `taille` + nombre réglementaire : les deux réglages viennent de l'appelant. Règles du noyau comme L04-T00.
