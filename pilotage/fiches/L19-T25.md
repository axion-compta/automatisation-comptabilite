## Contexte
Fiche du MVP issue de l'audit de couverture UX du 12/11/2026 (conception L19). Le noyau (L13-T06) et le composant Indicateur refusent 0 pour une absence de donnée ; aucun contrôle ne parcourt tous les écrans avec le profil `vide` du faux serveur.

## À faire
1. Pour chaque écran découvert, rendu sur faux serveur avec le profil `vide` ; échec si un nœud d'indicateur ou de montant affiche « 0 », « 0,00 » ou « 0 € ».
2. Tests nommés : `aucun-zero-avec-profil-vide`, `chaque-ecran-a-un-message-vide`, `liste-des-ecrans-non-vide`.

## Hors périmètre
Correction d'un écran fautif : la signaler dans le journal et s'arrêter.

## Pièges
Un zéro réel (solde nul calculé) n'existe pas dans le profil vide : aucune exception à prévoir. Tests d'abord. Recoupements de fichiers vérifiés le 12/11/2026 contre les fiches à faire.
