## Contexte
Spec 15, TB-R1 et TB-R3. Un seul service calcule chaque indicateur, à partir des écritures VALIDÉES ; brouillons et proposées sont rendus à part (« en attente : N, montant »), car l'IA propose et l'humain valide. Définitions de la spec : CA = comptes « ventes » hors compte de rabais, moins ce compte ; charges = classe « charges » hors comptes d'impôt sur les bénéfices ; résultat provisoire = classe « produits » moins charges (libellé figé « résultat provisoire avant impôt », jamais « bénéfice ») ; trésorerie = comptes de banque et de caisse. D31 : les numéros de compte de ces définitions ne sont PAS écrits dans le code : ils sont un argument (`DefinitionsIndicateurs`), fourni plus tard par `packages/parametres`.

## À faire
1. `chiffres.ts` :
   - `DefinitionsIndicateurs { ca: { prefixes: string[]; deduire: string[] }; charges: { prefixes: string[]; exclure: string[] }; produits: { prefixes: string[] }; tresorerie: { prefixes: string[] } }` ;
   - `calculerChiffres(ecritures, periode, definitions)` → `{ ca; charges; resultatProvisoire; tresorerie; enAttente: { nombre; montant } }` en `Centimes`, via `balance()` de `../livres/balance.js` sur les écritures `valide` dont la date est dans la période (bornes incluses) ; trésorerie = solde à la fin de la période (toutes écritures validées jusqu'à `fin`) ;
   - un compte de `deduire` ou `exclure` n'est jamais compté deux fois, même s'il commence par un préfixe inclus ; définitions vides ou préfixe vide = erreur `definitions_invalides` ;
   - `chiffreAffaires`, `resultatProvisoire`, `tresorerie` exportées aussi seules (utilisées par L15-T03).
2. Tests nommés (préfixes INVENTÉS, ex. `'91'`, `'919'`, `'92'`, pour prouver que rien n'est en dur) : `ca-avec-deduction`, `compte-deduit-pas-compte-deux-fois`, `charges-hors-exclus`, `resultat-produits-moins-charges`, `tresorerie-solde-a-la-fin`, `brouillon-et-propose-hors-chiffres` (montés à part dans `enAttente`), `periode-bornes-incluses`, `aucune-ecriture-zero`, `definitions-vides-refusees`, `somme-exacte-au-centime` (1 000 écritures générées : CA calculé = somme attendue faite à la main par une boucle simple).

## Hors périmètre
Pas de TVA (service TVA, lot 03), pas de capitaux propres (lot 14), pas d'arrondi, pas de période (L15-T06).

## Pièges
Centimes entiers, sans division ni flottant. Aucun numéro de compte réel dans `src` ni dans les tests. Sensible (argent) : relecture Opus, double relecture.
