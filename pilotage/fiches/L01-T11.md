## Contexte
Spec 03 (déclarations et FEC), §08 : grand livre, balance, journaux. Contrôle CC-K02 (spec 12) : « Balance de l'exercice : Σ débits = Σ crédits de toutes les écritures validées. » Un brouillon n'entre jamais dans un état officiel.

## À faire
1. `packages/noyau/src/livres/balance.ts` (importe le modèle de `../ecritures/modele.js`) :
   - `balance(ecritures)` : seulement les écritures `valide` (les contre-passées comptent, leurs contre-passations aussi) ; une ligne par compte `{ compte, totalDebit, totalCredit, solde }` (solde = débit − crédit), triée par numéro de compte en ordre de chaîne ; plus `totaux { debit, credit }` ;
   - `grandLivre(ecritures, compte)` : lignes validées du compte, triées par date puis par numéro d'écriture, chacune avec `cumul` (solde progressif) ;
   - `journal(ecritures, codeJournal)` : écritures validées du journal triées par numéro.
2. Tests nommés : `brouillon-exclu`, `totaux-equilibres`, `solde-par-compte`, `cumul-final-egal-solde` (pour chaque compte, dernier cumul du grand livre = solde de la balance), `contre-passation-annule`, `tri-par-date-puis-numero`.

## Hors périmètre
Pas de soldes d'ouverture ni d'à-nouveaux (clôture, plus tard), pas d'export.
