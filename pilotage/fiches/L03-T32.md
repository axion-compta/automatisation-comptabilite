## Contexte
Spec 03, §02 et §04 : `GET /exercices/{eid}/tva/estimation` (`non_calculee` sans montant si doute ou régime non traité), `GET /tva/declarations/{did}` (cases + sources). Spec 03, §01 : toute réponse d'un document préparé contient la mention, la version du paquet, le statut, le validateur ou `null`, et les contrôles. Choix de ce lot : la mention est un CODE (`prepare_par_ia`) dans le contrat ; la phrase est dans `packages/textes` (L03-T39). Le préfixe de société viendra avec l'isolation (P4).

## À faire
1. `packages/contrat/src/domaines/tva.ts` : schémas zod exportés `PeriodeTva`, `EstimationTva` (union discriminée sur `etat`), `CaseDeclaration`, `DeclarationTva { …; mention: z.literal('prepare_par_ia'); versionPaquet; statut; validePar: string | null; valideLe: string | null; controles: { regleId; resultat }[] }`, et les réponses `ReponsePeriodesTva`, `ReponseEstimationTva`, `ReponseDeclarationTva` (même convention que L01-T52) ; routes oRPC `listerPeriodesTva` (`GET /exercices/{exercice}/tva/periodes`, enveloppe `{ body, decalage, total }`), `lireEstimationTva` (`GET /exercices/{exercice}/tva/estimation`), `lireDeclarationTva` (`GET /tva/declarations/{declaration}`) ; erreurs `EXERCICE_INCONNU` et `DECLARATION_INCONNUE` (404).
2. `tva-service.ts` : service pur sur `genererDeclarations()` (L03-T31), import relatif.
3. `routes.ts` : ajouter le domaine `tva` à `contrat` sans toucher aux autres clés. Régénérer `openapi.json` (`pnpm contrat:openapi`).
4. `apps/serveur/src/domaines/tva.ts` branché dans `creerRouteur` de `app.ts`.
5. Tests nommés : `periodes-enveloppe-et-tri`, `estimation-non-calculee-sans-montant`, `estimation-calculee-avec-montants`, `declaration-avec-sources-et-mention`, `declaration-inconnue-404`, `openapi-contient-les-routes-tva`, `serveur-repond-a-la-tva` (Fastify `inject`).
