## Contexte
Spec 03, §12 (D45, tranchée dans son principe ; D31) : règle par pays et par catégorie (pièces, écritures et livres, FEC et déclarations, états et PV, journal des actions, sauvegardes, conversations, signalements), `duree_annees` nullable, point de départ (clôture de l'exercice, date du document, fin de contrat), statut `non_verifie` ou `valide`. « Si plusieurs durées s'appliquent, la plus longue gagne. » « `duree_annees` vide ou statut `non_verifie` → aucune purge possible ; date affichée "à confirmer". » « Gel actif → toute suppression refusée, y compris en fin de contrat. »

## À faire
1. `packages/noyau/src/conservation/regles.ts` (ajout d'années par `ajouterAnnees` de `../dates/civiles.js`, L03-T19) :
   - types `CategorieConservation`, `PointDepart = 'cloture_exercice' | 'date_document' | 'fin_contrat'`, `RegleConservation { pays; categorie; dureeAnnees: number | null; pointDepart; statut: 'non_verifie' | 'a_verifier' | 'valide'; source: string }` ;
   - `conserverJusquAu(regles, { pays: string[]; categorie; dates: Partial<Record<PointDepart, string>> })` → `{ etat: 'date'; date; regle } | { etat: 'a_confirmer'; raison: 'aucune_regle' | 'duree_vide' | 'non_verifie' | 'date_depart_absente' }` : retient les règles des pays donnés et de la catégorie ; une seule règle vide ou non `valide` suffit à rendre `a_confirmer` (on ne peut pas savoir laquelle est la plus longue) ; sinon la date la plus tardive gagne ;
   - `purgePossible(resultat, { gels: { pose_le: string; leve_le?: string }[]; aujourdhui })` → `{ ok: true } | { ok: false; code: 'gel_actif' | 'a_confirmer' | 'trop_tot' }` : un gel sans `leve_le` bloque toujours ; le gel est examiné AVANT tout le reste.
2. Tests nommés (durées INVENTÉES, ex. 7 et 3 ans ; jamais une durée légale réelle) : `date-depuis-la-cloture` (exercice clos le 31/03/2026, 7 ans → 31/03/2033), `plus-longue-gagne`, `deux-pays-plus-longue-gagne`, `duree-vide-a-confirmer`, `non-verifie-a-confirmer`, `gel-bloque-meme-si-echu`, `purge-trop-tot-refusee`, `gel-leve-n-empeche-plus`.

## Hors périmètre
Aucune purge réelle, aucune sauvegarde (L03-T56, bloquée par D42). Aucune valeur par pays : elles viendront de `packages/parametres` après relevé sourcé (D31).

## Pièges
Règles du noyau comme L03-T01. Le 29 février : `ajouterAnnees('2028-02-29', 1)` suit la règle écrite dans L03-T19 ; tester ce cas. Cas limites exigés : `dureeAnnees` NaN, Infinity, négative ou non entière → `duree_vide` (jamais une date) ; liste de règles vide → `aucune_regle` ; pays en minuscules refusé ; `aujourdhui` mal formé → exception locale `ErreurConservation('date_invalide')`. La mention « Conservez vos justificatifs originaux » est un texte (L03-T39), pas un code ici.
