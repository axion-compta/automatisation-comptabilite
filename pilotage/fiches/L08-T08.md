## Contexte
Spec 08, fichier 05 §2 : « une alerte ne part que s'il y a un problème ; une alerte porte un code, l'identifiant console du client et une heure, jamais un nom, un montant, un IBAN ni un nom d'hôte ; deux alertes du même code dans l'heure sont regroupées. » Fichier 05 §4 : alerte à Will à chaque arrêt d'urgence et chaque reprise (codes `arret_urgence`, `reprise_apres_arret` de L08-T00). La console porte le port d'alertes (`apps/api/src/alertes/port.ts`) : ce module ne fait que préparer des alertes propres.

## À faire
1. `packages/noyau/src/exploitation/alertes.ts` :
   - `creerAlerte(brut: unknown)` → `Alerte` : objet seulement ; clés permises EXACTEMENT `code`, `clientRef`, `horodatage` ; toute autre clé = `ErreurExploitation('champ_inconnu')` ; `code` hors `CODES_ALERTE` = `champ_interdit` ; `clientRef` = `null` ou identifiant console de forme `^cli-[a-z0-9]{1,32}$` (un nom de société, une adresse, un IBAN échouent à cette forme) ; `horodatage` validé (L08-T00) ;
   - `regrouper(nouvelles: Alerte[], deja: { code; clientRef; envoyeeLe: string }[], fenetreSecondes)` → `{ aEnvoyer: Alerte[]; regroupees: number }` : une alerte de même `code` ET même `clientRef` qu'une alerte envoyée dans la fenêtre (bornes : envoyée il y a exactement `fenetreSecondes` = hors fenêtre) n'est pas renvoyée ; deux alertes identiques dans le même lot = une seule envoyée ; ordre de sortie : horodatage croissant, puis code ;
   - `estRegroupable` et la fenêtre en argument (réglage `alertes.regroupement_secondes`, L08-T02).
2. Tests nommés : `alerte-valide`, `champ-en-trop-refuse` (`nom`, `montant`, `iban`, `hote`, `message`), `client-ref-libre-refuse` (`Société Exemple`, `cli-`, `CLI-12`, chaîne de 33 caractères après `cli-`), `code-inconnu-refuse`, `meme-code-dans-l-heure-regroupe`, `borne-de-fenetre-exclue`, `codes-differents-ou-clients-differents-non-regroupes`, `doublon-dans-le-lot-envoye-une-fois`.

## Hors périmètre
Envoi réel (Telegram ou autre, par le port de la console : L08-T43, bloquée). Décision de lancer une alerte (L08-T06, L08-T07).

## Pièges
Règles du noyau comme L08-T00. Ne jamais recopier la valeur refusée dans le message d'erreur (elle peut être une donnée personnelle) : le message dit seulement le nom du champ. Horodatages dans le désordre : le résultat est trié, le tester. Sensible (sécurité, données personnelles) : relecture Opus.
