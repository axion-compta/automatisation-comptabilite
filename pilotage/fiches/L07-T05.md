## Contexte
Spec 07, `02-quotas-ia.md` §1 : une **pièce traitée** = une pièce dont la lecture est arrivée à l'état « proposition prête » pour la première fois ; une relecture, un doublon refusé, une pièce refusée par l'antivirus ne comptent pas. Compteur mensuel par société (pièces, jetons d'entrée, jetons de sortie, coût en micro-centimes entiers). Le coût vient de la consommation mesurée par la console, jamais d'un calcul en flottant ; il n'est jamais affiché comme un quota au client (D13, D15). Cas T-ABO-10 : même pièce relue 3 fois et un doublon refusé → compteur = 1.

## À faire
1. `packages/noyau/src/abonnement/compteur.ts` :
   - `type EvenementPiece = { pieceId: string; societe: string; type: 'proposition_prete' | 'relecture' | 'doublon_refuse' | 'antivirus_refuse'; horodatage: string }` ;
   - `moisDe(horodatage)` → `AAAA-MM` (après `verifierHorodatage`) ;
   - `compterPiecesTraitees(evenements, mois)` → `ReadonlyMap<string, number>` (société → nombre) : une pièce compte dans `mois` si son PREMIER `proposition_prete` (le plus ancien, quel que soit l'ordre de la liste reçue) tombe dans `mois` et si elle n'a AUCUN événement `doublon_refuse` ni `antivirus_refuse` ; une pièce dont le premier `proposition_prete` est dans un mois antérieur ne compte pas à nouveau ; `mois` hors forme `AAAA-MM` (ou mois 00, 13) → `date_invalide` ;
   - `type LigneConsommation = { societe: string; pieceId: string | null; action: string; modele: string; jetonsEntree: number; jetonsSortie: number; coutMicroCentimes: number; horodatage: string }` ;
   - `cumulerConsommation(lignes, mois)` → `ReadonlyMap<string, { jetonsEntree; jetonsSortie; coutMicroCentimes }>` : chaque nombre passe `verifierEntier(n, 0)` ; une somme qui n'est plus un entier sûr → `ErreurAbonnement('depassement_entier')`.
2. Tests nommés : `relue-trois-fois-et-doublon-compte-un` (T-ABO-10), `antivirus-ne-compte-pas`, `premiere-proposition-mois-precedent-ne-compte-pas`, `ordre-des-evenements-sans-effet` (liste inversée, même résultat), `deux-societes-separees`, `mois-invalide-refuse` (`2026-13`, `2026-1`, vide), `consommation-nan-infinity-negatif-decimal-refuses`, `depassement-entier-detecte` (deux lignes proches de `Number.MAX_SAFE_INTEGER`).
