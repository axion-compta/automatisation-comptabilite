## Contexte
Spec 08, fichier 07 §1 et §2 : échéance par défaut 1 mois après réception (art. 12.3, À VÉRIFIER) ; rappel à J-7 ; une demande reçue par Axion IA est transmise à la société sous 2 jours ouvrés (PROPOSÉ), sans y répondre sur le fond ; un refus porte un motif ET sa source. Les trois valeurs sont des réglages datés (L08-T02 : `rgpd.reponse_delai_mois`, `rgpd.rappel_avant_echeance_jours`, `rgpd.transmission_societe_jours_ouvres`) passés en ARGUMENT. Arithmétique des dates : `ajouterMois`, `ajouterJours`, `jourDeSemaine` de L03-T19.

## À faire
1. `packages/noyau/src/rgpd/demandes.ts` :
   - `nouvelleDemande({ id; societeId; type; recueLe }, { moisReponse })` → `DemandePersonne` à l'état `recue`, `echeance = ajouterMois(recueLe, moisReponse)` (31/01 + 1 mois → dernier jour de février, règle de L03-T19) ; type inconnu = `ErreurRgpd('type_inconnu')` ; `moisReponse` entier >= 1, sinon `delai_invalide` ;
   - `TRANSITIONS` : `recue → en_cours | transmise_a_la_societe`, `en_cours → traitee | refusee`, `transmise_a_la_societe` final, `traitee` et `refusee` finales ;
   - `changerEtat(demande, vers, { par; le; issue?; motif?; source?; fichierEmpreinte? })` → nouvelle demande (l'entrée n'est pas modifiée) + `EvenementPersonne` : transition hors table = `transition_interdite` ; demande finale = `deja_traitee` ; `refusee` exige `motif` (`verifierMotif`) ET `source` non vide (`source_manquante`) ; `traitee` exige une `issue` permise pour ce type (`ISSUES_PAR_DROIT`, sinon `issue_non_permise`) ; `acces_produit` et `portabilite_produite` exigent `fichierEmpreinte` (64 hexa, sinon `empreinte_invalide`) ; l'événement ne porte que l'id, le type, l'issue (jamais le motif en clair : seulement `motifFourni: true`) ;
   - `dateDeRappel(demande, joursAvant)` = `ajouterJours(echeance, -joursAvant)` ; `aRappeler(demandes, aujourdhui, joursAvant)` → ids des demandes NON finales dont la date de rappel est atteinte et l'échéance pas dépassée ;
   - `enRetard(demandes, aujourdhui)` → ids des demandes non finales dont l'échéance est DÉPASSÉE (le jour de l'échéance n'est pas un retard) ;
   - `transmettreAvantLe(recueLe, joursOuvres)` : ajoute des jours du lundi au vendredi (`jourDeSemaine`), sans jours fériés (limite écrite en commentaire : les jours fériés viendront d'un paramètre daté).
2. Tests nommés : `echeance-un-mois-fin-de-fevrier`, `transitions-permises-et-interdites`, `refus-sans-motif-ou-source-refuse`, `issue-non-permise-pour-le-type` (effacement traité en `acces_produit` refusé), `acces-produit-exige-empreinte`, `evenement-sans-motif-en-clair`, `rappel-a-j-moins-sept` (la veille : non ; le jour : oui ; demande traitée : non), `retard-le-lendemain-seulement`, `transmission-saute-le-week-end` (reçue un vendredi + 2 jours ouvrés = mardi).

Cas limites : `joursAvant` ou `joursOuvres` NaN, Infinity, négatif, 1.5 = `delai_invalide` ; `aujourdhui` mal formé = `date_invalide` ; liste vide = résultat vide.
