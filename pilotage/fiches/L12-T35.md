## Contexte
Spec 12, `05-traitement-des-doutes`, C6 (V3-CTL-033) : « Une règle apprise d'une correction humaine n'est promue qu'après un seuil de corrections concordantes (paramètre, valeur initiale 3), a un compteur d'usages, s'éteint après une contradiction, et ne s'applique jamais à une période clôturée. » La promotion, l'extinction et la période close sont DÉJÀ codées par L13-T05 (`principes/memoire-correction.ts`) : ne pas les recoder. Il manque le compteur d'usages et le cas CT-39 du catalogue.

## À faire
1. `packages/noyau/src/controles/doutes/apprentissage.ts` :
   - `compterUsages(applications: { regleCle; date; ecritureId }[], cle)` → nombre d'applications DISTINCTES (même écriture comptée une fois) ;
   - `etatAvecUsages(corrections, applications, societeId, cle, seuil)` → état de `etatRegle` (L13-T05) + `usages`.
2. `packages/noyau/src/controles/doutes/__tests__/apprentissage.test.ts`, tests nommés : `CT-39` (1 correction : pas de règle ; 3 concordantes : promue ; 1 contraire : éteinte ; période close : jamais appliquée), `usages-sans-doublon`, `usages-autre-cle-ignores`, `usages-autre-societe-ignores`, `eteinte-garde-ses-usages`, `seuil-invalide` (0, NaN, 2,5).

## Hors périmètre
Classement par rang de source (L13-T11).

Stryker (seuil 80 %) porte sur tout le noyau : chaque branche doit être tuée par un test. Ne pas toucher `packages/noyau/src/index.ts` ni `controles/moteur.ts` (imports par chemin relatif). Aucun taux, seuil, délai ni date légale dans `src` (garde:litteraux, D31) : tout seuil ou tolérance arrive en argument ou dans un `ParametreLu` (L12-T00) ; paramètre absent = `IMPOSSIBLE`, jamais OK (PRI-007).
