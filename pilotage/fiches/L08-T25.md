## Contexte
Spec 08, fichier 07 §2 : effacement : données hors obligation légale = effacées ; données sous conservation légale = refus avec explication et date de fin (« conservé jusqu'au JJ/MM/AAAA, source : … ») ; l'application n'a ni DELETE ni déclencheur : l'effacement réel est une action de la console (DEMANDE 2) ; d'ici là, la ligne est marquée « à effacer », masquée partout et exclue de l'IA. §3 : une donnée effacée reste dans les sauvegardes jusqu'à leur expiration ; la réponse le dit avec la date de fin. Cas T-EXP-8 : facture d'un exercice clos en 2025 (FR) : refus avec date et source. D3 : jamais pendant un gel. La date de conservation vient de `conserverJusquAu` (L03-T04).

## À faire
1. `packages/noyau/src/rgpd/effacement.ts` :
   - `deciderEffacement({ objet: { source; id }; conservation: ResultatConservation | null; gelActif: boolean; finSauvegardes: string | null }, aujourdhui)` → une des issues :
     - gel actif (examiné EN PREMIER) → `{ issue: 'refus_gel' }` ;
     - `conservation` nul (objet hors obligation légale) → `{ issue: 'a_effacer'; sauvegardesJusquAu: finSauvegardes }` ;
     - `conservation.etat === 'date'` et date >= aujourd'hui → `{ issue: 'refus_conservation'; jusquAu: date; source: regle.source }` ;
     - `conservation.etat === 'date'` et date dépassée → `a_effacer` ;
     - `conservation.etat === 'a_confirmer'` → `{ issue: 'refus_conservation'; jusquAu: null; source: null; aConfirmer: true }` (on ne sait pas : on GARDE, jamais d'effacement sur une règle non vérifiée) ;
   - `evenementEffacement(decision, demandeId, le)` → `personne.effacement_refuse` ou `personne.marque_a_effacer` (sans date ni source en clair dans `donnees` : seulement l'issue).
2. Tests nommés : `t-exp-8-facture-exercice-clos-refus-avec-date` (règle inventée de 7 ans, statut `valide` : date et source rendues), `hors-obligation-a-effacer`, `conservation-echue-a-effacer`, `regle-non-verifiee-on-garde`, `gel-avant-tout` (même si hors obligation), `fin-des-sauvegardes-rendue`, `jour-meme-de-fin-encore-conserve` (date = aujourd'hui : refus), `entrees-invalides-refusees` (`aujourdhui` mal formé, source vide dans une règle `date`).
