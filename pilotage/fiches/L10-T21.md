## Contexte
Spec 10, fichier 04 (« Balance âgée ») : tranches 0-30, 31-60, 61-90, plus de 90 jours après l'échéance (sans échéance : après la date de facture). Total = solde du compte client au centime ; un écart, même de 0,01 €, est une alerte (A19). Cas V24 au 30/11 : 2 200,00 échue depuis 10 jours, 1 200,00 depuis 45 jours → 0-30 : 2 200,00 ; 31-60 : 1 200,00 ; total 3 400,00.

## À faire
1. `packages/noyau/src/ventes/balance-agee.ts` :
   - `balanceAgee({ creances: { factureId; clientId; resteDu; echeance?; dateFacture }[], dateReference, bornesJours: number[], solde411 })` → `{ nonEchue: Tranche; tranches: Tranche[]; total; ecart; alerte?: 'A19' }`, `Tranche = { de; a: number | null; total; factureIds }` ;
   - classement SANS division : bornes de dates calculées par `ajouterJours(echeance, borne)` (L10-T00) puis comparaison ; référence ≤ échéance → `nonEchue` ; 30 jours pile → première tranche, 31 → deuxième ;
   - `bornesJours` : entiers > 0, strictement croissants, non vide (sinon `ErreurVente('bornes_invalides')`) ; reste dû nul ignoré.
2. Tests nommés (bornes [30, 60, 90] passées par le test) : `v24-deux-tranches`, `limite-30-et-31-jours`, `sans-echeance-date-de-facture`, `non-echue-a-part`, `ecart-un-centime-alerte-a19`, `total-egal-solde-sans-alerte`, `bornes-invalides` (vide, [60, 30], [30, 30], [0], [1.5], [NaN]), `ordre-d-entree-indifferent`, `liste-vide-total-zero`.
