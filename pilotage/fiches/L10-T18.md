## Contexte
Spec 10, fichier 03, règle 1 : TVA retenue = TVA lue ; contrôle `base × taux attendu` (paramètre daté à la date de l'opération) : écart > 0,01 € = carte « écart de TVA » ; la TVA retenue reste celle de la facture. Fichier 04 : A1 HT + TVA ≠ TTC ; A2 TVA lue ≠ base × taux attendu ; A3 taux inconnu pour la date. Cas V08 transposé au taux inventé 1 900 : HT 333,33, TVA attendue 63,33, TVA lue 64,00 → carte « écart de TVA 0,67 € », TVA retenue 64,00.

## À faire
1. `packages/noyau/src/ventes/controles-piece.ts` :
   - `controleTotaux({ ht, tva, ttc })` → `{ ok; ecart; anomalie?: 'A1' }` (au centime, sans tolérance) ;
   - `controleTvaParTaux(lignes: { tauxPdb; baseCentimes; tvaLueCentimes }[], tauxAttendus: number[])` → par taux : `ecartTva` (L01-T15) ; carte `A2` si `carte` ; taux absent de `tauxAttendus` → `A3` ;
   - `tauxAttendusALaDate(liste: ParametreLegal[], cle, pays, date)` → `{ taux: number[]; aVerifier: boolean } | { absent: true }` via `parametreAuJour` (L01-T14) ; `parametre_absent` → `{ absent: true }` (A3 pour toutes les lignes, jamais un taux par défaut) ; valeur = liste de points de base séparés par `|`, chaque élément entier ≥ 0, sinon `ErreurVente('parametre_mal_forme')`.
2. Tests nommés : `totaux-justes`, `totaux-ecart-un-centime-a1`, `v08-ecart-de-tva-a2-tva-lue-retenue`, `ecart-d-un-centime-sans-carte`, `taux-inconnu-a3`, `parametre-absent-a3-partout`, `parametre-a-verifier-marque`, `parametre-mal-forme` (`19.6`, `abc`, chaîne vide, `-1`).
