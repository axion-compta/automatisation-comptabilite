## Contexte
Spec 11, fichier 01 : `brouillon` (lu par l'IA ou dicté) → `a_completer` (payeur, justificatif ou nature manquant) → `propose` (écriture proposée, « Préparé par IA, à valider ») → `valide` (validée par une personne) → `rembourse` ou `en_compte_courant`. Sorties : `exclu_paye_societe`, `refuse` (motif tracé), `perso`. Invariant 6 : un frais `valide` ne se modifie que par une correction datée de l'écriture (contre-passation, L01-T09), jamais par un retour d'état.

## À faire
1. `packages/noyau/src/frais/statuts.ts` :
   - table `TRANSITIONS: Readonly<Record<StatutFrais, readonly StatutFrais[]>>` (seule source de vérité) ; `brouillon` → `a_completer`, `propose`, `exclu_paye_societe`, `refuse`, `perso` ; `a_completer` → `propose`, `exclu_paye_societe`, `refuse`, `perso` ; `propose` → `valide`, `a_completer`, `refuse` ; `valide` → `rembourse`, `en_compte_courant` ; statuts finals : aucune sortie ;
   - `peutPasser(de, vers)` ; `passer(frais, vers, { motif?; parPersonne?: string })` → nouveau frais (version + 1), l'objet reçu n'est jamais modifié ; refus `ErreurFrais('transition_interdite')` ; `refuse` sans motif non vide → `motif_obligatoire` ; `valide` sans `parPersonne` non vide → `transition_interdite` (« L'IA propose, une personne valide ») ;
   - `vers` inconnu (chaîne hors union, `''`) → `entree_invalide`.
2. Tests nommés : `chemin-nominal-jusqu-au-remboursement`, `valide-ne-revient-pas-en-arriere`, `statut-final-sans-sortie`, `refus-sans-motif-refuse`, `validation-sans-personne-refusee`, `version-incrementee-objet-intact` (`Object.freeze` sur l'entrée), `statut-inconnu-refuse`, `table-exhaustive` (chaque statut de l'union a une entrée ; parcours de toutes les paires (de, vers) comparé à une matrice écrite à la main dans le test).

## Hors périmètre
Qui décide de passer d'un statut à l'autre (payeur L11-T04, justificatifs L11-T05) ; invariants croisés (L11-T02).

## Pièges
Règles du noyau (eslint) comme L01-T06 ; Stryker sur tout le noyau. Ne pas toucher `packages/noyau/src/index.ts` ni `types.ts` (L11-T00). La matrice du test est écrite à la main, pas dérivée de `TRANSITIONS` (sinon le test ne rougit jamais).
