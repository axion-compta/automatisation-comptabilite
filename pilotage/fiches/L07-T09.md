## Contexte
Spec 07, `04-plans-cgv-mise-en-service.md` §1 : les plans sont des paliers de la console ; le module garde `code_palier`, `nom_affiche` (décrit par le volume), `pieces_par_mois`, `societes_max`, `fonctions` ; jamais « Essentiel », « Pro » ni « Étendu » (W12) ; aucun prix (le prix est au devis, hors module : D9, D41). `02-quotas-ia.md` §3 : « Demander le palier supérieur » exige l'accord du client, crée une Demande du portail et une ligne `abonnement.palier_demande` ; le palier reste inchangé tant qu'Axion n'a rien fait dans la console. Cas T-ABO-12. D30 : un compteur par société et un changement de forfait, sans rien coder en dur.

## À faire
1. `packages/noyau/src/abonnement/paliers.ts` :
   - `type Palier = { code: string; nomAffiche: string; piecesParMois: number; societesMax: number; fonctions: readonly string[] }` ;
   - `validerPaliers(liste: readonly unknown[])` → `Palier[]` : clés autorisées EXACTEMENT les 5 ci-dessus (toute autre clé, dont `prix`, `montant`, `tarif` → `champ_inconnu`) ; `code` et `nomAffiche` non vides ; `piecesParMois` et `societesMax` entiers >= 1 ; `fonctions` tableau de chaînes non vides ; codes uniques (`palier_invalide` sinon) ; `code` ou `nomAffiche` contenant le MOT « essentiel », « pro » ou « étendu » (sans casse, sans accents, mot entier : « proposition » est permis) → `nom_de_palier_interdit` ; liste vide → `palier_invalide` ;
   - `palierSuperieur(paliers, codeActuel)` → le palier de `piecesParMois` immédiatement supérieur, ou `null` ;
   - `demanderPalier({ accord, codeActuel, codeDemande, paliers, auteur, horodatage })` → `{ demande: { codeActuel; codeDemande; auteur; horodatage }; evenement: EvenementJournal; palierEnVigueur: string }` : `accord !== true` → `accord_manquant` (la chaîne `'true'` est refusée) ; code inconnu → `palier_inconnu` ; même code → `palier_identique` ; volume demandé <= volume actuel → `palier_non_superieur` ; auteur vide → `auteur_manquant` ; `palierEnVigueur === codeActuel` TOUJOURS.
2. Tests nommés (paliers fictifs `compta-1`, `compta-2`, `compta-3` de la spec, volumes inventés) : `cles-inconnues-refusees` (`prix`), `nom-interdit-mot-entier` (« Pro » refusé, « 100 pièces par mois » et « proposition » permis), `codes-en-double-refuses`, `volume-nan-decimal-zero-refuse`, `palier-superieur-dans-le-desordre` (liste non triée), `palier-superieur-du-plus-grand-nul`, `sans-accord-refus` (T-ABO-12), `avec-accord-une-demande-un-evenement-palier-inchange` (T-ABO-12), `demande-inferieure-ou-identique-refusee`.
