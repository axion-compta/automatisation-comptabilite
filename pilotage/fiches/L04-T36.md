2. `apps/serveur/src/pieces/ports-memoire.ts` : implémentations en mémoire de chaque port (antivirus programmable par empreinte, stockage `Map`, horloge fixe).
3. `apps/serveur/src/pieces/etape-entree.ts` :
   - `etapeEntree(octets, contexte)` : SHA-256 (`node:crypto`) ; `typeReel` (L04-T02) ; ZIP : `lireRepertoireZip` + `classerConteneur` (L04-T03) puis `controlerArchive` (L04-T04) : chaque fichier accepté devient une pièce enfant avec `pieceParenteId` (décompression par une fonction injectée dans le contexte, FAUSSE dans les tests) ; image : `controlerImage` (L04-T05) ; `evaluerLimites` (L04-T06) ; dépôt par `StockagePieces.deposerSiAbsent(compta/<societe>/originaux/<sha256>)` ; transition `recue` → `quarantaine` par `appliquerTransition` (L04-T28) ; refus = état `refusee` et code, rien dans le stockage ;
   - `etapeAntivirus(piece, contexte)` : `infecte` → `refusee` (code `infecte`) ; `indetermine` → `en_erreur` + `prochaineRelance` (L04-T28) ; `sain` → reste en `quarantaine` prête pour l'étape 3.
