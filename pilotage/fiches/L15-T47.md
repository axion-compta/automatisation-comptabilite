## Contexte
Spec 15, TB-R4 et TB-R5 : trois arcs (Pièces, Banque, TVA) ; couleur = pire couleur connue ; donnée absente = pointillés, ni vert ni rouge ; le centre porte un mot et un nombre ; aucun pourcentage sans son nombre ; un graphique rend aussi un tableau équivalent accessible. Style de la console (D5) : jetons de `packages/ui/src/jetons.ts`, aucun bleu, graisse 600 au plus. La couleur n'est jamais la seule information (mot et forme).

## À faire
1. `Anneau.tsx` : props `{ anneau: forme rendue par calculerAnneau (L15-T08); textes: { titre; arcs: Record<'pieces' | 'banque' | 'tva', string>; couleurs: Record<Couleur | 'pointille', string>; centre: string; colonnes: [string, string, string] } }` (aucun texte en dur) ; SVG `role="img"` avec `aria-label` construit depuis les textes ; arcs en traits continus ou pointillés (`stroke-dasharray`) selon l'état ; centre : mot puis « nombre sur sur » ; sous le SVG, un `<table>` (visuellement caché par une classe, lisible par les lecteurs d'écran) : arc, état en mot, nombre sur total.
2. `anneau.css` : couleurs par variables des jetons uniquement.
3. Tests nommés (jsdom) : `trois-arcs`, `pointille-si-absent`, `centre-mot-et-nombre`, `aucun-signe-pourcent-dans-le-rendu`, `tableau-equivalent-present`, `etat-en-mot-pas-seulement-couleur`, `textes-venus-des-props` (changer un texte de prop change le rendu).
