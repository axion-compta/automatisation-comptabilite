## Contexte
Spec 05, fichier 07 §2 : le classificateur applique dans l'ordre : règle de la société, historique concordant au-dessus d'un seuil, puis IA avec exemples, puis IA seule. La source utilisée est écrite dans la décision. « IA seule » est toujours « à vérifier ».

## À faire
1. `packages/noyau/src/agents/classificateur.ts` :
   - `classer({ regle?, historique: { compte; journal }[], propositionIaExemples?, propositionIaSeule? }, { seuilPointsDeBase, minimumHistorique })` → `{ compte; journal; source: SourceProposition; confiance: Confiance } | { source: 'aucune'; confiance: 'douteux' }` ;
   - historique concordant : le compte le plus fréquent atteint le seuil, calculé SANS division (`occurrences × 10000 >= seuilPointsDeBase × total`), et `total >= minimumHistorique` ; égalité entre deux comptes = pas concordant ;
   - confiance : règle et historique → `sur` ; IA avec exemples → `a_verifier` sauf si l'IA donne le même compte que l'historique non concordant le plus fréquent (`sur`) ; IA seule → toujours `a_verifier`.
2. Tests nommés (seuils inventés) : `regle-gagne`, `historique-concordant`, `historique-au-seuil-exact`, `historique-sous-le-seuil`, `historique-trop-court`, `egalite-pas-concordante`, `ia-exemples`, `ia-seule-a-verifier`, `rien-douteux`, `reglages-invalides` (seuil > 10000, -1, 1.5, NaN, Infinity ; minimum 0 accepté, -1 refusé).

## Hors périmètre
Pas d'appel au modèle : les propositions de l'IA sont des arguments. Pas d'écriture.
