## Contexte
Spec 08, fichier 07 §2 : accès = fichier ZIP (CSV + pièces) avec manifeste d'empreintes, produit en tâche de fond ; les données d'autres personnes sur une même pièce restent visibles seulement si la société le décide (case à cocher, journalisée) ; portabilité = même fichier, en CSV et JSON Lines lisibles par une machine. Cas T-EXP-7 : ZIP de 12 pièces + CSV, manifeste vérifié, 1 ligne de journal. Ici : la LISTE des fichiers (noms et octets) ; le ZIP réel est fait ailleurs. CSV : `ecrireCsv` de L15-T22 ; manifeste : `manifeste` de L03-T01.

## À faire
1. `packages/noyau/src/rgpd/paquet-acces.ts` :
   - `paquetAcces({ demandeId; type: 'acces' | 'portabilite'; occurrences; donnees: { source; id; champs: Record<string, string> }[]; pieces: { id; extension; octets: Uint8Array; autresPersonnes: boolean }[]; inclureAutresPersonnes: boolean })` → `{ fichiers: { nom; octets }[]; manifeste: string; empreinteManifeste: string; evenements: EvenementPersonne[] }` :
     - `donnees.csv` (toujours) via L15-T22 ; `donnees.jsonl` en plus pour `portabilite` (une ligne JSON par objet, clés triées, terminée par LF) ;
     - pièces sous `pieces/<id>.<ext>` ; une pièce qui cite d'autres personnes est EXCLUE si `inclureAutresPersonnes` est faux, et comptée dans `piecesExclues` du `LISEZ-MOI` minimal (`a-savoir.txt` : nombre de pièces exclues, sans nom) ;
     - `MANIFESTE.sha256` = `manifeste(fichiers)` (L03-T01) ; `empreinteManifeste` = empreinte de ce texte ;
     - événements : `personne.acces_produit` ou `personne.portabilite_produite` (id de la demande, nombre de fichiers) et, si `inclureAutresPersonnes`, `personne.autres_personnes_incluses` (événement distinct, la case est journalisée) ;
   - seules les données dont le couple `source:id` figure dans `occurrences` (L08-T23) entrent dans le paquet ; une donnée hors occurrences = ignorée (jamais incluse par erreur) ; extension hors `^[a-z0-9]{1,8}$` = `ErreurRgpd('valeur_interdite')`.
2. Tests nommés : `t-exp-7-douze-pieces-et-csv`, `portabilite-ajoute-jsonl`, `manifeste-verifie` (`verifierManifeste` rend `ok`), `autres-personnes-exclues-par-defaut`, `case-cochee-incluses-et-journalisee`, `donnee-hors-occurrences-ignoree`, `evenements-sans-contenu` (aucun nom ni e-mail dans les événements), `aucune-occurrence-paquet-minimal` (CSV d'en-tête seul, manifeste valide).
