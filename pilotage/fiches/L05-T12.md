## Contexte
Spec 05, fichier 04 §5 : annonce du nombre dès quelques objets ; récapitulatif détaillé au-delà d'un seuil ; plafond d'objets par proposition ; au-delà d'un autre seuil, renvoi vers l'écran. Limites glissantes par personne et par société : propositions par minute, objets par heure (toutes demandes comptées). Découper en petites demandes ne passe pas (T-CHT-5, 6, 7 ; A2-25). Les valeurs viennent des réglages (L05-T54), jamais du code.

## À faire
1. `packages/noyau/src/chat/volumes.ts` :
   - `classerVolume(n, { annonce, recapitulatif, maxProposition, renvoiEcran })` → `'simple' | 'annonce' | 'recapitulatif' | 'renvoi_ecran'` ; n > maxProposition = `renvoi_ecran` ; seuils non croissants, non entiers ou négatifs, n non entier ou négatif = `ErreurChat('parametre_invalide')` ;
   - `verifierLimites(historique: { horodatageMs; personne; societe; objets }[], demande, maintenantMs, { fenetrePropositionsMs, maxPropositions, fenetreObjetsMs, maxObjets })` → `{ permis: true } | { permis: false; code: 'trop_de_demandes' | 'volume_trop_grand' }` ; compte par couple personne et société ; fenêtre glissante (un événement à exactement `maintenant - fenetre` sort de la fenêtre).
2. Tests nommés (seuils inventés) : `classes-de-volume`, `bornes-exactes` (chaque seuil et seuil + 1), `au-dessus-du-plafond-renvoi`, `seuils-invalides` (ordre inversé, NaN, Infinity, 2.5, -1), `onzieme-proposition-refusee` (A2-25, avec max 10), `decoupage-ne-passe-pas` (T-CHT-7 transposé : demandes de 24 objets, plafond 200 par heure, la 9e refusée), `fenetre-glisse`, `autre-personne-non-comptee`, `autre-societe-non-comptee`, `historique-vide`.
