## Contexte
Spec 13 (principes), règle R10 : « aucun taux, seuil, délai ou durée légal n'apparaît en littéral dans le code : lecture par `parametre_au_jour(cle, pays, date)` ». R14 : « garde CI "littéraux légaux" : analyse du code qui refuse une liste de motifs (taux en nombre isolé, seuils, délais en mois liés au vocabulaire légal) hors tests et hors fichiers de paramètres ; liste d'exceptions signée par un humain. » Cas PRI-11-03 : un littéral de taux dans un module métier rend la CI rouge.

## À faire
1. `outils/gardes/litteraux.mjs`, même forme que les autres gardes : fonction pure `analyser(fichiers, exceptions)` exportée (fichiers = `[{ chemin, texte }]`), puis exécution sur les fichiers suivis par git. Fichiers examinés : `packages/noyau/src/**` et `apps/serveur/src/**`, extensions ts, tsx, mjs, hors `__tests__/` et hors `*.test.*`. `packages/parametres/` est exclu (fichiers de paramètres).
2. Rouge si une ligne contient :
   a. une date littérale de forme `AAAA-MM-JJ` dans une chaîne ;
   b. un littéral numérique autre que 0 et 1, sur une ligne qui contient aussi un identifiant dont le nom contient (sans casse) `taux`, `seuil`, `plafond`, `delai`, `duree`, `franchise` ou `bareme` ;
   c. une chaîne contenant un nombre suivi de `%`.
3. `outils/gardes/litteraux-exceptions.json` : liste `[{ "fichier": "...", "motif": "...", "raison": "..." }]`, vide au départ. Une exception sans `raison` non vide = rouge. Le fichier est sous `outils/gardes/` : il ne change que par une PR fusionnée par Will (c'est la signature humaine demandée par R14).
4. Tests `outils/gardes/test/litteraux.test.mjs` (node --test), nommés : `date-litterale-refusee`, `taux-litteral-refuse`, `seuil-compare-refuse`, `pourcentage-en-chaine-refuse`, `fichier-de-test-ignore`, `exception-avec-raison-acceptee`, `exception-sans-raison-refusee`.

## Hors périmètre
Pas de liste de vraies valeurs légales (aucun taux réel dans ce dépôt). Pas d'analyse de `apps/web`. Pas de script dans `package.json` (verifier lance déjà tous les `outils/gardes/*.mjs`).

## Pièges
Doit être verte sur le code actuel de main : lancer la garde avant d'ouvrir la PR. Les exemples des tests sont inventés et assemblés dans le test. Sensible (outils/gardes) : fusion par Will.
