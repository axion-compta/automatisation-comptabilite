## Contexte
Débloquée par la décision de Will du 07/11/2026 : J3a donné avec quatre conditions (données FICTIVES seulement ; fiche sensible relue par Opus ; aucune production sans le feu vert J10 ; ce qui exige le vrai schéma ou la vraie identité de la console s'écrit contre une INTERFACE et un faux serveur). L'identité, la session et la réauthentification viendront de la console (Keycloak, D29, ADR 0060) : ici, l'acteur arrive déjà construit, la garde ne lit aucun jeton.
Spec 13, fichier 01, R15 à R17 : chaque route d'un des 12 gestes exige une personne en session avec la permission et, selon le geste, une réauthentification récente ; sinon `403 geste_humain_requis` (ou `permission_manquante`, `reauth_requise`), une ligne `refus_geste` et l'événement `compta.geste.refuse`. Tests PRI-18-01 (36 refus : jeton de service, agent, tâche planifiée) et PRI-18-02 (24 refus comptable et lecture ; 12 acceptés après une réauthentification de moins de 5 min, délai en paramètre).
Briques : `verifierGeste`, `CATALOGUE_GESTES`, `Acteur` (L13-T02) ; `ROUTES_A_GESTE`, `VERBES_SENSIBLES` (L13-T37) ; `DepotRefus`, `RefusGeste`, `creerBaseMemoire` (L13-T47) ; imports par chemin relatif. La garde est une fonction autonome : elle n'est branchée ni dans `app.ts` ni dans `securite/index.ts` (fichiers communs, et `securite-squelette.test.ts` fige la liste des crochets).

   - `EvenementGesteRefuse { type: 'compta.geste.refuse'; societeId; geste: CodeGeste | null; code; operationId; acteurType; horodatage }` (aucun nom, aucun e-mail, aucun identifiant de personne) ;
   - `creerGardeGestes(o: { carte?: Readonly<Record<string, string>> (défaut ROUTES_A_GESTE); refus: DepotRefus; publier: (e: EvenementGesteRefuse) => void; maintenant: () => number; delaiReauthMs: number; nouvelId: () => string; signalerPanne: (e: unknown) => void })` ;
   - qui rend `verifier(d: { operationId; societeId; acteur: Acteur; canal; fusion?: boolean })` → `Promise<{ ok: true } | { ok: false; statutHttp: 403; code: 'geste_humain_requis' | 'permission_manquante' | 'reauth_requise' | 'route_non_declaree' }>`.
3. Règles :

   - operationId absent de la carte mais commençant (en minuscules, par début et jamais par « contient ») par un préfixe de `VERBES_SENSIBLES` : refus `route_non_declaree`, ligne avec `geste: null` (fermé par défaut) ; sinon : `{ ok: true }` sans écriture ;
