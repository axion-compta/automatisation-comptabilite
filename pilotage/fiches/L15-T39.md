## Contexte
Spec 15, EX-R1 à EX-R3. `POST /exports { liste, format: "xlsx" | "csv", filtres, tri? }` (`Idempotency-Key` obligatoire) pour toute liste du contrat ; les filtres et le tri sont ceux de l'écran et la requête est CELLE DE LA LISTE (même fonction) : les lignes exportées sont celles affichées. Totaux de l'écran, étiquetés. Jusqu'à N lignes en direct ; au-delà, une tâche (stockage et téléchargement : L15-T65, bloquée) ; au-delà de M : 413 `export_trop_gros`. `societe_id` dans le corps : 400 `societe_unique` (le schéma strict le refuse). Le fichier n'est jamais envoyé par e-mail ni à un tiers.

## À faire
1. `domaines/exports.ts` : corps strict `{ liste: string; format; filtres?: Record<string, string | number>; tri?: string }` (tout champ en plus, dont `societe_id`, = 400 `CHAMP_INCONNU` ; le test le vérifie avec `societe_id`) ; en-tête `Idempotency-Key` ; route `exporter` (`POST /exports`) ; réponse `{ body: { nom; typeContenu; octetsBase64; nbLignes; empreinte (SHA-256 hexadécimal du fichier) } }` ; erreurs `LISTE_NON_EXPORTABLE` 404, `EXPORT_TROP_GROS` 413, `EXPORT_EN_TACHE_A_VENIR` 501.
2. `domaines/exports-service.ts` :
   - `SOURCES` : table `operationId` → fonction de liste du service existant (`listerExercices`, `listerPlan`, `listerTiers`, `listerAlertes`) appelée avec les MÊMES filtres que la route, page par page jusqu'au total ; liste du catalogue (L15-T02) absente de `SOURCES` = `LISTE_NON_EXPORTABLE` ; filtre inconnu de la route de liste = 400 ;
   - `exporterListe(liste, format, lignes, options)` → `{ nom; typeContenu; octets; parties? }` (parties XML de l'XLSX rendues pour L15-T04) par `ecrireCsv` (L15-T22) ou `partiesXlsx` et `ecrireXlsx` (L15-T24) ; nom par `nomDeFichier` (L15-T23) ; décision de volume par `decisionVolume` avec les réglages 10 000 et 100 000 (HYPOTHÈSE, point S2) écrits comme constantes du service ;
   - total : somme de la colonne `centimes` du catalogue par `ajouter` du noyau, étiquette code `total_lignes_filtrees` ; liste vide = en-têtes et total à zéro ;
   - même `Idempotency-Key` rejouée = même réponse ; empreinte par `node:crypto` côté serveur et `crypto.subtle` côté navigateur (fonction asynchrone commune).
3. Domaine déjà branché par L15-T69 (objet vide) : remplir l'objet du domaine dans son fichier du contrat et la fonction de routes de son fichier serveur (implémentation par le service), SANS toucher `routes.ts` ni `app.ts` ; régénérer `openapi.json` (`pnpm contrat:openapi`).
4. Tests nommés : `csv-memes-lignes-que-la-liste` (comparaison ligne à ligne avec la réponse de la route de liste, mêmes filtres), `xlsx-memes-lignes-que-la-liste`, `filtre-applique`, `total-egal-a-la-somme-au-centime`, `liste-vide-total-zero`, `societe-id-dans-le-corps-400`, `liste-inconnue-404`, `trop-gros-413` (service forgé avec un total au-delà du maximum), `au-dela-du-direct-501`, `sans-idempotency-key-400`, `empreinte-sha256-du-fichier`.
