## Contexte
Spec 09, §01 règle 5 : table `regle_forme` (forme, comportement, valeur, source) lue par le moteur. Comportements au MVP : compte de l'exploitant (EI seulement, jamais une société), compte courant d'associé (sociétés seulement), capital (SARL, SAS, SASU, EURL), dividendes (sociétés à l'IS), régime d'imposition par défaut. « Une forme sans ligne dans la matrice = profil bloqué. » Cas P06. Les vraies lignes (avec numéros de compte et sources) arrivent par L09-T28 ; ici la matrice est un argument.

## À faire
1. `packages/noyau/src/profil/forme.ts` :
   - `LigneRegleForme { forme: string; comportement: 'compte_exploitant' | 'compte_courant_associe' | 'compte_capital' | 'dividendes' | 'impot_par_defaut'; valeur: string; source: string }` ;
   - `regleDeForme(matrice, forme, comportement)` → `string | null` ; deux lignes pour le même couple = `ErreurProfil('regle_forme_ambigue')` ;
   - `formeCouverte(matrice, forme)` → faux si la forme n'a AUCUNE ligne (motif `forme_sans_regle`) ; `association` = `forme_refusee_mvp` ; forme hors `FORMES` = `forme_inconnue` ;
   - `comptesProposes(matrice, forme)` → liste triée des numéros (valeurs des comportements `compte_*` présents pour cette forme), sans doublon ; source vide dans une ligne = `ErreurProfil('source_absente')`.
2. Tests nommés (matrice inventée dans le test, numéros fictifs du type `9991`, `9992`, `9993`) : `sas-sans-compte-exploitant-p06` (ni le numéro « exploitant » ni doublon ; courant d'associé et capital présents), `ei-compte-exploitant-p06` (ni courant d'associé ni capital), `forme-sans-ligne-bloquee`, `association-refusee-mvp`, `forme-inconnue` (`SA`, `sarl`, chaîne vide), `regle-ambigue-refusee`, `source-absente-refusee`, `comptes-tries-sans-doublon` (matrice donnée dans le désordre).

## Hors périmètre
Pas de plan comptable (`packages/noyau/src/plan/`, L01-T12) ; pas de vraies lignes (L09-T28) ; pas d'impôt historisé (L09-T11).

Règles du noyau comme L01-T06. AUCUN numéro de compte réel dans le module (garde L01-T02) : la matrice arrive toujours en argument. La spec cite les comptes 108, 455 et 1013 : ils vivent dans les données de L09-T28, jamais ici.
