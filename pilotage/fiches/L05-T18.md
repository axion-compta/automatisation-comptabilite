## Contexte
Spec 05, fichier 06 §3 : le modèle n'écrit ni montant, ni date, ni compte, ni taux ; il écrit `{{ref:<appel_outil>.<champ>}}`. Le serveur remplace chaque référence par la valeur du résultat d'outil AVANT l'envoi du morceau, même pendant le flux. Référence inconnue = morceau retenu, « je ne sais pas » à la place. Chaque chiffre affiché porte une source cliquable. Cas T-CHT-13.

## À faire
1. `packages/noyau/src/chat/references.ts` :
   - type `Segment = { sorte: 'texte'; texte } | { sorte: 'valeur'; valeur: string | number; nature: 'montant' | 'date' | 'compte' | 'taux' | 'nombre'; source: { type; id } } | { sorte: 'inconnu' }` ;
   - `resoudre(texte, resultats: Record<appel, Record<champ, { valeur; nature; source }>>)` → `Segment[]` ; nom d'appel et de champ `[a-z0-9_]+` ; référence mal formée = texte tel quel SANS les accolades ;
   - `class TamponReferences` : `pousser(morceau)` → segments prêts ; garde la fin d'un morceau qui peut être le début d'une référence (`{`, `{{`, `{{ref:ap…`) ; `terminer()` vide le tampon (référence jamais fermée = `inconnu`).
2. Tests nommés : `remplacement-simple` (T-CHT-13 : montant fictif 48 250 centimes et sa source), `reference-inconnue`, `champ-inconnu`, `reference-coupee-en-deux`, `reference-coupee-caractere-par-caractere`, `accolades-simples-gardees`, `reference-jamais-fermee`, `deux-references-collees`, `texte-vide-et-morceaux-vides`, `valeur-nan-ou-infinity-refusee` (résultat d'outil invalide = `inconnu`).

## Hors périmètre
Pas de mise en forme des montants (le front, `packages/ui/src/format/affichage.ts`). Pas de filtre des chiffres en dur (L05-T19).

## Pièges
Règles du noyau (eslint). Fiche sensible (chiffres montrés au client). Aucun texte affiché : « je ne sais pas » est le segment `inconnu`, son texte vient de L05-T43.
