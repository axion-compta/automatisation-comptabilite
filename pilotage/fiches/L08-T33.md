## Contexte
Le contrat fait foi (ADR 0002). Même méthode que L07-T14 : contrat déclaré et figé d'abord, serveur branché sur un fichier par domaine qui répond « non implémenté » (501), puis domaines implémentés en parallèle (L08-T35, L08-T37) sans toucher les fichiers communs. Spec 08, fichier 02 §5 : `GET /sante` → `{ etat, version, migration }`, aucune donnée de client. Fichier 07 : demandes des personnes traitées par l'administrateur de la société. Routes sans préfixe de société, comme le lot 01. Étiquettes `acces:*` comme le lot 07 (lues par la garde L07-T22) : les droits des personnes restent possibles dans TOUS les états d'accès (`acces:compte`).

## À faire
1. `packages/contrat/src/domaines/sante.ts` : route `lireSante` (`GET /sante`, `tags: ['acces:lecture']`) → `{ etat: 'ok' | 'degrade' | 'panne'; version: chaîne x.y.z; migration: entier >= 0 | null }` (AUCUN autre champ : schéma `strict`).
2. `packages/contrat/src/domaines/personnes.ts` (enums = constantes de L08-T01, recopiées en `z.enum` et comparées par test) :
   - `listerDemandes` (`GET /personnes/demandes`, `tags: ['acces:compte']`) → `{ body: DemandeVue[] }` avec `DemandeVue = { id; type; recue_le; echeance; etat; en_retard: booléen; a_rappeler: booléen; issue: Issue | null; conserve_jusqu_au: date | null; source_motif: chaîne | null }` (le motif libre n'est PAS renvoyé dans la liste) ;
   - `enregistrerDemande` (`POST /personnes/demandes`, `successStatus: 201`, en-tête Idempotency-Key, corps `{ type; recue_le }`) → `DemandeVue` ;
   - `rechercherPersonne` (`GET /personnes/recherche`, query `{ nom?; email?; iban? }`) → `{ body: { source; id; par }[] }` ; erreurs `RECHERCHE_VIDE` 422, `RECHERCHE_TROP_COURTE` 422 ;
   - `traiterDemande` (`POST /personnes/demandes/{id}/traitement`, en-tête Idempotency-Key, corps `{ issue; motif?: chaîne 1 à 500 après trim; source?: chaîne; inclure_autres_personnes?: booléen }`) → `DemandeVue` ; erreurs `REGLAGE_ABSENT` 503 (déclarée aussi sur les 3 autres routes de `personnes`), `DEMANDE_INTROUVABLE` 404, `DEJA_TRAITEE` 409, `TRANSITION_INTERDITE` 409, `ISSUE_NON_PERMISE` 422, `MOTIF_MANQUANT` 422, `SOURCE_MANQUANTE` 422.
3. `routes.ts` : ajouter `sante: { lireSante }` et `personnes: { listerDemandes, enregistrerDemande, rechercherPersonne, traiterDemande }` sans toucher les autres clés ; `openapi.ts` seulement si la génération ne parcourt pas déjà toutes les clés ; régénérer `openapi.json`.
4. `apps/serveur/src/domaines/options-exploitation.ts` : `type OptionsExploitation = { horloge?: () => string; dateReference?: string; reglagesPersonnes?: { moisReponse: number; joursRappel: number }; reglesConservation?: readonly unknown[] }` (les deux dernières clés servent à L08-T37 ; aucune valeur par défaut). `sante.ts` et `personnes.ts` : chacun exporte UNE fonction de signature figée `implementerSante(os, options)` / `implementerPersonnes(os, options)` qui rend des bouchons `new ORPCError('NOT_IMPLEMENTED')`. `app.ts` : branche les deux domaines ; `creerApp` accepte une clé d'options `exploitation?: OptionsExploitation` sans casser les appels existants (si un objet d'options existe déjà, par L01-T23, L01-T25 ou L07-T14, y ajouter la clé).
5. Tests nommés : `routes-exploitation-dans-openapi`, `post-avec-idempotency-key` (`routesEcritureSansEnTete()` reste `[]`), `sante-sans-donnee-de-client` (le schéma de sortie de `lireSante` a exactement 3 clés), `enums-egaux-au-noyau` (types de droit, états, issues), `chaque-route-a-une-etiquette-acces`, `motif-vide-ou-blanc-refuse-par-le-schema` (`''`, `'   '`, 501 caractères), `cles-existantes-inchangees`, et dans `exploitation-branchement.test.ts` (Fastify `inject`) : `cinq-routes-branchees` (statut différent de 404, sans exiger 501).

## Pièges

Rester sous 400 lignes, `openapi.json` compris : si la génération dépasse, sortir `rechercherPersonne` dans une fiche suivante et le noter au journal. Les noms `implementerSante`, `implementerPersonnes` et le type `OptionsExploitation` sont un contrat entre fiches. Ne pas modifier `contrat.test.ts`. Aucun montant ni nom de personne dans les schémas de sortie de la liste. Sensible (droits) : relecture Opus.
