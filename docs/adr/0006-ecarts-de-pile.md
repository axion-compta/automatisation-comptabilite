# ADR 0006 : Écarts de pile

- Statut : accepté
- Date : 2026-11-02

## Contexte
Une dépendance ou un outil hors pile peut sembler utile ponctuellement.

## Décision
Tout écart à la pile est justifié par un ADR dédié, et les dépendances sont déclarées une seule fois dans la fiche de socle ou dans la fiche qui les introduit.

## Conséquences
Pas de dépendance ajoutée en passant ; le fichier de verrouillage reste sous contrôle.
